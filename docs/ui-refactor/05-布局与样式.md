# 布局与样式

[返回入口](README.md)。本轮用户已修正 Penpot 的依据范围，修改边界见[冲突与修改边界](00-冲突与修改边界.md)。本组文档为第一设计权威。以下采用[样式约束](https://github.com/Yun-Shan/ffxiv-gearing-calc/issues/2#issuecomment-6216126292)；已覆盖此前保留 prefers-reduced-motion、采用 clamp、职业简称 tab 等建议。

### 视觉基线

- Penpot 尚未按本次重构修改，仅作颜色、字体、视觉语言等风格参考；结构、内容、布局、流程及验收按本组重构设计与用户后续确认。
- 完整旧 Single / 当前 Joint 实现仅作为实现参考。
- 当前路由使用的临时 `SingleWorkbenchPageNew` 不作为视觉基线。
- 已明确的产品变化（Laboratory 导航、Result 四栏指标、Search History 新承载、Gear Comparison、同属性替换）不算视觉回归；其余架构/状态重构不应顺手改版。
- 主要验收视口：`1440×695`、`1920×1080`。

### Workbench 总体几何

所有 `selection / conditions / progress / result` 使用同一外层几何：

```text
AppHeader
├─ Main: minmax(0, 1fr)
└─ SidePanel: 280px
```

- `phase` 不改变 main/aside 宽度、gap、padding 或页面结构。
- 280px 由 Workbench layout 持有，SidePanel 自身 `width: 100%`。
- App shell 采用下列结构，页面不单独计算 viewport 减 Header：

```text
App
  height: 100dvh
  display: flex
  flex-direction: column
Header
  flex: 0 0 64px
Route host
  flex: 1 1 auto
  min-height: 0
Workbench
  height: 100%
```
- 页面按父级剩余空间布局，主要操作保持可访问，不靠 `overflow:hidden` 裁掉正常内容。用户已确认 Comparison 装备表允许滚动，保留完整行列。

明确允许滚动的区域：

1. Search History record list（纵向）；
2. Joint tab strip 内容过多时（横向）；
3. Select / Combobox / dropdown / 选择型 Popover 的 option list（纵向）；
4. 装备限制中的已选列表，按剩余父容器高度分配；
5. Comparison 的装备表区域，溢出的行列通过表格滚动访问。

### Header

- Header 高度固定 `64px`。
- 顶部导航为 `[单职业搜索] [实验室]`；/joint 与 /gear-comparison 的 Laboratory 所属语境由页面自身表达，顶栏仅在 /lab 设置 aria-current="page"。
- 移除旧 first/last-child 固定宽度、nav `flex-basis` 以及移动端 104px 双行 Header 等历史布局。

### SidePanel

SidePanel 不是纯背景壳，也不是 boolean-prop 大组件，而是一套固定右栏模板：

```tsx
<SidePanel>
  <SidePanel.Header />
  <SidePanel.Content>
    <SidePanel.Section>
      <SidePanel.Rows>
        <SidePanel.Row label="...">...</SidePanel.Row>
      </SidePanel.Rows>
    </SidePanel.Section>
  </SidePanel.Content>
  <SidePanel.Status />
  <SidePanel.Actions />
  <SidePanel.Footer />
</SidePanel>
```

- Root：背景、顶部强调线、总体纵向布局。
- Header / Status / Actions / Footer：各自持有稳定结构与样式，上层不重复写对应 SCSS。
- Content 提供统一纵向 flow；`Section / Rows / Row` 提供重复出现的正文排版。
- `Row` 使用显式组件抽象（`label + children`）。
- Footer 可内建稳定产品文案（如“纯前端计算 · 可离线运行”），附加 action 由调用方组合。
- 不使用 `showXxx / compactXxx / resultXxx` capability props。
- 正常内容全部走文档流；绝对/固定定位仅用于真正 overlay。

### Search History

History 保持此前已确认设计：

- Selection：直接放在职业选择内容下方，占 Main 剩余高度，History 自身允许纵向滚动。
- Conditions / Progress / Result：SidePanel Footer 提供“搜索记录”入口，打开真正 overlay；浏览 History 不改变当前 phase，也不自动取消 Progress。
- 两种承载共享同一 `SearchHistory` 内容与 record 样式，仅宿主不同。
- 去掉旧 `<details>` 双用途结构以及 `defaultOpen / hideSummary` 适配。
- IndexedDB 一次读取全部记录；UI 用 IntersectionObserver 渐进挂载，不做数据库分页或 UI 上一页/下一页分页。
- History overlay 的 header 固定，record list 滚动。
- 旧 dataVersion completed result 始终允许查看；跨版本“编辑条件”时再弹确认。

### Conditions 样式所有权

- 当前 Joint Conditions 布局本身不满意，因此 **不作为任何共享辅助布局的参考来源**。
- 共享辅助布局只保留 Single 中已经证明有价值、重构后仍明确复用的简单模式，如 Section / FieldGrid。
- Field 等基础控件持有自己的 CSS Module，不再依赖全局 `.config-field / .number-field / .check-row / .check-indicator`。
- Field 自身不携带外部 margin；父级用 flex/grid + `gap` 排列。
- 删除 `:global` 穿透、祖先 data-attribute selector、深层 DOM selector；父级只负责子组件之间的排列。
- Single / Joint 若控件自身视觉确有差异，通过明确组件或显式 `className` 表达，不因恰好位于某祖先下而偷偷改变。
- GCD 等大量选项若需要滚动，应以 dropdown/popover/combobox 的“选择列表”形式承载，而不是在 Conditions 正文中永久嵌滚动区。

### GearTable

- 新统一 GearTable 以当前 `SingleJobGearTable` 的紧凑语义 `<table>` 视觉为基线，淘汰旧 div/grid 表格和 `compact` 双实现。
- row-driven API 只改变数据适配，不顺手重做视觉。
- stat columns 从 rows 中实际存在的展示 stat 求 union、去重并按稳定顺序生成；不接收显式 `statColumns` prop。
- 样式评估可默认最多同时出现 7 个 stat，降低极端列数风险。
- Comparison marker 放在 slot label 第二行；Joint job 的“共享”也使用同一 marker 位置。
- 同属性替换 action 放在装备名称之后的独立紧凑列，表头文字为空；所有槽位均无替换时不生成此列。
- 总属性使用普通 `SummaryRow`，不使用固定 `<tfoot>`，以支持 Comparison 中多个方案各自的总属性行。
- Comparison GearTable 允许区域内滚动，不要求四方案同时完整 fit；保留所有数据和主要操作。

### Result / Joint Result

Single Result：

- 已确认 CoreMetricBar 从旧 5 格改为 4 格：Damage / GCD(+tank mitigation) / Crit / Direct Hit。
- 这是有意设计变化；其余 Result 区域优先保持现有视觉语义。

Joint Result：

```text
Result header
[共享装备] [职业图标 + 职业全称] [职业图标 + 职业全称] ...
当前 Tab 内容
```

- Joint 相比 Single 主体只额外增加一行 tabs。
- Tab 固定使用职业图标 + 职业全称，不用缩写；不换行，过多时 tab strip 横向滚动。
- “联合结果 / 单职业基线保留百分比”等整体信息放进“共享装备” tab，利用该 tab 内容较少的空间，不在所有 tab 上方额外占一块。
- Shared tab：联合结果概览 + 共享 GearTable，无 CoreMetricBar。
- Job tab：与 Single Result 共用 `CoreMetricBar + GearTable` 主体模板；完整 gearset 中共享装备通过 slot marker 第二行标识。
- SidePanel 跟随当前 tab 更换摘要内容，但模板、尺寸、actions/footer 不变。
- Main Header 不重复放“调整条件”，workflow action 统一放 SidePanel。

### 通用交互优先 Base UI

Popover、Dialog / Alert Dialog、Toast、Select、Combobox、Menu、Tabs 等通用交互优先使用 Base UI，复用其 Portal、定位、collision、focus、keyboard、dismiss、ARIA 等行为，不自行重复造基础交互。

- 项目代码负责产品样式和业务组合。
- 只有重复出现的项目级视觉模板才再做薄包装；不要求每个 Base UI primitive 都包一层。
- HistoryOverlay 可使用 Base UI 的定位/Portal 基础能力，但保留自己的大型 surface/content 模型。
- Toast 的 viewport/定位等基础机制使用 Base UI。

### 响应式与尺寸规则

本次重构中：

- **现有所有 `@media` 均删除**，包括 `prefers-reduced-motion`；这些状态都没有经过当前设计论证。
- **`clamp()` 尽量不用**；此前即使讨论过可用，也默认改为 flex/grid 的自然弹性布局。只有未来出现 flex/grid 无法表达、且有明确设计依据的连续尺寸需求时再单独论证。
- 不通过 breakpoint 创造桌面/移动端不同页面形态。
- 优先使用：`flex`、`grid`、`minmax()`、`min-width:0`、`min-height:0`、`gap`、自然内容收缩。
- `64px Header`、`280px SidePanel`、基础 input/button/icon/padding/gap 等是合法设计常量；要删除的是补偿其它实现细节的 magic number。
- 所有旧 `overflow:auto`、复杂 viewport 公式、深层 selector、phase-specific geometry 在迁移时默认删除，除非属于上面列出的明确例外。

### 验收重点

在 `1440×695` 与 `1920×1080` 下分别核对：

- Main + 280px SidePanel 几何不随 phase 改变；
- 页面和工作台继承父级剩余高度；Comparison 装备表可滚动；
- 必要内容和主要 action 均完整可见，无裁切；
- History / 超长 Joint tabs / 下拉选项 / 装备限制列表 / Comparison 装备表仅在各自语义边界内滚动；
- 没有残留旧 `@media`；表格与指标动态字号按后续确认使用容器单位及 `clamp()`；
- 没有依赖全局 class、`:global` 或祖先 DOM 结构才能成立的组件视觉；
- Base UI 已覆盖的通用交互不重复手写定位/focus/keyboard/dismiss 逻辑。

## 浮层与交互补充

聊天最终阶段还明确：正常内容走文档流，Popover/dropdown/History、Modal、Toast 通过 Portal 和统一层级管理，避免被页面裁切。不构建 boolean-prop 万能 Overlay。HistoryOverlay 保持大型业务 surface 与内容模型，header 固定，仅列表滚动；确认 Modal 不默认开启滚动。

Toast 在 64px Header 下方的视口右上角，可关闭；基础定位、focus、queue 等使用 Base UI。控件自身持有 focus-visible 样式。Joint tabs 采用真实 tab 语义，键盘/点击后确保选中项可见，仅移动 tab strip，不滚动页面。

本次只整理已有交互原则，不新增 Base UI API。实施具体组件前按[工程规则](../rules/工程规则.md)查官方 AI 文档索引及对应组件，验证实际版本支持的 API。

清理范围包含 src/ui 及 src/styles.scss 等必要全局 UI 样式中的全部现有 @media 和旧全局 field class；不将其作为目录外残留保留。

### 装备表字号和表头轨道

表头行高仅由 table grid 的首轨道控制为 32px；表头自身高度 100%。正文基准字号保留 12–16px 限制，中间值为 `calc(0.38 * (100cqh - 32px) / max(1, 行数))`。所有单元格继续沿用已有 em 比例。表格最大高度仍为行数 × 50px 加 32px 表头；不再用 ResizeObserver 反写表头高度。
