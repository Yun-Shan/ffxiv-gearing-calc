# 实施与验收

[返回入口](README.md)。以下顺序将来源中的依赖关系组织成执行建议，不表示已完成。

## 实施范围与顺序

主要范围为 src/ui；必要全局 UI 样式、App/UI entry 与直接相关测试同步纳入。基础布局在页面迁移时立即应用，不先为每个页面制造临时布局。

| 顺序 | 交付内容 | 验证重点 |
| --- | --- | --- |
| 1 | AppShell / WorkbenchLayout / SidePanel / Base UI 通用交互承载 | viewport 继承、固定几何、Portal、焦点与键盘行为 |
| 2 | phase / Draft / validation / scope | 有效语义 round-trip、类型配对、单一派生 validation |
| 3 | Conditions 与 Equipment 事务 | GCD/Food、shared/job 权限、跨 scope 候选与拒绝操作 |
| 4 | controller / History | 非阻断存储、run identity、取消与来源版本、历史确认 |
| 5 | Result / GearTable / replacement | 四栏指标、rows、完整候选组与原子选择、同记录最后表示持久化 |
| 6 | Laboratory / Comparison / Import | 平级路由、4 方案、基准删除、职业切换确认、无效指标拒绝、Food 往返 |
| 7 | 旧实现删除与最终样式清理 | 全局样式和全部现有 @media 清理、无双状态来源 |
| 8 | 完整真实 Playwright 验收 | 两目标视口真实搜索/计算/取消/历史/导入/替换与全部页面 |

每个功能按真实依赖接入 domain：需要新契约时提交具体方案、文件范围、行为影响和验证方案；用户确认后实现真实契约、接入当前功能并做集成验证。等级收敛、equivalentGear 判定、固定配装公式链等按此流程执行，不统一推迟到全部 UI 完成后。Mock 支持前置组件开发，不代替该功能的真实接入。

## Mock 的使用与证据边界

mock、fixture、测试 adapter 及组件测试放在所属 UI/测试范围内，仅用于测试或明确的开发预览入口，不替换正常产品路径中的真实 domain，不伪造真实计算/搜索结果。fixture 明确标记测试用途，使用可追溯数据，不作为产品默认值。模拟的是依赖返回契约，不是另写领域算法。

每个功能记录 mock 对应的真实接口、需要确认的 domain 实现及覆盖用例。mock 组件测试只证明 UI 契约和行为，不能证明公式、候选完整性、等价关系或最优性。domain 获批处理后补真实适配与集成验证，最终 Playwright 使用真实路径。

shell/表格等布局契约应在对应页面迁移时应用，不把全部视觉风险留到最后。旧实现只在新路径验证后删除，不保持新旧双状态来源。逐步清理 JobConfigFields、EquipmentRestrictionFields、useSingleWorkbenchPanelState、旧 singleWorkbench flag、GCD 字符串状态、historyRefresh、旧 ConfigSnapshot 和临时 SingleWorkbenchPageNew 等替代入口；以实际引用关系确认可删除范围。

## 验收清单

### 状态与条件

- [x] Conditions 外没有可变 Draft，store 不保存 feedback/Toast、AbortController、validation、文案/回调快照。
- [x] Snapshot 恢复新 Draft/runtime；摘要使用同一转换与 formatter，不调用 restore 改状态。
- [x] Page 只组合 scope/layout；共享 feature 只提升真实跨页语义，页面专有组合留 page-local。
- [x] GCD 支持单边速度；双空/反序无效；mode 切换不留隐藏值，objective 不在 Draft。
- [x] 职业上限、同步映射、可穿戴性与属性 cap 分离；低同步不排除可穿戴高等级装备。
- [x] Joint 目标归一化、Food strategy、shared 全局 exclusions、Job item-level exclusions 与 ring/ring2 ownership 事务符合规范。
- [x] Main/Aside/Section 读同一 validation 快照，invalid > pending > valid，提交重新读最新值。

### 搜索与历史

- [x] controller 随 Provider 存活；进度属于 Main，Aside 只有冻结摘要；Result 不保留 progress 总结。
- [x] cancel 等实际 settle；导航先解除 ownership 再 abort；A 的迟到回调不能覆盖 B 或历史目标。
- [x] cancelled/no-result/failed 从 Snapshot 重建 Conditions；一次性反馈走对应 Toast。
- [x] History start/finish/read/update 失败不阻断搜索或页面流转，start 失败不 finish。
- [x] Result 与 History 用同一 settle 时间，耗时不包括数据库等待；新搜索捕获当次 dataVersion，历史加载保留原 dataVersion/historyId，迟到的 history.start 不关联错误结果。
- [x] Progress 可浏览 History；载入需确认、确认后重读 state；已完成则不再 cancel。
- [x] 任意 dataVersion 的 completed result 可查看且不按当前数据重算；跨版本编辑需确认。
- [x] History 两宿主同视觉、渐进挂载且一次读库，无旧 details 适配或数据库分页。

### 结果、替换与比较

- [x] 四栏指标与目标高亮正确；总属性来自 result.stats，使用 SummaryRow。
- [x] Joint 图标+全称 tabs、共享 tab 内概览、职业完整配装与实际有效条件摘要正确。
- [x] GearTable 无业务 mode，列从 rows 派生，marker/row className 不扩散成细粒度样式协议。
- [x] 同步 Single 槽位通过 key 引用含当前项的完整候选数组；选择只更新 selected，候选数组不变。戒指完整数组附带唯一子集，另一槽唯一冲突显示但禁用；不修改 Snapshot/指标/耗时，同 History 只更新 result 等价表示，写入失败仅 Toast。验证范围见[Mock 盘点与真实接入](07-Mock盘点与真实接入.md)。
- [x] Comparison 同职业、最多 4 方案且上限提示；基准删除、单方案/空状态、切换职业确认清空正确；零值/非有限关键伤害禁止加入；装备分组包含 variant/custom/meld/最终属性与 Food。
- [x] 伤害绝对及相对差、GCD 绝对差、Tank 减伤百分点；跨 dataVersion 明显提示且不重算历史。
- [x] 导入按当前数据计算固定配装，无搜索/伪历史/伪耗时；职业不匹配拒绝，不自动换职业；导出包含 Food。

- [x] Header 64px，Aside 280px，phase 不改变主几何，shell 持有 viewport。
- [x] 正常内容与主要动作可访问，无裁切隐藏；Comparison 全部行列允许通过装备表滚动查看，不要求同时完整显示。
- [x] History、溢出 Joint tabs、选择列表、装备限制已选列表与 Comparison 装备表在各自语义边界滚动。
- [x] 删除 src/ui 与必要全局 UI 样式中现有全部 @media（包括 prefers-reduced-motion），清理 src/styles.scss 旧全局控件 class；已确认的表格/指标动态字号可使用容器单位及 clamp，其余布局优先 flex/grid。
- [x] SCSS Modules 所有权清楚，无全局控件 class、:global、祖先结构穿透或补偿性 viewport 公式。
- [x] Base UI 负责通用交互；验证键盘、关闭/焦点返回、Portal 裁切与选中 tab 可见性。
- [x] 最终真实路径验证含 Food 分享/导入往返、替换后重载 History、连续替换最终表示持久化，以及 Laboratory 到各独立页面的导航。
- [x] 依据重构设计与用户确认检查真实浏览器交互、几何及截图；Penpot 仅作风格参考，不以旧画板结构或像素匹配作为通过条件。

## Domain 方案确认与范围外事项

等级收敛、同属性等价判定算法和固定配装公式链已在对应功能接入前逐项提交方案、获得确认并完成真实 domain 实现。分享格式解析与往返验证已随固定配装入口完成。后续涉及领域/搜索语义变化仍须先确认；UI 不猜测游戏数据或补写公式。具体映射与 API 使用真实数据及官方文档核实，缺失必需资料明确失败。

Comparison 暂不做手工编辑、自动判断最佳、URL/分享状态持久化、跨职业数值比较；imported entries 刷新持久化及导入等价列表不在第一版要求。网站统计暂缓，其余会改变 domain/search 的 TODO 不顺手纳入；已明确的等级规则变化与结果/导入契约仍属于本组范围。
