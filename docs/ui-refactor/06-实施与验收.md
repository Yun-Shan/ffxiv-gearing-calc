## 实施边界与顺序

本次代码重构范围明确限定为 `src/ui/**`。需要 domain 新能力的部分先通过 UI 边界契约和 mock 完成组件测试，不能把 domain 修改作为 UI 开工前提。等级规则等 domain 冲突的具体方案留到下述确认阶段，不要求用户现在提前批准。

| 阶段 | 交付边界 | 验证重点 |
| --- | --- | --- |
| 1. UI 契约与测试替身 | 在 src/ui 内定义所需边界、adapter 和 mock，列明尚缺的 domain 能力 | mock 输入输出契约、成功/失败/取消与必要边界；不在 UI 重写公式 |
| 2. 状态与 Draft | phase 判别联合、compile/recover、纯 validation、装备语义事务 | 编译有效语义 round-trip、Food/mode、Joint objective、戒指 ownership |
| 3. scope 与 Conditions | per-job sections、equipment capability hooks、同一 validation 快照、摘要 | Single/Joint 复用边界、pending、有效限制派生、提交前重读 |
| 4. controller 与历史 | 单 Provider 单 controller、run identity、旁路持久化、settle 时间 | 通过 mock 覆盖取消/失败/无解、迟到回调、历史确认与版本、存储失败 |
| 5. Result 与表格 | 四栏指标、Joint tabs、row-driven table、替换 command | 使用契约 fixture 验证展示、原子交换与回写；不声称等价算法已验证 |
| 6. 实验室与 Comparison | 平级导航/源码、History adapter、链接导入及含 Food 导出 UI | mock 固定配装计算等未就绪依赖，完成组件与状态测试 |
| 7. shell 与 UI 收尾 | Selection API、统一 SidePanel、History 两宿主、样式迁移与旧 UI 清理 | 完成全部 src/ui 重构和组件测试，汇总 mock 与真实能力差距 |
| 8. domain 方案确认与处理 | 仅在 UI 全部完成后、最终 Playwright 复核前，提交具体 domain 改动方案；用户确认后才修改 src/domain | 文件范围、规则冲突、行为影响、接口及验证方案逐项确认；获批后运行必要领域回归与正式验收 |
| 9. 最终 Playwright 测试复核 | 接入确认后的真实 domain，完成最终浏览器测试 | 两目标视口全状态、真实搜索/计算/取消/历史/导入/替换；不能用 mock 通过代替真实集成通过 |

阶段 8 未获确认前，不修改 src/domain，不提前进行依赖该改动的最终 Playwright 验收。UI 开发期间可做必要的局部浏览器检查，但不记为最终复核。其它 src/ui 外修改仍需单独确认，domain 授权不能扩展到数据、全局样式、依赖或配置文件。

## Mock 的使用与证据边界

mock、fixture、测试 adapter 及组件测试保存在 src/ui 内，仅用于测试或明确的开发预览入口，不替换正常产品路径中的真实 domain，不伪造真实计算/搜索结果。fixture 明确标记测试用途，使用可追溯数据，不作为产品默认值。模拟的是依赖返回契约，不是另写领域算法。

完成 UI 阶段时，列出每项 mock 对应的真实接口、未实现能力与覆盖用例。mock 组件测试只证明 UI 契约和行为，不能证明公式、候选完整性、等价关系或最优性。domain 获批处理后补真实适配与集成验证，最终 Playwright 使用真实路径。

shell/表格等布局契约应在对应页面迁移时应用，不把全部视觉风险留到最后。旧实现只在新路径验证后删除，不保持新旧双状态来源。逐步清理 JobConfigFields、EquipmentRestrictionFields、useSingleWorkbenchPanelState、旧 singleWorkbench flag、GCD 字符串状态、historyRefresh、旧 ConfigSnapshot 和临时 SingleWorkbenchPageNew 等替代入口；以实际引用关系确认可删除范围。

## 验收清单

### 状态与条件

- [ ] Conditions 外没有可变 Draft，store 不保存 feedback/Toast、AbortController、validation、文案/回调快照。
- [ ] Snapshot 恢复新 Draft/runtime；摘要使用同一转换与 formatter，不调用 restore 改状态。
- [ ] Page 只组合 scope/layout；共享 feature 只提升真实跨页语义，页面专有组合留 page-local。
- [ ] GCD 支持单边速度；双空/反序无效；mode 切换不留隐藏值，objective 不在 Draft。
- [ ] 职业上限、同步映射、可穿戴性与属性 cap 分离；低同步不排除可穿戴高等级装备。
- [ ] Joint 目标归一化、Food strategy、shared 全局 exclusions、Job item-level exclusions 与 ring/ring2 ownership 事务符合规范。
- [ ] Main/Aside/Section 读同一 validation 快照，invalid > pending > valid，提交重新读最新值。

### 搜索与历史

- [ ] controller 随 Provider 存活；进度属于 Main，Aside 只有冻结摘要；Result 不保留 progress 总结。
- [ ] cancel 等实际 settle；导航先解除 ownership 再 abort；A 的迟到回调不能覆盖 B 或历史目标。
- [ ] cancelled/no-result/failed 从 Snapshot 重建 Conditions；一次性反馈走对应 Toast。
- [ ] History start/finish/read/update 失败不阻断搜索或页面流转，start 失败不 finish。
- [ ] Result 与 History 用同一 settle 时间，耗时不包括数据库等待；新搜索捕获当次 dataVersion，历史加载保留原 dataVersion/historyId，迟到的 history.start 不关联错误结果。
- [ ] Progress 可浏览 History；载入需确认、确认后重读 state；已完成则不再 cancel。
- [ ] 任意 dataVersion 的 completed result 可查看且不按当前数据重算；跨版本编辑需确认。
- [ ] History 两宿主同视觉、渐进挂载且一次读库，无旧 details 适配或数据库分页。

### 结果、替换与比较

- [ ] 四栏指标与目标高亮正确；总属性来自 result.stats，使用 SummaryRow。
- [ ] Joint 图标+全称 tabs、共享 tab 内概览、职业完整配装与实际有效条件摘要正确。
- [ ] GearTable 无业务 mode，列从 rows 派生，marker/row className 不扩散成细粒度样式协议。
- [ ] 同步 Single 替换原子交换 selected/replacements，不修改 Snapshot/指标/耗时；同 History 只更新 result 等价表示，写入失败仅 Toast。
- [ ] Comparison 同职业，第一方案为基准；装备分组包含 variant/custom/meld/最终属性与 Food。
- [ ] 伤害绝对及相对差、GCD 绝对差、Tank 减伤百分点；跨 dataVersion 明显提示且不重算历史。
- [ ] 导入按当前数据计算固定配装，无搜索/伪历史/伪耗时；职业不匹配拒绝，不自动换职业；导出包含 Food。

### 布局与交互

在 1440×695 与 1920×1080 分别覆盖 Single/Joint 的 selection、conditions、progress、result，以及 Laboratory、Comparison、History overlay、确认框、替换列表与超长 tabs。Comparison 覆盖 Single/Joint 历史提取、历史与导入混源、跨版本提示、错误职业拒绝、长名称及经确认的多方案容量边界：

- [ ] Header 64px，Aside 280px，phase 不改变主几何，shell 持有 viewport。
- [ ] 正常内容、所有必要表行与主要动作完整可见，无滚动兜底或裁切隐藏。
- [ ] 只有 History、溢出 Joint tab strip 与选择列表按规范滚动。
- [ ] 删除 src/ui 内现有全部 @media（包括 prefers-reduced-motion），clamp 默认不用，优先 flex/grid；目录外残留单独列出，未经确认不修改。
- [ ] SCSS Modules 所有权清楚，无全局控件 class、:global、祖先结构穿透或补偿性 viewport 公式。
- [ ] Base UI 负责通用交互；验证键盘、关闭/焦点返回、Portal 裁切与选中 tab 可见性。
- [ ] 最终真实路径验证含 Food 分享/导入往返、替换后重载 History、连续替换最终表示持久化，以及 Laboratory 到各独立页面的导航。
- [ ] 依据重构设计与用户确认检查真实浏览器交互、几何及截图；Penpot 仅作风格参考，不以旧画板结构或像素匹配作为通过条件。

## 待展开边界与范围外事项

已定稿的是契约，以下实现设计仍需单独完成：domain 同属性等价判定算法、固定配装导入如何复用公式链、分享格式的真实解析与往返验证。它们不允许由 UI 猜测游戏数据或自行补公式。具体映射与 API 使用真实数据及官方文档核实，缺失必需资料明确失败。

Comparison 暂不做手工编辑、自动判断最佳、URL/分享状态持久化、跨职业数值比较；imported entries 刷新持久化及导入等价列表不在第一版要求。网站统计暂缓，其余会改变 domain/search 的 TODO 不顺手纳入；已明确的等级规则变化与结果/导入契约仍属于本组范围。
