# 冲突与修改边界

[返回入口](README.md)。本页定义本轮重构的最终适用边界，依据 [Issue #2 最终决断](https://github.com/Yun-Shan/ffxiv-gearing-calc/issues/2#issuecomment-6218665833)。

## 设计权威

本组重构文档及用户确认是第一权威。Penpot 只作颜色、字体、密度与局部视觉语言参考，不用旧画板否定已确认的结构、内容、布局或流程。完整旧 Single / 当前 Joint 实现仅作实现参考，SingleWorkbenchPageNew 不作为视觉基线。

已确认的产品与架构规则直接适用，不再保留 UI 未决清单。本轮规则、README 和前端总览已按已实现契约同步；验收结论仍以具体测试与浏览器证据为准。

## 修改范围

| 范围 | 执行边界 |
| --- | --- |
| src/ui/** | 重构主要范围 |
| src/styles.scss 等全局 UI 样式、必要 App/UI entry、直接相关测试 | 完成已确认 UI 重构所需的最小必要修改直接纳入；必须清理旧全局 field class 和全部现有 @media |
| src/domain/** 中改变领域/搜索语义的修改 | 在对应功能需要真实契约时，提交具体方案、文件范围、行为影响和验证方案，用户确认后实施并集成 |
| src/data/** | 单独提交方案确认，不预设需要重生成 |
| 构建、依赖、数据脚本等其它修改 | 没有本次 UI 重构直接必要关系的修改不纳入，需单独确认 |

不能为避开 domain 确认而在 UI 复制公式、等价判定或搜索算法。Mock 只用于前置组件测试/明确开发预览，不代替真实功能集成。

## 与现行规则的关系

| 当前依据 | 本次最终决断 |
| --- | --- |
| 旧 Penpot 权威与画板一致性验收 | 本组文档为第一权威，Penpot 仅风格参考；真实浏览器按重构设计验收 |
| 非同步计算等级依赖最高候选装备 | 目标为 wearableLevel = jobMaxLevel；非同步 calculationLevel = jobMaxLevel，同步取映射等级与职业上限较小值；已按用户确认接入，见 Mock 盘点与真实接入 |
| 历史结果保留原值，不作为当前版本重新推荐 | 不同 dataVersion 的完成结果可查看与比较且不重算；跨版本编辑条件先确认 |
| 工程规则的 page-local 组件与共享边界 | 页面专有组合留页面；真实跨页业务语义放 features；独立目录、SCSS Modules、UI 不重写公式等约束继续适用 |

## 产品行为与实现确认

Joint 跨 scope 规则见[条件与编译](02-条件与编译.md)：宽 scope restriction 可清理窄 scope force；窄 scope 不静默修改宽 scope；新 force 不跨 scope 删除 restriction。

Comparison 见[结果与实验室](04-结果与实验室.md)：最多 4 方案；删除基准后取剩余顺序首项；已有方案切职业需确认并清空；关键伤害为零或非有限值的方案不加入；路由固定 /gear-comparison。

M01–M04 的领域方案均已确认并接入。用户已确认 Comparison 装备表允许滚动，替代四方案完整 fit 与容量暂留要求；保留最多四方案及完整行列，不分页或截断数据。新的领域语义或未确认产品设计仍须确认。
