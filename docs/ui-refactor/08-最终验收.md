真实数据检查覆盖了 PLD 同步 475 的搜索和替换、RDM/BLM 联合搜索与共享装备、真实历史记录刷新恢复，以及真实固定配装分享导入。导入时没有新建搜索历史或搜索耗时；真实旧版本结果可查看且不重算，同版本导入不会触发跨版本提示，职业不匹配会被拒绝。零值/非有限指标拒绝由 Comparison 模型测试覆盖。

## 几何和来源树

两种视口的页面文档尺寸均与 viewport 相同，没有额外页面滚动或被视口裁切的主要操作。Header 均为 64px；Aside 均为 280px 宽，贴合 viewport 底部：

| 视口 | Aside | 文档尺寸 | 额外越界操作 |
| --- | --- | --- | --- |
| 1440×695 | x=1160, y=64, 280×631，底边=695 | 1440×695 | 无 |
| 1920×1080 | x=1640, y=64, 280×1016，底边=1080 | 1920×1080 | 无 |

来源树在两种视口都由真实职业装备目录生成 41 个节点。验证了节点专属可访问名称、装备数量 badge、来源字典序、点选子节点后的父节点部分选中、父节点全选/全清，以及下方扁平来源列表同步。Checkbox 标签修复后，节点自身名称显式关联到对应控件，没有继承外层“排除来源”字段名。

Joint 结果 tabs 与当前所选职业在两种视口均正常显示。单一可共享装备组最多 5 个职业，当前目标宽度可容纳所有 tab；通过键盘切换并确认选中 tab 与结果面板相连。无需制造额外窄屏或伪结果来声称发生了溢出。

## 验收中修复

- 修正数据版本身份：计算、历史和导入使用领域 `defaultDataVersion`；职业/装备图标清单继续与游戏资源目录版本比较。此前同一游戏数据下真实历史与导入会被误报为跨版本；修复后浏览器验证不再误报，真正旧版本仍显示提示。
- 修正来源树 checkbox 的 `aria-labelledby`，令树中每个 checkbox 读取自己的节点标签。补充组件回归。
- 更新 Single 历史测试夹具使用 `currentDataVersion`，不再用图标资源版本冒充计算数据版本。
