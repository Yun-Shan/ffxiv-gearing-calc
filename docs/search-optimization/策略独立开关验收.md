# 搜索策略独立三态配置验收

本次将可选搜索优化统一为逐项 `auto/on/off`，缺省全部 `auto`。策略目录以 [`SEARCH_STRATEGY_IDS`](../../src/domain/search/core/strategies.ts) 为准；T14/T15 的共享状态与私有包络共同构成一条完整证明路径，使用同一个开关。公式、候选合法性、独立基线、完整域最高坚韧、原分母、BigInt/有理数目标、签名带完整复核、原模型与共享身份验证不提供关闭选项。

## 执行契约

- `auto` 沿用已有性能选择政策；`on` 只越过性能启用门槛，仍检查结构、数学证书、数值安全、实际预算与取消；`off` 跳过该可选优化，继续完整后备求解。不能把未获证或预算耗尽当成最优性完成。
- 策略作为 `SearchOptions.strategies` 执行选项，在入口复制、校验和冻结，贯穿单职业、联合、串行/并行独立基线、受限子搜索及底层求解请求。Node 的配置方法见[运行说明](../../scripts/node-tests/README.md#搜索策略)。
- 高级设置在浏览器全局保存，供之后的单职业和联合搜索共用；运行中修改只影响下次执行。策略不写入装备条件、Draft、Snapshot、历史或分享。重开设置或启动搜索会读取其他标签页的新偏好，存储不可用时保留当前页面可用的设置。
- 依赖证书继续生效：T11 关闭后，有速度约束的 T34 缺少完整投影证书时跳过；共享状态路径关闭后，T49 开启不会反向启动它。关闭额外种子/求解器热启动，不妨碍其他界计算内部准备并验证必需的合法下界。
- 资源支撑开关覆盖模型加强行、签名资源过滤及共享状态的价格/分片资源界；关闭时保留完整状态枚举。联合因子加强开关也覆盖独立基线导出的冗余代理上界行，基础比例包络与实际身份链接仍保留。
