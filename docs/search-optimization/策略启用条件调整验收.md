# 策略启用条件调整验收

相等变量商表示在证书成立时保持原模型的合法解与目标，但压缩后的模型不保证求解更快。联合搜索根据完整矩阵的非零系数与非空行密度决定是否采用该表示，成本条件不满足时继续使用原模型。

净变量缩减比例的分母采用本次变换前、已经实际应用其他变换后的变量总数，分子仅计本次商变换的净减少量。阈值以整数交叉乘积比较。资源加强与其他投影带来的前置收益分别归属各自策略。

可选表示选择必须保留原始列恢复和约束验证。职业效用等价也须满足原始分母、共享贡献、食物和私有候选等完整证书要求。性能启用条件不能代替这些证书。

当前场景及逐职业精确目标见[搜索结果基准](tools/acceptance-baseline.json)，同一版本的九轮完整领域耗时见[九轮耗时基准](九轮耗时基准.md)。这些测量用于后续性能比较，不能单独证明某个模型变换的普遍收益。
