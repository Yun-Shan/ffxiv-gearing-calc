# 搜索耗时优化总结

当前性能证据来自 2026-11-01 对 22 个正式场景的九轮串行复跑，共 198 次搜索。全部结果合法、证明完整，每职业 30 秒的耗时目标达标 195 次。四坦 A 有三次略超 120 秒目标，分别为 120.32、120.17、120.60 秒。逐案最小值、算术均值、最大值及原始样本见[九轮耗时基准](九轮耗时基准.md)。

场景包含单职业与联合搜索、同步与无同步、共享与独立食物、共享装备及 GCD 约束。四坦 A 固定关闭共享状态搜索，以覆盖联合 MIP 路线。完整输入与精确目标见[搜索结果基准](tools/acceptance-baseline.json)，运行入口见[搜索耗时优化说明](README.md)。

每次搜索的耗时直接取领域结果 `statistics.elapsedMs`，覆盖候选准备、独立基线、求解、结果还原与资源清理。性能目标与结果合法性、证明完整性分别判断。九轮统计描述这次测量窗口的分布，后续执行仍可能超出区间。

共享状态枚举、因子与资源加强、模型压缩和原生求解引导的收益取决于完整候选与约束。实际完成依据及数学条件见[当前搜索算法最优性证明](../当前搜索算法最优性证明.md)。合法起点和可选预算只能影响搜索效率，最优性复核仍须覆盖原候选域。

已知错误完成反例与验证限制见[通用数学策略迁移验收](通用数学策略迁移验收.md)。
