# 大整数的精确表示、压缩与 HiGHS 接口边界

- 日期：2026-10-18（Asia/Shanghai）。
- 范围：整理当前数学分析中大整数的处置方式，保持 canonical 参数映射、严格比较、同分语义与安全上界方向。
- 状态：分析与实施建议，不表示相关优化已接入生产，也不构成性能结论。本轮不启动装备搜索、MIP 或性能测试。
- 路径约定：代码路径相对于项目根目录；文档链接相对于本文。

## 1. 结论与不变量

大整数可以通过公因子约分、公共项消去、指数约简和代数恒等变换缩小，但不能保证所有实例都能降为安全 Number。需要同时保留两层：**BigInt/精确有理数负责认证，HiGHS 使用适合浮点求解的线性模型**。

本文建议改变内部计算表示，不改变以下语义：

- 属性贡献 `g`、职业 baseStat、等级与 BLU 参数，以及 `g -> tier -> factor` 的映射。
- 预算、caps、共享身份、食物与装备合法性。
- 原始分数之间的大小、相等、严格改善关系；跨职业使用既定归一化比值之和。
- 上界不低估、必要条件不排除应保留解，以及证明不可用时安全回退。

将大整数改成小整数后，必须明确恢复关系或等价比较式。仅“数值看起来接近”不能作为转换依据。工程约束以[领域与搜索规则](../rules/领域与搜索规则.md)和[工程规则](../rules/工程规则.md)为准；公式事实以[canonical 参考模型](canonical-evaluator-reference.md)为准。

## 2. 先区分大整数的来源

| 来源 | 典型对象 | 建议 |
| --- | --- | --- |
| 公式的整数倍率 | CRT 因子的 `1_000_000`、DET/TEN 档位 | 只提取整个使用域共同的因子，不能直接删除加法常数 |
| 多个因子相乘 | 三副属性乘积、完整伤害乘积 | 比较前消去公共部分；必要时保留 BigInt |
| 比值交叉比较 | DPS、职业归一化分数 | 分数约分、公共分母消去后再乘 |
| 幂比较 | 单位资源边际比较 | 比值先约分，成本指数再约简 |
| 抵消后的符号 | 曲率判据、乘积差值 | 优先使用已证明的代数差值式 |
| 人工边界证书 | `P=Q²`、`P±1` | 从构造开始用 BigInt；保留压力用例的验证目的 |

BigInt 的十进制位数大，不等于模型变量多；反之，系数可精确表示，也不等于浮点求解已经提供任意精度证明。

## 3. raw-to-tier 参数可先作精确约分

对整数模型：

```text
t(g) = c + m * floor((a*g+b)/q)，q>0
```

若 `d=gcd(a,b,q)>0`，则分子、分母同时除以 d，内部有理数完全不变，floor 与 tier 也完全不变。这里不缩放 g，不移动 floor，不改变 m。

例如 L100 普通公式在贡献坐标下可写成：

```text
CRT = 50   + floor(10*g/139)
DHT =        floor(55*g/278)
DET = 1000 + floor(7*g/139)
TEN = 1000 + floor(28*g/695)
```

BLU 的 CRT/DHT 仍分别保留原 `+200` 偏移。各等级 DET 的 `detTrunc` 不能丢掉；因为当前 `d=detTrunc` 整除 1000，可精确写为：

```text
DET = 1000 + d * floor(140*g/(det*d))
```

然后再约去线性系数与分母的公因子。不能把该式改成一般的 `1000+floor(140*g/det)`，后者会改变低等级阈值。

这里的等式针对精确整数模型。若将来改写生产中的浮点运算顺序，仍须按 [raw-tier-transform](theorems/raw-tier-transform/README.md) 重新核验截断等价域与 canonical 对照；数学等式本身不保证任意浮点执行顺序等价。

## 4. 公因子缩放：可压缩，但必须携带尺度

### 4.1 因子表的精确缩放

对固定使用上下文的因子表，若：

```text
s_i = gcd{F_i(t) : t 属于本次完整档位表} > 0
F_i(t) = s_i * f_i(t)
S = product_i s_i
P(x) = S * p(x)
```

则在同一可行域内：

```text
argmax P = argmax p
U_original = S * U_reduced
P > B  iff p > floor(B/S)
P >= B iff p >= ceil(B/S)
```

理由是 S 为固定正数，且 p 为整数；因此乘除 S 不改变排序，floor/ceil 恰好处理阈值与整数格点的关系。严格与非严格阈值不能共用同一种舍入。

所有阈值转换均采用精确整数/有理数运算。示例：`S=5,B=11` 时，严格要求 `p>=3`，非严格也要求 `p>=3`；`B=10` 时严格要求 `p>=3`、非严格要求 `p>=2`。

使用约束：

- 公因子必须覆盖所认证的全部档位；不能只从抽样点推定。
- 同一个查询器内尺度固定；缓存必须绑定档位域及尺度。
- 不同上下文使用不同尺度时，比较 `S_A*p_A` 与 `S_B*p_B`，不能直接比较缩小后的值。
- 原始因子及恢复映射保留，UI、历史分数和结果复核仍按 canonical 语义。
- 多职业允许每职业采用不同尺度，但分子和对应独立基线必须同步处理，使 `score_j/baseline_j` 不变；不能比较未经恢复的跨职业整数。

### 4.2 当前公式的通用缩放空间有限

CRT 因子为 `F(t)=1_000_000+t(t+b)`，普通/BLU 的 b 都是偶数。连续档位的一阶差 `2t+b+1` 为奇数，二阶差为 2；任意全域公因子必须同时整除二者，因此只能为 1。当前支持等级的 CRT 映射可在非负贡献域达到连续档位，故不存在大于 1 的全域整数缩放因子。

DHT 因子域包含连续整数 `4000/4001`（BLU 为 `4200/4201`），全域公因子也为 1。DET 只取 `detTrunc` 的倍数，且可取相邻倍数，因此其全域公因子为：

| 等级 | DET 全域公因子 |
| --- | ---: |
| 50 | 5 |
| 60 | 2 |
| 70/80/90/100 | 1 |

有限档位域可能有额外公因子，可以动态认证；表内只有一个档位时，也可以将该常量完整提取。这里的全域结论只排除统一整数除法，不排除其他精确表示。

特别是，CRT 内的 `1_000_000` 是加法项，不能直接删掉或整除截断；改成有理数 `F/1_000_000` 虽可精确表示，但分母仍需保留，不保证整体存储或计算更小。

## 5. 比较前消项，避免先制造巨大乘积

### 5.1 相同因子与乘积公因子

同一职业上下文内，比较双方相同的正因子可以先消去。例如非坦克恒定 TEN 因子 1000，不必在比较两侧重复相乘。武器、主属性等只有实际相同时才能消去；作为上界的某因子与 incumbent 因子不同，不能强行当公共常量。

精确整数例子：

```text
P0 = 4,080,000,000,000
P1 = 4,315,825,466,400
gcd(P0,P1) = 2400

比较 P0 与 P1
等价于比较 1,700,000,000 与 1,798,260,611
```

工程上优先在因子列表之间做 GCD 消去，再乘剩余项；已生成乘积后约分只缩小后续计算，无法避免本次大乘法。互质输入可能压缩很少，不承诺固定压缩率。

### 5.2 DPS 和有理数比较

对正分母：

```text
A/a ? B/b  iff A*b ? B*a
```

可先约简各自分数，再在左右乘积间消去公共因子。若两侧最终仍很大，就继续用 BigInt；不能截断商代替有理数比较。

多职业目标仍是各归一化比值之和。分数相加时可以先用分母 GCD 构造最小公倍数结构，避免无条件相乘所有分母；相加后再约分。分母互质时仍可能增长。

不同职业的分数不是通过取 log 后求和比较的；`Σ r_j` 与 `Σ log(r_j)` 不是同一目标。

### 5.3 阈值商与余数

若只需要 `floor(P/O)`、`ceil(P/O)`，可用精确商余关系：

```text
P = O*q + r，O>0，0<=r<O
floor(P/O) = q
ceil(P/O) = q + [r>0]
```

上游若已经具有该表示，可以避免不必要地重建 P。若从任意大 P 出发，第一次除法仍需要处理该大数，不能宣称完全消除了成本。

不得丢弃余数。`P=Q²+1` 与 `P=Q²` 的非严格阈值就可能不同。用于验证大整数精度的压力用例应保留，不能为了数值变小而删除该验证目标。

## 6. 边际幂比较与差值恒等式

### 6.1 先约分比值和指数

按 [marginal-comparison](theorems/marginal-comparison/README.md)，正因子、正整数成本下：

```text
(F1/F0)^cG ? (G1/G0)^cF
```

分别将两个比值约成最简分数。再令 `d=gcd(cF,cG)`，指数同时变为 `cG/d`、`cF/d`，比较结果不变：原两侧分别是新两侧的 d 次方，而正数的 d 次幂严格递增。

最后才构造必需的整数幂；还可在两侧因子表示中继续精确消项。无法有效压缩时保留 BigInt，或使用已有带误差界的对数区间先判定；区间重叠必须回退精确比较/跳过可选加强，不能以普通浮点 log 的符号裁决。

### 6.2 优先采用已有代数差值式

按 [tier-log-curvature](theorems/tier-log-curvature/README.md)，对 CRT 的相邻档位：

```text
F(t+2)*F(t) - F(t+1)^2
  = 2,000,000 - 2*t² - (2*b+4)*t - (b+1)²
```

对仿射因子 `F(t)=A+t` 与整数步长 k：

```text
F(t+2k)*F(t) - F(t+k)^2 = -k²
```

在仅需要符号的证明中，可直接使用右式，避免生成两个大乘积。只适用于已证明的对应表达式；不能凭相似形状把其他乘积差替换成近似式。

## 7. Number 与 BigInt 的分界

BigInt 应在可能超出安全范围的首次运算之前进入计算链：

```text
正确：BigInt(a) * BigInt(b)        # 前提：a、b 本身已是准确的安全整数
错误：BigInt(a * b)               # a*b 若已舍入，转换不能恢复原值
```

从字符串接收大整数时直接构造 BigInt，不经过 Number。BigInt 除法向零截断；数学 floor/ceil 对负分子的处理必须单独实现，不能将正数公式无条件用于有符号余量。

Number 快速路径只能在事先证明全部整数中间量都在 `[-(2^53−1),2^53−1]` 内、且运算方式保持整数精确性时使用。结果碰巧是整数、`Number.isInteger` 为真，或乘完后才检查，均不能证明输入和中间结果未舍入。可在 BigInt 中认证界后选择快速路径；不能靠已可能失真的 Number 乘积证明自己安全。

当前公式的一个有限域示例：若三个贡献各自均在 `[0,3000]`，六档等级、普通/BLU 公式的盒域最大三因子乘积不超过 `148,337,081,737,350`，小于 `Number.MAX_SAFE_INTEGER`。由各因子单调性，取盒域顶角即可核验该界。该范围包含部分非实际职业等级的公式组合，只是代数覆盖；不表示真实候选贡献始终不超过 3000。

因此不能把这个有限域结论推广到完整伤害、任意预算、DPS 交叉乘积或幂比较。快速路径不可用时回退 BigInt；不降低精度。

## 8. HiGHS 不直接承担任意精度整数运算

### 8.1 项目接口事实

- `src/domain/search/linear-mip.ts`：`LinearMipRow.terms`、`rhs`、变量上下界与目标系数使用 `number`。
- 本地安装的 `highs/types.d.ts`：`NumberInput` 为 `readonly number[] | Float64Array`，矩阵值为浮点数组；本地依赖类型用于核对接口，不应修改。
- [HiGHS 官方 C 接口源码](https://github.com/ERGO-Code/HiGHS/blob/master/highs/interfaces/highs_c_api.h)：模型系数和边界采用 double。
- `src/domain/search/loadout-finder-exact-mip.ts` 的 `addRatioUpperNecessaryCuts`：先以 BigInt 求必要阈值，检查安全整数范围，再转为 Number；超限时不加入该可选加强行。

因此可以在模型准备/认证层使用 BigInt，但不能把 BigInt 大整数当作任意精度系数直接交给当前 HiGHS 接口。将其写入 LP 文本或十进制字符串，也不会把求解器的系数运算改成任意精度。

整数变量约束的是取值类型，不意味着矩阵、LP 松弛、对偶界和求解过程采用任意精度整数算术。输入整数能精确表示，也不能消除 HiGHS 的浮点容差。

### 8.2 先产生小系数的证明结果

| BigInt 层的认证结果 | 可交给 HiGHS 的形式 |
| --- | --- |
| 候选在完整乐观上界下不能严格改善 | 在相应严格改善模型中加入 `x=0`，并遵守 tie/身份语义 |
| 某离散签名组合不可能改善 | 加入排除该组合的线性行 |
| 已认证必要支撑 `w·g>=K` | 精确约分或安全放松后，提交受控系数与 RHS |
| 数值仍过大且该加强可选 | 不加入该行，保留既有完整证明路径 |

第一类无需把巨大伤害乘积传入求解器。它把精确认证转换为小系数逻辑约束，通常比强行把整个乘积编码为线性系数更直接。

任何模型行都必须对其作用域有效。依赖 incumbent、固定分支或候选域的证书不能不加条件地在别的模型上下文复用。

### 8.3 整数行先做 GCD 化简

设 x 是整数变量，`a_i` 为整数，`d=gcd_i |a_i|>0`，令 `a_i=d*a'_i`。则整数格点上：

```text
Σ a_i*x_i >= K  iff Σ a'_i*x_i >= ceil(K/d)
Σ a_i*x_i <= K  iff Σ a'_i*x_i <= floor(K/d)
Σ a_i*x_i >  K  iff Σ a'_i*x_i >= floor(K/d)+1
```

此处 K 可为精确有理数。等价性依赖新左端仍为整数；含任意连续变量时不能直接这样取整 RHS。等式行的整数 RHS 若不能被 d 整除，则无整数解，不应对 RHS 强行四舍五入。

RHS 转换与系数约分在 BigInt/有理数层完成。全零系数的行单独判断恒真或不可行，不进行 `gcd=0` 除法。

### 8.4 无法等价缩小时，只能使用已证明的保守放松

对非负变量 `z>=0`，若原必要行是 `a·z>=K`，且已精确认证：

```text
a'_i >= a_i，对每个 i 成立
K' <= K
```

则所有满足原行的点都满足 `a'·z>=K'`，所以新行是安全但可能更弱的必要条件。对于 `a·z<=K`，采用 `a'_i<=a_i`、`K'>=K` 可得到同方向安全放松。

有负取值变量时不能直接套用：需先用有限下界变换 `x=l+z`、精确更新 RHS 并证明 `z>=0`，或用完整变量界推导误差补偿。误差与舍入方向必须覆盖实际系数；不能使用普通浮点四舍五入后再假定这些不等式成立。

上述是输入行的数学安全性，还需避免系数过小被求解器阈值忽略、比例悬殊导致数值退化，及容差影响严格改进边界。不能因为缩小后进入安全 Number 范围，就声称获得形式化有理数最优性证书。求解器信任边界见[当前搜索算法最优性证明](../当前搜索算法最优性证明.md)。

### 8.5 回退必须与操作性质匹配

- 可选剪枝证书算不出：不剪枝，不把“未知”当作“不可改善”。
- 可选加强行无法安全编码：跳过该加强，继续既有完整模型。
- 核心目标或硬约束无法安全表示：明确失败或采用另一个已证明完整的正式路径，不能静默丢弃核心约束。
- 取消、超时或求解未完成：遵守项目失败语义，不返回近似结果并宣称最优性已证明。

## 9. 建议的接入顺序与验证

先做不改变游戏参数的精确消项与约分，再考虑更复杂的快速路径：

1. 保留 canonical 因子与输入坐标；在比较入口消去相同因子、约分有理数。
2. 幂比较先约简比值和成本指数，曲率符号继续使用已证明的差值式。
3. 对完整档位域认证公共尺度，明确缓存域与恢复系数，并同步转换阈值。
4. 需要 MIP 行时先作整数 GCD 化简，认证可编码范围；不可用的可选加强安全跳过。
5. 最后才评估 Number 快速路径和更多符号表示，保持 BigInt 回退及同分边界。

验证至少覆盖：

- 原始与缩小表示的 `g -> tier -> factor` 恢复逐点一致；普通/BLU、所有支持等级及 DET 截断。
- 原始和压缩比较的 `< / = / >` 全部一致；阈值的整除与非整除、`B−1/B/B+1`。
- 公因子为 1、大公因子、因子相同/不同、互质分母、成本指数互质/非互质。
- 固定尺度和不同上下文尺度，保证没有跨缓存域混用。
- 超过 `2^53−1` 的输入从构造开始采用 BigInt；验证 Number 丢失 `+1` 的反例。
- HiGHS 行的等价化简或保守放松在小型整数模型上逐点验证，覆盖有符号系数及变量界；核心约束不能因超限而被跳过。

本文件是处置说明，不替代每项变换的实现验证；未修改生产代码或生成数据，未启动装备搜索或性能测试。运算次数减少、数值变小是否改善耗时，仍需后续按任务范围另行验证。

## 10. 定理使用路径的审计结论（本轮）

本节把前述原则落到“**读定理、写验证、接实现**”三个使用层级，回答：哪些值可以用 Number，哪些必须从构造开始用 BigInt/精确有理数，哪些转换点需要显式 guard。结论是**定理本身不依赖浮点**，风险集中在“表示切换点”和“大数进入 Number 的时机”，不是数学命题。

### 10.1 三个使用层级

| 层级 | 对象 | 允许的表示 | 禁止 |
| --- | --- | --- | --- |
| 证明层 | 定理中的等式、不等式、阈值、像集 | 任意精度数学；只要求表达式正确 | 用“数值接近”“浮点抽样”替代证明 |
| 证书层（`verify.mjs`/测量） | 有限域逐点核对、反例、阈值边界 | BigInt/精确有理数；小整数 Number 当且仅当证明每个中间量都在 2^53−1 内并断言 | 先 Number 乘再转 BigInt；用 PASS 代替一般证明 |
| 实现层 | 候选上界、frontier 阈值、联合比值、MIP 行 | 精确认证用 BigInt；索引/成本/计数/MIP 系数可用 Number；HiGHS 系数是 float | 把 BigInt 大数直接转 Number；用浮点决定严格剪枝 |

### 10.2 数量级与类型选择

| 量 | 典型值/界 | 是否可能 >2^53 | 定理使用要求 |
| --- | --- | --- | --- |
| 贡献 `g`、档位、`κ`、`R` | 数量级 10^2–10^4 | 否 | Number 可，但输入须 `Number.isSafeInteger` |
| 单因子 `F_C,F_H,F_D` | 约 10^6、10^3–10^4、10^3–10^4 | 否（各自） | Number 可；**乘积不能因此假定安全** |
| 三副属性乘积 `Φ=F_C·F_H·F_D` | L100 典型约 4×10^12；§7 的 g≤3000 盒域上界 ≤148,337,081,737,350 | 在已认证贡献/cap 域内否；超出该包络时可能 >2^53 | 盒域内 Number 可（须断言安全）；超出包络或与完整目标/外部大 `B` 混合时必须 BigInt 交叉比较 |
| 完整伤害乘积 `P`（6 因子） | 例如 L100 WHM、对 canonical evaluator 输入 `(CRT,DHT,DET)=(1000,1000,1000)`、其余属性 0（数量级示例，不是一套真实装备）时 `P=34,469,205,833,790,000,000≈3.45×10^19` | **是** | 从第一个乘积开始 BigInt；禁止 Number |
| DPS 交叉乘积 `P·gcd` | 同上 `P·250≈8.62×10^21` | **是** | BigInt 交叉乘法；不得先做除法 |
| 阈值 `B=⌊P_inc/O⌋`、`⌈P_inc/O⌉` | 可达 `P_inc` 量级 | **是** | BigInt 商余；严格/非严格分别 floor/ceil；保留 `B±1` 测试 |
| 归一化比值 `u_j` / 联合目标和 `J*` | BigInt 分子/分母；分母可增长 | **是** | BigInt 有理数；`Σu_j` 用 BigInt 累加/交叉相乘；MIP 缩放行须先验证安全范围 |
| 边际幂 `F^cost`、`N^δ` | 指数可达数十–数千，值天文级 | **是** | 先约分比值/指数；精确比较用 BigInt；log 只能作带误差界的筛选，重叠必须精确回退 |
| 食物/预算和、Lagrange RHS | 约 10^2–10^5 | 通常否 | Number 可；若出现乘积型界或分数，先做精确化 |
| 压力构造 `P=Q²`、`P±1` | `Q≈4.08×10^12`，`P≈1.67×10^25` | **是** | 从构造起 BigInt；验证 `+1` 不被吞、floor/ceil 边界正确 |

两个具体精度反例（同一 `P` 与实际合法输入）：

```text
P  = 34,469,205,833,790,000,000
Number(P) 的实际整数值 = 34,469,205,833,790,001,152   （误差 +1,152）
P*250 的精确值         = 8,617,301,458,447,500,000,000
Number(P*250) 实际值   = 8,617,301,458,447,500,312,576 （误差 +312,576）
```

因此“乘积看起来是整数”“Number.isInteger 为真”都不能证明比较正确；完整伤害、DPS、`P_inc` 与 `B` 的路径必须 BigInt。

### 10.3 各定理家族的算术审计

| 定理家族 | 大数对象 | 当前验证/实现处理 | 判定 |
| --- | --- | --- | --- |
| raw-tier-transform / tier-log-curvature | 档位、因子、乘积差 | 档位用 Number（小）；因子/必要乘积用 BigInt 或已证差值式；曲率公式避免大乘积 | 合规（差值式只用于已证对象） |
| pairwise-endpoint / pairwise-slice | 切片内两个因子乘积 | 切片乘积用 BigInt；关键集只比较档位/阈值 | 合规 |
| free-budget-upper-bound `U(b,R,κ)` | 三因子乘积、`U` | 因子表 Number；乘积和 `U` 用 BigInt；`R/caps` 用 Number；生产查询返回 `bigint` | 合规；**接入时与候选上界用 BigInt 比较，不得转 Number** |
| simplex-vertex-reduction | 切片/顶点三因子乘积、`U` | 所有乘积 BigInt；端点扫描直接比较 BigInt | 合规 |
| strict-improvement-frontier | `P_inc/O/gcd/B`、`Φ`、`K_w`、同分像集 | `B/P_inc/O/gcd` BigInt；`Φ` 的三因子值用 Number 但逐点断言 `<2^53`；阈值用 BigInt 交叉比较；同分用像集/BigInt；压力用例 `P=Q²` 已固化 | 合规（但 `Φ` 的 Number 表只适用于已认证三因子域） |
| attribute-swap-criterion | 交换两侧因子乘积、幂比较 | BigInt；运行时不使用 log | 合规 |
| joint-loss-sum-bound | 比值/分数和、联合阈值 | 全部 BigInt 有理数；MIP 缩放行先检查安全范围再转 Number | 合规（求解器边界见 §8） |
| substat-sum-upper-bound | 逐槽和/食物界/约束界 | 和与 cap 很小；食物 bonus 用 BigInt 有理数后 cap 到 Number；无完整伤害乘积 | 合规（受食物 cap/贡献域安全整数前提约束） |
| substat-sum-lower-bound-pruning | `L1/R`/slab 和 | 数量级 10^2–10^4，Number；没有乘积/大阈值 | 合规（若未来把界扩展到 >2^53 必须改 BigInt） |
| coordinate-lower-bound-box | `Φ`、`B`、`l_i`、`T` | 三因子 `Φ` 用 BigInt；盒域表用 Number 但断言安全；`B` 在示例中为三因子量级 | 条件合规：`B` 转 Number 前应有显式安全 guard（见 10.4） |
| marginal-comparison | 幂比较、log 误差 | 验证用 BigInt 幂；定理要求先约分；log 只用于可选筛选 | 条件合规：实现必须精确回退，log 不决定剪枝 |
| raw-marginal-envelope | log 包络/近似比值 | 精确比较用 BigInt；log 仅用于把近并列分开，符号核对走精确式 | 条件合规：近并列阈值/浮点误差必须保留精确回退 |
| 共享模型/测量脚本 | 因子表、乘积、有理数 | 因子/乘积/食物分数用 BigInt；Number 只用于计数/索引 | 合规 |
| 生产 exact MIP 上界 | 七因子完整乘积、DPS 交叉 | `safeDamageFactors` 要求七因子为正安全整数；`exactProduct` 用 BigInt；交叉乘法 BigInt | 合规；候选上界若返回 `undefined` 不得当“不可改善” |
| 生产资源预算界 | 可加对数得分、有理斜率 | 斜率用 BigInt，查询返回 BigInt；属保守上界，非精确等式 | 合规（不声称精确） |
| HiGHS 接口 | 矩阵/RHS/目标系数 | double；BigInt 阈值须先安全编码，超范围跳过可选行 | 合规但受 float 求解器信任边界限制 |

### 10.4 已确认的表示切换点与建议 guard

1. **`canonical-model.mjs` 的 `floorDiv/ceilDiv`**：内部用 BigInt，最后 `Number(quotient)` 返回。当前调用只产生档位值（≤10^4），安全；但这是**未断言的契约**。建议加 `Number.isSafeInteger` guard，或对通用入口保留 BigInt 返回值，避免未来把大商转成 Number。
2. **`coordinate-lower-bound-box/verify.mjs` 的 `Number(B)`**：示例 `B` 是三因子量级（≤10^13）；建议在转换前断言 `Number.isSafeInteger(B)`，否则走 BigInt 比较，避免把该模式复制到完整目标 `B`。
3. **`raw-marginal-envelope` 的 log 预筛**：精确比较已在 BigInt 中做；log 只用于近并列分流。任何实现不得用 log 符号决定剪枝；近并列阈值必须回退精确比较。
4. **`marginal-comparison` 的幂比较**：先约分比值和指数；真实实现不得直接构造巨大 `F^c` Number；BigInt 或带误差界的区间比较 + 精确回退。
5. **`free-budget-upper-bound` 接入**：`prepareSubstatFactorBudgetQuery` 返回 `product: bigint`；候选上界必须与 `exactProduct` 的 BigInt 比较，不能把 `U` 转 Number 再和 `candidateUpperBound` 混用。
6. **`joint-loss-sum-bound` 的 MIP 行**：缩放阈值在 BigInt 中算，超 `MAX_SAFE_INTEGER` 跳过可选行；核心约束不得因溢出错删。tie/严格边界必须用 `B±1` 用例复核。
7. **`substat-sum-upper-bound` 的食物 `bonusOf`**：`Number(uncapped)` 发生在 cap 之后，cap 是安全小整数；若数据/规则允许大 cap，必须先断言安全范围。
8. **单因子 Number 不等于乘积安全**：`canonical-model` 的因子函数返回 Number 只说明单因子安全；任何“因子表 Number → 三个因子相乘仍 Number”的推论都被 10.2 的反例排除。
9. **全量验收的 `P_inc`**：生产 `exactProduct` 已 BigInt；任何自写复核脚本若先用 Number 算完整乘积再转 BigInt，都会在转换前丢精度（10.2 的 +1,152 例），必须从因子构造就开始 BigInt。
10. **HiGHS 边界**：BigInt 认证只作用于模型准备/剪枝逻辑；LP 松弛、对偶界与求解器容差仍是 float，不能把 BigInt 正确性当作求解器最优性证明。

### 10.5 定理使用检查清单

在把一个定理接入实现或写成验证脚本前，按顺序检查：

1. **确定域的界**：列出该定理用到的所有乘积、`B`、交叉乘积、幂的最大值；不能只写“是整数”。
2. **选择表示**：单因子/和/计数可在认证范围内用 Number；乘积、阈值、DPS 交叉、比值和、幂从构造开始 BigInt/有理数。
3. **转换点 guard**：每个 `Number(bigint)` 前检查 `Number.isSafeInteger` 或证明商/值在安全范围；转换后不能再用于精确比较。
4. **阈值方向**：严格/非严格分别 floor/ceil；保留 `B−1/B/B+1` 与整除/非整除用例。
5. **比较方式**：比值用交叉乘法；乘积比较不做除法；同分用像集/精确交叉等式，不用“整除足够”的简写。
6. **约分与恢复**：约分/公因子缩放必须携带尺度与恢复映射；不同上下文尺度不直接比较。
7. **浮点只能作可选加速**：log/近似筛选必须带保守方向与精确回退；不能决定严格剪枝。
8. **MIP 编码**：只提交已认证的小系数/RHS；超范围可选行安全跳过；核心约束不得静默丢弃。
9. **验证压力**：每个涉及大数的定理至少有一个 >2^53 的压力用例（完整乘积/DPS 交叉/`P=Q²`/大分母和），并覆盖 `+1` 丢失与近 tie 边界。
10. **文档前置条件**：在定理的“应用前提”中写清所需整数域/界；本文件 §10.2–10.4 可作为统一引用。

### 10.6 结论

- **数学层**：当前定理不依赖浮点；“精确整数比较”是正确性前提，不是性能选项。
- **验证层**：现有 `verify.mjs`/测量脚本的主体已用 BigInt/精确有理数；剩余风险集中在少数 Number 转换点（10.4 第 1–3、7 条）和压力用例覆盖，而不是定理结论本身。
- **实现层**：完整伤害、DPS、`B/P_inc`、联合比值必须 BigInt；三副属性乘积仅在已认证贡献/cap 盒域内可用 Number，且一旦与外部阈值/完整目标混合就必须 BigInt。
- **求解器层**：HiGHS 仍是浮点；BigInt 认证用于模型准备与剪枝逻辑，不能替代求解器容差/最优性证明。
- 本轮**未修改生产代码、未启动搜索/MIP/benchmark**；上述是定理使用与验证的结论，不构成性能或生产正确性承诺。
