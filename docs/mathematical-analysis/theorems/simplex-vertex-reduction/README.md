# 三属性自由预算 simplex 的顶点/边界降维：否证、充分条件与安全回退

## 1. 标题与状态

- **目录**：`docs/mathematical-analysis/theorems/simplex-vertex-reduction/`
- **定理 1（无条件顶点公式）**：**已否证**。给出两个完整精确反例（含逐项算术、其它两个顶点、内部最优、边界最大与精确间隙），并验证每个支持等级都有反例。同时否证 **boundary-only 归约**。
- **定理 2（顶点最优的充分条件）**：**已证明**。若三个属性对在所有定第三坐标切片上满足端点最大，则 `U` **存在**顶点最优解；该条件**充分不必要**（必要性已由显式反例否证，见 §7）。
- **定理 3（证书可判定但在真实区间失败）**：**已证明并给出失败见证**。端点最大证书是逐切片的有限精确判定；但在真实等级/因子区间上它**失败**，因此 vertex-only **不得无条件启用**。
- **定理 4（无顶点假设的安全回退）**：**已证明（含 caps 修正）**。精确回退 = [free-budget-upper-bound](../free-budget-upper-bound/README.md) 的档位三元组预算公式；只依赖**部分**属性对证书的精确降维是**caps 感知**的：无 cap 绑定（`S*<=min(κ_i,κ_j)`）且 `Cert_{ij}` 时归约到两个零 facet；一般 caps（`Cert_{ij}` 时）归约到四个 facet `{x_i=0,x_j=0,x_i=κ_i,x_j=κ_j}`，每个 facet 是 2D 精确问题（pairwise 关键集）；原「两个零 facet 无条件成立」被 §7.4 的反例否证。对未证明的 majorant **不主张紧致性**。
- **性能**：**未评估**。本文不给出剪枝收益、运行时间或「应该预计算多少个 support」之类的经验结论；也不使用任何等级/职业 magic case。
- **验证**：[verify.mjs](verify.mjs)（有限网格精确证书；本文所有反例数值均由该脚本重算）。

## 2. 范围与依据

本文研究 [Issue #3](../../issue-3-body.md) **证明目标 3** 的自由预算松弛 `U(b,R)`，以及 [评论 01 新优先级 2/3](../../issue-3-comment-01.md)、[评论 02 §五](../../issue-3-comment-02.md) 提出的降维问题：

- **边界定理**：对任意内部点，是否存在一条允许的两属性交换路径，始终不降低目标并最终到达边界？
- **顶点定理**：若所有两属性定和切片都端点最大，能否证明**至少存在顶点最优解**？这个充分条件的严格证明是什么？
- **部分归约**：只有部分属性对的端点定理成立时，最优解能否被限制在特定 edge/facet 上？（cap 绑定时需 0/κ 四 facet，见 §5 定理 4(2) 与 §7.4 的反例）
- **有限关键点**：如果边界/顶点结论有反例，能否证明只需检查少数 raw 阈值交点 / cap 边界？

评论 02 §五 明确要求：**禁止未经证明直接写 `U = max(三个顶点)`**。本文的结构是「先否证强命题（定理 1），再证明充分条件（定理 2），再把充分条件变成可判定证书并指出它在真实区间失败（定理 3），最后给出不依赖顶点假设的安全回退与部分归约（定理 4）」。

符号、档位模型、因子公式、定义域与假设与 [free-budget-upper-bound](../free-budget-upper-bound/README.md) §3–§4 **完全相同**，本文不重复推导，只引用。权威事实基础同该文 §2（参考文档、`equipped-effects.ts`、`substat-factor-budget.ts`、`exact-mip-candidate-upper-bound.ts`）。

## 3. 符号、量词与定义域

沿用 [free-budget-upper-bound](../free-budget-upper-bound/README.md) §3 的全部记号（**全部坐标是档位输入贡献，不是面板总值**；换算契约与第二轮 baseStat 审计见 §13）：

```text
b = (C0,H0,D0) ∈ Z_{>=0}^3, R ∈ Z_{>=0}, κ ∈ (Z_{>=0} ∪ {+∞})^3   （贡献/增量坐标）
K = κ_C + κ_H + κ_D, S* = min(R, K)
t_i(g), F_C(t), F_H(t), F_D(t), f_i(g) = F_i(t_i(g))
A(b,R,κ), U(b,R,κ) = max_{x∈A} Π_i f_i(b_i+x_i)
```

本文新增：

- **满预算单纯形（含 cap）**：

  ```text
  Δ(b,R,κ) = { x ∈ A(b,R,κ) : Σ_i x_i = S* }
  ```

  由 [free-budget-upper-bound](../free-budget-upper-bound/README.md) 定理 2，`U` 在 `Δ` 上取到。无 cap 时 `S* = R`，`Δ` 就是通常的整数 simplex `{x >= 0 : c+h+d = R}`。

- **顶点**：`Δ` 的顶点，即**至多一个坐标严格位于其边界之间**的点；坐标 `i` 的边界是下界 `0` 与上界 `κ_i`（`κ_i = +∞` 时无上界）。等价刻画：至少两个坐标取到边界值（`0` 或 `κ_i`）。该刻画由「`Δ` 是盒约束 + 一个等式约束的多面体」立得：顶点需要除等式外至少两条独立的作用约束。

- **三顶点集合**（无 cap 或 cap 不绑定时）：

  ```text
  V3(R) = { (R,0,0), (0,R,0), (0,0,R) }
  ```

  caps 受限时应写成 `V(κ,S*) = { (x_C,0,0), (0,x_H,0), (0,0,x_D) : x_i = min(κ_i,S*) }`；当 `S* > κ_i` 时该形式甚至不可行，正确候选集是「至多一个自由坐标」的全部顶点。评论 01 的「3 顶点公式」只对 `S* <= min_i κ_i` 的 caps 不绑定情形有意义。

- **两属性定第三坐标切片**：固定属性 `k` 的贡献增量为 `κ`（即最终贡献 `b_k + κ`），剩下属性对 `(i,j)`，预算 `S ∈ Z_{>=0}`：

  ```text
  G_{ij}(x; S, κ) = F_i(b_i + x) * F_j(b_j + S - x) * F_k(b_k + κ)
  x 的可行区间：L = max(0, S - κ_j), U = min(κ_i, S)
  ```

  端点最大（endpoint-max）性质：

  ```text
  ∀ x ∈ [L,U] ∩ Z :  G_{ij}(x; S, κ) <= max( G_{ij}(L; S, κ), G_{ij}(U; S, κ) )
  ```

- **端点最大证书 `Cert(b,R,κ)`**：对三个属性对 `(C,H)`、`(C,D)`、`(H,D)` 与每个 `κ ∈ [0, min(κ_k,S*)]`，令 `S = S* - κ`，上述端点最大性质都成立。

## 4. 假设

除沿用 [free-budget-upper-bound](../free-budget-upper-bound/README.md) §4 的 (A1)–(A6) 外：

- **(B1) 满预算定理**：使用该文定理 2（无 cap 时存在总成本 `R` 的最优解；有 cap 时存在总成本 `S*` 的最优解）。
- **(B2) 因子严格增**：`F_C, F_H, F_D` 在档位域上严格递增，用于「档位更高则因子更大」与切片端点比较；证明见该文引理 0。
- **(B3) 精确整数比较**：所有切片值、顶点值都用 `BigInt` 精确比较；不使用浮点 `log`、导数或「近似 single-crossing」作为证明依据。评论 02 §四 特别警告：floor 之后 `G(x+1)-G(x)` 的符号可以多次跳变，continuous/smooth 近似不能替代精确整数证明。
- **(B4) 证书与实例绑定**：`Cert(b,R,κ)` 依赖 level（隐含在公式与档位参数中）、BLU 标记、`b`、`R`、`κ`；本文不假设它可在任意参数范围内无条件成立。定理 3 正是说明它在真实区间失败。
- **(B5) 无 magic case**：不允许「某个等级/职业/品级用顶点、其它用精确搜索」这类未证明的分支。任何 vertex-only 的启用都必须以实例（或其全称参数域）上的证书为条件。

## 5. 精确命题

### 定理 1（无条件顶点公式与 boundary-only 归约：已否证）

**命题 (1a)** 以下全称命题为假：

```text
∀ level, job, b, R :  U(b,R,(+∞,+∞,+∞))
   = max( F_C(b_C+R)·F_H(b_H)·F_D(b_D),
          F_C(b_C)·F_H(b_H+R)·F_D(b_D),
          F_C(b_C)·F_H(b_H)·F_D(b_D+R) )
```

**命题 (1b)** 「边界归约」为假（无 cap 情形）：不存在一条「把内部点的目标值不降低地推到至少一个坐标为 0 的边界」的通用路径；即 `U` 的全局最优可以在**三个坐标都严格为正**的内部点取得。

**命题 (1c)** 对每个支持等级 `level ∈ {50,60,70,80,90,100}`，都存在精确反例（见 §6.1、§7 的逐等级表）。

### 定理 2（顶点最优的充分条件：已证明）

若 `Cert(b,R,κ)` 成立（三个属性对、所有定第三坐标切片都端点最大），则 `U(b,R,κ)` **存在顶点最优解**：存在一个满足「至多一个坐标严格位于边界之间」的最优分配。

**关于措辞的精确区分**：

- 定理断言的是**存在顶点最优解**（`∃`），不是「所有最优解都在顶点」（`∀`）。平台/并列会使内部点也是最优（§7）。
- 条件是**充分**的，**不是必要**的。§7 给出「顶点最优但证书失败」的精确实例，因此不能反过来要求证书成立才能顶点最优。
- 条件是对**所有**三个属性对与**所有**定第三坐标切片的要求；部分成立时见定理 4(4b) 的 facet 归约。

### 定理 3（证书可判定，但在真实区间失败：已证明 + 有限证书）

1. **可判定性**：对固定的 `(level, job, b, R, κ)`，`Cert(b,R,κ)` 是有限判定：三个属性对 × `(min(κ_k,S*)+1)` 个 `κ` × 每个切片的有限整数区间 `[L,U]`。因此它是**精确可判定**的（暴力 `O(S)` 扫描；利用 [pairwise-slice-critical-set](../pairwise-slice-critical-set/README.md) 的有限候选点集合只需检查更少的点即可做同一判定）。
2. **在真实区间失败**：在真实等级/因子范围内的具体实例上，`Cert` 为假，并给出显式的失败切片见证（§6.3）。因此 vertex-only **不得无条件启用**；任何启用必须逐实例（或对全称参数域给出证明后）检查证书。
3. **结论**：`顶点公式` 不是固定等级公式的定理，只能作为「证书通过时」的条件优化。

### 定理 4（无顶点假设的安全回退与部分归约：已证明）

1. **精确回退（有限关键点）**：

   ```text
   U(b,R,κ) = max { Π_i F_i(t_i) : t_i ∈ T_i(b_i,κ_i,R), Σ_i θ_i(t_i) <= R }
   ```

   即 [free-budget-upper-bound](../free-budget-upper-bound/README.md) 定理 3 的档位三元组预算公式；它不依赖任何端点/顶点/单峰假设，恒等于 `U`，可用 `prepareSubstatFactorBudgetQuery` 在预处理后以「每个 DHT 档位一次二分」的代价精确查询。

2. **部分归约（只有部分属性对证书成立；caps 感知）**：设属性对 `(i,j)` 的端点最大性质对**所有**定第三坐标切片成立（记 `Cert_{ij}`）；令 `S* = min(R, K)`、`K = Σκ`。定义二维精确极值

   ```text
   H_{ab}(T) = max { F_a(b_a + x) · F_b(b_b + T - x) : x ∈ [max(0,T-κ_b), min(κ_a,T)] }
   ```

   （区间为空或 `T<0` 时 `H_{ab}(T) = -∞`；`κ=+∞` 视为无上界）。则正确的精确归约是：

   - **一般 caps（含 caps 绑定）**：存在最优解落在四类 facet 的并上

     ```text
     {x_i=0} ∪ {x_j=0} ∪ {x_i=κ_i} ∪ {x_j=κ_j} ，
     ```

     且**精确四 facet 公式**为

     ```text
     U(b,R,κ) = max(
       F_i(b_i) · H_{jk}(S*),                         # x_i = 0
       F_j(b_j) · H_{ik}(S*),                         # x_j = 0
       S* >= κ_i 时  F_i(b_i+κ_i) · H_{jk}(S*-κ_i),    # x_i = κ_i（κ_i 有限）
       S* >= κ_j 时  F_j(b_j+κ_j) · H_{ik}(S*-κ_j)     # x_j = κ_j（κ_j 有限）
     )
     ```

     不可行 facet 取 `-∞`；每个 facet 都是固定一个坐标 `0`/`κ` 后的**二维精确问题**，可用 [pairwise-slice-critical-set](../pairwise-slice-critical-set/README.md) 的有限关键点集合精确求出。
   - **无 cap 绑定 + 证书（原两零 facet 版本）**：若再满足 **`(C1)` `S* <= min(κ_i,κ_j)`**（等价于 `κ_i,κ_j >= S*`，即该属性对的 caps 在满预算面不绑定），则 cap facet 不会给出新的自由坐标端点（`x_i=κ_i` 只能与其它坐标 `=0` 同时出现，仍落在零 facet），于是原等式**仍然成立**：

     ```text
     U(b,R,κ) = max( F_j(b_j) · H_{ik}(S*),  F_i(b_i) · H_{jk}(S*) )
     ```

   因此「一个属性对的证书」在 caps 不绑定时足以把三维优化精确降为两条二维切片；caps 绑定时必须用四 facet 公式（或退回 (4.1) 的精确档位公式）。三个属性对全部成立时仍回到定理 2 的 capped 顶点结论——**定理 2 不受本项修正影响**（其证明已按 `L=max(0,S-κ_j)`、`U=min(κ_i,S)` 处理 caps 端点；§7.4 的反例点本身就是一个 cap 顶点）。
   **警告**：不满足 `S*<=min(κ_i,κ_j)` 时，原两零 facet 公式可能给出 `-∞` 或严格低于 `U` 的值（§7.4：严格低于 `U` 的值会被误当作上界，不安全）；**禁止**在这种情况下使用二 facet 公式。

3. **无任何证书时的严格上界（不主张紧致）**：
   - 首选仍是 (4.1) 的精确公式（最强）。
   - 若连精确查询都不可用，可使用单资源 Lagrangian 上界 `prepareFactorResourceBudgetUpperBound`（`factor-resource-budget-upper-bound.ts:88-147`）等已在生产使用的严格上界；它是**另一个**上界，通常更松，本文不声称其与 `U` 相等或紧致。
   - **警告**：不能把未证明的 majorant / 经验 support 混入「安全上界」；不能因为「看起来更紧」把凸/凹方向搞反（comment 02 §六 的警告）。任何非精确 bound 都必须单独证明不等式方向（`upper >= U`）。

## 6. 证明

### 6.1 定理 1 的证明

记 `b = (200,200,200)`。所有档位与因子都由参考文档 §3–§4 的公式直接计算：

反例 A（`level = 100`，普通，`div = 2780`）：

- CRT 顶点 `g_C = 810`：`t_C = floor(200·810/2780) + 50 = floor(58.27) + 50 = 108`；`F_C(108) = 10^6 + 108·(108+350) = 1,049,464`。DHT 基线 `g_H = 200`：`t_H = floor(550·200/2780) = floor(39.57) = 39`，`F_H = 4,039`。DET 基线 `g_D = 200`：`t_D = floor((140·200 + 1000·2780)/2780) = floor(2,808,000/2780) = 1010`，`F_D = 1010`。乘积 `1,049,464 · 4,039 · 1,010 = 4,281,172,946,960`。
- DHT 顶点 `g_H = 810`：`t_H = floor(550·810/2780) = 160`，`F_H = 4,160`；CRT 基线 `g_C = 200`：`t_C = floor(40,000/2780) + 50 = 14 + 50 = 64`，`F_C = 1,026,496`；DET 基线 1010。乘积 `1,026,496 · 4,160 · 1,010 = 4,312,925,593,600`。
- DET 顶点 `g_D = 810`：`t_D = floor((140·810 + 2,780,000)/2780) = floor(2,893,400/2780) = 1040`，`F_D = 1040`；CRT 64、DHT 39。乘积 `1,026,496 · 4,039 · 1,040 = 4,311,858,037,760`。
- 三顶点最大为 DHT 顶点的 `4,312,925,593,600`。
- 内部点 `(9,245,356)`：`g = (209,445,556)`。`t_C = floor(41,800/2780)+50 = 15+50 = 65`，`F_C = 10^6 + 65·415 = 1,026,975`；`t_H = floor(550·445/2780) = 88`，`F_H = 4,088`；`t_D = floor((140·556 + 2,780,000)/2780) = floor(2,857,840/2780) = 1028`，`F_D = 1028`。乘积 `1,026,975 · 4,088 · 1,028 = 4,315,825,466,400 > 4,312,925,593,600`。
- 因此 (1a) 假。内部点三个坐标都 `> 0`，且它是完整 simplex 上的全局最优（[verify.mjs](verify.mjs) 穷举 `c+h+d = 610` 的 `(611·612)/2 = 186,966` 个点复核），故 (1b) 假。

反例 B（`level = 50`，BLU，`div = 341`，`det = 202`，`detTrunc = 5`）：

- BLU 的 CRT/DHT 档位带常数偏移（CRT `+250 = 50+200`，DHT `+200`），`b_C = 150`。例如 CRT 顶点 `g_C = 1700`：`t_C = floor(200·1700/341) + 250 = 997 + 250 = 1247`；`F_C(1247) = 10^6 + 1247·(1247+150) = 2,742,059`。
- 三个顶点乘积分别为 `14,073,535,555,730`（CRT）、`9,372,805,482,865`（DHT）、`11,701,499,473,650`（DET），三顶点最大为 CRT 顶点的 `14,073,535,555,730`。
- 内部点 `(1396,1,103)` → 贡献 `(1596,201,303)`：`t_C = floor(319,200/341)+250 = 936+250 = 1186`，`F_C = 2,584,496`；`t_H = floor(110,550/341)+200 = 324+200 = 524`，`F_H = 4,524`；`t_D = 5·floor((140·303+202,000)/1010) = 5·242 = 1210`，`F_D = 1210`。乘积 `2,584,496 · 4,524 · 1,210 = 14,147,634,483,840 > 14,073,535,555,730`。
- 因此 (1a)、(1b) 再次被否证；该例的间隙更大（52.65 bp），且全局最优仍严格内部。

(1c)：每个支持等级的紧凑反例见 §7 表 7.1（由 [verify.mjs](verify.mjs) 的逐等级扫描给出）。**第二轮审计修正**：见证只使用职业上限内的 `(level, job)` 组合（生成数据中 BLU 的 `maxJobLevel = 80`，故 level 90/100 不使用 BLU；level 90 使用 WHM、baseline `(100,100,100)`、`R = 100`，内部最优 `(5,59,36)`）。由于 (1a) 是局部否证即可推翻的全称命题，一个反例已足够；逐等级表只是排除「仅某一等级参数造成的巧合」。∎

### 6.2 定理 2 的证明

设 `Cert(b,R,κ)` 成立。由 [free-budget-upper-bound](../free-budget-upper-bound/README.md) 定理 2，取一个满预算（`Σx_i = S*`）最优解 `x`。

若 `x` 至多一个坐标严格位于其边界之间，则 `x` 是 `Δ` 的顶点（§3 的刻画），结论成立。

否则 `x` 至少有两个坐标严格位于边界之间。取其中两个 `i ≠ j`，令第三个坐标 `k` 固定为 `x_k =: κ`（显然 `0 <= κ <= min(κ_k,S*)`），令 `S = S* - κ`。切片上的可行区间为 `[L,U] = [max(0,S-κ_j), min(κ_i,S)]`，且 `x_i ∈ [L,U]`（因为 `x` 可行：`x_i >= 0`、`x_i <= S - x_j` 与 `x_i <= κ_i`）。由 `Cert_{ij}(S,κ)`：

```text
目标值(x) = G_{ij}(x_i; S, κ)          （G_{ij} 已含第三因子 F_k(b_k+κ)，不得再乘）
         <= max( G_{ij}(L; S, κ), G_{ij}(U; S, κ) )。
```

取使右边最大的那个端点，记为 `x'`：它满足 `Σx'_i = S*`、边界约束，故 `x' ∈ Δ`；其目标值 `>= 目标值(x) = U`，故 `x'` 也是最优解。而 `x'` 在坐标 `i` 或 `j` 上取到边界值（`L` 的端点是 `x_i = L`：若 `L > 0` 则 `L = S - κ_j`，即 `x_j = κ_j`；若 `L = 0` 则 `x_i = 0`；`U` 的端点同理是 `x_i = κ_i` 或 `x_j = 0`），第三个坐标不变。因此 `x'` 的「严格位于边界之间的坐标数」比 `x` 至少少 1。

对 `x'` 重复上述步骤。每次减少一个自由坐标，`S*` 与可行性保持不变，目标值不降。至多两步后得到至多一个自由坐标的最优解，即 `Δ` 的顶点。∎

**备注（caps 绑定）**：上述证明对任意 caps 成立，只需把切片端点换成 `L = max(0,S-κ_j)`、`U = min(κ_i,S)`，并把「顶点」按 §3 的「至多一个自由坐标」理解。评论 01 的三顶点公式是 `S* <= min_i κ_i` 时的特例；caps 把 `S*` 限制为 `K` 时 `Δ` 可能退化为单点（caps 点），此时顶点公式的候选集也必须相应改变。

### 6.3 定理 3 的证明

**可判定**：固定实例后，`Cert` 的每个量词都是有限集合：`κ ∈ [0, min(κ_k,S*)]` 有限；每个切片的 `x ∈ [L,U] ∩ Z` 有限。逐点用 `BigInt` 比较即可在有限时间内决定真值。利用 [pairwise-slice-critical-set](../pairwise-slice-critical-set/README.md)，切片最大值只需在「端点 + 阈值交点」的有限候选集合上比较，判定代价可进一步下降，但**判定性质不变**（有限、精确）。

**在真实区间失败**：在反例 A、B 的实例上，`Cert` 为假。直接见证（由 [verify.mjs](verify.mjs) 穷举全部切片得到）：

```text
反例 A（level 100 WHM b=(200,200,200) R=610）：
  DHT-DET 切片，固定 CRT 增量 κ=17（CRT 最终贡献 217），S=593，x*=78（DHT 增量 78，DET 增量 515）：
    切片最大 = 4,314,301,435,500
    端点 = (4,309,722,153,975, 4,310,789,181,000)      ← x=0 与 x=S 两端
    相对差 = 8.14 bp
  全部 3×(610+1)=1833 个切片中 1038 个违反端点最大。

反例 B（level 50 BLU b=(200,200,200) R=1500）：
  CRT-DET 切片，固定 DHT 增量 κ=887，S=613，x*=445（CRT 增量 445，DET 增量 168）：
    切片最大 = 11,121,233,392,760
    端点 = (11,048,725,376,520, 11,053,725,420,280)
    相对差 = 61.07 bp
  全部 3×1501=4503 个切片中 3340 个违反端点最大。
```

（这两个实例的全局最优也严格优于三顶点，见定理 1，因此失败不是「切片选得不好」的偶然，而是与顶点公式失效一致的必然现象：由定理 2 的逆否命题，顶点非最优 ⇒ `Cert` 为假。）

因此 `Cert` 不是「固定等级公式的普遍定理」；它只能作为逐实例（或经过完整参数域证明后）的条件证书。任何实现若默认 `Cert` 成立并只算顶点，都会在反例 A/B 这类输入上返回**严格偏低**的上界，从而不安全（上界必须 `>= U`）。∎

### 6.4 定理 4 的证明

**(4a) 精确回退**：这就是 [free-budget-upper-bound](../free-budget-upper-bound/README.md) 定理 3，引用其证明；本文不重复。

**(4b) 部分归约（caps 感知）**。设 `(i,j)` 的端点最大性质对所有定第三坐标切片成立（`Cert_{ij}`）。取满预算最优解 `x`（定理 2 of A）。

- 若 `x_i` 或 `x_j` 取到其边界值（`0` 或 `κ`），则 `x` 已在四 facet 并上。
- 否则 `x_i`、`x_j` 都严格位于边界之间。令 `k` 为第三坐标、`κ := x_k`、`S := S* - κ`；对 `x` 应用 `(i,j)` 切片的端点最大性质：存在端点 `x' ∈ Δ`，`目标值(x') >= 目标值(x) = U`，且 `x'_i` 或 `x'_j` 取到切片区间 `[L,U] = [max(0,S-κ_j), min(κ_i,S)]` 的端点。端点只有四种情形：
  `x_i = L = 0`、`x_i = L = S-κ_j`（即 `x_j = κ_j`）、`x_i = U = κ_i`、`x_i = U = S`（即 `x_j = 0`）。
  因此 `x'` 落在 `{x_i=0} ∪ {x_j=0} ∪ {x_i=κ_i} ∪ {x_j=κ_j}` 之一，且仍是最优解。

故存在最优解落在四 facet 并上。四个 facet 各自固定一个坐标，剩下两坐标满足 `Σ = S*`（或在 cap facet 上 `Σ = S*-κ_i`）与盒约束，其最大值正是上面四 facet 公式中的二维 `H` 表达式（区间定义与 facet 一致：下界使另一坐标不超 cap，上界使本坐标不超 cap；空区间 ⇒ facet 为空 ⇒ `-∞`）。由于每项都是对应 facet 上的精确最大值、且并集包含一个最优解，四者取 max 即为 `U`，等式成立。若 `(C1) S* <= min(κ_i,κ_j)`，则 `x_i=κ_i` 只能在其它坐标为 0 时出现（仍属零 facet），`x_j=κ_j` 同理，四 facet 公式化为原两零 facet 公式——这就是 (C1) 下原式仍成立的原因。∎

**(4c) 三个证书 ⇒ 顶点**：由定理 2（其证明已按 caps 端点处理），`U` 等于 capped 顶点最大值；本项 caps 修正只影响 (4b) 的零 facet 断言，不影响本结论。§7.4 的反例点 `(14,6,0)` 本身就是 `Δ` 的一个 cap 顶点，与该结论一致。∎

**(4d) 无证书时的严格上界**：精确回退 (4a) 是恒等式，天然满足 `>= U`。单资源 Lagrangian 上界满足 `upper >= U` 的证明属于其自身模块（`factor-resource-budget-upper-bound.ts:83-147`：上凸包 + 非负价格支撑线给出可加整数对数得分的上界，再取 `ceil`）；它作用在「每个因子独立的可加预算」模型上，是 `U` 的另一个松弛，因此 `>= U`，但一般更松。本文不声称任何非精确 bound 与 `U` 相等；也不允许把未逐层证明方向的 majorant 组合进来。

**关于「只保留上界方向」的廉价版本**：在 `Cert_{ij}` 成立时，(4b) 的等式还可以写成不显式求 `H` 的端点扫描形式

```text
K_feas = { κ ∈ Z : max(0, S*−κ_i−κ_j) <= κ <= min(κ_k, S*) }      （空区间切片直接不扫描）
U = max_{κ ∈ K_feas} max( G_{ij}(L(κ); S*−κ, κ),  G_{ij}(U(κ); S*−κ, κ) )
```

其中 `L(κ) = max(0, S*−κ−κ_j)`、`U(κ) = min(κ_i, S*−κ)`。**注意 `G_{ij}` 已按 §3 的定义包含第三因子 `F_k(b_k+κ)`**，所以扫描式外层**不能**再乘一次 `F_k`（否则如 `R=0` 时得到 `4.08e15` 而非 `4.08e12`，不再是精确等式）；**同时必须只扫描非空切片**（`L(κ) <= U(κ)`，等价于上式 `K_feas` 的下界；空切片强行取端点会得到越 cap 的非法点并可能 `>U`）。`K_feas` 的无穷 cap 约定：`κ_i=+∞` 或 `κ_j=+∞` 时 `S*−κ_i−κ_j = −∞`，下界取 `0`；`κ_k=+∞` 时上界取 `S*`。它只需 `O(S*)` 次因子求值（或按 `F_k` 的档位跳变与切片断点压缩），是「精确但比三维档位三元组枚举便宜」的版本；这里的「只保留端点」由 `Cert_{ij}` 逐切片保证其合法（每个**非空**切片的内部最大值不超过该切片端点最大）。**该扫描本身是 caps 感知的**（`L/U` 已含 caps），在 `Cert_{ij}` 成立时恒等于 `U`，不需要两个零 facet；只有当 `S* <= min(κ_i,κ_j)`（caps 不绑定于该属性对）时，它才可化简为两零 facet 的 `H` 公式。caps 绑定时必须保留 cap 端点（或按 §5 定理 4(2) 的四 facet 公式逐 facet 求 `H`）；§7.4 的反例中该扫描正确给出 `U`，而两零 facet 公式给出 `-∞`。**若 `Cert_{ij}` 不成立，则不能把内部最大值换成端点值**（那会得到低于 `U` 的不安全值）。若改用已证明的 majorant 代替 `H`，则只得到严格有效但可能不紧的上界——这种组合本文**不主张紧致性**；要与其它 bound 取 min，必须分别证明各自 `>= U` 后再合成。∎

### 7.2 充分条件不是必要的（必要性已否证）

`level = 50`、WHM、`b = (0,0,0)`、`R = 15`：

```text
U = 4,120,800,000,000（DET 顶点：F_C(50)=1,020,000，F_H(0)=4,000，F_D(1010)=1,010）
```

顶点最优成立。但 `Cert` 失败：DHT-DET 切片（固定 CRT 增量 `κ = 2`，`S = 13`）在 `x* = 5`（DHT 增量 5、DET 增量 8）处

```text
1,020,451 · 4,008 · 1,005 = 4,110,417,446,040
> 端点最大 = 4,102,213,020,000（两端点相等）
```

相对差 20 bp。因此「三个属性对全部端点最大」不是顶点最优的**必要**条件；把它当成必要条件会误判可用场景（虽然不会产生错误上界，但会造成不必要的回退）。**目前只能证明它是充分条件**；更弱的充要/参数化条件见 §12。

### 7.3 其它边界退化

1. **`R = 0`**：`Δ` 只有原点，三顶点公式与精确值都等于 `P(b)`，顶点公式平凡成立；这不能说明任何一般性。
2. **`R` 小于所有属性的首个跳档成本**：所有分配的目标值相同，于是三顶点公式恰好精确（任一顶点都是最优），`Cert` 平凡成立。这是「证书通过」的退化原因之一，不代表真实装备尺度上的行为。
3. **平台/并列**：「所有最优解都在顶点」为假。例如 `level = 100`、WHM、`b=(0,0,0)`、`R = 5` 时三个坐标都无法跨档（首跳成本 14/6/20），所有可行分配目标值相同；顶点是最优，内部点同样是最优。定理 2 只承诺存在顶点最优解。
4. **caps 绑定**：`S* = K` 时 `Δ` 退化为单点（caps 点），「三顶点」候选可能不可行（`S* > κ_i`）；正确的顶点集必须按 §3 的 capped 顶点刻画。评论 01 的三顶点公式只适用于 caps 不绑定的情形。caps 绑定还会使**定理 4(2) 的两个零 facet 归约失效**，见 §7.4 的精确反例。
5. **负贡献**：`g < 0` 时 canonical `Math.trunc(v+1e-7)` 与精确 floor 不等价（参考文档 §3.1），所有档位/因子论证失效；本文不主张负贡献域上的任何结论。正式候选路径的贡献逐项非负，故该分支不可达（参考文档 §2.2）。
6. **自由松弛本身**：反例 A/B 是**公式层面**的反例，说明「顶点公式」不是公式定理；它们不说明真实装备池的最优一定在内部（真实域可能根本达不到那些内部点）。剪枝安全性只依赖 `U` 是超集上界，不依赖反例点是否真实可达。

### 7.4 caps 绑定时两个零 facet 的反例（caps 绑定反例）

`level=100`、WHM、贡献基线 `b=(0,0,0)`、增量 caps `κ=(14,6,0)`、预算 `R=20` ⇒

```text
K = 14+6+0 = 20，S* = min(R,K) = 20，Δ = {x : 0<=x<=κ, Σx = 20}。
```

CRT-DHT 属性对（固定 DET=0，`S = S* = 20`）的满预算切片区间为

```text
[L,U] = [max(0, S-κ_H), min(κ_C, S)] = [max(0,20-6), min(14,20)] = [14,14]，
```

切片被 caps 压成**单点** `(14,6,0)`，端点最大证书 `Cert_{CH}` 空真成立。但：

| 分配 `(c,h,d)` | 因子乘积 |
| --- | ---: |
| `(14,6,0)` | **4,082,824,451,000**（= U，唯一满预算点，两个坐标都在 cap 上） |
| `(14,0,0)` | 4,081,804,000,000（`x_H=0` 零边界最大） |
| `(0,6,0)` | 4,081,020,000,000（`x_C=0` 零边界最大） |

两个零边界都**严格低于** `U`；并且满预算 `Δ` 上根本不存在 `x_C=0` 或 `x_H=0` 的点（两个零 facet 都为空，原两零 facet 公式给出 `-∞`）。因此原定理「存在最优解落在 `x_i=0` 或 `x_j=0`」及其 H 公式在此**不成立**；`(14,6,0)` 位于 `x_C=κ_C` 与 `x_H=κ_H` 两个 cap facet 上。改用 §5 定理 4(2) 的四 facet 公式（或 (4b) 的 caps 感知端点扫描/精确档位公式）可得 `U = 4,082,824,451,000`；使用端点扫描时必须用修正版（`G_ij` 已含第三因子、只扫非空切片，见 §6.4/F2/F3）。

**无 cap 绑定正例**（原公式仍成立）：`level=100`、WHM、`b=0`、`κ=(100,100,100)`、`R=8` ⇒ `S*=8 <= min(κ_C,κ_H)`，`Cert_{CH}` 成立；原两零 facet 公式 = 四 facet 公式 = U = `4,081,020,000,000`（verify.mjs `T4-nonbinding-two-facet-valid`）。

**结论/警告**：只有当 `S* <= min(κ_i,κ_j)`（caps 不绑定于该属性对）且 `Cert_{ij}` 成立时，才可用原两零 facet 公式；否则必须用四 facet 公式或精确档位公式，**不得**把二 facet 的低值当上界（它会低于 `U`，造成不安全剪枝）。

## 10. 应用前提与安全回退

### 10.1 该层要回答的问题

对候选装备或 partial branch，先用 [free-budget-upper-bound](../free-budget-upper-bound/README.md) 的 §10 构造 `b, R, κ` 与其它乘区的乐观上界；本文决定**用哪种方式计算 `U`**：

```text
A. vertex-only      ：若 Cert(b,R,κ) 通过 => U = max(顶点乘积)（有限次因子求值）
B. partial-facet    ：若仅 Cert_{ij} 通过        => U = caps 感知归约：
                       (B1) 一般 caps：四 facet 公式（0/κ 各两个 facet，每个 2D 精确 H）
                       (B2) 若 S* <= min(κ_i,κ_j)（caps 不绑定）：可简化成
                            U = max(F_j(b_j)·H_{ik}(S*), F_i(b_i)·H_{jk}(S*))
C. finite-critical  ：否则                        => U = 档位三元组预算公式（精确查询）
D. fallback         ：精确查询不可用             => 单资源 Lagrangian 上界 / 现有精确求解器
```

### 10.2 前提清单

- **P1–P8**：沿用 [free-budget-upper-bound](../free-budget-upper-bound/README.md) §10.2 的全部前提（公式域、baseline 下界、R/κ 乐观界、因子正性、BigInt、其它乘区乐观上界、查询可用）。
- **P9（证书完整性）**：`Cert` 或 `Cert_{ij}` 必须覆盖**所有**需要的切片：三个属性对（或所选属性对）× 第三坐标 `κ ∈ [max(0,S*−κ_i−κ_j), min(κ_k,S*)]` × 切片可行区间 `[L,U]`。不允许只抽查部分 `κ`、部分 baseline 或部分区间就宣称证书成立。**注意**：不能因为「某切片没有真实可达点」而跳过它——`Cert` 服务的是松弛最大值 `U`，其最大点可能在满预算面上而该面未必有真实点；真实域的和界（slab）只可用于真实域可行性/枚举（见 [substat-sum-lower-bound-pruning](../substat-sum-lower-bound-pruning/README.md) PR3）。**但要区分空切片**：`L(κ)>U(κ)` 的切片在松弛域中不可行（不属于需认证的可行切片，可直接跳过；强行取端点会产生越 cap 的非法点并可能大于 `U`，见 §6.4/F3）；`L(κ)<=U(κ)` 的可行切片即使没有真实可达点也必须认证。**caps 绑定检查**：`Cert_{ij}` 通过后，若 `S* > min(κ_i,κ_j)`（caps 绑定于该属性对），必须用四 facet 公式（0/κ 各两个 facet）或 caps 感知端点扫描，**禁止**退回两零 facet 公式（§7.4）：两零 facet 公式在该情形可能给出 `-∞` 或严格低于 `U` 的值。
- **P10（状态绑定）**：`Cert` 依赖 `(level, BLU 标记, b, R, κ)`；若同一预计算证书要在不同 `b/R/κ` 上复用，必须证明该证书对复用参数域**全称**成立（例如对某区间内的所有 `b` 证明），否则必须逐实例重查。禁止「在某装备池上验证过就全局启用」。
- **P11（无 magic case）**：不得按等级/职业/品级选择不同结论。§7.1 的表只是否证见证，不是启用条件。
- **P12（精确比较）**：顶点值、切片值、`U`、完整乘积都用 `BigInt`；DPS 用 `candidateUpperBoundCannotImproveIncumbent` 的交叉乘法（`exact-mip-candidate-upper-bound.ts:128-140`）。上界必须 `>= U`，否则剪枝不安全。

### 10.3 运行时决策过程（伪代码）

```text
function substatUpperBound(level, jobClass, b, R, kappa):
    Sstar = min(R, sum(kappa))
    # 仍用精确公式兜底：本层只决定「能否用更便宜的精确计算」
    exact = prepareSubstatFactorBudgetQuery(classTables(level, jobClass, b, kappa), maxWork)
    if exact is undefined:
        return LagrangianFallback(...)   # D 层；或跳过本层
    if Cert(level, jobClass, b, R, kappa):          # A 层（可选，若更便宜）
        return max over capped vertices               # 注意 Sstar/kappa 决定顶点集
    # 可选 B 层：若某个属性对的子证书通过（且比精确查询便宜）
    for (i,j) in pairs:
        if Cert_ij(level, jobClass, b, R, kappa):
            if Sstar <= min(kappa_i, kappa_j):
                return max(F_j(b_j)*H_ik(Sstar), F_i(b_i)*H_jk(Sstar))   # 无 cap 绑定的两零 facet
            else:
                return FourFacet(level, jobClass, b, R, kappa, i, j)      # caps 感知：0/κ 四个 facet
    return exact(R)                                   # C 层：精确公式
```

注意：A/B 层是否真的更便宜**未评估**；在证书代价高于精确查询时，直接走 C 层仍然完全安全（精确公式与顶点公式同为 `U` 的精确值，只在证书成立且更便宜时才有使用 A/B 的意义）。

### 10.4 安全回退与不可做的事

- 证书不通过 → 不降维，走 C 层精确公式。
- **caps 绑定不得用两零 facet**：`Cert_{ij}` 通过但 `S* > min(κ_i,κ_j)` 时，两零 facet 公式不是 `U` 的精确值（可能 `-∞` 或严格偏低）；必须用四 facet 公式/caps 感知端点扫描，或走 C 层。§7.4 给出精确反例。
- 精确查询不可用 → D 层（Lagrangian 上界 / 精确求解器 / 跳过该层）。
- **不可**：证书不通过时仍按三顶点近似；把「切片大多满足」当作「证书成立」；用经验阈值或「看起来顶点更高」做剪枝；把顶点值当作「真实可实现的最优」去删除真实装备（自由松弛不保证存在合法替代，comment 02 §七）。
- 顶点/边界值只能用于**上界**（`U` 的精确值）；剪枝语义仍是「若 upper 不能严格改善 incumbent 则分支不可改善」，不能用于构造或声明具体替代配装。

5. floor 实参非负（可达域）：CRT ≥ 50、DHT ≥ 0、DET ≥ `1000/detTrunc` ≥ 200（`detTrunc ∈ {5,2,1}`），故 `Math.trunc(v+1e-7) = floor(v)`（参考文档 §3.1；误差界证明见 [raw-tier-transform](../raw-tier-transform/README.md)）；负贡献域不满足该等价，不在定义域。
6. 本文的 `R`、`κ`、`(c,h,d)`、切片变量 `x` 是**贡献增量**（面板差值），偏移在差分中抵消；只有 baseline 与具体点需要按 §13.5 从面板换算。完整代数与不变性证明见 [free-budget-upper-bound](../free-budget-upper-bound/README.md) §13.2/§13.5。

### 13.5 应用契约：面板 → 贡献换算（本目录用法）

本文的降维流程在 §10.3 伪代码中接收 `b,R,κ`。若上游只有面板值：

```text
b_i   = P_i^0 − o_i          （o_CRT = o_DHT = sub，o_DET = main；不能统一平移）
R, κ 不变                    （贡献增量 = 面板差值）
切片变量 x 直接就是面板差值   （x = P_i − P_i^0）
```

不变性证明与 doc A §13.5 相同：`t_i` 只通过 `P − o_i` 依赖面板，因此 `Δ`、`G_{ij}`、`Cert`、顶点/内部最优、`U` 与全部反例在换算下逐点对应。**运行时校验**：用 `gearAndFoodValue` 当 `g` 前，验证 `getBaseStats` 归约（`baseStats[stat] = o_i`）在当前数据版本成立；BLU 的 `maxJobLevel = 80`，因此 level 90/100 不得与 BLU 组合（§13.6）。
