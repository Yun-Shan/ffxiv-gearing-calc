### 2.2 本文证明什么、不证明什么

范围内：

1. 归一化比值 `r_j` 的正性与上界 `r_j <= u_j`（定理 1）。
2. 损失和判据的等价形式、soundness（无严格改善）、严格变体、精确有理比较算法与整数缩放的安全性（定理 2）。
3. 既有单职业必要界 `candidateUpperBoundCannotImproveJointIncumbent` 是损失和判据在「其余职业 `u_k = 1`」时的特例；损失和判据在相同上界下不弱于单职业判据，并在精确实例上**严格更强**；给出一般 `n` 的非冗余充要条件（定理 3）。
4. 共享选择耦合不等式、其「只能作全局证书、不能判定具体方案」的精确语义，以及拉格朗日（共享变量乘子）形式的有效上界与仿射 majorant 模板（定理 4）。

- 不证明任何具体候选池、具体装备池或具体品级下的剪枝数量；不估计经验收益。

## 3. 符号、量词与定义域

### 3.1 对象

| 符号 | 含义 |
| --- | --- |
| `n`、`J_n = {1,...,n}` | 职业数（正整数）与职业下标集 |
| `S`、`s ∈ S` | 共享方案集合与其中一个共享方案 |
| `F_j` | 职业 `j` 在**与基线相同的目标与硬约束**下的全部合法完整配装集合 |
| `X_j(s) ⊆ F_j` | `F_j` 中共享槽位恰为 `s` 的全部合法配装（补全集合） |
| `x = (x_1,...,x_n)` | 一个联合配置：`x_j ∈ X_j(s)`，`s` 对所有职业相同 |
| `f_j: F_j -> Q_{>0}` | 职业 `j` 的精确目标值（§3.2） |
| `B_j ∈ Q_{>0}` | 职业 `j` 的归一化基线（§4 A3） |
| `r_j(x_j) = f_j(x_j)/B_j` | 具体补全的归一化比值 |
| `R_j(s) = max_{x∈X_j(s)} f_j(x)/B_j` | 共享方案级最优归一化比值（`X_j(s) ≠ ∅`） |
| `U_j(s) ∈ Q_{>0}` | 对 `max_{x∈X_j(s)} f_j(x)` 的**已证上界**（§4 A6） |
| `u_j(s) = min(1, U_j(s)/B_j)` | 归一化上界（损失和判据中的 `u_j`） |
| `l_j(s) = 1 - u_j(s) ∈ [0,1)` | 归一化损失 |
| `J(x) = Σ_j r_j(x_j)`、`J(s) = max_{x∈X(s)} J(x) = Σ_j R_j(s)` | 联合归一化目标值（给定 `s` 时各职业补全彼此独立，故 `J(s)` 可分离求和） |
| `J* = p/q` | 当前联合 incumbent 的精确归一化值，`p,q ∈ Z_{>0}` |
| `τ = J* - (n-1)` | 既有单职业判据的单职业阈值 |

「共享」的语义严格按领域规则（[领域与搜索规则.md](../../../rules/领域与搜索规则.md) 第 37–39 行）：同一共享槽位要求**同一物品与完整镶嵌/参数身份**（按部位名称对齐，不能只匹配属性总和）；主手、副手/盾牌始终由各职业独立选择；两枚戒指可分别或同时共享，未共享的一枚仍须满足唯一性，完整共享戒指对按无序身份多重集保留重复非 unique 戒指的重数；共享食物取各职业可用**物理身份**的交集。因此「同一 `s`」对不同职业可能产生**不同的属性贡献**（可变等级装备的 `main`/`secondary` 按职业解析），这正是需要逐职业 `U_j(s)` 的原因。

### 3.2 目标函数的精确定义

记六个伤害因子（单位与分母见参考模型 §4）：

```text
WD(x)  = weaponDamage(x)        MS(x) = mainStat(x)       （分母 100）
DET(x) = determination(x)       TEN(x) = tenacity(x)      （分母 1000）
CRT(x) = critical(x)            DHT(x) = directHit(x)
P_j(x) = WD·MS·DET·TEN·CRT·DHT  （BigInt 精确整数乘积）
c_j(x) = gcdCentiseconds(x)     （精确整数，> 0）
```

- `damage` 目标：`f_j(x) = P_j(x)`（正整数）。
- `dps` 目标：`f_j(x) = P_j(x)/c_j(x)`（正有理数）。

`traitMultiplier` 与各因子的固定分母对同一职业/等级为常量，比值与排序中抵消；本文始终对**同一职业**内部比较，因此只用上述 `f_j`。对 `dps` 的精确比较语义（`src/domain/search/exact-mip-candidate-upper-bound.ts:113-140`）为

```text
f_j(x) <= f_j(y)  <=>  P_j(x)·c_j(y) <= P_j(y)·c_j(x)
```

即代码中的 `upperProduct * incumbentGcd <= incumbentProduct * upperGcd`。本文所有比值、上界、比较都按这一精确有理语义进行，不使用 `Number`/`log`/浮点近似。

归一化后 `dps` 的比值为

```text
r_j = (P/c) / (B_P/B_c) = P·B_c / (B_P·c)
```

其中 `B_P, B_c` 是基线因子的乘积与 gcd；这与生产 `exactUpperRatio`（`src/domain/search/loadout-finder-exact-mip.ts:2415-2431`）的 `numerator = P·B_c`、`denominator = B_P·c` 一致。

**坐标声明（贡献 `g` vs 面板总值）**：本文出现的所有属性坐标、候选属性向量、baseline、剩余预算、caps 与 `U_j(s)` 构造，默认都在**贡献坐标** `g`（装备 + 镶嵌 + 食物带来的属性贡献）上；`f_j`/`r_j`/`U_j`/`B_j`/`J*` 是目标值或其无量纲比例，本身不含属性坐标，但它们的**求值输入**是贡献而非面板总值。归约链（权威事实见参考模型 §2.1/§2.2）：

```text
panel(stat) = baseStats[stat] + g_stat        （equipped-effects.ts:127）
tier 实参    = panel − sub（CRT/DHT/TEN，以及 SKS/SPS）
             = panel − main（DET）             （equipped-effects.ts:138-149）
⇒ tier 实参 = g_stat；且当前数据下 baseStats.CRT=DHT=TEN=SKS/SPS=sub、baseStats.DET=main
```

因此：**构造 `U_j(s)` 时若只有面板值，必须先减 `sub`/`main` 换成贡献再代入档位/因子公式**；直接把面板值当贡献会漏掉等级自带的基础属性（§13 的数值复核表与 V10 反例）。注意攻击主属性（STR/DEX/INT/MND）的基础值由 `getBaseStats` 的 `statModifiers`/`clanStats` 规则给出，一般不等于 `main`，其面板↔贡献换算以 `getBaseStats` 为基准（不是「面板−main」）；但求值器输入仍是贡献 `g_attack`。详细审计见 §13。

### 3.3 精确有理数约定

1. 有理数统一表示为二元组 `(a,b)`，`a ∈ Z`、`b ∈ Z_{>0}`、`gcd(|a|,b)=1`；`0` 记为 `(0,1)`。
2. 大小比较只用交叉相乘：`a/b <= c/d  <=>  a·d <= c·b`（`b,d > 0`）。全部运算在 `BigInt` 上进行。
3. 求和用公共分母或逐项约分累加（实现对应 `sumCappedRatios`，见 §9），不使用除法取整。
4. 截断 `u_j = min(1, U_j/B_j)`：先精确比较 `U_j` 与 `B_j`，再决定取 `1/1` 还是既约比值；不经过 `Number`。
5. 若为了整数模型而缩放取整：**上界分量向上取整**（`ceil`，如 `ceil(u_j·scale)`），**阈值分量向下或精确**（`floor(threshold·scale)` 再 `+1` 作为「严格超过阈值」的必要下界）。方向由定理 2.5 规定；方向错误会产生不安全剪枝（§7 C7、C8）。
6. 损失 `l_j = 1 - u_j` 是精确有理数；由定理 1 有 `u_j ∈ (0,1]`，故 `l_j ∈ [0,1)`。

### 3.4 量词与定义域

除特别注明外，本文定理对**任意**满足 §4 假设 A1–A8 的实例成立，量词顺序为

```text
∀ n ≥ 1，∀ 职业集 J_n，∀ 共享方案 s ∈ S，∀ 补全 x_j ∈ X_j(s)，
∀ 已证上界 U_j(s)，∀ 精确 incumbent J* = p/q（同一归一化尺度）
```

其中「存在」型命题（定理 3.3、3.4）给出显式见证或构造。「对具体方案」与「对整个 `S`」的结论在定理 4 中严格区分。定义域边界：`g >= 0` 是参考模型 §2.2 由「候选贡献逐项非负」推出的**结构性事实**（不是本文额外假设），且四个副属性分支的档位 floor 实参恒非负（CRT `>=50`、DHT `>=0`、DET `>=200`、TEN `>=1000`），故 `Math.trunc(v+1e-7) = floor(v)` 在可达域**无条件成立**；因子正性与单调性见参考模型 §5。构造 `U_j(s)` 时必须使用贡献坐标（§13）。

补充说明（A3/A5 的「归一化尺度」语义，必须区分两个概念）：

- **归一化尺度（normalization scale）**：任意 `B_j ∈ Q_{>0}`，只要求它在**同一尺度**下支配所有合法补全（`f_j <= B_j`），用作 `r_j = f_j/B_j` 的分母。它只决定「1 单位 = 多少目标值」，不要求可达。
- **可达基线（attained baseline）**：实际取到的单职业全局最优 `B_j = max_{F_j} f_j`。只有这种情况下 `r_j = 1` 才等价于「该补全达到单职业最优」，`1 - r_j` 才等于「相对真实可达最优的损失」。
- 若 `B_j` 只是已证上界而非可达最优，`r_j = f_j/B_j` **作为比值仍然有定义**，但它的语义从「相对可达最优的比例」变为「相对已证上限的比例」，`1 - r_j` 不再等于相对真实可达最优的损失；此时定理 1、2 仍然成立，但**必须对 incumbent、候选上界、阈值使用同一个 `B_j`**。混用不同尺度会使比较失去意义并可导致不安全剪枝（§7 C6）。若 `B_j` 不支配可行值（连上界都不是），则定理 1 的 `r_j <= 1` 失效、`min(1,·)` 截断点被误用，判据不健全（§7 C5）。
- 生产实现取的 `B_j` 是精确单职业最优（`src/domain/search/loadout-finder-v3.ts:1207-1218`、`:1294-1313`），因此语义是「相对可达最优」。§10.2 P2/P3 要求运行时区分「可达基线」与「仅上界的归一化尺度」，并在后者下重新解释 `J*` 与损失预算。

## 5. 精确命题

以下定理均在 §4 假设下陈述；证明见 §6。

### 5.1 定理 1（归一化范围与上界支配）

**定理 1.1（正性与归一化范围）**
设 A1–A3 成立。则对任意 `j`、任意 `s`、任意 `x_j ∈ X_j(s)`：

```text
0 < r_j(x_j) <= 1.
```

若进一步 `B_j` 是可达的单职业全局最优（`B_j = max_{F_j} f_j`），则 `r_j(x_j) = 1` 当且仅当 `x_j` 是单职业全局最优。

**定理 1.2（上界支配）**
设 A1–A3、A6 成立。则对任意 `j`、`s`、`x_j ∈ X_j(s)`：

```text
r_j(x_j) <= U_j(s)/B_j，  且  r_j(x_j) <= u_j(s) = min(1, U_j(s)/B_j)。
```

进而 `R_j(s) <= u_j(s)`（若 `X_j(s) ≠ ∅`）。

**定理 1.3（假设的必要性）**
定理 1.1 的 `r <= 1` 必须依赖 A2（`f > 0`）与 A3（`B_j` 支配 `f_j`）；定理 1.2 的 `r <= u` 还必须依赖 A6 中 `U_j(s)` 对**同一 `s`** 的有效性。缺少 A3 或把某个 `s'` 的上界用于 `s ≠ s'` 都可能使结论失效并导致不安全剪枝（精确反例见 §7 C5、C11）。

### 5.2 定理 2（损失和判据）

**定理 2.1（损失和等价形式）**
设 `n >= 1`，`J* = p/q`（`p,q ∈ Z_{>0}`），`u_1,...,u_n ∈ (0,1]`。则

```text
Σ_j u_j <= J*    <=>    Σ_j (1 - u_j) >= n - J*。
```

两边的差为同一有理数：`Σ(1-u_j) - (n-J*) = J* - Σu_j`；等号一一对应。若 `J*` 由可达联合方案按同一尺度计算，则 `J* <= n`，故 `n - J* >= 0`，右端是真正的「损失预算」。

**定理 2.2（soundness：不能严格改善）**
设 A1–A7 成立。对任意共享方案 `s` 与任意联合配置 `x`（`x_j ∈ X_j(s)`），若

```text
Σ_j u_j(s) <= J*，
```

则

```text
J(x) = Σ_j r_j(x_j) <= Σ_j u_j(s) <= J*，
```

即 `(s,x)` **不能严格改善** incumbent（严格改善定义为 `J > J*`）。等价地，若某方案能严格改善，则必有 `Σ_j u_j(s) > J*`。

**定理 2.3（严格变体与 tie 语义）**
在定理 2.2 条件下：

- 若 `Σ_j u_j(s) < J*`，则 `J(x) <= Σu_j < J*`，严格低于 incumbent。
- 若 `Σ_j u_j(s) = J*`，则只能推出 `J(x) <= J*`；**tie 可能发生**。因此 `<=` 判据只排除「严格改善」，不排除「同分」。
- 若任务要求保留或枚举 tie，则不得只凭 `<=` 删除同分方案；必须使用严格变体（`<`）或显式 tie 处理。

**定理 2.4（精确有理比较算法）**
设 `u_j = a_j/b_j`（`a_j,b_j ∈ Z_{>0}`，`1 <= a_j <= b_j`），`J* = p/q`（`p,q ∈ Z_{>0}`）。用 BigInt 维护累加对 `(A,B)`：

```text
(A,B) <- (0,1)
对 j = 1..n:
    A/B <- (A·b_j + a_j·B) / (B·b_j)，用 gcd 约分
判据：A·q <= p·B    （等价于 Σu_j <= J*）
```

算法只用加法与乘法（以及可选的最大公约数约分），没有除法取整与浮点，因此与精确有理比较完全等价。

**定理 2.5（整数缩放的必要性方向）**
设 `T ∈ Q_{>0}` 是某个严格阈值（全和时 `T = J*`；子集时 `T = J* - (n-k)`，见定理 3.5），缩放因子 `scale ∈ Z_{>0}`。定义向上取整系数 `c_j = min(scale, ceil(scale·u_j))`（当 `u_j <= 1` 时 `min` 不生效）与阈值下界 `R = floor(scale·T) + 1`。则

```text
Σ_j u_j > T   =>   Σ_j c_j >= R；
```

等价的剪枝方向为：`Σ_j c_j < R  =>  Σ_j u_j <= T`，即不能严格改善。证明只用「`c_j >= scale·u_j` 且 `R` 是严格大于 `scale·T` 的最小整数」。该定理给出实现中 `ceil` 取整 + `floor(T·scale)+1` 阈值的安全性依据（§9）。

### 5.3 定理 3（推广与非冗余性）

**定理 3.1（单职业判据是损失和判据的实例）**
记 `τ = J* - (n-1) = (p - (n-1)q)/q`。对任意有理上界比 `û = U_j/B_j`（`û >= 0`，分母为正），定义两个判定：

```text
PJ_j(û)  :=  [τ > 0 且 û <= τ]                                   （既有单职业判据）
LS_j(û)  :=  [û + (n-1) <= J*]                                   （其余职业 u_k = 1 的损失和判据）
```

则：

1. 若 `τ > 0`，则 `PJ_j(û) <=> LS_j(û)`；算式上 `û + (n-1) <= J* <=> û <= J* - (n-1) = τ`。
2. 若 `τ <= 0`，则 `PJ_j(û) = false`（生产实现用 `thresholdNumerator > 0` 守卫）；此时对正 `û` 有 `LS_j(û) = false`，唯一可能的例外是 `û = 0` 且 `J* = n-1`（此时 `LS_j` 取等号成立而 `PJ_j` 保守返回 false）。
3. 因此生产函数 `candidateUpperBoundCannotImproveJointIncumbent` 的判定与「`u_j = û`、其余 `u_k = 1`」的损失和判据一致（边界仅差上述保守情形）；且由于 `û <= τ <= J*-(n-1) <= 1`（`J* <= n`），触发时 `û` 必在 `(0,1]` 内，故它正是损失和判据在 `u_j = min(1,û)` 下的**合法实例**，其 soundness 由定理 2.2 保证。

**定理 3.2（包含方向：损失和判据不弱于单职业判据）**
设 `s` 是具体共享方案，`u_k = u_k(s) ∈ (0,1]` 是同一批已证上界。若对某个 `j` 有 `PJ_j(u_j)`（即 `u_j <= τ`，`τ > 0`），则

```text
Σ_k u_k = u_j + Σ_{k≠j} u_k <= u_j + (n-1) <= (J* - (n-1)) + (n-1) = J*，
```

即 `LS(s)` 也触发。所以**单职业判据的拒绝集合 ⊆ 损失和判据的拒绝集合**；在相同上界数据下，损失和判据至少和单职业判据一样强。反方向不成立（定理 3.3）。

**定理 3.3（非冗余精确实例）**
取 `n = 2`，`J* = 8/5`，`u_1 = 9/10`，`u_2 = 7/10`。则：

```text
τ = J* - (n-1) = 8/5 - 1 = 3/5
PJ_1：9/10 <= 3/5 ？  9·5 = 45 > 10·3 = 30  →  不触发
PJ_2：7/10 <= 3/5 ？  7·5 = 35 > 10·3 = 30  →  不触发
LS ：9/10 + 7/10 = 16/10 = 8/5 <= 8/5       →  触发（等号）
损失形式：Σ(1-u_j) = 1/10 + 3/10 = 4/10 = 2/5 = n - J* = 2 - 8/5  →  等号成立
```

即：两个单职业判据都不触发，而损失和判据触发；因此损失和判据**严格更强（非冗余）**。语义为「不能严格改善」：`J <= Σu_j = J*`，同分仍可能，按定理 2.3 处理 tie。
**严格变体**：取 `u_2 = 13/20`，则 `Σu = 9/10 + 13/20 = 18/20 + 13/20 = 31/20 < 8/5 = 32/20`，且 `13/20 > 12/20 = 3/5`（两个单职业判据仍不触发），损失和判据给出 `J < J*` 的严格结论。

**定理 3.4（一般 n 的非冗余充要条件）**
设 `n >= 2`，`τ = J* - (n-1)`。存在上界向量 `u ∈ (0,1]^n` 使得

```text
（i）所有单职业判据均不触发：u_j > τ（当 τ <= 0 时自动成立）
（ii）损失和判据触发：Σ_j u_j <= J*
```

当且仅当

```text
J* < n。
```

（`J* = n` 时不存在；`n = 1` 时两判据恒等，永无非冗余。）构造性证明：`J* < n` 时，

- 若 `τ <= 0`（即 `J* <= n-1`）：取 `u_j = J*/n`，则 `Σu = J*` 且每个 `u_j > 0 >= τ`；
- 若 `τ > 0`：令 `g = J* - nτ = (n-1)(n-J*) > 0`，取 `ε = g/(2n)`、`u_j = τ + ε`，则 `u_j <= 1`、`Σu = nτ + g/2 < J*` 且 `u_j > τ`。

若 `J* = n`，则 `τ = 1`、`J* <= n` 蕴含 `u_j <= 1 = τ`，故 (i) 不可能，且 `J* = n` 只能发生在每个职业都在同一共享方案下达到单职业最优（`r_j = 1` 对所有 `j`）的退化边界。

**定理 3.5（子集阈值族）**
对任意子集 `S ⊆ J_n`，`k = |S|`，令 `τ_S = J* - (n-k)`。若 `Σ_{j∈S} u_j <= τ_S`，则

```text
J(x) <= Σ_{j∈S} u_j + (n-k) <= τ_S + (n-k) = J*，
```

即不能严格改善。该判据等于损失和判据在未选职业上取 `u_k = 1` 的实例；且它被全量损失和判据弱支配（子集判据触发 => 全量判据触发，因为 `Σ_all u = Σ_S u + Σ_{J\S} u <= (J*-(n-k)) + (n-k) = J*`）。实现中的子集阈值族（大小 `1..3` 与 `n`）在代数上正是该族；`|S| = n` 的全量实例就是本判据的核心形式。

### 5.4 定理 4（共享选择耦合）

**定理 4.1（耦合不等式）**
设 `S` 有限，`u_j: S -> R` 任意（归一化时 `u_j(s) ∈ (0,1]`）。则

```text
max_{s∈S} Σ_j u_j(s) <= Σ_j max_{s∈S} u_j(s)。
```

定义耦合损失 `Δ = Σ_j max_s u_j(s) - max_s Σ_j u_j(s) >= 0`。右端是「每个职业可各自虚构一个最有利共享方案」的解耦松弛，左端才要求同一共享方案；`Δ` 就是「必须共用同一 `s`」带来的损失。对归一化 `u_j <= 1` 还有 `Σ_j max_s u_j(s) <= n`。

**定理 4.2（语义：只能作全局证书，不能判定具体方案）**
记 `ρ = Σ_j max_{s∈S} u_j(s)`。

1. 若 `ρ <= J*`，则对**所有** `s ∈ S` 有 `Σ_j u_j(s) <= J*`，即全局证书：「不存在任何共享方案能严格改善 incumbent」。这是定理 4.1 唯一能直接支持的剪枝结论（且它一次覆盖整个 `S`）。
2. 若 `ρ > J*`，则定理 4.1 对**任何具体 `s`** 都不给出结论：`ρ` 是「最优可达和」的上界，而不是某个给定方案的界。存在精确实例使每个具体方案都满足损失和判据、但 `ρ > J*`（§7 C12 与验证脚本 V7），因此不能用 `ρ` 取代逐方案的 `Σ_j u_j(s)` 判定。
3. 计算 `ρ` 需要每个职业的 `max_{s∈S} U_j(s)/B_j`，这本身是「单职业在共享约束下的最优化」；把它作为全局终止证书是合理的，但不能替代具体方案的损失和评估。

**定理 4.3（拉格朗日/共享变量乘子上界）**
设 `S` 有限、`n >= 2`、`u_j: S -> R` 任意。对任意 `λ = (λ_{j,s})_{j=2..n, s∈S} ∈ R^{(n-1)|S|}`：

```text
max_{s∈S} Σ_{j=1}^n u_j(s)
    <= max_{s∈S} [ u_1(s) + Σ_{j=2}^n λ_{j,s} ]
       + Σ_{j=2}^n max_{s∈S} [ u_j(s) - λ_{j,s} ]。
```

`λ = 0` 退化为定理 4.1。此外，对 `λ` 取下确界时等式成立：

```text
min_λ { 上式右端 } = max_{s∈S} Σ_j u_j(s)。
```

（这是共享分布线性规划的对偶；见 §6.4 的证明。）因此「耦合」本身不产生对偶间隙：任何差距都来自**对 `λ` 族的限制或对 `max_s` 的松弛**，而不是来自耦合不等式的形式。

**定理 4.4（共享特征仿射 majorant 模板）**
设 `φ: S -> R^m`，`K ⊆ R^m` 是已证凸松弛（`φ(S) ⊆ K`，例如逐坐标箱体 `l <= z <= u`）。若对每个 `j` 存在 `α_j ∈ Q`、`β_j ∈ Q^m` 使

```text
u_j(s) <= α_j + β_j·φ(s)     （∀ s ∈ S），
```

则以支撑函数 `h_K(b) = sup_{z∈K} b·z` 有

```text
max_{s∈S} Σ_j u_j(s) <= Σ_j α_j + h_K(Σ_j β_j)。
```

对箱体 `K = {z : l_k <= z_k <= u_k}`，`h_K(b) = Σ_k [ b_k >= 0 ? b_k·u_k : b_k·l_k ]`。这是可计算的严格上界模板；其紧度取决于共享特征与 majorant 的选取。

**定理 4.5（未解决：可计算的紧联合耦合界）**
在 §4 的实际元素（有限共享方案集 `S`、逐职业坐标极大上界 `U_j(s)`）上，是否存在一个可计算函数 `B(S, {U_j})` 满足：

1. 有效性：`max_{s∈S} Σ_j min(1, U_j(s)/B_j) <= B(S,{U_j})`；
2. 可计算性：计算量不超过逐职业上界表规模的多项式，**不逐个枚举 `S`**、也不求解与 `|S|` 同规模的线性规划；
3. 严格性：存在实例使 `B(S,{U_j}) < Σ_j max_{s∈S} U_j(s)/B_j`，且在实际装备池上 `B <= J*` 的概率非零。

目前只证明了定理 4.1（解耦界）与定理 4.3/4.4（精确但对 `λ`/特征受限）。**该命题未解决**，精确陈述见 §12 O1。

## 6. 证明

### 6.1 定理 1 的证明

**定理 1.1。** 由 A2，`f_j(x_j) > 0`；由 A3，`B_j > 0`。正数之比为正，故 `r_j = f_j/B_j > 0`。由 A3，`B_j >= f_j(x_j)`，两边除以正数 `B_j` 得 `r_j <= 1`。若 `B_j = max_{F_j} f_j` 且 `x_j ∈ X_j(s) ⊆ F_j`，则 `r_j = 1 <=> f_j(x_j) = B_j <=> x_j` 取到单职业全局最优。`∎`

**定理 1.2。** 由 A6，对每个 `x_j ∈ X_j(s)` 有 `f_j(x_j) <= U_j(s)`；除以 `B_j > 0` 得 `r_j(x_j) <= U_j(s)/B_j`。由定理 1.1，`r_j(x_j) <= 1`。两个上界同时成立，故 `r_j(x_j) <= min(1, U_j(s)/B_j) = u_j(s)`。对 `x_j` 取最大值得 `R_j(s) <= u_j(s)`。`∎`

**定理 1.3。** 必要性由 §7 C5 的精确反例（`B_j` 小于可行值时 `r > 1` 且 `u < r`，判据触发但存在严格改善）与 §7 C11（跨方案误用上界）直接给出。`∎`

### 6.2 定理 2 的证明

**定理 2.1。** 两边做恒等变形：

```text
Σ u_j <= J*  <=>  n - Σ u_j >= n - J*  <=>  Σ (1 - u_j) >= n - J*。
```

每个 `1 - u_j >= 0`（因为 `u_j <= 1`），`n - J* >= 0` 由 `J* <= n`（定理 1.1 对可达 incumbent 逐项求和）。等号情形显然一一对应。`∎`

**定理 2.2。** 对任意 `s` 与 `x_j ∈ X_j(s)`，由定理 1.2 逐项得 `r_j(x_j) <= u_j(s)`。求和：

```text
J(x) = Σ_j r_j(x_j) <= Σ_j u_j(s) <= J*。
```

严格改善要求 `J(x) > J*`，与上式矛盾。`∎`

**定理 2.3。** 第一条由 `J(x) <= Σu_j < J*` 直接得。第二条：当 `Σu_j = J*` 时只能得 `J(x) <= J*`；要看到 tie 真实可能，取 `n = 2`、`J* = 8/5`、某个方案的真实比值 `r = (9/10, 7/10)`（其 `u_j = r_j` 合法），则 `J = 8/5 = J*`；若另有 incumbent 同为 `8/5`，该方案与 incumbent 同分而非更优。因此 `<=` 判据只能排除严格改善；删除同分方案需要额外的 tie 语义授权（§10.2 P9）。`∎`

**定理 2.4。** 归纳证明累加不变式：每步后 `(A,B)` 是最简表示的 `Σ_{i<=j} u_i`（加法与约分保持有理数相等且分母为正）；最终 `A/B = Σu_j`。由 `B,q > 0`，

```text
A/B <= p/q  <=>  A·q <= p·B。
```

所有中间量是整数（BigInt），无除法取整与浮点，故算法与精确比较等价。`∎`

**定理 2.5。** 由 `c_j >= scale·u_j` 得 `Σc_j >= scale·Σu_j > scale·T`。左端是整数，右端是实数（有理数）；整数严格大于 `scale·T` 等价于至少为 `floor(scale·T)+1 = R`（`scale·T >= 0` 时）。剪枝方向是其逆否命题。实现中 `ratioUpperCoefficientExact` 的 `ceil` 与 `minimumScaledSum = thresholdNumerator·scale/incumbentDenominator + 1n`（整数除法，正数即 floor）恰好对应该方向（§9）。`∎`

### 6.3 定理 3 的证明

**定理 3.1。** 设 `τ = (p-(n-1)q)/q`。

1. `τ > 0` 时，

```text
û <= τ  <=>  û <= (p-(n-1)q)/q  <=>  û·q <= p-(n-1)q  <=>  û + (n-1) <= p/q = J*。
```

最后一步两边乘 `q > 0` 再整理。右端正是 `LS_j`（`Σ = û + (n-1)`）。生产函数（`src/domain/search/joint-candidate-upper-bound.ts:18-21`）算的正是 `T = p-(n-1)q`、`û_num·q <= û_den·T`，即同一不等式。
2. `τ <= 0` 时生产函数因 `T > 0` 守卫返回 false。对 `û > 0`，`û + (n-1) > n-1 >= J*`，故 `LS_j = false`；例外 `û = 0` 且 `J* = n-1` 时 `LS_j` 取等号成立，而生产实现保守返回 false（不剪枝，安全）。
3. 触发时 `û <= τ = J* - (n-1) <= n - (n-1) = 1`（用 `J* <= n`），故 `min(1,û) = û`，`u_j = û ∈ (0,1]`；于是 `LS_j` 是定理 2.2 的合法实例，其 soundness 成立。`∎`

**定理 3.2。** 已在命题中给出推导：`Σ_k u_k = u_j + Σ_{k≠j} u_k <= u_j + (n-1) <= τ + (n-1) = J*`，其中第二个不等号用每项 `u_k <= 1`，第三个用 `PJ_j` 触发。故 `LS` 触发。`∎`

**定理 3.3。** 全部为整数/有理数运算，见命题中的逐步等式与 §11 V6 的精确校验（交叉相乘 45>30、35>30、16/10=8/5、4/10=2/5=2-8/5）。严格变体 `31/20 < 32/20` 同理。`∎`

**定理 3.4。** 必要性：由定理 1.1，可达 incumbent 满足 `J* <= n`，故只剩 `J* = n`（`J* > n` 不可能）。此时 `τ = 1`，条件 (i) 要求 `u_j > τ = 1`，与 `u_j <= 1` 矛盾。`n = 1` 时 `τ = J*`，`PJ` 与 `LS` 是同一判定（定理 3.1），不存在「一个触发另一个不触发」的向量。
充分性：`J* < n`，分两种情形（命题中已给出构造并验证 `u_j ∈ (0,1]`、`u_j > τ`、`Σu <= J*`）：

- `τ <= 0`：`u_j = J*/n`；因 `J* > 0`、`J* <= n`，有 `u_j ∈ (0,1]`；`Σu = J*`；`u_j > 0 >= τ`。
- `τ > 0`：`g = J* - nτ = J* - n(J*-(n-1)) = (n-1)(n-J*) > 0`；取 `u_j = τ + g/(2n)`。则 `u_j > τ`；`Σu = nτ + g/2 < nτ + g = J*`；并且

```text
u_j <= 1  <=>  J* - (n-1) + g/(2n) <= 1  <=>  g/(2n) <= n - J*
          <=>  (n-1)(n-J*)/(2n) <= n-J*     （因 n - J* > 0）
          <=>  (n-1)/(2n) <= 1，
```

最后一式恒成立，故 `u_j <= 1`。见证存在。`∎`

**定理 3.5。** 推导见命题。子集判据触发 => 全量判据触发：`Σ_all u = Σ_S u + Σ_{J\S} u <= (J*-(n-k)) + (n-k) = J*`，其中未选职业每项 `u <= 1`。第二个「弱支配」方向由定理 3.3（`k=1` 即单职业判据）已给出反例。`∎`

### 6.4 定理 4 的证明

**定理 4.1。** 对每个固定 `s`，逐项有 `u_j(s) <= max_{s'} u_j(s')`，求和得 `Σ_j u_j(s) <= Σ_j max_{s'} u_j(s')`。左端对 `s` 取最大：`max_s Σu_j(s) <= Σ_j max_s u_j(s)`。`∎`

**定理 4.2。** (1) 若 `ρ <= J*`，则对每个 `s`，`Σ_j u_j(s) <= ρ <= J*`，由定理 2.2 得所有方案的配置都不能严格改善。(2) `ρ` 是 `max_s Σu_j(s)` 的上界而不是 `Σu_j(s)` 本身；存在性由 §7 C12 的精确矩阵实例给出（每个方案各自满足损失和判据，但 `ρ > J*`）。因此不能从 `ρ > J*` 推出任何具体方案的结论。(3) `ρ <= J*` 的全局证书与逐方案判定是「全称结论」与「特称判定」两种不同结论；前者一旦成立足以终止整个共享域搜索，后者用于逐方案/逐前缀剪枝，二者不可互换。`∎`

**定理 4.3。** 对任意 `s` 与任意 `λ`，

```text
Σ_j u_j(s) = [u_1(s) + Σ_{j>=2} λ_{j,s}] + Σ_{j>=2} [u_j(s) - λ_{j,s}]
          <= max_{s'} [u_1(s') + Σ_{j>=2} λ_{j,s'}] + Σ_{j>=2} max_{s'} [u_j(s') - λ_{j,s'}]。
```

中间等式只是加减同一批 `λ`；右端与 `s` 无关，对 `s` 取最大即得弱对偶界 `λ = 0` 时两项分别为 `max u_1` 与 `Σ max u_j`，即定理 4.1。
下确界等式：考虑线性规划

```text
max  Σ_{j,s} u_j(s)·y_{j,s}
s.t. Σ_s y_{j,s} = 1                （∀j）
     y_{j,s} - y_{1,s} = 0          （∀j>=2, ∀s）
     y >= 0
```

等式约束强制所有职业共享同一分布 `q_s = y_{1,s}`，于是目标 `= Σ_s q_s Σ_j u_j(s) <= max_s Σ_j u_j(s)`，且在单点分布处取等；另一方面该 LP 的对偶（对 `y_{j,s} - y_{1,s} = 0` 引入自由乘子 `λ_{j,s}`、对概率约束引入 `μ_j`）在消去 `μ` 后目标恰为上式右端，故由有限维 LP 强对偶，`min_λ` 右端 = `max_s Σu_j(s)`。`∎`

**定理 4.4。** 对任意 `s`，逐项代入 majorant 并求和：

```text
Σ_j u_j(s) <= Σ_j α_j + (Σ_j β_j)·φ(s) <= Σ_j α_j + sup_{z∈K} (Σ_j β_j)·z = Σ_j α_j + h_K(Σ_j β_j)。
```

对 `s` 取最大即得。箱体情形支撑函数按坐标分解，逐坐标在 `l_k, u_k` 取最大即可。`∎`

**定理 4.5。** 未证明；精确陈述与已排除的候选形式见 §12 O1。`∎`（标注为未解决）

## 7. 反例与边界退化

以下反例中，C3、C4、C5、C7、C8 与 C12 的判定/方向已固化在 [verify.mjs](verify.mjs) 的相应检查中（V5–V8）；其余为构造性反例，不依赖脚本。全部使用精确有理数/整数，不使用浮点。

### C1 损失和判据不能推出单职业判据（方向澄清）

定理 3.3 的同一组数据：`n=2, J*=8/5, u=(9/10,7/10)`。损失和判据触发，而两个单职业判据都不触发。因此：

- **正确方向**：单职业判据是损失和判据在其余 `u_k = 1` 时的实例（定理 3.1）；且单职业判据触发时损失和判据必然触发（定理 3.2）。
- **错误方向**：「损失和判据触发 => 单职业判据触发」不成立。该反例正是非冗余性的来源（定理 3.3/3.4）。

### C2 `n = 1` 退化

`n = 1` 时 `τ = J*`，`PJ` 与 `LS` 都化为 `u_1 <= J*`，两判据恒等，不存在严格更强。非冗余条件（定理 3.4）要求 `n >= 2`。

### C3 `J* = n` 边界

`J* = n = Σ_j r_j` 只能发生在每个职业都在同一共享方案下达到单职业最优（`r_j = 1` 对所有 `j`）。此时 `τ = 1`，任何 `u_j <= 1` 都触发单职业判据；损失和判据同样触发（`Σu <= n = J*`）。由定理 3.4，非冗余空间为空。实现中该边界直接终止搜索（`src/domain/search/loadout-finder-exact-mip.ts:4543`）。

### C4 `τ <= 0` 边界（`J* <= n-1`）

生产单职业判据因 `thresholdNumerator > 0` 守卫恒返回 false（不剪枝）；损失和判据仍可能有意义。精确例子：`n = 2`，`J* = 1/2`，`u_1 = u_2 = 1/4`：单职业阈值 `τ = -1/2` 不触发，而 `Σu = 1/2 <= J*` 触发。这属于保守退化：当 `J* <= n-1` 时单职业必要界没有剪枝能力，损失和判据仍可作构造性剪枝。

### C5 无效归一化基线（A3 必须）

设某职业真实可行目标值 `f = 2`，却取 `B = 3/2`（不支配可行值），`U = 2`（对 `f` 的合法上界），`n = 1`，`J* = 11/10`。则

```text
r = f/B = 2/(3/2) = 4/3 > 1
u = min(1, U/B) = min(1, 4/3) = 1
Σu = 1 <= 11/10 = J*  →  判据触发（声称不能严格改善）
但该方案 r = 4/3 > 11/10 = J*  →  实际严格改善。
```

失效点正是 `min(1,·)` 的截断：`u = min(1,U/B) < r` 当 `r > 1`。因此 A3（`B_j` 支配全部可行值）是 soundness 的硬前提。

### C6 归一化尺度混用（A3/A5 必须）

即使两个 `B` 都是合法上界，混用也不同尺度。抽象数值例：真实尺度 `B = 2`，incumbent `f = 2` 得 `J* = 1`；候选 `f = 3`（真实比值 `3/2 > J*`，严格改善）。若候选上界 `U = 3` 却用另一个合法上界尺度 `B' = 4` 归一化，得 `u = 3/4 <= 1 = J*`，判据错误剪掉该严格改善方案（同一候选若按 `B = 2` 得 `r = 3/2`）。结论：`B_j` 必须在 incumbent、上界、阈值三处**完全一致**；A3 只保证「每个尺度自身支配」，不保证跨尺度可比。

### C7 浮点比较的双向误判（A7 必须）

- 精确 `1/10 + 7/10 = 8/10`；IEEE-754 双精度计算 `0.1 + 0.7 = 0.7999999999999999 < 0.8`。若用浮点判断严格性，会把等号误判为「严格改善可能」。
- 精确 `1/10 + (7/10 + 1/(10·10^17)) = 8/10 + 1/(10·10^17) > 8/10`；同一 double 计算仍得 `0.7999999999999999 <= 0.8`。若用浮点做非严格剪枝判定，会把「精确和超过阈值」误判为「未超过」，即**错误触发剪枝**（不安全方向）。
  因此：判据的最终比较必须用 BigInt 交叉相乘（定理 2.4/2.5）；浮点只能用于启发式顺序，不能决定剪枝。

### C8 `J*` 向上取整不安全（A5 必须）

设真实 incumbent `J* = 3/2`，但阈值被向上取整为 `J*_used = 2`。某方案归一化上界 `u = (1,1)`（每个职业都不超过其基线）。损失和判据 `Σu = 2 <= 2 = J*_used` 触发，但该方案可能实际达到 `J = 19/10 > 3/2`，是对真实 incumbent 的严格改善。因此阈值只能取精确值或**向下**保守值；向上取整会产生不安全剪枝。

### C9 空补全集合（A8）

若 `X_j(s) = ∅`，则 `R_j(s)`、`r_j` 无定义，损失和判据不适用；这属于可行性问题，应使用可行性/共享冲突约束处理，不能把空集当作「上界为 0」塞进损失和（会错误地产生巨大损失并可能剪掉别的东西）。实现中 `coordinateUpperAttributes` 找不到候选时返回 `undefined`（`src/domain/search/loadout-finder-exact-mip.ts:2333、2368`），调用方跳过该上界而不是伪造 0。

### C10 未截断比值与 `J* = n` 的实现层不对称

生产单职业判据接受**未截断**的比值 `û = U_j/B_j`，可能在 `û > 1` 时不触发；损失和判据使用 `u_j = min(1,û)`。对 `J* < n`，二者判定完全一致（因为触发时 `û <= τ < 1`，未截断与截断相同）；在 `J* = n` 时二者可能出现差异（`û > 1` 时生产判据不触发而截断判据触发）。由于 `J* = n` 时搜索已终止（C3），该差异不影响正式结果；文档把它登记为**实现层保守不对称**，不改变定理陈述。

### C11 跨方案误用上界（A6 必须）

`U_j(s)` 必须针对同一个 `s` 的补全集计算。抽象反例：共享方案 `s1` 对职业 `j` 有补全可达 `f = 8`，共享方案 `s2` 对职业 `j` 只可达 `f = 3`（共享物品对职业 `j` 不利）；若把 `s2` 的紧上界 `U_j(s2) = 3` 用于判定 `s1`，则 `u_j = 3/B` 可能远小于真实 `8/B`，导致错误剪枝。`U_j(s)` 的构造必须先固定 `s` 已承诺的共享贡献（§10.1 步骤 1–2）。

### C12 耦合不等式无法判定具体方案

`n = 2`，`S = {s1,s2}`，`u_1(s1) = 1, u_1(s2) = 1/10, u_2(s1) = 1/10, u_2(s2) = 1`（全部为正，符合 `U/B > 0`）。则

```text
max_s Σ_j u_j(s) = 11/10，   Σ_j max_s u_j(s) = 1 + 1 = 2，  Δ = 9/10；
J* = 3/2 时每个具体方案都满足 Σu(s) <= J*（可剪），
但解耦界 ρ = 2 > J*，对任何具体方案都不给出结论。
```

反向地，若 `ρ <= J*`（如 `u_1 ≡ u_2 <= 1/2`、`J* = 11/10`），则一次给出「所有方案都不可严格改善」的全局证书。二者语义不同（§5.4 定理 4.2）。

## 10. 应用前提与安全回退

### 10.1 `U_j(s)` 的正确构造（充分条件）

以下构造保证 A6（严格上界）且尽量收紧；它对应实现中的 `coordinateUpperAttributes`（`src/domain/search/loadout-finder-exact-mip.ts:2298-2388`），但**其每个松弛步骤的合法性是运行时代码义务**，本文只给出充分条件与有限证书。

**坐标契约（本小节全部量都在贡献坐标上）**：baseline、候选属性向量、剩余预算、caps、`U_j` 一律是**贡献** `g`（装备 + 镶嵌 + 食物），不是面板总值；求值器与档位函数的输入也是贡献（`equipped-effects.ts:59-104`、`:110-154`；V10 有限核验）。若运行时只有面板值，先按参考模型 §2.1 换算：`CRT/DHT/TEN/SKS/SPS` 贡献 = 面板 − `sub`，`DET` 贡献 = 面板 − `main`；**不得**把面板总值直接代入档位/因子公式或坐标极大构造。（攻击主属性的基础值由 `getBaseStats` 的 `statModifiers`/`clanStats` 规则给出，一般不等于 `main`，见 §13.5。）

1. **固定共享承诺（贡献坐标）**：对共享方案 `s` 的每个共享槽位，确定物理物品与完整镶嵌/参数身份；按部位名称与物理身份映射到职业 `j` 的**贡献**（可变等级装备的 `main`/`secondary` 按职业解析；同一物理物品对不同职业的贡献可以不同）。承诺的对象是该职业在此共享方案下的贡献向量。主手、副手/盾牌不入共享，始终按职业私有处理。
2. **私有槽位贡献坐标松弛**：对每个**贡献坐标** `g_k`，取职业 `j` 私有候选（候选属性本身已是贡献：装备/镶嵌/食物合并后、尚未加基础属性）在**同一下标集合/限制**下的坐标最大值；对成对戒指槽先求「完整戒指对/受限身份」候选集合，再在集合内逐坐标取最大（实现 `:2334-2369`）。坐标极大贡献向量不必同时可达，但它是所有补全贡献向量的坐标上界。
3. **共享贡献预算/相关性收紧（可选、更紧）**：若希望保留 CRT/DHT/DET 的有限**贡献预算**与档位相关性，可用已证预算松弛查询（参考模型 §6 第 1、2 条）在松弛域上求最大乘积，而不是坐标极大。若采用 [free-budget-upper-bound](../free-budget-upper-bound/README.md) 的 `U(b,R,κ)`，其契约与本文一致且全部是贡献坐标：`b = (C0,H0,D0)` 是分支已提交的三属性**贡献** baseline，`R` 是剩余来源对三属性**贡献总和**的严格上界，`κ` 是逐属性**剩余贡献** cap；`U(b,R,κ)` 只上界 `critical·directHit·determination` 乘积，必须再乘以 WD/main/TEN 的乐观上界（DPS 还需最小 GCD 下界）才得到完整 `U_j(s)`。所有松弛都必须是真实可行域的**超集**；「顶点公式」只有在相应端点/顶点定理前提被验证时才能使用（参考模型 §6 与相关定理）。该档位三元组预算查询当前未接入正式搜索路径（参考模型 §6 第 2 条），因此只能作为可选的更紧来源/回退基础，不改变本文证明。
4. **戒指唯一性**：为了紧，保留无序身份多重集与重复非 unique 戒指的重数；只忽略唯一性约束会扩大集合，仍是安全上界但更松。任何「共享身份交换」都必须保持物理身份，不得只对属性总和做匹配（领域规则第 37–38 行）。
5. **食物**：若 `s` 固定共享食物身份，则逐职业按该物理身份的食物参数计算；若当前上界需要覆盖尚未固定的剩余食物选择，则对每个**贡献坐标**取**允许食物集合**上的最大值，并保留精确的取整与封顶公式（参考模型 §4；实现 `:2372-2387`；食物增益是加在贡献上的，仍属贡献坐标）。这会放宽「同一食物服务所有坐标」的耦合，但保持严格上界。独立食物策略下，每个职业在各自允许食物集合上取最大。
6. **DPS 的 GCD 方向**：`u_j = min(1, U_j/B_j)` 中 `U_j` 必须使用**最小可达 GCD**（等价于最大速度**贡献**，速度基值同样是 `sub`，见 §13.5），因子乘积使用同一松弛贡献向量；因为 `f = P/c`，`P` 越大、`c` 越小时 `f` 越大。由参考模型 §5，`P` 对相应贡献坐标非减、`c` 对速度贡献坐标非增，故坐标极大贡献向量同时给出「`P` 上界 + `c` 下界」，`U_j = P(up)/c(up)` 是有效上界。实现比较式见 `:2415-2431`。
7. **硬约束方向**：松弛只允许**扩大**可行集（丢弃约束检查、按坐标独立取最大都属于扩大）；不允许为了收紧而加入未经证明的新约束。空候选返回 `undefined`（`:2333、2368`）而不是伪造 0。
8. **特殊公式路径**：BLU 武器伤害查表、自定义参数武器（曼德维尔/义军）等若不能证明对应分量对松弛坐标的单调性，则不得套用坐标极大构造，必须单独证明或跳过该职业的该类上界。实现显式跳过 BLU 的 candidate-specific 上界（`:2448`），本文沿用该保守策略。
9. **精确化**：所有取整/封顶必须复现 canonical evaluator 语义（参考模型 §3.1、§4），最终把 `U_j/B_j` 化为既约精确有理数并 cap 到 1；不得用浮点近似上界。

**引理 10.1（坐标极大上界的有效性，充分条件）**
设 `g^up` 是**贡献**坐标的松弛向量，满足：对每个补全 `x_j ∈ X_j(s)` 的每个贡献坐标 `g_k(x_j) <= g^up_k`；目标各因子对其对应贡献坐标非减，`c` 对速度贡献坐标非增。则

```text
f_j(x_j) <= P_j(g^up)                     （damage）
f_j(x_j) <= P_j(g^up)/c_j(g^up)           （dps）
```

证明：逐因子用单调性得 `P_j(x_j) <= P_j(g^up)`；dps 再用 `c_j(x_j) >= c_j(g^up) > 0`，两边取倒数并乘正数。有限样本证书见 §11 V1（生产求值器、多个等级/职业、坐标极大构造、逐点 `r <= u`）。

### 10.4 与既有单职业判据的非冗余增益

- 相同上界数据下，损失和判据的拒绝集**包含**单职业判据的拒绝集（定理 3.2）；增量来自「多个职业同时 `u_j < 1`」的联合损失预算（定理 3.3/3.4）。
- 非冗余在 `n >= 2` 且 `J* < n` 时一般存在（定理 3.4）；`J* = n` 时两层判据重合，增量消失。
- 实现层的子集阈值族（大小 `1..3` 与 `n`，`:4091-4126`）与逐前缀直接比较（`:4070`）是同一判据族的不同表达；本文证明该族的代数结构与界，不评价其在具体装备池上的收益。

### 10.5 紧度与非冗余的构造建议

正确性（soundness）只要求 `U_j` 是已证上界；**非冗余**（真正多剪掉东西）还要求上界足够紧，使多个职业同时出现 `u_j(s) < 1` 且 `Σ_j u_j(s) <= J*`（定理 3.4 说明这种向量在 `J* < n` 时存在，但不保证某个具体 `U_j` 构造能达到）。构造建议：

1. **先固定共享承诺，再只松弛私有选择。** 命中方案 `s` 的共享槽位/共享食物身份必须作为硬承诺保留，只对剩余私有槽位与剩余食物选择做松弛（§10.1 步骤 1–2）。若把共享选择本身也松弛掉，`U_j` 会退化为接近单职业基线，`u_j` 接近 1，损失和判据退化（通常不再触发）。
2. **保留 CRT/DHT/DET 的有限贡献预算与可达性结构。** 逐坐标极大忽略预算相关性，松但安全；用已证的预算松弛/顶点查询（参考模型 §6 第 1、2 条、`free-budget-upper-bound`、`simplex-vertex-reduction`）可以在保持超集性质的同时显著收紧，从 `u_j ≈ 1` 降到有意义的值。若采用 `U(b,R,κ)`，注意其 `b/R/κ` 都是**贡献坐标**（§10.1 步骤 3、§13.6），且该档位三元组查询当前未接入正式搜索路径（参考模型 §6 第 2 条）。任何「顶点/端点」简化必须先验证对应定理前提，不能默认成立。
3. **DPS 的 gcd 界必须保持乐观方向。** 对每个补全 `c_j(x) >= c_j(up)`（即用最大速度/最小 GCD），并对因子乘积用同一 `up` 向量；见 §10.1 步骤 6 与引理 10.1。用「最大 GCD」或把 gcd 当常数都会破坏上界。
4. **共享食物与戒指约束只能朝放宽方向处理。** 共享食物：先取物理身份交集，再对未固定选择按坐标取最大（保留精确取整/封顶）；戒指：保留无序多重集与唯一性重数为紧度服务，忽略唯一性只扩大集合、仍安全但更松。任何「跨职业交换共享身份」都不得绕过物理身份与唯一性（领域规则第 37–38 行）。
5. **基线与联合必须复用同一目标与同一硬约束。** 若基线在同一目标/约束的**更大**可行域上求得，`B_j` 仍是合法上界（保守）；若基线用了更小的候选域或更强约束，`B_j` 可能不再支配联合可行值，必须重新认证（A3/A4；领域规则第 45 行禁止用单职业基线剪枝后的候选池代替联合候选池）。
6. **紧度是性能问题，不是正确性问题。** 上界过松只会让判据不触发（安全回退到精确求解）；上界过松本身**不会**产生不安全剪枝；产生不安全的是 A3/A6/A7 失效（§7 C5–C8、C11）。因此允许按运行时预算选择「坐标极大 / 预算松弛 / 放弃该上界」而不影响正确性。

## 12. 未解决问题

**O1（定理 4.5，核心未解决）可计算的紧联合耦合界。**
精确问题：给定有限共享方案集 `S`（同一物品+完整镶嵌/参数身份、戒指无序多重集唯一性、共享食物物理身份交集）与逐职业精确上界函数 `U_j(s)`（按 §10.1 构造或更强的已证上界），构造一个函数 `B(S,{U_j})` 满足：

1. `max_{s∈S} Σ_j min(1, U_j(s)/B_j) <= B(S,{U_j})`（严格有效上界）；
2. 计算量不超过逐职业上界表规模的多项式，不逐个枚举 `S`、也不求解与 `|S|` 同规模的 LP（否则等于枚举）；
3. 存在实例使 `B < Σ_j max_{s∈S} U_j(s)/B_j`（优于解耦界），且 `B <= J*` 在实际装备池上有非零出现概率。

已知：定理 4.1（解耦界，可计算但通常过松）、定理 4.3（`λ` 形式，弱对偶有效，但精确最优需要 `|S|(n-1)` 个乘子或等价的 `max_s` 访问）、定理 4.4（仿射 majorant 模板，需要共享特征与凸松弛的可计算表示）。缺口在于：当前 `U_j(s)` 由逐职业坐标极大给出，**没有暴露对 `s` 的凸/仿射结构**；如何从候选模型（共享物品身份、镶嵌、食物、戒指多重集）构造可证明的共享特征松弛并保持有理数精确取整，未知。

**O2 BLU 与自定义参数武器的上界构造。**
BLU 武器伤害查表（`equipped-effects.ts` 中的 `blueMageWeaponDamageAddition`）与自定义参数武器（曼德维尔四参数、义军四槽分配）对松弛坐标的单调性/上界构造尚未一般化证明。当前安全策略是跳过这些路径的归一化上界（实现跳过 BLU candidate-specific 上界）。未解决问题：为这些路径给出可证明的 `U_j(s)` 构造，或证明其单调性以复用 §10.1。

**O3 仅能证明「基线上界」而非可达最优时的语义。**
若精确单职业最优不可得（例如基线求解超时）而只有已证上界 `B_j^up`，定理 1、2 的证明仍然成立（只要 A3 成立且三处同尺度），但 `J*` 变为「相对已证上限的归一化分数」，`n - J*` 不再是相对可达最优的损失预算；此时损失和判据的 soundness 仍在，但可解释性与紧度下降。未解决：为「基线仅上界」场景给出保持原损失语义的替代判据（例如同时维护可达下界与已证上界区间），并证明剪枝安全。

### 13.3 归约链（事实层）

1. **源码**：`equippedAttributeTier` 先算 `value = (baseStats[stat] ?? 0) + gearAndFoodValue`，再按分支减 `sub` 或 `main`（`src/domain/search/equipped-effects.ts:127-149`）；`getBaseStats`（`:178-203`）对 `"main"`/`"sub"` 类基础属性取 `floor(levelMod[kind] * statModifier / 100) + clanStats[stat][0]`。
2. **数据推导**（不是定义）：当前生成数据 `baseStats = {CRT:"sub", DHT:"sub", DET:"main", TEN:"sub", SKS:"sub", SPS:"sub", ...}`；`clanStats` 与 `jobSchemas[*].statModifiers` 都不含这些副属性键，故对全部职业与支持等级 `baseStats.CRT = baseStats.DHT = baseStats.TEN = baseStats.SKS = baseStats.SPS = sub`、`baseStats.DET = main`（参考模型 §2.1；V10 逐等级核验）。
3. **归约结论**：`value − sub`（CRT/DHT/TEN/SKS/SPS）与 `value − main`（DET）精确等于贡献 `g`；因此面板↔贡献换算为

```text
CRT/DHT/TEN/SKS/SPS 贡献 = 面板 − sub
DET 贡献                = 面板 − main
```

4. **可达域非负**：正式候选路径贡献逐项非负（参考模型 §2.2 的结构性结论），故 `g >= 0`，且四个副属性档位 floor 实参恒非负（CRT `>=50`、DHT `>=0`、DET `>=200`、TEN `>=1000`）；`Math.trunc(v+1e-7) = floor(v)` 在可达域**无条件成立**，不需要把它当运行时守卫。
5. **攻击主属性注意**：攻击主属性（STR/DEX/INT/MND）的基值走 `getBaseStats` 的 `statModifiers`/`clanStats` 规则，**一般不等于 `main`**（例如 WAR 100 级 STR 基值 464、`main = 440`，V10 记录）。因此「面板 − main」只对 DET 成立；攻击主属性若需从面板换算，必须用 `getBaseStats` 给出的基值。求值器输入仍是贡献 `g_attack`，本定理不依赖该换算（只消费 canonical evaluator 的输出）。若数据版本更新导致 `baseStats`/`clanStats`/`statModifiers` 变化，§2.1 的推导必须重新核验（参考模型 §2.1 末段），V10 会因此失败并提示重跑。

**（a）与 `free-budget-upper-bound` 的 `U(b,R,κ)` 契约一致性核对**（逐项）：

| `U(b,R,κ)` 契约项 | §10.1 审计前 | §10.1 审计后 |
| --- | --- | --- |
| `b = (C0,H0,D0)` 是已提交的三属性**贡献** baseline（不是面板值） | 未显式声明坐标 | 步骤 3 明确「三属性贡献 baseline」 |
| `R` 是剩余来源对三属性**贡献总和**的严格上界 | 只写「有限总预算」，口径歧义 | 改为「有限**贡献**预算 `R`」并给出语义 |
| `κ` 是逐属性**剩余贡献** cap（允许 +∞） | 未出现 `κ` | 补 `κ` 语义与「必须是已证乐观界」 |

| 档位三元组查询当前**未接入正式搜索路径** | 未说明 | 补参考模型 §6 第 2 条与「仅作可选更紧来源/回退基础」 |

结论：**修正后与 `U(b,R,κ)` 契约一致**；修正只涉及文档口径，不改变引理 10.1 的有效性论证（其证明本就以贡献坐标的单调性为前提）。

**（b）运行时契约 K1–K9**：

- **K1（求值输入）**：凡是调用 `equippedAttributeTier` / 整数因子求值器 / canonical evaluator 的地方，传入的一律是**贡献** `g`；禁止传面板总值（V10 反例给出量化差异）。
- **K2（面板→贡献换算）**：`CRT/DHT/TEN/SKS/SPS`：面板 − `sub`；`DET`：面板 − `main`；攻击主属性：面板 − `getBaseStats(attackStat)`（不是面板 − `main`）；WD 是基础 0 的加法量，不做减法。
- **K3（共享承诺）**：`s` 固定共享槽位物理身份后，逐职业得到的是**贡献向量**（同一物品对不同职业可不同）；固定共享承诺后再对私有槽位做贡献坐标松弛（§10.1 步骤 1–2）。
- **K4（`U_j(s)` 构造）**：baseline、剩余贡献预算 `R`、逐属性剩余贡献 caps `κ` 全部用贡献坐标；若用 `U(b,R,κ)`，它只上界 `critical·directHit·determination` 乘积，需再乘 WD/main/TEN 乐观上界与 DPS 最小 GCD 下界；查询未接入生产时只能作可选更紧来源（§10.1 步骤 3）。
- **K5（基线 `B_j`）**：由 canonical evaluator 在**贡献空间**的候选上求得精确单职业最优（生产 `loadout-finder-v3.ts:1207-1218`）；不是面板统计量，也不得由面板值直接构造。
- **K6（食物）**：食物增益是**贡献增量**；其计算可能使用 `baseValue`（基础属性）与贡献 `raw`（参考模型 §2.2 的公式），上界构造必须逐字复现该公式与取整/封顶，不允许用面板近似。
- **K7（算术/取整）**：定理 2.4/2.5 的精确有理比较与保守取整方向不变；坐标换算不引入浮点。
- **K8（fail-closed）**：若只拿到面板值且无法可靠换算（例如特殊攻击主属性基值缺失、数据版本不一致），按 §10.3 跳过该层剪枝，不得用估计基值继续。
- **K9（数据版本联动）**：若 `baseStats`/`clanStats`/`statModifiers` 变化，参考模型 §2.1 的推导与 V10 必须重跑；变化后仍满足归约才可沿用本文的 `U` 构造契约。
