## 2. 范围与依据

### 2.1 范围

本定理只处理一个**纯代数**问题：给定两条"因子转移"的起点/终点与 raw 成本，如何精确判定哪一条的单位成本对数增益更大。它是公式坐标上的命题，不涉及装备池、孔位、食物、同步、MIP、搜索策略或性能。

本定理**不**主张：

- 不主张跨属性的边际比较可以直接用于真实装备空间的剪枝或删除装备；
- 不主张逐单位贪心能导出全局最优（见 §5 定理 3 的适用范围与 §12）；
- 不主张任意部分窗口之间的比较可以用"档位转移"的边际代替（部分窗口需要 [raw-marginal-envelope](../raw-marginal-envelope/README.md)）；
- 不重复证明档位映射、阈值与周期等基础事实，这些由 [raw-tier-transform](../raw-tier-transform/README.md) 与 [canonical evaluator 参考模型](../../canonical-evaluator-reference.md) §2–§3 给出。

## 3. 符号、量词与定义域

- `Z`：整数集；`Z_{>0}={1,2,...}`；`Q_{>0}`：正有理数集。
- **坐标约定（贡献坐标）**：本文的 `g`、区间、阈值 `g_k`、成本 `cF/cG` 与全部数值例子都采用**贡献坐标**：属性贡献 = 面板总值 − 基础属性（CRT/DHT/TEN 减 `sub`，DET 减 `main`；换算见[参考模型 §2.1](../../canonical-evaluator-reference.md)）。`F0,F1,G0,G1` 是**因子值**（由整数档位唯一决定）。因子公式不含 baseStat，故因子级命题不受 baseStat 影响；**不得**把面板总值直接当作 `g`/成本使用（完整审计见 §13）。
- `F0,F1,G0,G1 ∈ Z_{>0}`：被比较的两条转移的因子起点/终点。这里 `F` 与 `G` 只是两条转移的记号，可以来自同一种因子（例如 CRT 的两个档位转移）或不同因子；它们不必属于同一属性。
- `cF,cG ∈ Z_{>0}`：两条转移的 raw 成本（投入的属性贡献单位数，即贡献坐标下的阈值差）。**本文只处理正整数成本**；成本为 0 的退档转移在 canonical 模型中真实存在（见 §7.4），但不满足本定理前提。
- `ln`：自然对数。对正数 `x`，`ln x` 有定义且严格单调。
- 转移（edge）：三元组 `e=(A,B,c)`，`A,B ∈ Z_{>0}`，`c ∈ Z_{>0}`；其单位成本对数增益定义为
  `U(e) := ln(B/A)/c`。
- 完整 tier 转移：对固定 `(level, job, stat)` 与因子 `F`，设档位序列 `t_k` 与阈值 `g_k`（**`g_k` 以贡献为单位**：使 `t(g) ≥ t_k` 成立的最小贡献 `g ≥ 0`）。从第 `k` 档到第 `k+1` 档的完整转移为
  `F0=F(t_k)`、`F1=F(t_{k+1})`、`cF=g_{k+1}-g_k`。
  只有这种"起点/终点均在档位阈值上"的转移才对应本文的边际判据；任意部分窗口的增益由 [raw-marginal-envelope](../raw-marginal-envelope/README.md) 的精确窗口公式给出。
- 定义域：属性贡献 `g ∈ Z_{≥0}`（当前候选模型保证；结构性论证见[参考模型 §2.2](../../canonical-evaluator-reference.md)：基础属性归约 + 候选贡献非负 ⇒ 档位实参恒非负）。canonical evaluator 的 `floor = Math.trunc(v+1e-7)` 在可达域上与精确 `floor` 等价（证明在 [raw-tier-transform](../raw-tier-transform/README.md)；本文引用该结论）。
- 量词约定：本文的"对所有……成立"均指对所有满足显式前提的整数/转移成立；反例均给出具体整数。

## 4. 假设

(A1) **正性**：`F0,F1,G0,G1 > 0`。canonical evaluator 通过 `safeDamageFactors`（`exact-mip-candidate-upper-bound.ts:96-106`）要求七个整数因子均为**安全正整数**；在 `g ≥ 0` 上 `F_C ≥ 1,000,000`、`F_H ≥ 4000`、`F_D ≥ 1000`，故 (A1) 对真实定义域成立（正性的全局证明见 [canonical evaluator 参考模型](../../canonical-evaluator-reference.md) §5 与 [tier-log-curvature](../tier-log-curvature/README.md)）。本定理把正性列为**显式前提**，因为它不可省略（§7.3）。

(A2) **正成本**：`cF,cG ∈ Z_{>0}`。成本必须是原始属性单位数，且严格为正。

(A3) **定义域**：`g ≥ 0`（由基础属性归约 + 候选贡献非负结构性成立，参考模型 §2.2），且档位/因子为整数模型（不是重新定义的浮点近似）；截断等价性由 [raw-tier-transform](../raw-tier-transform/README.md) 提供。

(A4) **完整档位转移**：两条被比较的转移都是完整 tier 转移（§3 的定义），成本为对应阈值差。

(A5) **用途范围**：判据可用于（a）自由资源松弛中的单步局部交换排序与启发式打分，（b）为精确交换判据/上界提供快速前置判断。**不得**仅凭它删除真实装备或证明全局最优；真实装备空间的严格判据见 [attribute-swap-criterion](../attribute-swap-criterion/README.md) 与 [strict-improvement-frontier](../strict-improvement-frontier/README.md)。

(A6) **坐标前提（贡献坐标）**：`F0,F1,G0,G1` 必须是由**贡献坐标**档位算出的因子值；`cF,cG` 必须是由贡献坐标阈值算出的正整数阈值差。baseStat 只作为 `panel = baseStat + 贡献` 的换算常数（CRT/DHT/TEN 为 `sub`，DET 为 `main`），不进入任何因子或成本公式。面板总值不得直接当作 `g`/成本输入（§13 审计；面板与贡献的换算见[参考模型 §2.1](../../canonical-evaluator-reference.md)）。

## 5. 精确命题

### 定理 1（三种等价形式）

设 `F0,F1,G0,G1 ∈ Z_{>0}`、`cF,cG ∈ Z_{>0}`。则以下三式等价：

```text
(i)   ln(F1/F0)/cF  ≥  ln(G1/G0)/cG
(ii)  F1^cG · G0^cF ≥ F0^cG · G1^cF
(iii) (F1/F0)^(1/cF) ≥ (G1/G0)^(1/cG)          （几何均值形式）
```

并且：把任意一式中的 `≥` 换成 `>`（严格形式）或 `=`（等式形式），三者仍逐式等价。特别地，`(ii)` 是纯整数不等式，可用 `BigInt` 精确判定，不需要任何浮点运算。

> 记号提醒：`(ii)` 中因子侧的指数是**对方**的成本（`F1` 的指数是 `cG`，`G0` 的指数是 `cF`），这正是 comment-02 §七 的更正内容。

### 定理 2（issue 正文形式不等价；偏差恒等式）

记

```text
正确形式： A  := F1^cG · G0^cF,      B  := F0^cG · G1^cF
issue 形式：A' := (F1·G0)^cG,        B' := (G1·F0)^cF
```

则对一切正整数输入有**精确有理恒等式**

```text
A' = A · G0^(cG−cF)        B' = B · F0^(cF−cG)
A'/B' = (A/B) · (F0·G0)^(cG−cF)
```

取对数（把比较量视为实数）得到两种"比较标量"之差：

```text
[cG·ln(F1·G0) − cF·ln(G1·F0)] − [cG·ln(F1/F0) − cF·ln(G1/G0)]
    = (cG−cF)·(lnF0 + lnG0)
    = (cG−cF)·ln(F0·G0)
```

若把两边都除 `cF·cG` 化成"每单位成本"标量，则差为 `(cG−cF)/(cF·cG)·ln(F0·G0)`。

推论：

1. 两种形式对**所有**输入给出相同真值，当且仅当 `cF = cG` 或 `F0·G0 = 1`（正整数下即 `F0=G0=1`）。当 `cF ≠ cG` 时，issue 形式的判定等价于把正确比值 `A/B` 与阈值 `(F0·G0)^(cF−cG)` 比较，而正确判据的阈值是 `1`；因此两种错误方向都可能发生。
2. 特别地，issue 形式在 `cF = cG` 时恰好正确——这正是这个错误长期不易被发现的原因（§7.3）。
3. §7.1、§7.2 给出两个精确整数反例：一个在真值为"相等"时 issue 形式判"严格更差"；另一个把顺序完全反转。§7.5 给出 canonical evaluator 上真实公式参数的反例。

### 定理 3（序与链式/复合引理）

在转移集合 `E={(A,B,c): A,B,c∈Z_{>0}}` 上定义 `e1 ≽ e2 :⟺ U(e1) ≥ U(e2)`（`U(e)=ln(B/A)/c`）。则：

1. **全预序**：`≽` 自反、传递、任意两条可比较；且 `e1 ≽ e2` 当且仅当 `(F0,F1,cF)=(A1,B1,c1)`、`(G0,G1,cG)=(A2,B2,c2)` 满足定理 1 的交叉指数判据。
2. **链式（复合）引理**：若 `e1=(A,B,c1)`、`e2=(B,C,c2)` 可复合，则复合转移 `e1∘e2=(A,C,c1+c2)` 满足

   ```text
   U(e1∘e2) = (c1·U(e1) + c2·U(e2)) / (c1+c2)         （加权平均）
   min(U(e1),U(e2)) ≤ U(e1∘e2) ≤ max(U(e1),U(e2))
   ```

   且不等式严格当且仅当 `U(e1) ≠ U(e2)`。故**复合/打包永远不会比其最好的组成转移有更高的单位增益**；逐单位增益无法靠"捆绑"被放大。
3. **传递性**：`U` 是实数，`≽` 的传递性直接来自实数序；因此对任意多条转移做两两交叉指数比较后得到的是与某个实数排序一致的偏序（不存在循环）。
4. **适用范围限制（重要）**：上述比较只对**单次完整 tier 转移**的"局部交换"有意义。原因是：(a) 部分窗口的增益依赖起点余数，不是档位增益（见 [raw-marginal-envelope](../raw-marginal-envelope/README.md) 的窗口公式）；(b) 不同属性的档位阈值网格**不同步**（`a/q` 不同、周期不同），一次交换后双方的起点档位都改变，下一单位的最优选择随之改变；逐单位贪心与"边际平衡点"都**不能**单独推出全局结论。issue-3-comment-02 §四/§五已警告"连续近似的边际平衡只意味着微分趋势"，而 floor 后会出现多次符号跳变；相应的反例（端点最大不成立、切片内部严格局部极大）由 [pairwise-endpoint-max](../pairwise-endpoint-max/README.md) 与 [pairwise-slice-critical-set](../pairwise-slice-critical-set/README.md) 证明，本文不重复证明。
5. 与精确交换判据的关系：自由资源松弛下的**精确**定和交换 `F_C(C+Δ)·F_H(H−Δ) ? F_C(C)·F_H(H)` 的正确判据是整数交叉乘法（见 [attribute-swap-criterion](../attribute-swap-criterion/README.md)）；本定理的每单位 log 增益只用于比较**连续单步**的边际，不替代该判据。

### 定理 4（前提必要性、浮点可靠性与并列语义）

(a) **正性必要**：若任一因子 `≤ 0`，则 `(i)` 无定义；且 `(ii)` 的真假可以与"增益比较"无关（负数的整数幂还依赖指数奇偶）。因此 (A1) 不能省略。正整数域上 `(ii)` 与 `(i)` 等价（定理 1）。

(b) **正成本必要**：`cF,cG ∈ Z_{>0}`。若 `cF=0`，`(i)` 的分母为 0（每单位增益无定义/无穷）；而把 `cF=0` 代入 `(ii)` 会把 `F0` 与 `F1` 完全消去（`F^0=1`），判据退化为只比较 `G0,G1`，与 `(i)` 不再等价。canonical 模型中确有成本 0 的档位转移（仅 level 50 DHT，见 §7.4），此时必须回退。若成本是正有理数（而不是正整数），`(i)` 仍有意义，但 `(ii)` 需要取公共分母后再做整数幂；运行时使用整数成本，本文不展开有理成本版本。

(c) **浮点 log 不能作证明**：`Math.log` 的结果有舍入误差，两个不同有理数的每单位增益可以任意接近；用浮点比较决定"严格更优"可能翻转。可靠的运行时实现要么用 `BigInt` 交叉乘法（推荐），要么用**带误差上界的定点对数**并按下述加宽规则处理：

> **误差加宽引理.** 设 `L̂_F, L̂_G` 分别是 `ln(F1/F0)`、`ln(G1/G0)` 的估计，且已知绝对误差上界 `|L̂_F−ln(F1/F0)| ≤ ε`、`|L̂_G−ln(G1/G0)| ≤ ε`（`ε>0`）。令 `S = cG·ln(F1/F0) − cF·ln(G1/G0)`，`Ŝ = cG·L̂_F − cF·L̂_G`。则
> `|Ŝ − S| ≤ (cF+cG)·ε`。
> 因此：若 `Ŝ > (cF+cG)ε`，则 `S > 0`（A 严格更优）**可靠**；若 `Ŝ < −(cF+cG)ε`，则 `S < 0`（B 严格更优）**可靠**；其余情形（`|Ŝ| ≤ (cF+cG)ε`）必须判"无法判定"并回退到精确 BigInt，绝不能按浮点符号剪枝。
> 证明：`|cG(L̂_F−lnρF)| ≤ cG·ε`、`|cF(L̂_G−lnρG)| ≤ cF·ε`，三角不等式即得。

(d) **并列语义**：`A = B`（交叉指数判据取等）表示两条转移的单位成本 log 增益**精确相等**，此时不构成"严格更优"。凡以"严格改善"为目标的剪枝必须使用严格 `>` 判定；并列必须保守保留（与 `exact-mip-candidate-upper-bound.ts:114-140` 的"严格更差 / 不能严格改善"语义一致，见 [canonical evaluator 参考模型](../../canonical-evaluator-reference.md) §0）。

## 6. 证明（仅精确论证）

### 6.1 定理 1 的证明

设 `F0,F1,G0,G1>0`、`cF,cG∈Z_{>0}`。

**(i) ⇒ (ii).** 由 `(i)`，两边乘正数 `cF·cG`：

```text
cG·ln(F1/F0) ≥ cF·ln(G1/G0).
```

由对数律与正性，`cG·ln(F1/F0) = ln((F1/F0)^{cG})`，`cF·ln(G1/G0)=ln((G1/G0)^{cF})`。于是 `ln X ≥ ln Y`，其中 `X=(F1/F0)^{cG}>0`、`Y=(G1/G0)^{cF}>0`。`ln` 在 `(0,∞)` 上严格增，故 `X ≥ Y`。展开正分母：

```text
F1^{cG}/F0^{cG} ≥ G1^{cF}/G0^{cF}.
```

两边乘正数 `F0^{cG}·G0^{cF}` 得 `F1^{cG}·G0^{cF} ≥ F0^{cG}·G1^{cF}`，即 `(ii)`。

**(ii) ⇒ (i).** 上述每一步都是等价变换（乘正数、`ln` 严格增、正数幂运算），逆推即得。

**(iii) ⇔ (i).** 因 `F1/F0>0`、`G1/G0>0`，有 `(F1/F0)^{1/cF} = exp(ln(F1/F0)/cF)`、`(G1/G0)^{1/cG}=exp(ln(G1/G0)/cG)`；`exp` 在 `R` 上严格增，故 `(iii) ⇔ (i)`。也可直接验证：`(iii)` 两边取 `cF·cG` 次方（`x↦x^{cF·cG}` 在 `(0,∞)` 上严格增）即得 `(F1/F0)^{cG} ≥ (G1/G0)^{cF}`，与上面的中间式相同，故 `(iii) ⇔ (ii)`。

**严格与等式版本.** `ln` 与 `exp` 都是严格单调双射，正数乘除与正幂都是严格单调变换，故 `≥`、`>`、`=` 在三种形式间逐一对应。等式情形即 `F1^{cG}G0^{cF} = F0^{cG}G1^{cF}`，是整数等式，可用 BigInt 精确判定。证毕。

### 6.2 定理 2 的证明

直接代数展开：

```text
A' = (F1·G0)^{cG} = F1^{cG}·G0^{cG} = (F1^{cG}·G0^{cF})·G0^{cG−cF} = A·G0^{cG−cF}
B' = (G1·F0)^{cF} = G1^{cF}·F0^{cF} = (F0^{cG}·G1^{cF})·F0^{cF−cG} = B·F0^{cF−cG}
```

两式相除（所有量正）：

```text
A'/B' = (A/B)·G0^{cG−cF}·F0^{cG−cF} = (A/B)·(F0·G0)^{cG−cF}.
```

取对数得

```text
ln(A'/B') − ln(A/B) = (cG−cF)·ln(F0·G0).
```

再乘 `cF·cG` 即得到"原始比较标量"之差 `(cG−cF)(lnF0+lnG0)`；除 `cF·cG` 即得每单位成本标量之差 `(cG−cF)/(cF·cG)·ln(F0·G0)`。这也直接说明 issue 形式等价于把 `A/B` 与 `(F0·G0)^{cF−cG}` 比较，而非与 `1` 比较。

一致性条件：若 `cF=cG`，则 `G0^{0}=F0^{0}=1`，故 `A'=A`、`B'=B`；若 `F0=G0=1`，同理。反之若 `cF≠cG` 且 `F0G0>1`，则修正因子 `(F0G0)^{cG−cF}≠1`，对满足 `A/B` 恰在 `1` 与 `(F0G0)^{cF−cG}` 之间的输入，两种形式真值相反（§7.1、§7.2 为显式构造）。证毕。

### 6.3 定理 3 的证明

1. **全预序**：`U(e)` 是实数，`≽` 是实数自然序沿 `U` 的拉回，故自反、传递、全（任意两实数可比较）。由定理 1，`U(e1)≥U(e2)` 等价于把 `(A1,B1,c1)` 当 `F` 侧、`(A2,B2,c2)` 当 `G` 侧代入交叉指数判据。
2. **复合**：`U(e1∘e2)=ln(C/A)/(c1+c2)=[ln(B/A)+ln(C/B)]/(c1+c2)=[c1·U(e1)+c2·U(e2)]/(c1+c2)`。因 `c1,c2>0`，这是严格凸组合，落在两端点之间；严格性由 `U(e1)≠U(e2)` 与两个正权重给出。
3. **传递性**：若 `U(e1)≥U(e2)` 且 `U(e2)≥U(e3)`，则 `U(e1)≥U(e3)`。
4. **适用范围**：见 §5 定理 3 第 4、5 条；那里引用的反例与警告是本文结论的边界，不在此重复证明。

### 6.4 定理 4 的证明

(a) 若某因子 `=0`：`(i)` 出现 `ln 0`（无定义/`−∞`）；若因子 `<0`：`ln` 无定义，且 `(ii)` 的整数幂符号取决于指数奇偶，无法表达"更大增益"。正整数情形已在定理 1 证明。canonical 的 `safeDamageFactors` 正是逐因子检查 `>0` 与安全整数，故 (A1) 有运行时可检查的对应实现。

(b) `cF=0`：`(i)` 除以 0；`(ii)` 中 `F0^0=F1^0=1`，`F` 侧信息全部丢失。例如 `F0=1,F1=100,cF=0`、`G0=2,G1=1,cG=1`：`(i)` 无定义，而 `(ii)` 变成 `2≥1`（不再涉及 `F`），不等价。负成本无资源含义。

(c) 误差加宽引理：见 §5 定理 4(c) 陈述与三角不等式证明；关键点是 `Ŝ−S = cG(L̂_F−lnρF) − cF(L̂_G−lnρG)`，故 `|Ŝ−S| ≤ cG·ε + cF·ε`。当 `Ŝ > (cF+cG)ε` 时 `S ≥ Ŝ−(cF+cG)ε > 0`；另一侧对称。未越界时不能判定，必须回退。

(d) 并列语义：由定理 1 的等式版本，`A=B` 与 `(i)` 取等完全对应；`exact-mip-candidate-upper-bound.ts:127-140` 的 `cannotImprove` 用 `<=`，即"相等不构成严格更差"，与此一致。证毕。

## 7. 反例与边界退化

### 7.1 主反例（真值相等，issue 形式判"严格更差"）

输入：`F0=10, F1=80, cF=3; G0=1000, G1=2000, cG=1`。这里 `F0..G1` 是**因子值**、`cF,cG` 是**贡献单位**的正整数成本——它们是抽象代数赋值，不是角色面板属性值；本反例不涉及 baseStat。

真值（同一实数公式）：

```text
ln(F1/F0)/cF = ln(8)/3 = ln(2) = 0.693147...
ln(G1/G0)/cG = ln(2)/1 = ln(2) = 0.693147...      ⇒ 精确相等
```

正确判据（定理 1）：

```text
A = F1^cG·G0^cF = 80^1·1000^3 = 80·10^9 = 8·10^10
B = F0^cG·G1^cF = 10^1·2000^3 = 10·(8·10^9) = 8·10^10        ⇒ A = B，相等 ✓
```

issue 正文形式：

```text
A' = (F1·G0)^cG = (80·1000)^1 = 80,000
B' = (G1·F0)^cF = (2000·10)^3 = 20,000^3 = 8·10^12
A' < B'   ⇒ issue 形式断言"左端严格更差"，与真值"相等"矛盾 ✗
```

用定理 2 的恒等式核对这个数值：

```text
cG−cF = −2
A' = A·G0^(cG−cF) = 8·10^10 / 1000^2 = 8·10^4 = 80,000        ✓
B' = B·F0^(cF−cG) = 8·10^10 · 10^2 = 8·10^12                  ✓
A'/B' = 10^−8 = (F0·G0)^(cG−cF) = (10·1000)^(−2)              ✓
```

对数偏差：`ln(A'/B') − ln(A/B) = ln(10^−8) = −8·ln10 ≈ −18.42`；而定理 2 的公式给出 `(cG−cF)(lnF0+lnG0) = −2·(ln10+ln1000) = −2·4ln10 = −8ln10` ✓。（注意是 `ln F0 + ln G0`，不是 `ln G0 − ln F0`；后者会给出 `−4ln10`，与数值不符。）

### 7.2 反向反例（issue 形式把顺序判反）

输入：`F0=10, F1=11, cF=1; G0=20, G1=30, cG=2`。同样，`F0..G1` 是因子值、`cF,cG` 是贡献单位成本，与 baseStat 无关。

```text
真值：ln(11/10)/1 ≈ 0.09531 < ln(30/20)/2 = ln(1.5)/2 ≈ 0.20273   ⇒ A 更差
正确判据：A = 11^2·20 = 121·20 = 2420；B = 10^2·30 = 100·30 = 3000
          A < B  ⇒ A 更差 ✓
issue 形式：A' = (11·20)^2 = 220^2 = 48,400；B' = (30·10)^1 = 300
          A' > B' ⇒ issue 形式判 A 更优 ✗（顺序被反转）
恒等式：A'/B' = (A/B)·(F0·G0)^(cG−cF) = (2420/3000)·200 = 161.33 = 48400/300 ✓
```

### 7.3 退化：`cF = cG` 时两种形式恰好一致

若 `cF=cG=c`，则 `A'=(F1G0)^c=F1^cG0^c=A`、`B'=(G1F0)^c=B`，两式逐项相同。验证脚本在 `F0,F1,G0,G1∈[1,9]`、`c∈{1,2,3}` 的全部 19,683 组上逐项核对了该恒等。这说明 issue 写法的错误只在 `cF≠cG` 时显现，也解释了为什么简单的等成本测试发现不了它。

### 7.4 边界：成本为 0 的档位转移

canonical 模型中 `level 50` 的 DHT 存在**零成本跳档**：`t_DHT(2)=2` 与 `t_DHT(3)=3` 的最小贡献阈值都等于 `g=2`（因为 `a=550 > q=341`，一个 raw 单位可跨多个档位）。此时"从 tier 2 到 tier 3 的每单位成本增益"分母为 0，定理 1/2 的 `cF,cG∈Z_{>0}` 前提不成立，必须排除或改用窗口公式（见 [raw-marginal-envelope](../raw-marginal-envelope/README.md) §7）。这是"正成本"假设在真实参数下确实必要的证据。

### 7.5 canonical evaluator 上的真实反例（顺序反转）

固定等级公式本身（不是人为构造）就能触发 issue 形式的错误。取 `level=100`、普通职业（`b_C=350`）：

- `DHT` 的完整档位转移 `t=0 → 1`：`F0 = 4000`、`F1 = 4001`；阈值差 `cF = τ_{DHT,1} − τ_{DHT,0} = 6`。
- `CRT` 的完整档位转移 `t=800 → 801`：`G0 = 1,920,000`、`G1 = 1,921,951`；阈值差 `cG = 14`。

真值：

```text
ln(4001/4000)/6      ≈ 4.1661·10^−5
ln(1921951/1920000)/14 ≈ 7.2545·10^−5        ⇒ DHT 更差
```

正确判据的 BigInt 比较给出"DHT 更差"；而 issue 形式给出"DHT 更优"（因 `cG−cF=8`，修正因子 `(F0·G0)^8 = (4000·1920000)^8` 巨大，把方向翻转）。两处成本均由阈值公式计算得到，是真实的完整档位转移。该算例由 [verify.mjs](verify.mjs) §3d 精确核对。

**坐标复核（贡献单位 vs 面板值）**：两处阈值都是**贡献坐标**的数值。level 100 的 `sub=420`，于是面板坐标为：

```text
DHT  t=0 的阈值：贡献 g=0     → 面板 420；t=1 的阈值：贡献 g=6     → 面板 426；差值 6
CRT  t=800 的阈值：贡献 g=10425 → 面板 10845；t=801 的阈值：贡献 g=10439 → 面板 10859；差值 14
```

常数平移不改变阈值差（故 `cF=6, cG=14` 在两坐标下数值相同），但把面板值直接代入贡献档位公式会得到错误档位：`floor(550·420/2780)=83 ≠ 0`、`50+floor(200·10845/2780)=830 ≠ 800`。因此定理输入必须使用贡献坐标；[verify.mjs](verify.mjs) §8 对该换算与"坐标误用可检测"做了断言。

### 7.6 边界：非正因子

`F0=2,F1=2,cF=1; G0=5,G1=0,cG=1`：整数交叉指数形式为 `2·5 ≥ 2·0`（成立），但 `ln(G1/G0)=ln0` 无定义，`(i)` 无意义。这证明 (A1) 不是形式化装饰，而是等价性成立的必要条件；canonical 的 `safeDamageFactors` 提供了可执行的检查点。

### 7.7 边界：浮点近并列

两个单位增益可以任意接近；`Math.log` 的舍入（以及 `F1/F0` 的双精度除法舍入）可能在近并列处给出错误符号。故运行时不得以未加宽的浮点符号作为"严格更优"的依据；须用 BigInt 或 §5 定理 4(c) 的加宽规则。

## 10. 应用前提与安全回退

### 10.1 运行时比较契约

```text
compareMarginal(F0, F1, cF, G0, G1, cG) -> "A-strictly-better" | "B-strictly-better" | "equal" | "undecided"

前置检查（任一失败 → "undecided"，转安全回退）:
  F0,F1,G0,G1 是 Number.isSafeInteger 且 > 0          // 因子值（由贡献坐标档位计算）
  cF,cG 是 Number.isSafeInteger 且 > 0                // 贡献单位的阈值差（不是面板值）
  坐标：面板属性值不得直接作为 g/cost；若只有面板值，先减 offset
        （CRT/DHT/TEN: sub；DET: main，参考模型 §2.1）再计算档位与成本
  （如来自档位转移：成本必须由贡献坐标阈值差给出，并要求 > 0）

精确计算（全部用 BigInt，无浮点）:
  A = F1^cG * G0^cF
  B = F0^cG * G1^cF
  A > B  -> "A-strictly-better"
  A < B  -> "B-strictly-better"
  A == B -> "equal"          // 并列，不构成严格改善

安全回退（前置失败或需要更高层结论时）:
  不在边际层面下结论；在实际候选点上用完整目标函数的 BigInt 精确乘积比较
  （exactProduct / exact ratio cross multiplication），或直接返回 "undecided" 不剪枝。
```

### 10.2 使用限制

- 只对 §3 定义的**完整 tier 转移**使用；部分窗口用 [raw-marginal-envelope](../raw-marginal-envelope/README.md)。
- **贡献坐标**：所有 `F*`/`c*` 输入必须来自贡献坐标（`g = panel − offset`）；不接受把面板总值当贡献。面板输入必须先按 §13.2 换算；坐标未知或混用时走回退。
- "A-strictly-better" 只表示**局部单位成本 log 增益**更大；在自由资源松弛中可用于单步交换排序，**不得**单独据此删除真实装备（共享装备身份、孔位/meld/food 可行性另需论证，见 [attribute-swap-criterion](../attribute-swap-criterion/README.md) 与 issue-3-comment-02 §七）。
- 严格剪枝必须用严格 `>` 结论；"equal" 一律保守保留（与 `exact-mip-candidate-upper-bound.ts:114-140` 的并列语义一致）。
- 若运行时只有定点对数而没有已证明的 `ε`，不得启用本判据；有 `ε` 时按 §5 定理 4(c) 加宽并在未越界时回退。
- 该函数是"证明组件"：其正确性依赖 §4 的 (A1)–(A4)；任何前提检查失败都必须走回退路径，不得以经验阈值代替。

## 13. baseStat 影响审计（贡献坐标 vs 面板总值）

本节是用户要求的第二轮核对记录：检查本文所有命题、数值例与验证输入是否被 `baseStat` 影响，以及是否存在"把面板总值当贡献"的坐标混用。结论先行：**本文没有定理因 baseStat 改变**；baseStat 只出现在 `value = baseStats[stat] + gearAndFoodValue` 的归约与面板/贡献换算中，所有公式与证明都在贡献坐标下成立。本节补充的是**显式坐标声明**与数值例的坐标标注。

### 13.1 坐标声明

| 本文的量 | 坐标/对象 | 与 baseStat 的关系 |
| --- | --- | --- |
| `g`（属性贡献）、区间、窗口起点 | 贡献坐标 | 定义即 `g = panel − baseStat`；本文的唯一自变量坐标 |
| 阈值 `g_k` | 贡献单位 | 面板阈值 = `g_k + offset`（同一属性内是常数平移）；数值随坐标变，贡献坐标是定义 |
| 成本 `cF,cG`（= `g_{k+1}−g_k`） | 贡献单位阈值差 | 同一属性内对常数平移不变，但**必须由贡献坐标阈值计算**；跨属性/跨坐标混用不可比 |
| `F0,F1,G0,G1` | 因子值（整数） | 由整数档位唯一决定；因子公式 `F_C/F_H/F_D` 不含 baseStat |
| `U(e)=ln(B/A)/c` | 实数 | 只依赖因子比与正成本；不含任何属性坐标 |
| 面板总值 `panel` | `baseStat + g` | **仅用于换算**；不进入本文任何公式、反例或数值例 |
| `offset` | CRT/DHT/TEN 取 `sub`，DET 取 `main` | 由等级参数决定（[参考模型 §2.1](../../canonical-evaluator-reference.md)），当前数据下与职业无关；BLU 只改变档位常数 `c` 与 `b_C`，不改变 baseStat |

**明确否定的用法**：本文没有把面板值当作 `g`、阈值或成本。§7.1/§7.2 的输入是抽象**因子值 + 贡献单位成本**（`10/80/1000/2000` 等是因子值，不是面板属性）；§7.5 的 6/14 是贡献单位阈值差。

**逐项回答（任务清单）**：`g`/区间/阈值 `g_k` ✓贡献单位；成本 `cF,cG` ✓贡献单位阈值差（同一属性内对常数平移不变）；因子 `F0..G1` ✓因子值（由贡献档位决定，与 baseStat 无关）；面板总值 ✓仅作换算常数，不进入本文公式与数值例。

### 13.2 归约链（canonical → 本文坐标）

```text
value = baseStats[stat] + gearAndFoodValue                     (equipped-effects.ts:127)
baseStats.CRT = baseStats.DHT = baseStats.TEN = sub,
baseStats.DET = main                                            (getBaseStats :178-203；参考模型 §2.1)
offset = sub（CRT/DHT/TEN）或 main（DET）
g = value − offset = gearAndFoodValue                           （本文的贡献坐标）
t(g) = c + mult·floor((a·g + b)/q)                              （参考模型 §3）
      floor 实参 = a·g/q + c + b/q ≥ 0 对 g ≥ 0 结构性成立       （参考模型 §2.2；verify-canonical-model.mjs 的可达域非负证书）
```

面板与贡献的换算：

```text
CRT/DHT/TEN：贡献 = 面板 − sub；  DET：贡献 = 面板 − main
所有属性：  面板 = 贡献 + offset
```

因此：**t(g)、阈值、余类、周期、跳档成本与因子值都是 baseStat-无关的函数**（baseStat 只在上述换算中出现）；但若给定的是面板值，必须先减 offset 才能进入本文公式。本文的定义域、例子与验证脚本一律使用贡献坐标。

### 13.3 逐命题判定表

**总判断**：本文全部命题都是**因子级/成本级代数命题**，不受 baseStat 影响——`F0..G1` 是因子值、`cF,cG` 是贡献单位成本；baseStat 不进入任何公式。唯一需要显式声明的是坐标：若把面板值当贡献使用（输入坐标错误），档位与因子会被错位、阈值（作为坐标数值）整体平移，跨坐标混用还会使 `cF/cG` 不可比；但这不是定理结论对 baseStat 的依赖。

| 条目 | 是否受 baseStat 影响 | 判定与理由 |
| --- | --- | --- |
| 定理 1（三种等价形式） | **否** | 纯代数；输入只有因子值 `F0..G1` 与正整数成本 `cF,cG`，不含属性坐标。baseStat 只影响"因子/成本如何从角色数据取得" |

| 定理 3（序与复合） | **否**（成本定义有坐标要求） | `U(e)` 只依赖因子比与正成本；"完整 tier 转移"的成本必须是贡献坐标阈值差（A2/A4） |

| 定理 4(b)（正成本前提） | **否**（坐标要求） | 要求 `cF,cG` 是贡献单位阈值差且 `>0`；零成本跳档见 §7.4 |

**审计精确化说明（对任务表述的一处细化）**：任务表述"若把面板值当贡献会改变 `cF/cG` 与阈值"需要精确化——阈值**作为坐标数值**会因常数平移改变（面板阈值 = 贡献阈值 + offset）；但**同一属性内**的阈值差 `cF/cG` 在纯常数平移下数值不变。真正的问题是：(i) 把面板值直接代入贡献档位公式会使档位与因子错位（§13.4 有可检测反例）；(ii) 跨属性或跨坐标混用时 `cF/cG` 失去可比性。因此运行时仍**必须**使用贡献坐标，不能因"差不变"而把面板值当贡献。

### 13.4 数值复核

1. **§7.1/§7.2 反例**：`F0=10,F1=80,G0=1000,G1=2000` 是**因子值**（例如 CRT 因子可到 `1,020,000` 量级、DHT 因子约 `4000` 量级；10/80 等只是抽象赋值），`cF=3,cG=1` 是贡献单位成本；不涉及 baseStat。
2. **§7.5 真实反例（level 100 WHM，`sub=420`，`main=440`）**：

   ```text
   DHT t=0→1：贡献阈值 0 → 6       面板阈值 420 → 426        差 6
   CRT t=800→801：贡献阈值 10425 → 10439  面板阈值 10845 → 10859  差 14
   ```

   验证：`floor(550·6/2780)=1`；`50+floor(200·10425/2780)=800`、`50+floor(200·10439/2780)=801`。把面板值当贡献：`floor(550·420/2780)=83≠0`、`50+floor(200·10845/2780)=830≠800`（[verify.mjs](verify.mjs) §8 断言）。
3. **§7.4 零成本跳档（level 50，`sub=341`）**：`t=2` 与 `t=3` 的贡献阈值同为 `g=2`，面板阈值同为 `343`，成本 0；常数平移不改变"同阈值"事实。
4. **结论**：本文全部数值例与反例在贡献坐标下正确；若外部只提供面板值，按 §13.2 换算后所有结论与数值（F 值、阈值差、比较结果）不变。
