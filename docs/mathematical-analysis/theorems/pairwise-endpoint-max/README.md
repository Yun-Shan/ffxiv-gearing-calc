## 3. 符号、量词与定义域

### 3.1 属性、档位与因子

记支持等级集合 `Λ = {50, 60, 70, 80, 90, 100}`，等级参数 `(main, sub, div, det, detTrunc)` 见 [参考模型 §2](../../canonical-evaluator-reference.md)。三个副属性的档位统一写成

```text
t_stat(g) = c + mult · floor((a·g + b) / q),   g ∈ Z, g >= 0
```

| stat | a | b | q | c | mult |
| --- | --- | --- | --- | --- | --- |
| CRT | 200 | 0 | div | 50（BLU: 250） | 1 |
| DHT | 550 | 0 | div | 0（BLU: 200） | 1 |
| DET | 140 | 1000·det | det·detTrunc | 0 | detTrunc |

对应因子（`equipped-effects.ts:95-99`）：

```text
F_C(t) = 1_000_000 + t·(t + b_C),  b_C = 350（普通）/ 150（BLU）
F_H(t) = 4000 + t
F_D(t) = t
```

其中 `g = b + x` 是“装备+食物的属性贡献”减去基础属性后的净贡献（归约见参考模型 §2.1）；档位与因子都是整数。

### 3.2 切片

固定等级 `ℓ ∈ Λ`、公式类别 `job ∈ {普通, BLU}`（因子只通过 BLU 标记区分；canonical evaluator 的 22 个战斗职业都落入这两类）、属性对 `(i,j)`：

```text
(i,j) ∈ { (CRT,DHT), (CRT,DET), (DHT,DET) }
```

给定整数 baseline `b_i, b_j >= 0`、预算 `S >= 0`、整数 cap 区间 `0 <= lo <= hi <= S`，定义整数切片

```text
G(x) = F_i(t_i(b_i + x)) · F_j(t_j(b_j + S - x)),   x ∈ Z ∩ [lo, hi].
```

- 左属性 `i` 的贡献 `b_i + x` 随 x 单调增；右属性 `j` 的贡献 `b_j + S - x` 随 x 单调减。
- **坐标声明（重要）**：`b_i, b_j, S, lo, hi, x` 以及式中的 `t_stat(·)` 实参全部是**属性贡献 `g`**（装备 + 食物贡献），**不是角色面板总值**。面板总值 = 基础属性 + 贡献，其中 CRT/DHT 的基础属性是 `sub`、DET 的基础属性是 `main`（[参考模型 §2.1](../../canonical-evaluator-reference.md)）；换算与审计见 §13。
- `b_i,b_j,S,lo,hi` 是**运行时输入**；本文的定理对它们做全称量化，反例对它们做存在量化。
- 记 `D = hi - lo`（切片长度）、`x` 为整数点；一个“步”指 `x = s-1 → s`（`s ∈ (lo, hi]`）。

**定义 3.1（步的类型）** 对步 `s`：

- **C 步**（左档位跳变）：`t_i(b_i+s) > t_i(b_i+s-1)`；
- **R 步**（右档位下降）：`t_j(b_j+S-s) < t_j(b_j+S-s+1)`；
- **联合步**：C 步且 R 步；**中性步**：既非 C 也非 R；
- **上升步**：`ΔG(s) := G(s) - G(s-1) > 0`；**下降步**：`ΔG(s) < 0`；**平坦步**：`= 0`。

记 `J+ = #{上升步}`、`J- = #{下降步}`、`F0 = #{平坦步}`，于是 `J+ + J- + F0 = hi - lo`。

**定义 3.2（平台 / 严格局部极大平台）** `G` 在 `[lo,hi]` 上是整数值阶梯函数。一个**平台**是极大的常量区间 `[u,v]`（`G(u)=…=G(v)`，且边界处不相等）。若 `u > lo` 时 `G(u) > G(u-1)` 且 `v < hi` 时 `G(v) > G(v+1)`（或 `[u,v]=[lo,hi]`），称它是**严格局部极大平台**。若不计端点边界，内部严格局部极大平台数记为 `L_max`。

### 3.3 量词约定

- 反例（§5.1、§7）：`∃ ℓ, job, (i,j), b_i, b_j, S, x`（x 严格在 `(0,S)` 内）使 `G(x) > max(G(0), G(S))`。只要一个反例成立，全称命题即被否证。
- 正定理（§5.2、§5.3）：对 `∀ ℓ ∈ Λ, ∀ job ∈ {普通,BLU}, ∀ (i,j), ∀ b_i,b_j >= 0, ∀ 0 <= lo <= hi <= S` 成立；个别条款需要额外的可验证前提（如“左档位恒定”），前提在命题中显式写出。
- 所有“最大/最小”都是整数意义下的精确值；`floor` 为精确整数下取整（定义域 `g >= 0`，与 canonical 的 `Math.trunc(v+1e-7)` 等价，见 §4(H4)）。

## 5. 精确命题

### 5.1 Theorem 1（全域端点最大的否证，已否证）

**命题 1.1** 对每一对属性 `(i,j) ∈ {(CRT,DHT), (CRT,DET), (DHT,DET)}` 与每一个支持等级 `ℓ ∈ Λ`，存在整数 baseline `b_i,b_j >= 0`、预算 `S >= 0` 与整数 `x* ∈ (0,S)`，使

```text
G(x*) > max( G(0), G(S) ).
```

因此“对所有允许输入，G 的最大值必由两端点之一取得”为假。更强地：在普通职业与 BLU 两类下都出现反例；实际尺度网格（baselines `{0,100,300,500,800,1000,1500,2000}^2`、`S ∈ {50,100,200,400,610,800,1000,1500,2000}`）中，36 个 `(pair, level, job)` 组合**全部**出现反例。

（显式反例与算术见 §7.1；网格证书见 §7.2。）

### 5.2 Theorem 2（切片阶梯结构与非单峰性，已证明）

设 `G` 为 §3.2 的切片，步集 `(lo, hi]`。

**(a) 步分类引理。** 对每一步：

1. `ΔG > 0 ⇒ C 步`；`ΔG < 0 ⇒ R 步`；
2. `C 步且非 R 步 ⇒ ΔG > 0`；`R 步且非 C 步 ⇒ ΔG < 0`；
3. `中性步 ⇒ ΔG = 0`；
4. 联合步的符号由精确乘积比较决定，不能只由“类型”判定。

**(b) 平台对应引理。** 每个上升步 `a` 开启一个极大常量区间 `[a, b]`（`G(a)=…=G(b)`，且 `b<hi` 时 `G(b+1)≠G(b)`）；不同上升步开启不同区间；区间数等于 `J+ - δ`，其中 `δ=1` 当且仅当从某个上升步起的区间一直延伸到 `hi`，否则 `δ=0`。

**(c) 严格局部极大平台判据。** `[a,b]` 是内部严格局部极大平台，当且仅当它由上升步开启且以严格下降步结束（`b<hi` 且 `G(b+1)<G(b)`）。等价地，把符号序列压缩掉 0 后，它就是“`+` 后紧跟 `-`”的模式。记内部严格局部极大平台数为 `L_max`，则

```text
L_max = # { i : 压缩符号序列中 s_i = +, s_{i+1} = - }
      <= min( J+, J-, #上升段数 ).
```

**(d) 非单峰性。** 若存在上升步 `u < v` 与位于二者之间的下降步 `w`（`u < w < v`），则压缩符号序列至少有两次符号变化（`+→-` 与 `-→+`）。因此：`G` 不满足“离散增量符号至多发生一次变化”；`G` 既不能由“先减后增”的单谷假设推出端点最大，也不能由“单峰”假设推出。评论 1 的 single-crossing 猜想被结构性否证。

**(e) 计数下界与 Θ 证书。**

1. 无条件：`J+ >= #(仅 C 步)`（每个仅 C 步都是上升步），`J- >= #(仅 R 步)`；因此 `L_max <= min(J+, J-)`。
2. 若切片内所有联合步都是严格上升步（这可用逐步精确乘积比较在 O(#联合步) 内检查），则 `J+ = #(C 步)`，且当相邻上升步之间都有下降步时 `L_max = J+ = #(左档位跳变数) = a_i·D/q_i + O(1)`（`a_i <= q_i` 时）。特别地，70 级 CRT-DHT 的证书切片给出 `J+ = L_max = 136 = ⌈610·200/900⌉ ≈ 0.223·D`，即 `Θ(D·a_CRT/q)`。
3. 若左档位每步都跳变（如 50 级 DHT：`a=550 > q=341`），则 `J+ = D - #(联合下降步)`；此时严格局部极大平台由下降步“收口”，50 级 DHT-DET 证书给出 `L_max = 139 = #(仅 R 步) ≈ 0.139·D`。
4. 一般渐近陈述：在“联合步符号恒定”的切片（可在运行时检查）中，符号模式以共同周期（见 [pairwise-slice-critical-set](../pairwise-slice-critical-set/README.md) §5.2）重复，`L_max` 随 D 线性增长，常数由相位类决定；因此 `L_max = Θ(D·min(1, a_i/q_i, a_j/q_j))`（以精确相位类计数为准，见姊妹定理）。本文只把上式作为**已证明的界与已核对的证书**，不把未量化的“一般相位”下界写成无条件定理。

### 5.3 Theorem 3（条件端点定理与精确判据，已证明）

**(a) 左档位恒定 ⇒ 非增。** 若 `t_i(b_i+x)` 在 `[lo,hi]` 上恒定，则 `G` 在 `[lo,hi]` 上非增，最大值在 `lo` 取得。

**(b) 右档位恒定 ⇒ 非减。** 若 `t_j(b_j+S-x)` 在 `[lo,hi]` 上恒定，则 `G` 在 `[lo,hi]` 上非减，最大值在 `hi` 取得。

**(c) 精确判据。** 记

```text
K_L = { lo } ∪ { x ∈ (lo,hi] : t_i(b_i+x) > t_i(b_i+x-1) }.
```

则（证明见 §6.3(c)）

```text
max_{x∈[lo,hi]∩Z} G(x) = max_{x∈K_L} G(x),
```

并且

```text
端点最大成立  ⇔  max_{x∈K_L} G(x) <= max( G(lo), G(hi) ).
```

这是**精确判据、不是采样**：计算 `max_{K_L} G` 只需 `|K_L| <= floor(a_i·D/q_i)+2` 次因子求值；`K_L` 可由 [pairwise-slice-critical-set](../pairwise-slice-critical-set/README.md) §5.1 的阈值公式在 `O(|K_L|)` 内枚举（对称地也可用右关键集 `K_R`）。

**(d) 没有更强的闭式充分条件（在本文范围内）。** 除 (a)(b) 外，不主张任何“由固定等级参数与 baseline/budget 直接判定的闭式充分条件”。并证明：任何形如“每一步左因子相对增益 ≥ 右因子相对增益”（或反向）的**逐点比率分离条件**在同时含 C 步与 R 步的切片上必然被违反（§6.4）。

## 6. 证明

### 6.0 窗口档位增益引理（引用并给出证明）

对 `t(g)=c+mult·floor((a g+b)/q)`（`a>0, q>0, g>=0`），令 `r(g) = (a g+b) mod q ∈ [0,q)`（模运算取非负代表元）。则对任意整数 `δ >= 0`：

```text
t(g+δ) - t(g) = mult · floor( (r(g) + a·δ) / q ).        (6.0.1)
```

证明：写 `a g+b = m q + r(g)`（`m = floor((a g+b)/q)`）。则

```text
a(g+δ)+b = m q + (r(g)+aδ),
```

两边取 floor 后相减，`m q` 贡献 `m` 的差被消去，得 `floor((r+aδ)/q)`。∎

对“贡献减少 δ”的方向，令 `y` 为起点贡献、`t(y)-t(y-δ)`：

```text
t(y) - t(y-δ) = mult · ceil( (a·δ - r(y)) / q ),        (6.0.2)
```

因为 `floor((r-aδ)/q) = -ceil((aδ-r)/q)`。式 (6.0.1)(6.0.2) 是 [raw-marginal-envelope](../raw-marginal-envelope/README.md) 的窗口档位增益引理在本模型中的形式；本文用它计算跳变位置与每周期事件计数。

### 6.1 Theorem 1 的证明

Theorem 1 是存在性否定命题，证明即**给出精确反例**（反例本身即否证），并给出可复核的网格证书。三组反例的逐步算术见 §7.1，其中每一步都只用到 §3 的整数公式与精确整数乘法。因此 `¬(∀ 输入，max = max(端点))`。网格只作为“反例在实际尺度上普遍存在”的证书列表（§7.2），不承担证明作用；**单个反例已经足以否证全称命题**。

### 6.2 Theorem 2 的证明

**(a) 步分类。** 设步 `s`。

- 若 `s` 不是 C 步，则 `t_i` 在 `s-1,s` 两点相等，故 `F_i` 相等；又 `t_j` 随 x 单调不增（贡献 `b_j+S-x` 随 x 减 1，`t_j` 非减），所以 `F_j(s) <= F_j(s-1)`，于是 `ΔG <= 0`。若同时也不是 R 步，则 `F_j` 相等，`ΔG = 0`。这证明了“上升步必为 C 步”“中性步必平坦”；对偶地，若 `s` 不是 R 步，则 `t_j` 两点相等、`F_j` 相等，`F_i` 非减，故 `ΔG >= 0`，从而“下降步必为 R 步”。
- 若 `s` 是 C 步且不是 R 步：`F_i` 严格增（`F_C(t+1)-F_C(t)=2t+1+b_C>0` 对 `t>=0`；`F_H(t+1)-F_H(t)=1>0` 对 `t>=0`；`F_D(t+1)-F_D(t)=1` 对 `t>=t_D(0)>=1000`），`F_j` 相等，故 `ΔG > 0`。对偶得“仅 R 步必严格下降”。
- 联合步：`F_i` 严格增而 `F_j` 严格减，`ΔG` 的符号由

```text
ΔG > 0  ⇔  F_i(t_i(s-1)+δ_i)/F_i(t_i(s-1))  >  F_j(t_j(s))/F_j(t_j(s-1))
```

决定（其中 `δ_i = t_i(s)-t_i(s-1) > 0`，`t_j(s) < t_j(s-1)`），即由精确交叉乘法决定，不能由“是联合步”这一事实推出。∎(a)

**(b) 平台对应。** 设 `a` 是上升步。由 (a)，`G` 在 `a` 处严格上升：`G(a) > G(a-1)`。令 `b` 为最大的 `y ∈ [a,hi]` 使 `G(a)=…=G(y)`（存在，至少 `y=a`）。由定义 `[a,b]` 是极大常量区间，且它的左端点必为 `a`（因为 `G(a)>G(a-1)`，区间不能向左延伸）。反之，一个极大常量区间 `[u,v]` 若其值严格高于左邻（`u=lo` 或 `G(u)>G(u-1)`），则 `u` 是上升步且由唯一性 `a=u`。因此“上升步”与“左端严格高于左邻的极大常量区间”一一对应；区间数 = `J+` 减去“左端到 `hi` 仍为常量”的那一个（至多一个，否则两个区间相同）。∎(b)

**(c) 严格局部极大平台判据。** 设区间 `[a,b]` 由上升步 `a` 开启（于是 `G(a)>G(a-1)`）。若 `b<hi`，由极大性 `G(b+1)≠G(b)`。`[a,b]` 是（内部的）严格局部极大平台 ⇔ `G(b+1)<G(b)`。把符号序列中所有 0 删除（平台内部即 0 步），则 `[a,b]` 对应压缩序列中某个 `+` 与其后第一个非零符号；后者为 `-` 当且仅当 `G(b+1)<G(b)`。因此 `L_max` 等于压缩序列中相邻 `(+,-)` 的个数。又每个这样的 `-` 只可能跟随一个 `+`，故 `L_max <= J-`；每个 `(+,-)` 需要一个上升步与一个上升段起点，故 `L_max <= J+` 且 `<=` 上升段数。∎(c)

**(d) 非单峰性。** 设上升步 `u<v` 且下降步 `w` 满足 `u<w<v`。在压缩符号序列中（删除所有 0 后），`u` 处为 `+`、`w` 处为 `-`、`v` 处为 `+`。在 `w` 之前的最后一行 `+` 处（`u` 保证其存在），其下一个非零符号必为 `-`，故出现一次 `+→-` 相邻变化；在 `w` 之后的第一行 `+` 处（`v` 保证其存在），其前一个非零符号必为 `-`，故出现一次 `-→+` 相邻变化。这两处变化分别位于 `u` 与 `w` 之间、`w` 与 `v` 之间，位置不同。因此压缩符号序列至少有两次符号变化（一次 `+→-`、一次 `-→+`）。评论 1 的“增量符号最多变化一次 / 至多一个内部极小”被否证。∎(d)

**(e) 计数。** 仅 C 步由 (a)(2) 是上升步，故 `J+ >= #仅C步`。若所有联合步也是上升步，则每个 C 步都是上升步：`J+ = #C步`。若进一步相邻上升步之间都有下降步（或等价地每个上升段长度为 1），则每个上升步的平台都以下降步结束，`L_max = J+`。左档位跳变数由 §6.0 的阈值/周期结构给出：`t_i` 在长度 `D` 的区间上总增益为 `a_i D/q_i` 量级，故 `#C步 = a_i D/q_i + O(1)`（`a_i <= q_i`；`a_i > q_i` 时每步都跳变，`#C步 = D`）。证书数字（§7.3、§11）：

```text
70 级 WHM CRT-DHT, b=(300,500), S=610:
  #C步 = 136, #联合步 = 68（全部上升）, 上升步 J+ = 136, 下降步 305, 平坦 169,
  L_max = 136, 136/610 = 0.2230 ≈ 200/900 = 0.2222 = a_CRT/q。
50 级 WHM DHT-DET, b=(100,100), S=1000:
  左(DHT)档位每步跳变: #C步 = 1000 = D; 联合步 139（全部下降）; 仅DHT步 861;
  上升步 J+ = 861; 下降步 139; L_max = 139 = #仅R步（由下降步收口）。
```

第 2 条中“所有联合步上升”的前提可以更细地写成可验证不等式。以 CRT-DHT 为例：联合步的净符号由

```text
( F_C(t_C+1)/F_C(t_C) ) · ( F_H(t_H-δ)/F_H(t_H) ) > 1
⇔ (2t_C + 1 + b_C)·(4000 + t_H - δ) > δ·F_C(t_C)
```

决定（`δ ∈ {1,2}` 是右档位在同一步的下降量；50 级 DHT 的 `a=550>q=341` 允许 δ=2）。在 70 级证书切片的档位范围（`t_C ∈ [116,252]`、`t_H ∈ [305,678]`、δ=1）内该不等式恒成立，故 68 个联合步全部上升；这与 `verify.mjs` 的精确逐点比较一致。∎(e)

### 6.3 Theorem 3 的证明

**(a)** 若 `t_i` 在 `[lo,hi]` 恒定，则 `F_i` 恒定；`t_j(b_j+S-x)` 随 x 不减（贡献减小、档位非增），`F_j` 非增。故 `G` 非增，最大值在 `lo`。∎

**(b)** 对偶：`t_j` 恒定 ⇒ `F_j` 恒定；`F_i` 随 x 非减。故 `G` 非减，最大值在 `hi`。∎

**(c)** 把 `[lo,hi]` 分成左档位 `t_i(b_i+x)` 的极大常量区间 `I_1,…,I_m`（按 x 递增）。每个 `I_k` 的左端点或为 `lo`，或为某个 C 步位置 `x`（即 `x∈K_L`）。在每个 `I_k` 内 `F_i` 恒定、`F_j` 随 x 非增，故 `G` 在 `I_k` 上非增，最大值在 `I_k` 的左端点取得。因此 `max_{[lo,hi]} G = max_{k} G(左端点) = max_{K_L} G`。于是

```text
max_{[lo,hi]} G <= max(G(lo),G(hi))
⇔ max_{K_L} G <= max(G(lo),G(hi)),
```

且 `max_{[lo,hi]} G = max_{K_L} G` 是**等式**，所以该判据是精确的（不是充分条件或近似）。`K_L` 的大小：每个跳变位置使左档位至少增加 `mult_i`，故 `#C步·mult_i <= t_i(b_i+hi)-t_i(b_i+lo)`，而两个 floor 之差 `<= floor(a_i D/q_i)+1`，所以 `#C步 <= floor(a_i D/q_i)+1`、`|K_L| <= floor(a_i D/q_i)+2`（当 `a_i > q_i` 时每步都跳变，此上界仍成立）。∎

**(d)** 见 §6.4。∎

### 6.4 为什么逐点比率分离条件不可行

设切片同时含 C 步与 R 步（非平凡切片）。考虑任何形如

```text
(†)  对每个步 s：F_i(s)/F_i(s-1) >= F_j(s-1)/F_j(s)
```

的“逐步左边际 ≥ 右边际”条件（或反向）。在仅 R 步处 `F_i` 不变（比值为 1），而 `F_j` 严格下降（右比值 `F_j(s-1)/F_j(s) > 1`），故 (†) 被违反；在仅 C 步处左比值 `>1`、右比值 `=1`，(†) 成立而反向条件被违反。因此对同时含两类步的切片，任何固定方向的逐点分离不等式都必然在某些步上失败，无法作为“G 单调”或“端点最大”的充分条件。70 级 CRT-DHT 证书切片的具体数值：仅 C 步 `x=2` 处 `F_C` 比值 `>1`、`F_H` 比值 `=1`；仅 R 步 `x=1` 处 `F_C` 比值 `=1`、`F_H` 比值 `>1`。

更一般地：即使要求“每个 C 步（含联合步）都是上升步”是可检查的（§6.2(e)），它也**不是**端点最大的充分条件——70 级 CRT-DHT 的 `(300,500,610)` 切片满足该条件且 `L_max=136`，最大值仍不在端点（§7.3）。要判定端点最大必须做 §6.3(c) 的精确判据。∎

- `136 = ⌈610·200/900⌉`，比率 `136/610 = 0.2230 ≈ a_CRT/q = 0.2222`：这就是 70 级 `Θ(D·a_CRT/q)` 的精确证书。

70 级 WHM CRT-DHT，**评论 01 的贡献坐标切片**（面板 `CRT=739 / DHT=743 / DET=769` 换算为贡献 `375 / 379 / 477`，见 §13 与参考模型 §2.1；固定第三属性为 DET 贡献 477），`bases=(375,379)`，`S=610`：

- 135 个 CRT 跳变 = 67 个仅 CRT 步 + 68 个联合步（全部上升）；DHT 档位下降步 373 个（305 个仅 DHT + 68 个联合）；
- 上升步 `J+=135`、下降步 `305`、平坦 `170`、`L_max=135`、`+→-` 转折 135；
- 最大值 `4,935,252,016` 在 `x=606` 取得（端点 `4,899,756,356 / 4,931,755,144`，比右端点高 7.1 bp）——依旧是端点最大反例；
- **审计注**：若错误地把面板值 `739/743` 直接当作贡献输入（这正是本轮审计修正的初始写法），会得到 0 个仅 CRT 步 + 135 个联合步、最大值 `5,541,801,705`——事件结构与数值都发生质变。因此“评论 01 的实际切片”必须使用贡献 `(375,379,610)`，而不是面板 `(739,743,610)`（§13）。

50 级 WHM DHT-DET，`bases=(100,100)`，`S=1000`：

- 左(DHT)档位每步跳变（`a=550 > q=341`，一步可跳 1 或 2 档），共 1000 个 C 步；其中 861 个仅 DHT 步（上升）+ 139 个联合步（全部下降）；
- 上升步 `J+=861`、下降步 `139`、平坦 `0`；**`L_max = 139 ≠ J+`**：`861-139 = 722` 个上升步后面（压缩零后）紧跟上升步，它们开启的平台不是严格局部极大；`L_max=139` 由下降步“收口”，`139/1000 = 0.139 ≈ a_DET/q_DET = 140/1010 = 0.1386`；
- 最大值 `7,332,160` 在 `x=3` 取得（端点 `7,323,360 / 6,149,310`）。
- 该实例说明：**“平台数 = 上升步数”不等于“严格局部极大平台数”**；任务 brief 的第 2 版表述（J+ 个局部极大）在左档位每步跳变时会把 861 误当作局部极大数，正确值是 139。本文采用严格定义并分别报告两者。

### 7.4 边界与退化

1. **`S=0`**：切片退化为单点，`G(0)` 即最大值，端点最大平凡成立；不是反例。
2. **`lo>0` / cap**：§6.3(c) 的关键集论证只依赖 `[lo,hi]`，把 `K_L` 换成 `{lo}∪{x∈(lo,hi]: C 步}`；`verify.mjs` 的 1944 个切片中含一半带 `lo>0` 的 cap 区间，并与全扫描逐点核对（§11）。
3. **DHT tier=0 平台**：等级 70 时 DHT 贡献 0 或 1 都是 `t_H=0`（`F_H≡4000`）。在 DHT 贡献 `<=1` 的尾部区间，`F_H` 恒定，`G` 只随 CRT 非减，不会出现下降步；此时“上升步”完全由 CRT 跳变驱动，`K_L` 的右端可能出现连续多个同类关键点。
4. **BLU**：`+200` 档位偏移与 `b_C=150` 只改变数值，不改变 §6 的任何结构证明；R1 的反例正是 BLU。BLU 可达等级上限为 80（生成数据 `jobSchemas["BLU"].maxJobLevel`），但公式本身在 90/100 仍有定义；应用时以运行时 `calculationJobLevelFor` 的结果为准。
5. **detTrunc**：50/60 级 DET 档位以 5/2 为步长；`K` 枚举必须按 `mult` 步进（见姊妹定理 §5.1），否则会漏掉/重复关键点。DET 作右属性时，其每步下降量是 `detTrunc`，联合步符号判据中的 `δ` 必须取 `detTrunc`。
6. **死区预算浪费**（端点最大失败的机理）：70 级 CRT-DHT，`bases=(300,500)`，`S=1000`。`x=996`：CRT 贡献 1296，`t_C=338`，`F_C=1,232,544`；DHT 贡献 504，`t_H=308`，`F_H=4308`；乘积 `5,309,799,552`。再投 4 点到 `x=1000`：CRT 贡献 1300，仍是 `t_C=338`（下一档阈值 `1301`，`1296..1300` 是死区），而 DHT 贡献 500 掉到 `t_H=305`；乘积 `5,306,101,920`。4 个 raw 点完全没有换来 CRT 档位，却损失 3 个 DHT 档位——这就是“预算可在死区被浪费”的精确机制。
7. **联合步可下降**：50 级 WHM CRT-DHT，`bases=(0,0)`，`S=200`。`x=6` 的联合步：`t_C 52→53`、`t_H 314→312`（DHT 一步掉 2 档），`G` 从 `4,404,179,856` 降到 `4,404,100,008`。此时 §6.2(e) 判据 `(2·52+351)·(4000+314-2) = 455×4312 = 1,961,960 < 2×F_C(52) = 2,041,808` 成立（即净下降）。该切片共有 9 个联合下降步。**结论：联合步方向必须用精确乘积判断，不能假定“CRT 跳变必赢”。**
8. **“单点最大”不成立**：严格局部极大平台是平台（可能长度 >1），例如 70 级证书切片的前六个平台区间 `2..2, 6..7, ...` 中已出现长度 2 的平台。若把“最大值在唯一内部点”作为假设，会在这些平台上直接失败。

## 10. 应用前提与安全回退

### 10.1 可以安全使用的结论

1. **禁止把“端点最大”当作剪枝/上界依据。** 对三对属性、六个等级、普通/BLU，端点归约都已被反例否定；在 70 级“真实尺度”切片 `(300,500,610)` 中最大值也不在端点。
2. **安全替代 A：精确关键集枚举。** 用 §5.3(c) 的判据：
   - 若只想判定某个 **具体切片** 的端点最大是否成立：枚举 `K_L`（或更小的 `K_R`），若全部 `<= max(G(lo),G(hi))`，则该切片可以安全地只用端点；否则必须用关键集最大值。
   - 若需要该切片的精确最大：直接在 `K_L`/`K_R` 上取最大，得到的就是切片精确最大值（与全扫描相等，已证明）。
3. **安全替代 B：条件单调引理。** 运行时若已证明左档位在 `[lo,hi]` 恒定（由于档位非减，只需比较 `t_i(b_i+lo)` 与 `t_i(b_i+hi)` 两个值即可判定），可安全取 `lo`；右档位恒定（比较 `t_j(b_j+S-lo)` 与 `t_j(b_j+S-hi)`）则安全取 `hi`。
4. **安全替代 C：O(1) 上界。** 若只需要一个**保守上界**（例如联合/三维查询的乐观 bound），可用 [pairwise-slice-critical-set](../pairwise-slice-critical-set/README.md) §5.3 的分段上界族 `U_m`（严格 ≥ 切片最大值，不是精确值）；成本与 `m` 成正比（固定 `m` 即 O(1)）。
5. **最终认证。** 任何会删除候选/分支的判定，最终都要用 canonical evaluator 的完整七因子精确乘积比较（`exact-mip-candidate-upper-bound.ts:96-140`）。副属性乘积只是完整乘积的一个乘区；端点/关键集论证只解决这个乘区。

### 10.2 运行时前提检查

- `ℓ ∈ {50,60,70,80,90,100}`，`job ∈` 生成数据 `jobSchemas`，BLU 标记由 schema 给出；
- `g >= 0` 且为整数并落在安全整数范围；`g >= 0` 由基础属性归约 + 候选贡献非负结构性成立（参考模型 §2.2），故 `Math.trunc(v+1e-7)` 与精确 floor 在可达域等价；负域仅定义域外；
- 因子正性（`safeDamageFactors`）；
- `0 <= lo <= hi <= S`、`b_i,b_j >= 0`；
- 比较语义：要判“不能严格改善”用 `<=`；要判“严格更差”用 `>`；相等候选必须保留（tie 语义见 `exact-mip-candidate-upper-bound.ts:114-140`）。

### 10.3 回退链

```text
A（最快）：条件单调引理 (a)/(b) 前提成立 → 直接取 lo 或 hi
B：精确判据 max_{K_L} G <= max(G(lo),G(hi)) 成立 → 端点最大，安全归约
C：不成立 → 在 K_L/K_R（取较小方向）上精确枚举得到切片最大值/上界
D：若只需要上界 → U_m（严格上界，非精确）
E：所有前提不成立（等级/域/BLU/整数性/方向不确定）→ 回退全扫描或 canonical evaluator 精确求值
```

其中 B/C 的“安全”含义是：对**公式坐标**上的上界成立；用于真实装备剪枝时还要叠加其它乘区的乐观界与共享装备约束，最终仍由精确乘积比较认证（§10.1 第 5 条）。

## 12. 未解决问题

2. **联合步符号的闭式判据。** §6.2(e) 给出了精确交叉乘法判据与一个可检查的不等式；是否存在仅依赖 `(t_C,t_H,b_C,δ)` 的简单闭式区域（例如“当 `t_C < 4000+t_H` 时所有联合步上升”）需要逐等级证明参数范围，尚未完成（部分等级/属性对会出现联合下降步，见 §7.4 第 7 条）。
3. **一般相位下的严格 Θ 下界。** 本文给出 `L_max <= min(J+,J-)` 与两个 Θ 证书；对“任意相位类、任意 `D`，`L_max >= c·min(J+,J-)` 型下界”，需要把相位类计数与联合步符号固定条件写成无条件的数论命题。已核对 `gcd(p_L,p_R)` 个平移等价相位类（常规等级即 `gcd(P_L,P_R)`，如 70 级 CRT-DHT 的 9 类）上的每周期事件计数，但把“符号恒定”从证书提升为定理仍是 open。
4. **反例幅度的精确上界。** 对每对属性，bp 级幅度与 `detTrunc`、死区宽度的定量关系尚无闭式；例如能否证明“CRT-DHT 的端点最大失败幅度 ≤ 某常数 bp（≥60 级）”，目前只有网格证据。

7. **真实装备可行域。** 本文反例在自由资源坐标中成立；把其转化为对真实装备候选的“安全剪枝”需要 §10.1 第 5 条的完整乘积认证与可行性约束，未在本文展开。

## 13. baseStat 影响审计（贡献坐标 vs 面板总值）

> 本轮审计范围：本目录与 [pairwise-slice-critical-set](../pairwise-slice-critical-set/README.md)（其审计节见 [§13](../pairwise-slice-critical-set/README.md#13-basestat-影响审计贡献坐标-vs-面板总值)）的全部命题、示例、`verify.mjs` 输入坐标与回报数字。审计依据：[参考模型 §2.1/§2.2](../../canonical-evaluator-reference.md)（2026-10-18 更新版）与 `equipped-effects.ts:127-149`、`:178-203`。

### 13.1 坐标声明

1. 本文一切 `g`、`b_i`、`b_j`、`S`、`lo`、`hi`、`x`、档位阈值 `g_k` 与反例/示例 baseline 都是**贡献坐标**（装备 + 食物贡献），**不是面板总值**。
2. 面板总值 = 基础属性 + 贡献；`equippedAttributeTier` 的实现是 `value = baseStats[stat] + gearAndFoodValue`，再减 `sub`（CRT/DHT/TEN）或 `main`（DET）（`equipped-effects.ts:127-149`；[参考模型 §2.1](../../canonical-evaluator-reference.md)）。因此导出函数 `equippedAttributeTier(job, level, stat, gearAndFoodValue)` 的第四个实参就是贡献 `g`。
3. 换算关系（`sub/main` 见参考模型 §2 表）：

```text
CRT 贡献 = 面板 CRT − sub
DHT 贡献 = 面板 DHT − sub
DET 贡献 = 面板 DET − main
TEN 贡献 = 面板 TEN − sub          （本文不直接使用）
```

4. **DET 的偏移与 CRT/DHT 不同**：CRT/DHT 减 `sub`，DET 减 `main`。在全部六个支持等级上 `sub != main`（例如 70 级 `sub=364`、`main=292`，相差 72），所以“把同一个面板平移量同时套到三属性上”是错误操作。具体地：对 **CRT-DHT** 对，若两者都用面板值，等价于各自贡献 `+sub`（两者差值不变、绝对水平整体偏移 `sub`，档位仍会变）；对 **CRT-DET / DHT-DET** 对，CRT/DHT 偏移 `sub` 而 DET 偏移 `main`（相差 `sub−main`），绝对水平与相对差同时改变。任何混合坐标的切片都会让 DET 档位整体偏移。

### 13.2 归约链（为什么档位只依赖贡献）

```text
面板总值 P_stat
  → value = baseStats[stat] + gearAndFoodValue   (equipped-effects.ts:127)
  → baseStats.CRT = baseStats.DHT = baseStats.TEN = sub,
    baseStats.DET = main                          (getBaseStats, :178-203)
  → value − sub（CRT/DHT/TEN）或 value − main（DET） = 贡献 g
  → t_stat(g) = c + mult·floor((a g + b)/q)        (参考模型 §3)
```

该归约是生成数据推导出的性质（不是定义）；在本数据版本下对全部职业/等级成立，`verify.mjs` §11 对其逐等级断言。参考模型 §2.2 进一步说明：正式候选路径上贡献逐项非负，故四个分支的 floor 实参恒非负（CRT `>=50`、DHT `>=0`、DET `>=200`、TEN `>=1000`），`Math.trunc(v+1e-7)=floor(v)` 在可达域无条件成立——本文 H4 因此只需保证定义域为贡献 `g >= 0`，不需要额外的浮点守卫。

### 13.4 数值复核：评论 01 切片的坐标修正

参考模型 §2.1 的换算是：70 级面板 `CRT=739 / DHT=743 / DET=769` → 贡献 `375 / 379 / 477` → canonical 档位 `133 / 231 / 1074`（`verify.mjs` §11 断言）。

于是评论 01 的 CRT-DHT 切片（固定 DET 贡献 477，`S=610`）应为 `bases=(375,379)`。修正前后对比：

| 项 | 面板值误用为贡献（修正前） | 正确贡献坐标（修正后） |
| --- | --- | --- |
| baseline | `(739,743)` | `(375,379)` |
| CRT 跳变 | 135 = 0 仅 CRT + 135 联合 | 135 = **67 仅 CRT + 68 联合** |
| DHT 档位下降步 | 373（237 仅 DHT + 135 联合） | 373（**305 仅 DHT + 68 联合**） |
| G 上升/下降/平坦 | 135 / 237 / 238 | 135 / 305 / 170 |
| `L_max`（严格局部极大平台） | 135 | 135 |
| 最大值 | 5,541,801,705 @ x=607 | **4,935,252,016 @ x=606** |
| 端点值 | 5,408,478,896 / 5,540,557,754 | **4,899,756,356 / 4,931,755,144** |
| 端点最大反例？ | 是（比右端点高 2.2 bp） | **是（比右端点高 7.1 bp）** |

结论：坐标误用不只改变数值，还**质变事件结构**（正确值为 68 个联合步 / 67 个纯 CRT 步；误用面板值时变成 135 个联合步 / 0 个纯 CRT 步），并会误导“为什么联合步可以上升”的解释。修正后：67 个纯 CRT 步与 68 个联合步都使 G 上升（联合步全部为正），`L_max=135`；最大值落在 `x=606`（靠近但不在右端点 `x=610`），与评论 01 “最高区域偏向 CRT 高 / DHT 低角落”的观察一致，但仍是端点最大反例。`verify.mjs` §3c 同时保留“面板值误用”的对照断言，防止回归。

### 13.5 应用契约

1. **外部调用方**：任何把面板总值送进本文公式/定理的代码路径，必须先按属性减去 base：CRT/DHT/TEN 减 `sub`，DET 减 `main`；不得对三属性使用同一个平移量。
2. **运行时前置检查**（并入 §10.2）：记录每个 `b_i` 的来源与坐标；断言 `b_i >= 0`；若输入是面板值，先换算并断言换算后 `>=0`；DET 单独校验（`panel_DET − main`）。
3. **TEN/SKS/SPS 等非本文属性**：不在 pairwise 定理内；若复用同一换算逻辑，TEN 用 `sub`，SKS/SPS 也用 `sub`（`equipped-effects.ts:147-151`）。
4. **档位阈值/K 枚举**：全部在贡献坐标上计算（`firstContributionWithTierAtLeast` 返回贡献）；不得对面板值直接套阈值公式，否则会整体偏移 `base` 个贡献点。
5. **回退**：若坐标来源不可靠（例如外部传入未标注的统计值），回退到 canonical evaluator：先由面板值算出贡献 `panel − baseStats[stat]`，再调用 `equippedAttributeTier`/因子求值器；最终比较仍用完整七因子 BigInt 语义。
6. **形式约束**：定义域 `g >= 0` 在正式候选路径上由参考模型 §2.2 结构性保证；对导出 API 的负贡献输入仍应显式拒绝（H4 的守卫），因为在负域 `Math.trunc(v+1e-7) != floor(v)`。

### 13.6 审计结论

- **唯一发现的真问题**：评论 01 示例原先把面板值 `739/743` 当作贡献使用（坐标标签错误，非定理错误）；已改为贡献 `(375,379,610)` 并重算（§13.4），脚本同步修正且 PASS。
- **所有命题不需要改述**：Theorem 1–3 的表述与证明本来就以贡献 `g` 为自变量；面板→贡献是运行时输入换算问题，不是数学前提变化。
- **DET 风险点**已显式登记：DET 的基础属性是 `main` 而非 `sub`，三属性面板基线不能用同一平移；涉及 DET 的示例/审计表已给出各自的面板等价。
- 其余反例（`b=(0,0)`、`(800,500)`、`(0,100)`、`(300,500)`、`(100,100)` 等）本来就是贡献坐标；面板等价见 §13.3 表 13.1。
- `verify.mjs` 新增 §11「baseStat 坐标审计」（6 个等级归约、70 级换算、面板误用反例、示例面板等价），与 §3c 的修正示例一并 PASS。
