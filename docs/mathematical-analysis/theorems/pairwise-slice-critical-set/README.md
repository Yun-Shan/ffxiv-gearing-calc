## 3. 符号、量词与定义域

### 3.1 与姊妹定理相同的部分

沿用 [pairwise-endpoint-max](../pairwise-endpoint-max/README.md) §3 的 `t_stat(g)=c+mult·floor((a g+b)/q)`、`F_C/F_H/F_D`、切片

```text
G(x) = F_i(t_i(b_i+x)) · F_j(t_j(b_j+S-x)),   x ∈ Z ∩ [lo,hi],  0 <= lo <= hi <= S,
```

以及 C 步 / R 步 / 上升步 / 下降步 / 平台的定义。记 `D = hi - lo`。

**坐标声明（重要）**：与姊妹定理一致，`b_i,b_j,S,lo,hi,x` 与档位实参 `g` 全部是**贡献坐标**（装备+食物贡献），不是面板总值；面板总值 = 基础属性 + 贡献，CRT/DHT 的基础属性是 `sub`、DET 是 `main`（[参考模型 §2.1](../../canonical-evaluator-reference.md)）。`K` 的阈值与位置也都在贡献坐标上定义；本轮 baseStat 审计见 §13。

### 3.2 新增：关键集与周期

**定义 3.1（左关键集）**

```text
K_L = { lo } ∪ { x ∈ (lo,hi] : t_i(b_i+x) > t_i(b_i+x-1) }.
```

**定义 3.2（右关键集）**

```text
K_R = { hi } ∪ { x ∈ [lo,hi) : t_j(b_j+S-x) > t_j(b_j+S-x-1) }.
```

注意 `K_R` 的第二个条件就是“在步 `x → x+1` 处右档位下降”（因为右贡献在 `x` 处为 `b_j+S-x`，在 `x+1` 处为 `b_j+S-x-1`）。

**定义 3.3（档位周期参数）** 对 `t(g)=c+mult·floor((a g+b)/q)` 令 `d = gcd(a,q)`：

```text
P  = q / d              （档位周期：t(g+P) = t(g) + mult·a/d）
shift_P = mult·a/d       （一个周期内的档位增量）
p  = 跳变指示序列 t(g+1)-t(g) 的最小周期（整除 P）
```

**定义 3.4（步型词）** 对切片的一个步 `s ∈ (lo,hi]`，记

```text
w(s) = ( [s 是 C 步], [s 是 R 步] ) ∈ {0,1}²  →  C / R / 联合 / 中性
```

其中 `C` 表示“仅 C 步”、`R` 表示“仅 R 步”、`联合` 表示二者同时、`中性` 表示二者皆非。

**定义 3.5（上界族 `U_m`）** 对整数 `m >= 1`，把 `[lo,hi]` 按 `u_j = lo + floor(j·D/m)`（`j=0..m`）分成 `m` 个块 `[u_j,u_{j+1}]`，定义

```text
U_m = max_{0<=j<m} F_i( t_i(b_i+u_{j+1}) ) · F_j( t_j(b_j+S-u_j) ).
```

`U_1` 即独立极值上界 `F_i(t_i(b_i+hi))·F_j(t_j(b_j+S-lo))`。

### 3.3 量词

Theorem 1/2/3 对 `∀ ℓ ∈ Λ, ∀ job ∈ {普通,BLU}, ∀ (i,j), ∀ b_i,b_j >= 0, ∀ 0<=lo<=hi<=S` 成立；`K` 的枚举还给出一致性算法。Theorem 4 是**未解决**命题（§5.4），只给出必要条件与反例证据。

## 4. 假设

与姊妹定理 §4 相同的 (H1)–(H7)：等级 ∈ `Λ`、整数非负定义域、因子正性、精确 floor、BLU 标记、精确比较语义、网格扫描数值安全。额外注意：

- **(H8) 关键集的量化是“全称”的**：Theorem 1 对每一组输入给出同一个构造（`K_L` 或 `K_R`），不是对某组输入的拟合。
- **(H9) `U_m` 的块边界是整数**：`u_j = lo + floor(jD/m)`；块的并覆盖 `[lo,hi]`（相邻块共享端点），因此 `U_m` 是切片上的上界（§6.3）。
- **(H10) 相位/周期陈述只依赖参数**：`P,p,L,shift` 由 `(level, stat)` 决定，不由 baseline/预算决定；这正是“按等级一次性预处理、运行时只查表”的前提。注意相位本身（`σ_i = b_i mod P_i`）必须由**贡献** baseline 计算；用面板值会整体平移相位（§13）。
- **(H11) 坐标**：`b_i,b_j,S,lo,hi` 是贡献坐标；面板值须先减 `baseStats`（CRT/DHT 减 `sub`、DET 减 `main`）再进入 `K`/`U_m`/相位计算（§13）。

## 5. 精确命题

### 5.1 Theorem 1（有限关键集，已证明）

**命题 1.1（关键集等式）** 对任意允许输入，

```text
max_{x∈[lo,hi]∩Z} G(x) = max_{x∈K_L} G(x) = max_{x∈K_R} G(x).
```

**命题 1.2（大小上界）** `|K_L| <= floor(a_i·D/q_i) + 2`，`|K_R| <= floor(a_j·D/q_j) + 2`。更精确地：左档位总增益为 `(t_i(b_i+hi)-t_i(b_i+lo))/mult_i` 个 `mult_i` 单位；当 `a_i <= q_i`（每步至多跳 1 个 `mult_i`）时跳变位置数恰等于该总增益，故 `|K_L| = (t_i(b_i+hi)-t_i(b_i+lo))/mult_i + 1`；当 `a_i > q_i`（如 L50 DHT 一步可跳 2 档）时每步都跳变，`|K_L| = D+1`，而 `floor(a_i D/q_i)+2` 仍给出合法（更松）的上界。

**命题 1.3（枚举算法与复杂度）** 给定输入，`K_L` 可由以下 O(|K_L|) 闭式枚举得到（`stat = i`）：

```text
K ← {lo}
k0 ← t_stat(b_stat + lo);  k1 ← t_stat(b_stat + hi);  m ← mult_stat
for k = k0+m, k0+2m, ..., k1:
    g_k ← firstContributionWithTierAtLeast(level, job, stat, k)   # 使 t_stat(g) >= k 的最小 g
    x   ← g_k - b_stat
    if lo < x <= hi:  K ← K ∪ {x}
```

其中 `firstContributionWithTierAtLeast(level,job,stat,k) = ceil((ceil((k-c)/mult)·q - b)/a)`（见参考模型/`canonical-model.mjs:112-117`；`g_k` 可能为负，但对 `k > t_stat(b_stat+lo)` 必有 `g_k > b_stat+lo >= 0`）。每个 `x` 只需一次 `G` 求值；总成本 `O(|K_L|)` 次因子求值（每次 2 次 tier + 2 次因子 + 1 次 BigInt 乘法），额外空间 O(1)。对称地可枚举 `K_R`。

**命题 1.4（方向选择）** 由于 `K_L` 与 `K_R` 任取其一都精确，运行时取较小者：

```text
cost = min( |K_L|, |K_R| )  ≈  D · min( a_i/q_i, a_j/q_j ) + O(1)
```

（`a_stat/q_stat >= 1` 时对应方向的“每步都跳变”上界为 `D+1`。）对 DET 作右属性的两个 pair，`K_R` 通常显著更小（因为 `a_DET/q_DET` 最小）。

**命题 1.5（工作示例，70 级 WHM CRT-DHT，`bases=(300,500)`，`S=610`）**

- `t_CRT(300)=116`、`t_CRT(910)=252`，`k=117..252` 共 136 个跳变；`K_L={0}∪{...}`，`|K_L|=137`；
- `K_R={610}∪{...}`，`|K_R|=374`（DHT 下降步 373 + 端点）；取 `K_L`，成本 137 次求值（全扫描 611 次，节省 4.46×）；
- 阈值公式前几个：`g_117=302 → x=2`，`g_118=306 → x=6`，`g_119=311 → x=11`，`g_120=315 → x=15`，…（与姊妹定理 §7.3 的平台起点一致）；
- `max_{K_L} G = 4,959,237,424`，在 `x=609` 取得（该值也是全切片最大值；注意它不是端点）。

### 5.2 Theorem 2（阶梯/交错周期结构，已证明）

**(a) 档位周期。** 对每个 `stat`，`t(g+P)=t(g)+shift_P`，其中 `P=q/gcd(a,q)`、`shift_P=mult·a/gcd(a,q)`；跳变指示序列 `g ↦ [t(g+1)>t(g)]` 以 `P` 为周期，其最小周期 `p` 整除 `P`。

**(b) 步型词的周期。** 在切片坐标 `s` 中，`C` 指示是 `(b_i+s) mod P_i` 的函数，`R` 指示是 `(b_j+S-s) mod P_j` 的函数，因此步型词 `w(s)` 以

```text
L = lcm(P_i, P_j)
```

为周期。其最小周期为 `p_word = lcm(p_i, p_j)`。

**(c) 每周期事件计数（与相位无关的部分）。** 一个共同周期内：

```text
#C 步 = a_i·L/q_i     （a_i <= q_i 时；a_i > q_i 时每一步都是 C 步，即 L）
#R 步 = a_j·L/q_j     （同上）
#联合步 = 相位相关；#中性步 = L - #C - #R + #联合步
```

**(d) tier 漂移。** 走过一个共同周期 `L` 后，左右档位（以档位值计）分别漂移

```text
t_i: + a_i·L/q_i,      t_j: - mult_j·a_j·L/q_j.
```

（每个 `R` 步右档位下降 `mult_j`，一个周期内右档位下降步数为 `a_j·L/q_j`，故档位值漂移 `mult_j·a_j·L/q_j`；左属性在本文三对中恒有 `mult_i=1`。）因此**阶梯形状以 L 为周期重复，但档位索引逐周期线性漂移**：这正是“可由周期结构复用，但不能把相位局部模式当成绝对档位”的原因。

**(e) 相位类与交错方式数。** 步型词的左、右分量分别由 `σ_i=(b_i mod P_i)`、`σ_j=((b_j+S) mod P_j)` 的相位决定；由于两个跳变指示序列的最小周期是 `p_i | P_i`、`p_j | P_j`，词最终只依赖 `(σ_i mod p_i, σ_j mod p_j)`。把切片整体平移 `t` 视为同一交错模式，相当于 `(σ_i, σ_j) → (σ_i+t, σ_j-t)`；两个相位类通过平移等价当且仅当存在 `t` 同时满足两个同余式，由 CRT 可解当且仅当 `(σ_i'-σ_i)+(σ_j'-σ_j) ≡ 0 (mod gcd(p_i,p_j))`。因此：

```text
互异步型词数        = p_i · p_j
词最小周期          = lcm(p_i, p_j)
平移等价交错方式数  = p_i·p_j / lcm(p_i,p_j) = gcd(p_i, p_j)
```

在常规等级（`p_i=P_i, p_j=P_j`）这些数退化为 `P_i·P_j`、`lcm(P_i,P_j)`、`gcd(P_i,P_j)`；50 级 DHT 作左/右属性时 `p=1` 会显著减少互异词数。联合步计数只依赖上述平移等价类；70 级 CRT-DHT（`p_i=P_i=9, p_j=P_j=18`）的 9 个相位类上联合步数为 2..4，见 §7.2 与 §11。

**(f) 非支配阶梯序列。** 定义状态 `(t_i(x), t_j(x))`；随 x 增加，第一坐标非减、第二坐标非增，所以所有被访问状态两两互不支配（除相同状态的重复），构成一条单调格路径。每个共同周期后状态整体平移 `(+a_i L/q_i, -mult_j·a_j L/q_j)`，步型词逐周期重复；因此**周期内“形状”不变、绝对位置漂移**。切片的局部极大/极小结构因此可归结为“一个周期内的步型词 + 漂移方向”。

### 5.3 Theorem 3（O(1) 严格上界族，已证明）

**命题 3.1（合法性）** 对任意 `m >= 1`，`U_m >= max_{x∈[lo,hi]} G(x)`。

**命题 3.2（分块细化单调收紧）** `U_1 >= U_2 >= U_4 >= … >= max G`；且 `m → ∞` 时 `U_m ↓ max G`。

**命题 3.3（复杂度）** 计算 `U_m` 需 `m` 次块界求值（每次 2 次 tier + 2 次因子）；固定 `m` 时 `O(1)` 次因子求值。它**不是精确算法**：在非平凡切片上 `U_m > max G`（见 §7.3 的紧度表），因此只能作为保守上界/剪枝界使用。

**命题 3.4（与精确关键集最大值的紧度，70 级 WHM CRT-DHT，`bases=(300,500)`，`S=610`）**

| `U_1` | 5,387,671,312 | 863 bp |
| `U_2` | 5,172,302,664 | 429 bp |
| `U_4` | 5,066,345,896 | 215 bp |

### 5.4 Theorem 4（关键集不可再小，未解决）

**命题 4.1（未解决）** 不存在（或不存在已知的）在**不加额外结构**的前提下把 `K_L`（或 `K_R`）严格缩小到 `K' ⊊ K` 且仍对所有输入精确的归约。本文给出：

1. 端点归约 `K'={lo,hi}` **错误**：引用 [pairwise-endpoint-max](../pairwise-endpoint-max/README.md) Theorem 1（三对属性 × 全部等级 × 普通/BLU 均有反例）。
2. 单峰/单一关键点归约 **错误**：引用姊妹定理 Theorem 2(c)：证书切片的严格局部极大平台数 `L_max` 可达 136（70 级 CRT-DHT）/139（50 级 DHT-DET）。
3. 按“固定残类”删除关键点 **有反例证据**：实际尺度网格上，内部 argmax 覆盖了**全部**关键点位置残类（§7.4 与 `verify.mjs` §9），所以任何基于残类的固定子集都会在某些输入漏掉 argmax。
4. **但本文不声称不可能性**：没有证明“不存在更聪明的依赖输入的归约”。一个严格缩小 `K` 的归约需要一个显式的支配关系（对每个被删点 `x`，给出保留点 `x'` 与对所有输入成立的参数不等式），或一个“记录单调”论证；两者都未完成。状态：**未解决**。

## 6. 证明

### 6.1 Theorem 1 的证明

**(1.1) 关键集等式。** 只证 `max = max_{K_L}`，`K_R` 对称。

把 `[lo,hi]` 按左档位 `t_i(b_i+x)` 的常量性分成极大区间 `I_1,…,I_m`（相邻区间在端点处档位不同）。每个 `I_k` 的左端点 `u_k`：`u_1 = lo`，其余 `u_k ∈ (lo,hi]` 且 `t_i(u_k) > t_i(u_k-1)`，即 `u_k ∈ K_L`。

在单个 `I_k` 上，`t_i` 恒定 ⇒ `F_i` 恒定；`x` 增加 1 时右贡献 `b_j+S-x` 减 1 ⇒ `t_j` 非增 ⇒ `F_j` 非增。故 `G` 在 `I_k` 上非增，最大值在 `u_k` 取得。于是

```text
max_{[lo,hi]} G = max_k G(u_k) = max_{K_L} G.  ∎
```

（`K_R` 的证明对偶：按 `t_j` 的常量区间分块，`G` 在每块上非减，最大值在右端点；右端点为 `hi` 或右档位下降位置。）

**(1.2) 大小上界。** 每个跳变位置使左档位至少增加 `mult_i`，而 `[lo,hi]` 上的总档位增益为 `mult_i·(floor((a_i·hi+b_i')/q_i) - floor((a_i·lo+b_i')/q_i))`。设 `A(x)=floor((a_i x+b_i')/q_i)`，则

```text
A(hi)-A(lo) = floor((a_i·hi+b')/q_i) - floor((a_i·lo+b')/q_i) <= floor(a_i·D/q_i) + 1
```

（用了 `floor(u+v)-floor(u) <= floor(v)+1`），故跳变位置数 `<= floor(a_i D/q_i)+1`，`|K_L| <= floor(a_i D/q_i)+2`。当 `a_i <= q_i` 时每步至多跳 1 个 `mult_i`，跳变位置数恰等于总增益 `(t_i(hi)-t_i(lo))/mult_i`；当 `a_i > q_i` 时每步都跳变，`|K_L| = D+1`，仍满足该上界。∎

**(1.3) 阈值公式的正确性。** `t_stat(g) >= k ⇔ c + mult·floor((a g+b)/q) >= k ⇔ floor((a g+b)/q) >= ceil((k-c)/mult) ⇔ a g+b >= q·ceil((k-c)/mult) ⇔ g >= (q·ceil((k-c)/mult) - b)/a`，取最小整数即 `g_k`。由于 `t_stat` 在相邻 `k`（步长 `mult`）之间的跳变位置恰是 `t_stat(g_k-1) < k` 且 `t_stat(g_k) >= k` 的点，`g_k` 正是第 `k` 档的阈值；对所有 `k ∈ (t_stat(b+lo), t_stat(b+hi)]` 收集 `x=g_k-b` 即得 `K_L \ {lo}`（重复的 `x` 去重，见 L50 DHT 一步 2 档的情形）。∎

**(1.4) 方向选择。** 两个方向各自精确（(1.1)），取较小关键集不损失正确性。密度估计 `|K_L|-1 ≈ D·a_i/q_i`、`|K_R|-1 ≈ D·a_j/q_j` 由 (1.2) 的差分关系得到。DET 的 `a/q` 在全部等级都最小（约 0.139–0.156），故含 DET 的两个 pair 常取 `K_R`。∎

### 6.2 Theorem 2 的证明

**(a)** 写 `ag+b = mq+r`，`r = (ag+b) mod q`。则 `a(g+P)+b = mq + r + aP`，且 `aP = a·q/d = q·(a/d)`，其中 `d=gcd(a,q)`，故 `floor((a(g+P)+b)/q) = floor((ag+b)/q) + a/d`。乘 `mult` 得档位漂移。跳变指示为

```text
t(g+1)-t(g) = mult·floor((r(g)+a)/q)
```

（窗口增益引理 (6.0.1) 的 `δ=1` 情形，见姊妹定理 §6.0），它是 `r(g)` 的函数；而 `r(g+P)=r(g)`（因 `aP` 是 `q` 的倍数），故指示序列以 `P` 为周期；其最小周期 `p` 必整除 `P`（有限周期序列的最小周期整除任一周期）。对全部支持等级/属性直接枚举得 `p` 的取值表（§7.2）；唯一退化是 50 级 DHT：`a=550>q=341`，每步都跳变，故 `p=1`。∎

**(b)** 切片中 `C` 步条件 `t_i(b_i+s)>t_i(b_i+s-1)` 只依赖 `(b_i+s) mod P_i`（因为 `r` 是模 `q_i` 的余数，而 `s ↦ b_i+s` 的相位周期为 `P_i`）；`R` 步条件 `t_j(y)>t_j(y-1)`（`y=b_j+S-s`）只依赖 `(b_j+S-s) mod P_j`，即 `s mod P_j`。因此步型词是 `(s mod P_i, s mod P_j)` 的函数，以 `L=lcm(P_i,P_j)` 为周期。最小周期是两指示最小周期的共同最小周期，即 `lcm(p_i,p_j)`。∎

**(c)** 一个周期 `L` 内左档位总增益为（由 (a) 漂移公式）`a_i·L/q_i` 个档位。若 `a_i <= q_i`，每次 C 步恰好增加 1 个档位（L50 DHT `a>q` 时一步可增 2，但每步都跳变），故 `#C 步 = a_i·L/q_i`；否则每步都是 C 步，`#C 步 = L`。右属性对偶。联合步数 = #C + #R − #(C 或 R)，由相位决定。∎

**(d)** 由 (a) 的漂移公式，走过 `L` 后 `t_i` 增加 `a_i L/q_i`（左属性 `mult_i=1`），而右档位下降步数为 `a_j L/q_j`、每步下降 `mult_j`，故 `t_j` 减少 `mult_j·a_j L/q_j`。∎

**(e)** 相位类：词 `w` 由相位对 `(σ_i mod p_i, σ_j mod p_j)` 决定（`p_i,p_j` 为两指示序列的最小周期；词最终只依赖这两项，因为指示序列在周期平移下不变）。将 x 平移 `t` 相当于 `σ_i → σ_i+t`、`σ_j → σ_j−t`。两个词互为平移当且仅当存在 `t` 同时满足两个同余式；由 CRT，可解当且仅当 `(σ_i'-σ_i)+(σ_j'-σ_j) ≡ 0 (mod gcd(p_i,p_j))`。故平移等价类数 = `gcd(p_i,p_j)`，且联合步计数只依赖该相对相位；互异词数为 `p_i p_j`，词最小周期为 `lcm(p_i,p_j)`，且 `p_i p_j / lcm(p_i,p_j) = gcd(p_i,p_j)`。在 70 级 CRT-DHT（`p_i=9,p_j=18`）上这就是 9 个相位类、联合步数取 2..4 的原因。∎

**(f)** 状态坐标单调性由档位单调性直接得到；每个状态是“左档位高、右档位低”的折衷，不同 x 的状态在至少一个坐标上严格优于另一个方向，因此两两不支配（相同坐标值的重复除外）。周期平移由 (a)(d) 得到。∎

### 6.3 Theorem 3 的证明

**合法性。** 对任意 `x ∈ [lo,hi]`，令 `j` 使 `u_j <= x <= u_{j+1}`。左档位随贡献非减 ⇒ `t_i(b_i+x) <= t_i(b_i+u_{j+1})` ⇒ `F_i(...) <= F_i(t_i(b_i+u_{j+1}))`；右贡献随 x 非增 ⇒ `b_j+S-x >= b_j+S-u_j` ⇒ `t_j(...) >= t_j(b_j+S-u_j)` ⇒ `F_j(b_j+S-x) <= F_j(t_j(b_j+S-u_j))`（`F_j` 非减）。两式相乘得 `G(x) <= U_{m,j}`，取最大即 `G(x) <= U_m`。∎

**单调收紧。** 把某块 `[u,v]` 细分为 `[u,w]`、`[w,v]`（`u<=w<=v`）。两块界为

```text
F_i(t_i(v))·F_j(t_j(u))          （原块）
F_i(t_i(w))·F_j(t_j(u)),  F_i(t_i(v))·F_j(t_j(w))   （细化后）
```

因为 `F_i(t_i(w)) <= F_i(t_i(v))`、`F_j(t_j(w)) <= F_j(t_j(u))`，两个细化块界都不超过原块界（另见：对右因子，`w>=u` 使 `b_j+S-w <= b_j+S-u`，`F_j` 非减 ⇒ 更小）。故 `U_{m+1} <= U_m`。∎

**收敛/非精确。** 固定 `x`，取包含 `x` 的块序列；块长趋于 0 时块界趋于 `G(x)`（`u_{j+1}↓x`、`u_j↑x`，由 `F` 的连续/阶梯极限），故 `U_m ↓ max G`。非平凡切片上 `U_m > max G`：只要最大值点 `x*` 不是某个块内“左因子取右端、右因子取左端”同时紧的点（一般不可能），块界就严格大于块内最大值；数值见 §7.3。∎

### 6.4 Theorem 4 的讨论

Theorem 4 不是已证明命题。其“需要什么”可以精确表述为：

> 若存在归约 `K'(输入) ⊆ K_L(输入)` 对所有输入满足 `max_{K'} G = max_{K_L} G`，则对每个被删除的关键点 `x` 与每个输入，必须存在保留点 `x'` 使 `G(x') >= G(x)`。由于关键点位置依赖输入（阈值随 baseline 平移），这要求一个对 `(level,job,pair,b_i,b_j,S,相位类)` 一致的支配关系，或一个只依赖残类/位置的、对所有输入成立的比较不等式。

已知的三种候选支配关系都失败：端点（姊妹定理 Theorem 1）、单峰/单关键点（姊妹定理 Theorem 2）、固定残类（本节 §7.4 的 argmax 覆盖证据）。是否存在别的（例如“记录最大值只可能在每个相位类的少数位置”）没有证明，见 §12。∎（未解决）

### 7.4 边界与退化

1. **`S=0` 或 `lo=hi`**：切片单点，`K_L={lo}`（`K_R={hi}`），命题 1.1 平凡成立。
2. **cap 区间**：`K` 的定义只用到 `[lo,hi]`，与 `S` 无关；`0 <= lo <= hi <= S` 任意。`verify.mjs` 用 1944 个含 `lo>0` 的切片核对。
3. **L50 DHT 作左属性（`a=550>q=341`）**：一步可增 2 档；阈值公式会对相邻 `k` 给出相同的 `g_k`，必须去重（`K` 定义为集合）。此时 `K_L` 大小为 `D+1`（不节省），应改用 `K_R`（DET 密度 0.139）。`p=1`（每步都跳变）。
4. **DET 作右属性（`mult=detTrunc`）**：`K_R` 的阈值步长是 `mult`（5 或 2 或 1），右档位每步下降量为 `detTrunc`；遗漏 `mult` 会重复/漏关键点，`verify.mjs` 用暴力跳变集逐点核对。
5. **DHT tier=0 平台**：右属性档位恒为 0 的区间上 `F_H≡4000`，此时 `K_R={hi}` 也可能精确（因为 `G` 在 `[lo,hi]` 上非减），与命题 1.1 一致，不是反例。
6. **`U_m` 的块边界**：`D < m` 时 `u_j` 会重复，产生单点块（块界等于该点精确值），`U_m` 仍然合法且更紧；不会产生下界。
7. **相位类与联合步**：`K` 枚举与相位无关（它只用左档位），但**联合步的符号**与相位/绝对档位有关（姊妹定理 §6.2(e)）；因此“某一切片中每个 C 步都是上升步”是逐切片可检查的，不是跨相位恒真的。
8. **argmax 的覆盖证据**（Theorem 4 的证据）：实际尺度网格上，内部 argmax 覆盖全部关键点位置残类：70 级 CRT-DHT `{5,0} mod 9` 全覆盖（422/576 个切片 argmax 在内部关键点）、70 级 CRT-DET 同（475/576）、50 级 DHT-DET 全部 31 个残类（543/576）、100 级 CRT-DHT 全部 10 个关键点位置残类（446/576）。这说明“固定残类子集”会漏解，但**不是**不可能性证明。

## 10. 应用前提与安全回退

### 10.1 精确 pairwise 最大

```text
输入：level, job, pair, b_i, b_j, S, lo, hi
1. 检查 §4 前提（等级 ∈ Λ、整数非负、g >= 0、因子正性）
2. 若左档位在 [lo,hi] 恒定 → 返回 G(lo)（条件单调引理）
3. 若右档位在 [lo,hi] 恒定 → 返回 G(hi)
4. 计算 |K_L|、|K_R| 的估计（阈值公式计数或密度 + 2），选较小方向
5. 枚举该方向的关键集并在其上取 BigInt 精确最大值；相等候选全部保留
6. 返回 max（这是切片的精确最大值，与全扫描相等）
```

### 10.2 端点最大判据（与姊妹定理组合）

若运行时只关心“该切片能否安全地只用端点”：

```text
max_{K_L} G <= max(G(lo),G(hi))  ⇔  端点最大成立（精确）
```

- 成立：后续可只用两端的精确求值（例如作为某些界的分量）。
- 不成立：必须用关键集最大值（不能“近似”为端点）。

### 10.3 保守上界

若只需要严格上界且希望 O(1)（不随 D 增长）：

```text
U_m（固定 m，例如 4/8/16）
```

- 它 ≥ 切片精确最大值（合法剪枝界），但不是精确值；越大的 m 越紧、成本越高。
- 用于联合/三维查询时，其它乘区仍须取严格乐观界，最终用完整七因子 BigInt 比较认证。

### 10.4 回退链

```text
A：条件单调引理成立 → 端点（O(1)）
B：关键集枚举（O(#K)，精确）
C：若 |K| 仍过大（如 L50 DHT 作左属性且不能用 K_R）→ 换方向；或退化为受限区间/分段
D：只需上界 → U_m
E：前提不成立或需要完整伤害/DPS → canonical evaluator 全扫描 / 现有 exact solver
```

### 10.5 安全边界

- 关键集等式只解决副属性乘积乘区；完整伤害还包括 `weaponDamage·mainStat·determination·tenacity·critical·directHit·(1/GCD)`，最终比较必须用 `exact-mip-candidate-upper-bound.ts:96-140` 的 BigInt 语义；**严格改善用 `>`、不能严格改善用 `<=`，相等候选保留**。
- 三属性/真实装备层面：本文只给“切片精确最大”这一子问题；把 pairwise 精确最大组合成三维上界需要额外证明（见 [simplex-vertex-reduction](../simplex-vertex-reduction/README.md)），不能直接把“逐边端点最大”当作既定事实（它已被否证）。
- 运行时若 `g<0`、非整数、超出安全整数、等级不在表内或 BLU 标记不可靠：停止使用本文定理并回退。其中 `g<0` 在正式候选路径不可达（基础属性归约 + 候选贡献非负，参考模型 §2.2），该守卫是防御性的。
- **可选：真实域可行性预筛（slab，仅限真实域）。** 若同一上下文已有经证明的安全和界 `L <= C+H+D <= R`（[substat-sum-lower-bound-pruning](../substat-sum-lower-bound-pruning/README.md)），则固定第三坐标 `d0`、两属性和 `S_pair` 的切片只有在 `S_pair + d0 ∈ [L,R]` 时才可能含真实完成，否则可跳过该切片（用于**真实域**枚举/可行性判定）。**不得**用于为 `U` 的松弛最大值计算或顶点/部分归约证书跳过切片——那些对象必须覆盖全部切片（见该文 PR3 的适用范围与反例）。

## 13. baseStat 影响审计（贡献坐标 vs 面板总值）

> 本轮审计与姊妹文档 [pairwise-endpoint-max §13](../pairwise-endpoint-max/README.md#13-basestat-影响审计贡献坐标-vs-面板总值) 同步进行；审计依据为 [参考模型 §2.1/§2.2](../../canonical-evaluator-reference.md)（2026-10-18 更新版）与 `equipped-effects.ts:127-149`、`:178-203`。

### 13.1 坐标声明

1. 本目录一切 `b_i,b_j,S,lo,hi,x`、档位实参 `g`、阈值 `g_k`、`K_L/K_R` 位置、`U_m` 块边界与相位 `σ_i=b_i mod P_i` 都是**贡献坐标**，不是面板总值。
2. 面板总值 = 基础属性 + 贡献；CRT/DHT 的基础属性是 `sub`、DET 是 `main`（`equipped-effects.ts:127-149`；参考模型 §2.1）。因此
   `CRT/DHT 贡献 = 面板 − sub`，`DET 贡献 = 面板 − main`；**DET 的平移量与 CRT/DHT 不同**（六个等级上 `sub != main`）。
3. 正式候选路径上贡献逐项非负，故 `g >= 0`；由参考模型 §2.2，档位 floor 实参结构性非负，`Math.trunc(v+1e-7)=floor(v)` 无条件成立。该结论不改变本目录任何证明，只把“运行时守卫”降级为对导出 API 的稳健性要求。

### 13.2 归约链

```text
面板 P_stat
  → value = baseStats[stat] + gearAndFoodValue     (equipped-effects.ts:127)
  → baseStats.CRT = baseStats.DHT = sub, baseStats.DET = main   (getBaseStats :178-203)
  → 贡献 g = value − sub（CRT/DHT）或 value − main（DET）
  → t_stat(g) = c + mult·floor((a g + b)/q)          → K_L/K_R、U_m、P/p/L 全部以 g 计算
```

`firstContributionWithTierAtLeast` 返回的 `g_k` 是贡献阈值；`K_L` 的跳变位置 `x = g_k − b_L` 中的 `b_L` 必须是贡献 baseline。若误用面板值，位置会整体平移 `base_L` 个贡献点，并可能改变去重结果（L50 DHT 一步 2 档）。

### 13.5 应用契约

1. 调用 `K` 枚举/`U_m`/相位计算前，必须把面板值换算成贡献：CRT/DHT 减 `sub`，DET 减 `main`；**不得**对三属性使用同一平移。
