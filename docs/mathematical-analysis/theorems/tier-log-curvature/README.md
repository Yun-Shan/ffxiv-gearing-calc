## 4. 精确命题

### Definition 4.1（正序列的离散对数凸/凹）

设 `I ⊆ ℤ` 为整数区间，`F: I → ℝ_{>0}`。

- 称 `F` 在 `I` 上 **log-convex**（对数凸），若 `∀t` 满足 `t, t+1, t+2 ∈ I` 有 `F(t+2)·F(t) >= F(t+1)²`；**严格** log-convex 指该不等式严格成立（取 `>`）。
- 称 `F` 在 `I` 上 **log-concave**（对数凹），若上述不等式反向 `<=`；**严格**指取 `<`。

等价刻画：`log F`（逐点有定义）作为离散序列的二阶差非负/非正。

### Definition 4.2（E 判据与比值序列）

对 `t, t+1, t+2` 均在定义域内，定义

```text
E(t) := F(t+2)·F(t) - F(t+1)²
r_t  := F(t+1)/F(t)                     （F(t), F(t+1) > 0）
```

### Lemma 4.3（判据等价，两向）

设 `F(t), F(t+1), F(t+2) > 0`。则

```text
E(t) > 0  ⟺  r_{t+1} > r_t  ⟺  log F 在 (t, t+1, t+2) 上严格凸
E(t) = 0  ⟺  r_{t+1} = r_t  ⟺  三点 log 线性
E(t) < 0  ⟺  r_{t+1} < r_t  ⟺  log F 在 (t, t+1, t+2) 上严格凹
```

特别地：`F` 在整数区间 `[u, v]` 上 log-convex ⟺ `E(t) >= 0` 对 `∀t ∈ [u, v-2]`；log-concave ⟺ `E(t) <= 0` 对 `∀t ∈ [u, v-2]`。

### Theorem 4.4（CRT 二次因子的 E 闭式）

对 `∀t ∈ ℤ`、`b ∈ ℝ`：

```text
F_b(t+1) = F_b(t) + 2t + 1 + b
F_b(t+2) = F_b(t) + 2(2t + 2 + b)
E_b(t)   = 2·F_b(t) - (2t + 1 + b)²
         = 2,000,000 - 2t² - (2b + 4)t - (b + 1)²
```

（`F_b(t) = 1,000,000 + t(t+b)`；中间代数在 §5.2 逐步展开。）

### Corollary 4.5（普通职业 `b = 350` 的切换）

```text
E_350(t) = 1,876,799 - 2t² - 704t
```

`E_350` 在 `t >= 0` 上严格递减，且

```text
E_350(808) = +2,239 > 0,     E_350(809) = -1,699 < 0
⟹ E_350(t) > 0 对所有整数 0 <= t <= 808；E_350(t) < 0 对所有整数 t >= 809
```

推论（比值语言）：`r_0 < r_1 < ... < r_809` 且 `r_809 > r_810 > r_811 > ...`，即比值序列在 `r_809` 取得严格全局最大。`F_350` 在索引区间 `[0, 810]` 上严格 log-convex，在 `[809, +∞)` 上严格 log-concave。（这里把 `F_350` 视为对全部整数 `t` 有定义的因子代数表达式；实际档位域从 `t >= 50` 开始。）

### Corollary 4.6（BLU `b = 150` 的切换）

```text
E_150(t) = 1,977,199 - 2t² - 304t
```

在 `t >= 0` 上严格递减，且

```text
E_150(921) = +733 > 0,       E_150(922) = -3,257 < 0
⟹ E_150(t) > 0 对整数 0 <= t <= 921；E_150(t) < 0 对整数 t >= 922
```

推论：`r_0 < ... < r_922 > r_923 > ...`，比值峰值在 `r_922`；`F_150` 在 `[0, 923]` 上严格 log-convex，在 `[922, +∞)` 上严格 log-concave。

### Lemma 4.7（CRT 因子全局正性）

对 `∀t ∈ ℝ`、`∀b` 满足 `b² < 4,000,000`（包含 `b ∈ {150, 350}`）：

```text
F_b(t) = 1,000,000 + t(t+b) = (t + b/2)² + 1,000,000 - b²/4 >= 1,000,000 - b²/4 > 0
```

因此 `log F_b` 对一切整数 `t` 有定义；`b = 350` 时最小值 `F = 969,375`（`t = -175`），`b = 150` 时最小值 `F = 994,375`（`t = -75`）。

### Theorem 4.8（DHT/DET 线性族：任意步长严格 log-concave）

对任意 `A ∈ ℝ`、`∀t ∈ ℤ`、`∀k ∈ ℤ_{>0}`：

```text
(A + t + 2k)·(A + t) - (A + t + k)² = -k² < 0
```

取 `A = 4000` 得 DHT：`F_H` 对任意正步长 `k` 严格 log-concave；取 `A = 0` 得 DET：`F_D` 同样严格 log-concave。等价地：`r_t = (A+t+1)/(A+t)` 严格递减。

### Corollary 4.9（DET 的 `detTrunc` 采样版本）

DET 档位只取 `mult = detTrunc ∈ {1, 2, 5}` 的倍数；相邻可达档位步长为 `mult`。对 `k` 个可达档位步长（即档位差 `mult·k`）：

```text
F_D(t)·F_D(t + 2·mult·k) - F_D(t + mult·k)² = -(mult·k)² < 0
```

即 DET 在采样后的序列上仍严格 log-concave，凹性强度是 `-(mult·k)²`（`mult=5` 时比 `mult=1` 强 25 倍）。

### Theorem 4.11（raw 级失败：tier 结论不可直接转移）

对每个等级 `ℓ` 与每个因子族（CRT 普通、CRT BLU、DHT、DET、TEN），令 raw 序列

```text
G(g) := F(t_{ℓ,σ}(g))        （t_{ℓ,σ} 为 raw-tier-transform 的整数档位模型）
E_raw(g) := G(g+2)·G(g) - G(g+1)²
```

则 `{E_raw(g)}_{g >= 0}` **同时取正号与负号**；等价地 raw 比值 `G(g+1)/G(g)` 既不单调不减也不单调不增，因此 raw 序列既不 log-convex 也不 log-concave。故 tier 级结论 **不能**直接转移到 raw 贡献坐标。

### Corollary 4.12（平台/跳变机制）

令 `F` 严格增且为正、`t(g)` 非减，`Δ(g) := t(g+1) - t(g) ∈ {0, 1, 2, ...}`。则

```text
E_raw(g) = G(g+2)G(g) - G(g+1)²
```

满足：

1. **平台后跳变**：若 `Δ(g) = 0` 且 `Δ(g+1) > 0`，则 `E_raw(g) = G(g)·(G(g+2) - G(g)) > 0`；
2. **跳变后平台**：若 `Δ(g) > 0` 且 `Δ(g+1) = 0`，则 `E_raw(g) = G(g+1)·(G(g) - G(g+1)) < 0`。

对线性因子族 `G(g) = A + t(g)`（DHT/DET/TEN）还有精确公式：

```text
E_raw(g) = (A + t(g))·(Δ(g+1) - Δ(g)) - Δ(g)²
```

于是 `Δ` 上升处 `E_raw > 0`（当 `A + t > Δ²`），`Δ` 下降处 `E_raw < 0`。raw 序列的比值在平台步为 1、在跳变步 `> 1`，因此必然振荡。

更一般地，对**任何非恒定的步序列** `Δ`，只要满足下列任一条件，`E_raw` 就同时取两符号：

1. **周期性**：`Δ` 以 `P` 为周期且非常值。绕一个周期一圈，`Δ` 必须同时出现上升转移（`Δ(g+1) > Δ(g)`）与下降转移（`Δ(g+1) < Δ(g)`，否则周期序列单调且最终恒定，与非常值矛盾）；由上式，上升处 `E_raw > 0`、下降处 `E_raw < 0`（需 `A + t > max Δ²`）。
2. **非减性**：`Δ` 非减且非常值。整数有界非减序列最终恒定于 `K∞ >= 1`；在最后一次严格上升处 `E_raw = (A+t)(Δ2-Δ1) - Δ1² >= (A+t) - K² > 0`，尾部恒定处 `E_raw = -K∞² < 0`。

floor-线性档位映射产生的 `Δ` 总是周期性的（周期 `P = q/d`），本项目的所有实例都落在条件 1；因此「任意非恒定（非减）步序列」在本文参数范围内的两种自然严格化都会导致 `E_raw` 双符号。

### Corollary 4.13（比值单调性的产品界，供应用层使用）

设 `F > 0` 在整数区间 `[t_1, t_2]` 上 log-convex（即 `E(t) >= 0` 对 `t_1 <= t <= t_2 - 2`）。则比值 `r_t` 在 `[t_1, t_2-1]` 上非减，且对 `n = t_2 - t_1 >= 1`：

```text
r_{t_1}^n  <=  F(t_2)/F(t_1)  <=  r_{t_2-1}^n
```

即（全部用 BigInt 交叉相乘/整数幂比较，避免浮点）：

```text
下界: F(t_2) · F(t_1)^{n-1} >= F(t_1+1)^n          （n >= 1）
上界: F(t_2-1)^n <= F(t_1) · F(t_2)^{n-1}
```

log-concave 分支（`E(t) <= 0`）同理但不等号反向。这是把「每档相对收益单调」转成严格可复核的乘积上/下界的接口；若区间跨切换点，则只能分段或回退。

## 5. 证明

### 5.1 Lemma 4.3（判据等价）的证明

`C := F(t)·F(t+1) > 0`。直接通分：

```text
r_{t+1} - r_t = F(t+2)/F(t+1) - F(t+1)/F(t)
              = [F(t+2)·F(t) - F(t+1)²] / [F(t+1)·F(t)]
              = E(t) / C
```

分母 `C > 0`，故 `r_{t+1} - r_t` 与 `E(t)` 同号；三种符号情形逐项对应。另一方面

```text
log r_{t+1} - log r_t = log F(t+2) - 2·log F(t+1) + log F(t)
```

恰是 `log F` 在索引 `t+1` 处的离散二阶差；比值单调（`log r` 的符号）因此等价于 `log F` 的离散凸/凹。区间版本按定义对每个内点 `t` 应用三点结论。∎

### 5.2 Theorem 4.4（E 闭式）的证明

记 `F = F_b(t) = 1,000,000 + t(t+b)`。

```text
F(t+1) = 1,000,000 + (t+1)(t+1+b)
       = 1,000,000 + t² + t(b+2) + (b+1)
       = [1,000,000 + t² + bt] + 2t + b + 1
       = F + 2t + 1 + b
F(t+2) = 1,000,000 + (t+2)(t+b+2)
       = 1,000,000 + t² + t(b+4) + 2b + 4
       = F + 4t + 2b + 4
       = F + 2(2t + 2 + b)
```

于是

```text
E(t) = F(t+2)·F(t) - F(t+1)²
     = [F + 2(2t+2+b)]·F - [F + (2t+1+b)]²
     = F² + 2F(2t+2+b) - F² - 2F(2t+1+b) - (2t+1+b)²
     = 2F·[(2t+2+b) - (2t+1+b)] - (2t+1+b)²
     = 2F - (2t+1+b)²
```

展开：

```text
2F          = 2,000,000 + 2t² + 2bt
(2t+1+b)²   = 4t² + 4t(1+b) + (1+b)²
E(t)        = 2,000,000 + 2t² + 2bt - 4t² - 4t(1+b) - (b+1)²
            = 2,000,000 - 2t² + (2b - 4b - 4)t - (b+1)²
            = 2,000,000 - 2t² - (2b+4)t - (b+1)²
```

∎

### 5.3 Corollary 4.5 / 4.6（切换点）的证明

由 Theorem 4.4，`E_b(t) - E_b(t+1) = 2(t+1)² - 2t² + (2b+4)·1 = 4t + 2 + 2b + 4 = 4t + 2b + 6`。对 `b=350`：`4t + 706 > 0`（`t >= 0`），故 `E_350` 在 `t >= 0` 上严格递减；对 `b=150`：`4t + 306 > 0`，同样严格递减。

`b = 350`：`(b+1)² = 351² = 123,201`，`2,000,000 - 123,201 = 1,876,799`；`704 = 2b+4`。

```text
E_350(808) = 1,876,799 - 2·808² - 704·808
           = 1,876,799 - 1,305,728 - 568,832 = +2,239
E_350(809) = 1,876,799 - 2·809² - 704·809
           = 1,876,799 - 1,308,962 - 569,536 = -1,699
```

严格递减 + 端点符号 ⇒ `E_350(t) > 0`（`0 <= t <= 808`）、`E_350(t) < 0`（`t >= 809`）（`t <= 808` 用 `E(t) >= E(808) > 0`；`t >= 809` 用 `E(t) <= E(809) < 0`）。

`b = 150`：`(b+1)² = 151² = 22,801`，`2,000,000 - 22,801 = 1,977,199`；`304 = 2b+4`。

```text
E_150(921) = 1,977,199 - 2·921² - 304·921
           = 1,977,199 - 1,696,482 - 279,984 = +733
E_150(922) = 1,977,199 - 2·922² - 304·922
           = 1,977,199 - 1,700,168 - 280,288 = -3,257
```

同法得符号区间。

比值语言：由 Lemma 4.3，`E_350(t) > 0`（`t <= 808`）⟺ `r_{t+1} > r_t`，故 `r_0 < r_1 < ... < r_809`；`E_350(t) < 0`（`t >= 809`）⟺ `r_{t+1} < r_t`，故 `r_809 > r_810 > ...`。故比值峰值在 `r_809`。BLU 同法（峰值 `r_922`）。

序列凸性语言：`E(t) >= 0` 对 `t ∈ [0, 808]` ⟺ `F` 在索引区间 `[0, 810]` 上 log-convex（内点二阶判据恰好是 `t=0..808`）；`E(t) < 0` 对 `t >= 809` ⟺ `F` 在 `[809, +∞)` 上 log-concave。注意两个结论指向不同的三点组，并不矛盾：`[0,810]` 的凸性不需要点 811，而凹性从三元组 `(809,810,811)` 开始。∎

### 5.4 Lemma 4.7（全局正性）的证明

配方：

```text
F_b(t) = t² + bt + 1,000,000 = (t + b/2)² + 1,000,000 - b²/4 >= 1,000,000 - b²/4
```

若 `b² < 4,000,000`，右端 `> 0`，故 `F_b(t) > 0` 对所有实数 `t` 成立（更强于整数）。`b = 350`：`b² = 122,500`，`1,000,000 - 30,625 = 969,375`，在 `t = -175` 取到；`b = 150`：`b² = 22,500`，`1,000,000 - 5,625 = 994,375`，在 `t = -75` 取到。∎

### 5.5 Theorem 4.8（线性族）的证明

令 `B = A + t`。则 `F(t) = B`，`F(t+k) = B + k`，`F(t+2k) = B + 2k`：

```text
(B + 2k)·B - (B + k)² = B² + 2Bk - (B² + 2Bk + k²) = -k² < 0
```

与 `t`、`A` 无关。`A = 4000`（DHT）、`A = 0`（DET）均满足；DET 的 `A=0`、`B = t > 0`（档位域 `t >= 1000`）后验成立。比值形式：`r_t = (A+t+1)/(A+t)`，`r_t - r_{t+1} = 1/[(A+t)(A+t+1)] > 0`，严格递减。∎

### 5.6 Corollary 4.9（DET 采样）的证明

DET 档位 `t = mult·u`（`mult = detTrunc`，`u ∈ ℤ`）；跨 `k` 个可达档位即 `Δ = mult·k`。把 Theorem 4.8 的 `k` 替换为 `mult·k`、`A = 0`：`(t+2·mult·k)t - (t+mult·k)² = -(mult·k)²`。∎

### 5.7 Corollary 4.10（可达区间）的证明

由 [raw-tier-transform](../raw-tier-transform/README.md) Theorem 4.7（`a=200, b=0, q=div, mult=1, c=50+200β`）：

```text
g_808 = ceil((808 - c)·q/200) = ceil((808 - 50 - 200β)·div/200)
```

逐等级计算得上表（脚本断言 `t(g_808)=808` 与 `t(g_808-1)=807`，即阈值最小性）。`g_809` 同式以 `809` 代入。

分支条件的推导：凸分支要求所有相关二阶判据 `E(t) >= 0`，相关 `t ∈ [t_min, t_max-2]`；而 `E_350(t) > 0` 对 `t ∈ [0, 808]`，故充分必要条件为 `t_min >= 0` 且 `t_max - 2 <= 808`，即 `t_max <= 810`；保守写法 `t_max <= 808`（避免依赖 `E(808)>0` 的边界情形，并给 `b_C` 变动留出余量）。凹分支要求 `E(t) <= 0` 对 `t ∈ [t_min, t_max-2]`；由 `E(t) < 0` 对 `t >= 809`，条件 `t_min >= 809` 即充分。若区间同时含 `<= 808` 与 `>= 809` 的 `t`，则存在 `t` 使 `E>0` 也存在 `t` 使 `E<0`，两个整体分支都不成立。BLU 等级 80 的数值：`g_921 = ceil((921-250)·1300/200) = ceil(872,300/200) = 4,362`。∎

### 5.8 Theorem 4.11（raw 级失败）的证明

**平台/跳变符号引理**：设 `F` 严格增且为正、`t` 非减。若 `Δ(g)=0` 且 `Δ(g+1)>0`，则 `t(g+1)=t(g)`、`t(g+2) > t(g)`，于是

```text
G(g+1) = G(g),   G(g+2) > G(g)
E_raw(g) = G(g+2)G(g) - G(g+1)² = G(g)·(G(g+2) - G(g)) > 0
```

若 `Δ(g)>0` 且 `Δ(g+1)=0`，则 `G(g+2)=G(g+1)>G(g)`，于是

```text
E_raw(g) = G(g+1)G(g) - G(g+1)² = G(g+1)·(G(g) - G(g+1)) < 0
```

**两种机制的存在性**：

1. 对 `a < q` 的实例（CRT 全部等级，DHT 等级 60–100，DET 全部等级，TEN 全部等级），档位增量 `Δ(g) ∈ {0, mult}`（因为每步 `a/q < 1`），且 `t` 非恒定、`Δ` 以 `P` 为周期。`t` 非恒定且平均增量 `mult·a/q < mult`，故 `Δ` 同时取 `0` 与正值；取任一最大连续跳变块，其起点前有 `Δ=0`（平台后跳变 ⇒ `E_raw > 0`），终点后有 `Δ=0`（跳变后平台 ⇒ `E_raw < 0`）。两符号都出现。
2. 对 `a > q` 的唯一实例（等级 50 DHT，`a=550`、`q=341`），`Δ ∈ {1, 2}` 且周期非恒定；由 `G(g) = 4000 + t(g)` 的精确公式

   ```text
   E_raw(g) = (4000 + t(g))·(Δ(g+1) - Δ(g)) - Δ(g)²
   ```

   在 `Δ` 上升处（`1→2`）：`E_raw = (4000+t)·1 - Δ(g)² >= 4000 - 4 > 0`；在 `Δ` 下降处（`2→1`）：`E_raw = -(4000+t)·1 - Δ(g)² < 0`。周期序列必同时含上升与下降转移，故两符号都出现。

   DET/TEN 也适合机制 2 的公式（`A=0` 或 `x = t >= 1000 > Δ²`），但机制 1 已覆盖它们。

**精确实例**：等级 70 DHT 的 `t(g) = floor(550g/900)`、`G(g) = 4000 + t(g)`。逐点计算（脚本断言）得 §4.11 的表：`E_raw(0) = 4000 > 0`、`E_raw(1) = -4001 < 0`、`E_raw(2) = 4001 > 0`、`E_raw(3) = -1 < 0`、`E_raw(4) = -4003 < 0`、`E_raw(5) = 4003 > 0`、……。符号 `+ - + - - + - + - - + - +` 已经同时含正负。等价地比值 `r_0 = 1 < r_1 = 4001/4000 > r_2 = 1 < r_3 = 4002/4001 > r_4 = 4003/4002 < ...` 不单调（`r_3 > r_4` 由 `E_raw(3) = -1 < 0` 给出，交叉相乘：`4002² - 4001·4003 = 1 > 0`）。

因此 raw 序列不满足 log-convex，也不满足 log-concave（两者都要求比值单调）。尽管 tier 级 DHT 是**严格 log-concave**（Theorem 4.8），raw 级结论不能由它推出。∎

### 5.9 Corollary 4.12 的证明

第 1、2 条即 §5.8 的平台/跳变符号引理。线性公式：令 `B = A + t(g)`、`u = Δ(g)`、`v = Δ(g+1)`，则 `G(g)=B`、`G(g+1)=B+u`、`G(g+2)=B+u+v`：

```text
E_raw = (B+u+v)B - (B+u)² = B² + Bu + Bv - B² - 2Bu - u² = B(v-u) - u²
```

`v > u ⇒ E >= B - u² > 0`（需 `B > u²`）；`v < u ⇒ E <= -B - u² < 0`。

**一般步序列**：若 `Δ` 以 `P` 为周期且非常值，则绕周期一圈时不可能只出现上升、不出现下降（否则逐步累加会使周期末值严格大于周期初值，与「以 `P` 为周期」矛盾），故上升与下降转移都存在，代入上式得两符号。若 `Δ` 非减且非常值，则整数值序列有界（`Δ <= K`）故最终恒定于 `K∞ >= 1`；最后一次严格上升处 `E = (A+t)(Δ2-Δ1) - Δ1² >= (A+t) - K² > 0`，尾部恒定处 `E = -K∞² < 0`。∎

### 5.10 Corollary 4.13 的证明

对 `t_1 <= i <= t_2 - 1`，`r_i = F(i+1)/F(i)`；`F(t_2)/F(t_1) = ∏_{i=t_1}^{t_2-1} r_i`。由 Lemma 4.3，`E(i) >= 0` 对 `i ∈ [t_1, t_2-2]` ⟺ `r_i <= r_{i+1}`，故

```text
r_{t_1}^n <= ∏ r_i <= r_{t_2-1}^n,   n = t_2 - t_1
```

交叉相乘即得两个整数不等式（所有因子为正，乘除不改变方向）：下界 `F(t_2)/F(t_1) >= r_{t_1}^n = F(t_1+1)^n/F(t_1)^n` ⟺ `F(t_2)·F(t_1)^{n-1} >= F(t_1+1)^n`；上界 `F(t_2)/F(t_1) <= F(t_2)^n/F(t_2-1)^n` ⟺ `F(t_2-1)^n <= F(t_1)·F(t_2)^{n-1}`。∎

## 6. 反例 / 边界与退化情形

### 6.1 raw 级反例与「严格交替」的精确澄清

§4.11 的等级 70 DHT 表已经给出双符号反例。需要明确的是：**raw 第二阶差分并不严格交替**。在 `g = 0..4` 的精确符号为 `+ - + - -`，其中 `E_raw(3) = -1`、`E_raw(4) = -4003` 连续为负。来源是档位增量 `Δ` 的周期模式（等级 70 DHT 的跳档成本依赖余数类，`Δ` 会出现连续两个 1）。这不影响否证：只要同时出现正号与负号，raw log-convex 与 raw log-concave 都已失败（`g = 0` 与 `g = 1` 两点即可）。若需要一个严格交替的干净阶梯模型，可令 `Δ(g)` 交替 `0,1,0,1,...`，此时 `E_raw` 的符号严格交替；但真实等级 70 DHT 的跳档成本不是这种模型，不能把理想化模式当作真实数据结论（评论 2 §二 末尾也强调必须区分 tier 级与 raw 级）。

### 6.2 切换点数值余量

`E_350(808) = 2,239` 相对因子量级（`F_350(808) ≈ 1.94·10^6`）很小，但它是**精确整数**结论；只要 `b_C`、常数 `1,000,000` 或 `350` 不变就成立。数据版本或公式变化时切换点会移动，必须重新计算（脚本每次运行重新求值并断言）。`E_150(921) = 733` 同样是小余量。因此本文把切换点绑定到 §1.2 的数据版本，而不是记忆常数。

### 6.3 档位域端点与零值

- `t = 0`：`F_b(0) = 1,000,000 > 0`、`F_H(0) = 4,000 > 0`，log 有定义；`F_D(0) = 0`，**不满足正性**，`log` 与比值都未定义。DET 的档位域从 1000 开始（raw-tier-transform Corollary 4.11），所以生产路径不会在 `t = 0` 使用 DET 比值；任何自行调用 `F_D` 的层必须先检查 `t > 0`。
- DET 在 `detTrunc > 1` 的等级 50/60：`F_D(t)` 的序列按 `mult` 采样；Theorem 4.8/Corollary 4.9 已覆盖，凹性强度 `-(mult·k)²`。
- BLU：`b = 150` 且 CRT/DHT 档位带 `+200` 偏移；切换点是 921/922。等级 80 时 `t=921` 需要 `g >= 4,362`（贡献坐标；对应面板 CRT = `380 + 4,362 = 4,742`），必须用 `G_max` 检查；若不可达，凸分支全程有效。
- 等级 50 的 CRT 切换贡献门槛只有 `g_808 = 1,293`（普通）/`952`（BLU），实际搜索预算很可能跨越该点；这是 §4.10 前提检查在生产中最可能触发的情形。这里的门槛是贡献，面板 CRT = `sub + g_808`（等级 50 普通为 `341 + 1,293 = 1,634`）。

### 6.4 跨切换区间（当前休眠，但必须覆盖）

例：`t ∈ [800, 850]`。此时 `E_350(806) > 0` 而 `E_350(809) < 0`，区间内同时存在正负二阶判据：既不能说整个区间 log-convex，也不能说 log-concave。`E_350(809) < 0` 意味着三元组 `(809,810,811)` 破坏凸性，`E_350(806) > 0` 意味着 `(806,807,808)` 破坏凹性。任何使用 §4.13 产品界的层必须在 `t_max <= 810`（凸）与 `t_min >= 809`（凹）两个分支间二选一；跨切换时回退（§9）。

### 6.5 其它边界

- `t < 0`：不在档位域（`t >= 0`），`E` 的符号结构未刻画（Lemma 4.7 只保证正性）。不要对负档位使用本文结论。
- 档位跳过（等级 50 DHT 的 `c_k = 0`）：tier 级结论只依赖档位值 `t`，与「某些档位未被 raw 取到」无关；但 raw 级反例的锯齿更复杂（Theorem 4.11 已覆盖）。
- 因子乘积跨 `detTrunc`：DET 档位粒度不同（5/2/1），跨等级比较时不能把「一个档位」当同一单位；本文的步长 `k` 始终以档位值为单位，`mult` 显式出现。

## 9. 应用前提与安全回退

### 9.1 运行时前提清单

1. `ℓ ∈ {50,60,70,80,90,100}`；BLU 仅 `ℓ <= 80`。
2. 先由 [raw-tier-transform](../raw-tier-transform/README.md) 的阈值模型与 `G_max` 计算每个属性的可达档位区间 `[t_min, t_max]`（CRT 用 `g_808/g_809` 表辅助；DHT/DET/TEN 的档位域见 §2.2）。**坐标**：`g_808/g_809`、`G_max` 与 `[0,G_max]` 是贡献坐标；`[t_min, t_max]` 是档位坐标。
3. 检查 A2 正性：CRT 任意整数 `t` 均可（Lemma 4.7）；DHT 需 `t >= -3999`（档位域自动满足）；DET 需 `t >= 1000`（域内自动满足）。
4. 选择分支：
   - 凸分支：`t_max <= 810`（保守：`t_max <= 808`）；
   - 凹分支：`t_min >= 809`（CRT）；DHT/DET/TEN 在档位域内对任意步长恒凹（Theorem 4.8），无需切换条件，但 DET 的步长必须写成 `mult·k`。
   - 跨切换：两个分支都不启用。
5. 用 §4.13 的产品界时，区间必须整体落在相应分支内；`DET` 的步长以 `mult` 为单位。
6. 任何前提失败 ⇒ 该曲率层跳过（不是近似、不是放宽）。
7. **坐标契约（外部输入）**：若调用方只有面板总值 `X`，必须先换算到贡献坐标再计算可达档位区间：`g_CRT = g_DHT = g_TEN = X − sub(ℓ)`、`g_DET = X − main(ℓ)`（参考模型 §2.1）。因子/判据/切换点本身的输入是档位 `t`，不得把面板值或贡献值直接当档位使用。偏差量随等级变化：等级 70 CRT 若把面板阈值 `3,775` 当贡献会得到 `t=888` 而非 `808`（多 `80` 档）。

### 9.2 条件失败时的安全回退

- **曲率层不可用**（跨切换、`t < 0`、DET 在 `t=0`、数据/公式变化）⇒ 直接使用精确整数因子逐档求值（`createIntegerDamageFactorEvaluator`，`equipped-effects.ts:59-104`）与 BigInt 精确比较（`exact-mip-candidate-upper-bound.ts:108-140`）。
- **需要严格上界**（例如预算-因子上界）⇒ 使用既有 `prepareFactorResourceBudgetUpperBound`（`factor-resource-budget-upper-bound.ts:88-147`）：它以每档 `(min cost, integer log score)` 的上凸包与 Lagrange 支撑线给出**不依赖曲率符号**的严格上界；本文的 §4.13 产品界只是其可选收紧，不是安全性的必要条件。
- **raw 贡献坐标**：禁止把本文的 tier 级凸凹、比值单调性直接用于 `g` 坐标；raw 级请使用 [raw-marginal-envelope](../raw-marginal-envelope/README.md) 的包络结论。
- **绝不引入经验阈值/经验切换点**：切换点 808/809、921/922 由精确整数公式推出且与数据版本绑定；它们不是「调参得到」的 magic value，也不能在 `b_C` 变化后继续沿用。

## 13. baseStat 影响审计（贡献坐标 vs 面板总值）

> 本节是对「基础属性是否影响定理 B」的逐条审计（用户要求的第二轮核对）。审计结论：**本文全部定理不受 baseStat 影响，无需重新证明**。因子 `F`、判据 `E`、比值 `r`、切换点 808/809 与 921/922 只定义在**档位** `t` 上；baseStat 只通过 `g ↦ t` 映射影响「可达档位区间」；raw 级命题（Cor 4.10 的 `g_808`、Theorem 4.11 的 raw 表）的输入是**贡献** `g`，不是面板值。需要补强的是输入坐标契约（§13.5）。

### 13.1 坐标声明

| 坐标 | 定义 | 本文中的出现位置 |
| --- | --- | --- |
| **面板总值** `X(σ)` | 角色面板 CRT/DHT/DET/TEN 总值（`base + 贡献`） | 仅在 §13.4 的换算复核与 §13.5 的输入契约中出现；**没有命题以面板值为自变量** |
| **贡献坐标** `g` | 装备 + 镶嵌 + 自定义/义军武器 + 食物带来的属性贡献 | §4.10 的 `g_808/g_809` 表、BLU `g_921 = 4,362`、§4.11 的 raw 表 `g = 0..12`、§6.3 的贡献门槛、§9.1 的 `G_max` |
| **档位坐标** `t` | `equippedAttributeTier` 的输出（由贡献经 `t(g)` 映射得到） | 全部因子 `F_C/F_H/F_D/F_T`、`E(t)`、比值 `r_t`、切换点 808/809 与 921/922、§4.12 的 `Δ`、§4.13 产品界、§6.4 跨切换示例 `[800, 850]` |

换算（参考模型 §2.1）：`X_CRT = X_DHT = X_TEN = sub + g`，`X_DET = main + g`；反之 `g = X − sub`（CRT/DHT/TEN）、`g = X − main`（DET）。本文的「阈值/区间」凡以 `g` 表示者一律是贡献；凡以 `t` 表示者一律是档位。已逐句核对 §4/§6/§9：无把 `g` 当面板值或把面板值当档位的命题。

### 13.2 baseStat 归约链（引用参考模型 §2.1/§2.2）

1. `equipped-effects.ts:127`：`value = (baseStats[stat] ?? 0) + gearAndFoodValue`，随后分支减 `sub` 或 `main`。
2. `getBaseStats`（`:178-203`）+ 数据事实（参考模型 §2.1）：`baseStats.CRT = DHT = TEN = "sub"`、`DET = "main"`；`statModifiers` 缺省 100、`clanStats` 无四键、TEN 由 `levelMod.sub` 预设覆盖。
3. `value − offset = g`（[raw-tier-transform](../raw-tier-transform/README.md) Lemma 4.2）⇒ 档位公式的输入只剩贡献 `g`。
4. 正式候选路径贡献逐项非负（参考模型 §2.2 的结构性结论）⇒ 可达域 `g >= 0`。
5. `g >= 0` ⇒ floor 实参 `V >= 0`（[raw-tier-transform](../raw-tier-transform/README.md) Lemma 4.3b：CRT `>= 50`、DHT `>= 0`、DET `>= 200`、TEN `>= 1000`）⇒ `Math.trunc(V + 1e-7) = floor(V)` 在可达域无条件成立（截断方向）；浮点误差界是另立的第二条件。
6. 档位 `t = c + mult·floor((a·g + b)/q)` 是 `(ℓ, β, σ, g)` 的函数，**不含 baseStat 显式项**；因子 `F` 只读 `t`，`E`/`r` 只读相邻因子值 ⇒ baseStat 不进入本文任何因子/判据/切换点表达式。

### 13.5 应用契约（外部只有面板值时）

1. 若只有面板总值 `X(σ)`，先换算：`g_CRT = g_DHT = g_TEN = X − sub(ℓ)`、`g_DET = X − main(ℓ)`（`(main, sub)` 见参考模型 §2）。

6. 本文不改变生产 API 的坐标语义；以上契约只约束使用本文定理的分析层。
