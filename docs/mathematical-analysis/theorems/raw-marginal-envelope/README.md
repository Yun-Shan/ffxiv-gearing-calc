## 2. 范围与依据

### 2.1 范围

本定理处理**固定等级、固定职业类（普通/BLU）、固定单属性因子**下的 raw 级（以属性贡献 `g` 为自变量）边际结构：

- 任意窗口 `[g, g+δ]` 的档位增益与因子增益的**精确公式与严格上下包络**；
- 余类周期与有限候选集，由此得到**不需要对数**的精确极值/比较算法；
- raw 级二阶对数差（离散 log-convex/log-concave）在 canonical 公式族中**两个方向都失败**；
- 单位预算增益的锯齿振幅与"平滑趋势"的确切关系。

本定理**不**主张：

- 不主张 raw 级 log-convex 或 log-concave（两者均被 §5 定理 2 否证）；
- 不主张三属性联合（乘积）的边际结构（见 [free-budget-upper-bound](../free-budget-upper-bound/README.md) 等）；
- 不涉及装备池、孔位、食物、同步与搜索实现，也不作性能声明；
- 不重复证明档位映射与阈值基础事实（由 [raw-tier-transform](../raw-tier-transform/README.md) 给出）；本文只推导所需引理并显式引用。

## 3. 符号、量词与定义域

### 3.1 档位模型的统一形式

**坐标约定（贡献坐标）**：本文的 `g`、`δ`、阈值 `τ_K`/`g_k`、余类/周期表、跳档成本、窗口与 `A/T` 表全部采用**贡献坐标**：属性贡献 = 面板总值 − 基础属性（CRT/DHT/TEN 减 `sub`，DET 减 `main`；归约链见 §13.2 与[参考模型 §2.1](../../canonical-evaluator-reference.md)）。`t(g)` 的公式不含 baseStat；基础属性只作为 `value = baseStats[stat] + 贡献` 中的常数偏移出现。**面板总值不得直接当作 `g` 使用**（完整审计见 §13）。

对固定 `level ∈ {50,60,70,80,90,100}`、职业类 `job ∈ {普通, BLU}`、属性 `stat ∈ {CRT,DHT,DET,TEN}`，[canonical evaluator 参考模型](../../canonical-evaluator-reference.md) §3 给出

```text
t(g) = c + mult · floor( (a·g + b) / q ),     g ∈ Z_{≥0},   a,q ∈ Z_{>0},  mult ∈ Z_{>0},  b,c ∈ Z
```

| 属性 | a | b | q | c | mult |
| --- | --- | --- | --- | --- | --- |
| CRT 普通 | 200 | 0 | `div` | 50 | 1 |
| CRT BLU | 200 | 0 | `div` | 250 | 1 |
| DHT 普通 | 550 | 0 | `div` | 0 | 1 |
| DHT BLU | 550 | 0 | `div` | 200 | 1 |
| DET | 140 | `1000·det` | `det·detTrunc` | 0 | `detTrunc` |
| TEN | 112 | 0 | `div` | 1000 | 1 |

其中六等级的 `(main, sub, div, det, detTrunc)` 取自参考模型 §2：`50:(202,341,341,202,5)`、`60:(218,354,600,600,2)`、`70:(292,364,900,900,1)`、`80:(340,380,1300,1300,1)`、`90:(390,400,1900,1900,1)`、`100:(440,420,2780,2780,1)`。BLU 只改变常数 `c`（CRT `+200`、DHT `+200`），不改变 `(a,b,q)`。

### 3.2 定义（tier 索引、余类、周期）

- **tier 索引** `K(g) := floor((a·g+b)/q)`（`g` 为贡献）；档位值 `t(g) = c + mult·K(g)`。对 DET（`mult>1`），档位值只取 `c + mult·Z` 中的值；**不得**把 `t` 按 1 递增插值（§7.5）。
- **余类** `r(g) := (a·g+b) mod q ∈ [0,q)`（`g≥0` 保证分子非负，故为普通余数；`g` 为贡献）。
- **周期与平移** `d := gcd(a,q)`、`P := q/d`、`s := a/d`（每 `P` 个 raw 单位的 tier 索引平移）、`shiftT := mult·s`（档位值平移）。由 [raw-tier-transform](../raw-tier-transform/README.md) 与 §6.3 的证明：
  `r(g+P)=r(g)`，`K(g+P)=K(g)+s`，`t(g+P)=t(g)+shiftT`。该组参数只由 `(a,q,mult)` 决定，**与 baseStat 无关**（§13）。
- **阈值**：对 tier 索引 `K ≥ K₀ := floor(b/q) = K(0)`，
  `τ_K := min{g∈Z_{≥0} : K(g) ≥ K} = max(0, ceil((K·q − b)/a))`（**贡献单位**）；
  对档位值 `k = c + mult·K`，其最小贡献阈值为 `τ_K`（`K ≥ K₀`）。阈值的存在性、最小性、跳档成本与周期的完整推导见 [raw-tier-transform](../raw-tier-transform/README.md)；此处只登记本文所需形式，并在 §6.3 对成本闭式给出独立推导。若改用面板坐标 `panel = g + offset`，则面板阈值 = `τ_K + offset`（常数平移），阈值差/跳档成本不变；但档位公式只对贡献坐标成立。
- **跳档成本** `c_K := τ_{K+1} − τ_K`（`K ≥ K₀`；非负整数）。
- **档位增益** `ρ_K := F(c+mult·(K+1)) / F(c+mult·K) > 0`；**单位成本档位 log 增益** `λ_K := ln(ρ_K)/c_K`（仅当 `c_K>0` 有定义）。
- **因子**（BigInt/整数坐标）：
  `F_C(t)=1,000,000+t·(t+b_C)`（`b_C=350` 普通，`150` BLU）；`F_H(t)=4,000+t`；`F_D(t)=t`；`F_TEN(t)=t`（tenacity 因子的分母 1000 为常数，不影响比较）。
- **窗口与单位预算 log 增益**：对 `δ∈Z_{≥1}`、`0≤u≤v−δ`，令
  `W_δ(u,v) := {g∈Z : u ≤ g, g+δ ≤ v}`（起点集合），
  `R_δ(g) := F(t(g+δ))/F(t(g)) > 0`，
  `Φ_δ(g) := (1/δ)·ln R_δ(g)`。
- **raw 级二阶对数差**：`Δ²u(g) := ln F(t(g+2)) − 2·ln F(t(g+1)) + ln F(t(g))`；其符号等价于整数比较 `F(t(g+2))·F(t(g))` 与 `F(t(g+1))²`。raw 级 log-convex 指 `Δ²u(g) ≥ 0` 对所有 `g` 成立；log-concave 指 `Δ²u(g) ≤ 0` 对所有 `g` 成立。
- **量词/定义域**：`g, δ, u, v ∈ Z`，`g≥0`，`δ≥1`；有限候选集枚举均在有限区间上进行。所有"对所有……"均指对满足前提的整数成立。

## 4. 假设

(B1) 等级参数与公式严格来自参考模型 §2–§3（六等级、普通/BLU）；`level`、`job`、`stat` 固定。

(B2) 定义域 `g∈Z_{≥0}`。canonical evaluator 的 `floor=Math.trunc(v+1e-7)` 仅在 `g≥0` 上与精确 floor 等价（[raw-tier-transform](../raw-tier-transform/README.md)）；本文所有整数推理都建立在精确 floor 上。

(B3) 因子映射 `F` 在其档位定义域上**严格递增且为正**：`F_C` 在 `t≥0` 上严格增（`2t+b_C>0`），`F_H=4000+t` 严格增且 `≥4000`，`F_D(t)=t` 在 `t≥1000` 上严格增，`F_TEN(t)=t` 同理。因此任意两个不同档位值的因子大小关系与档位值顺序一致。

(B4) 比较/包络只对**同一因子**（同 `level/job/stat`）的窗口有意义；跨属性窗口的先后顺序用 [marginal-comparison](../marginal-comparison/README.md) 的交叉指数判据，本文定理 1 只负责给出候选比值。

(B5) 对"单位成本档位 log 增益" `λ_K` 的引用要求 `c_K>0`；canonical 中 `c_K=0` 只出现在 level 50 DHT（§7.4），此时不得使用 `λ_K`，只能用窗口公式。

(B6) DET 的 `mult` 粒度：只使用可达档位值 `c+mult·K`；跳档成本与档位增益都按 tier 索引 `K` 计算，不得按 `t→t+1` 计算。

(B7) **坐标前提（贡献坐标）**：`g`、`δ`、`u`、`v`、阈值、余类/周期与 `A/T` 全部是贡献坐标；baseStat 只用于 `panel = baseStat + 贡献` 的换算（CRT/DHT/TEN 为 `sub`，DET 为 `main`），不进入 `t(g)`、因子或成本公式。若外部只提供面板值，必须先减 offset；坐标混用或未知时回退到 canonical evaluator 实际点求值（§13）。

## 5. 精确命题

### 5.1 引理 1（窗口档位增益的唯一公式）

对每个 `(level, job, stat)` 与任意 `g∈Z_{≥0}`、`δ∈Z_{≥0}`：

```text
t(g+δ) − t(g) = mult · floor( (r(g) + a·δ) / q ),     r(g) = (a·g+b) mod q.
```

**推论 1.1（两值与成员判据）** 记 `m_δ := (a·δ) mod q`、`Jmin := floor(a·δ/q)`、`Jmax := ceil(a·δ/q)`，并记 `ε_δ(g) := 1` 若 `r(g)+m_δ ≥ q`，否则 `0`。则

```text
t(g+δ) − t(g) = mult·( Jmin + ε_δ(g) ) ∈ { mult·Jmin, mult·Jmax }.
```

即窗口档位增益只可能取**至多两个值**；取上端点的充要条件是 `r(g) + ((a·δ) mod q) ≥ q`。当 `q | a·δ` 时 `Jmin=Jmax`，只有唯一值。

**推论 1.2（窗口增益只依赖余类）** `t(g+δ)−t(g)` 只依赖 `(δ, r(g))`；又 `r(g)` 以 `P` 为周期，因此固定 `δ` 时窗口增益模式在 `g` 上最多有 `P` 种。

### 5.2 引理 2（窗口因子增益的严格包络）

设 `F` 为 §3.2 的任一因子（严格递增、正，见 (B3)），`g∈Z_{≥0}`、`δ∈Z_{≥1}`，记 `t := t(g)`、`K := K(g)`、`J := Jmin + ε_δ(g)`（推论 1.1），则：

(a) **精确恒等式**

```text
F(t(g+δ)) / F(t(g)) = F( c + mult·(K+J) ) / F( c + mult·K ).
```

(b) **两值包络**（`Δmin := mult·Jmin`、`Δmax := mult·Jmax`，`Δ := mult·J` 为精确增量）：

```text
ln F(t+Δmin) − ln F(t) ≤ ln( F(t(g+δ))/F(t(g)) ) ≤ ln F(t+Δmax) − ln F(t).
```

精确值取且只取两端之一；当 `q ∤ a·δ` 时两端相差恰好一个相邻档位增益 `ln ρ_{K+Jmin}`（即包络宽度 = 一个档位增益）。每单位预算版本（除以 `δ>0`）：

```text
(1/δ)·[ln F(t+Δmin) − ln F(t)] ≤ Φ_δ(g) ≤ (1/δ)·[ln F(t+Δmax) − ln F(t)].
```

(c) **按跨越档位增益连乘**：令 `J := Jmin + ε_δ(g)`，则

```text
F(t(g+δ))/F(t(g)) = ∏_{j=0}^{J−1} ρ_{K+j},
```

且 `J ∈ {Jmin, Jmax}`；因此

```text
∏_{j=0}^{Jmin−1} ρ_{K+j} ≤ F(t(g+δ))/F(t(g)) ≤ ∏_{j=0}^{Jmax−1} ρ_{K+j}.
```

两个乘积的差别恰为（当 `Jmax=Jmin+1` 时）乘上 `ρ_{K+Jmin}>1`。

(d) **严格性**：因 `F` 严格增，精确值在 `ε_δ=0` 时等于下界、在 `ε_δ=1` 时等于上界（当 `Jmin=Jmax` 时两界重合、三值相等）；当 `Jmin<Jmax` 时两界不同（上界 = 下界 × `ρ_{K+Jmin}`，且 `ρ>1`），故**另一个**界是严格的。

### 5.3 引理 3（有限余类）

对每个 `(level, stat)`（BLU 不改变 `(a,b,q)`，只改变 `c`）：

```text
P := q / gcd(a,q)  是 r(g) 的最小正周期；  K(g+P) = K(g) + s,  t(g+P) = t(g) + mult·s；
可达余类集合 = { (a·j + b) mod q : j=0,…,P−1 } = { (b + d·j) mod q : j=0,…,P−1 },  d=gcd(a,q)，
且该集合恰有 P 个元素。
```

逐等级参数如下（`P` 与 `s=shiftK`；`shiftT=mult·s`）：

| level | CRT `(a,q,d,P,s)` | DHT `(a,q,d,P,s)` | DET `(a,q,d,P,s)` | TEN `(a,q,d,P,s)` |
| --- | --- | --- | --- | --- |
| 50 | (200,341,1,341,200) | (550,341,11,31,50) | (140,1010,10,101,14) | (112,341,1,341,112) |
| 60 | (200,600,200,3,1) | (550,600,50,12,11) | (140,1200,20,60,7) | (112,600,8,75,14) |
| 70 | (200,900,100,9,2) | (550,900,50,18,11) | (140,900,20,45,7) | (112,900,4,225,28) |
| 80 | (200,1300,100,13,2) | (550,1300,50,26,11) | (140,1300,20,65,7) | (112,1300,4,325,28) |
| 90 | (200,1900,100,19,2) | (550,1900,50,38,11) | (140,1900,20,95,7) | (112,1900,4,475,28) |

- `c_K ∈ { floor(q/a), ceil(q/a) }`，且相邻 `c_K` 至多相差 1；闭式
  `c_K = floor(q/a) + [ ρ_K < (q mod a) ]`，其中 `ρ_K := (b − K·q) mod a ∈ [0,a)`。
- **零成本跳档**只出现在 `level 50 DHT`（`a=550>q=341`）：例如档位值 `t=2` 与 `t=3` 的最小贡献阈值都是 `g=2`，故 `c_K=0`。

### 5.4 定理 1（区间上的有限候选精确包络查询）

固定 `(level, job, stat, F)`、区间 `[u,v]⊆Z_{≥0}`、预算 `δ∈Z_{≥1}`，设 `W := W_δ(u,v)` 非空。则：

(a) **有限候选集**：`Φ_δ(g)` 只依赖 `(K(g), ε_δ(g))∈Z×{0,1}`；所有可达组合可由余类周期显式枚举：

```text
对每个 g₀ ∈ {0,…,P−1}：r₀ = (a·g₀+b) mod q，K₀ = K(g₀)；
  取所有 t∈Z 使 g = g₀ + t·P 满足 u ≤ g ≤ v−δ，
  则 K = K₀ + t·s，ε = [ r₀ + (a·δ mod q) ≥ q ]。
```

候选数 `≤ min(|W|, P·(#t 值))`；用上面的显式参数可直接枚举。

(b) **极值**：`max_{g∈W} Φ_δ(g)` 与 `min_{g∈W} Φ_δ(g)` 都在上述候选集中取得；其**值**可以只用整数对 `(N,D) := (F(t+Δ), F(t))` 表示，**不需要对数**。

(c) **精确比较（同预算）**：两个候选 `(N,D)`、`(N',D')` 满足
`Φ_δ ≥ Φ'_{δ} ⟺ N·D' ≥ N'·D`（全部 BigInt 精确；`δ` 相同故约去）。
**跨预算/跨成本**：若比较 `(N,D,δ)` 与 `(N',D',δ')`，则
`ln(N/D)/δ ≥ ln(N'/D')/δ' ⟺ N^{δ'}·D'^{δ} ≥ N'^{δ}·D^{δ'}`（定理见 [marginal-comparison](../marginal-comparison/README.md) 定理 1；纯整数交叉指数）。

(d) **精确性**：上述结论是充要的；候选集包含 `W` 中每个 `g` 的像，故极值必在其中；比较式与实数比较等价（正性 + 对数严格单调 + 正幂严格单调）。

### 5.5 定理 2（raw 级凸凹性均失败）

先给出**符号刻画引理**。设 `t` 非减，令 `A=t(g)`、`A₁=t(g+1)`、`A₂=t(g+2)`，`Δ₁=A₁−A`、`Δ₂=A₂−A₁`：

- `Δ₁=Δ₂=0`：`Δ²u(g)=0`；
- `Δ₁=0<Δ₂`：`Δ²u(g) = ln F(A+Δ₂) − ln F(A) > 0`（`F` 严格增）；
- `Δ₁>0=Δ₂`：`Δ²u(g) = ln F(A) − ln F(A+Δ₁) < 0`；
- `Δ₁>0, Δ₂>0`：`Δ²u(g) = ln[ F(A₂)·F(A) / F(A₁)² ]`，符号由精确整数比较 `F(A₂)·F(A)` vs `F(A₁)²` 决定；对仿射族 `F(t)=A₀+t`，令 `x=A₀+A`，则
  `Δ²u(g) = ln[ (x+Δ₁+Δ₂)·x / (x+Δ₁)² ]`，
  其符号等于 `(Δ₂−Δ₁)·x − Δ₁²` 的符号；特别地 `Δ₁=Δ₂=m` 时恒为 `−m²` 的符号（负；这就是档位级 `−k²` 判据，见 [tier-log-curvature](../tier-log-curvature/README.md)）。

**定理**：对全部 36 个公式实例（6 等级 × `{CRT_普通, CRT_BLU, DHT_普通, DHT_BLU, DET, TEN}`），`Δ²u(g)` 在 `g∈Z_{≥0}` 上**既取正值也取负值**；因此既非 raw 级 log-convex 也非 raw 级 log-concave。证明是构造性的（§6.5）：

- 若 `a<q`（除 level 50 DHT 外的全部实例）：存在跳档成本 `≥2` 的档位（`ceil(q/a)≥2`）；用工位点 `g=j−2` 得正值，用"下一跳档成本 `≥2`"的工位点 `g=j′−1` 得负值（`j,j′` 为相应阈值）。
- 若 `a>q`（仅 level 50 DHT）：每个 raw 步都跨档，单步增量 `∈{1,2}`；`g=0` 的增量对为 `(1,2)`（加速）得正值，`g=1` 的增量对为 `(2,1)`（减速）得负值。

**推论（level 70 DHT 的精确符号字）**：`Δ` 字（`Δ(g)=t(g+1)−t(g)`，`g=0..17`）为

```text
010110101101011011
```

raw 二阶对数符号字（`g=0..17`）为

```text
+-+--+-+--+-+--+--
```

并以 18 为周期。符号完全由 `(Δ(g), Δ(g+1))` 决定：`(0,0)→0`、`(0,1)→+`、`(1,0)→−`、`(1,1)→−`；因为本实例中 `Δ∈{0,1}` 且相邻跳档成本≤2，`(0,0)` 不出现。

**否证一个过强的一般命题**：不存在"任意非恒定的非减阶梯序列都同时出现两种符号"的定理。反例：`t(g)=g`（均匀步长）与 `F(t)=4000+t`，则 `Δ²u(g)=ln[(A+g)(A+g+2)/(A+g+1)²]<0` 对全部 `g` 成立（严格 log-concave，无正号）。因此定理 2 必须逐实例证明/检查，不能当作一般阶梯序列的性质。

### 5.6 推论（锯齿振幅与平滑趋势）

定义（`δ=1`，单位预算）：

```text
A(F;level,stat) := max_{0≤g<P} ln R₁(g) − min_{0≤g<P} ln R₁(g)          （锯齿振幅）
T(F;level,stat) := (1/P)·ln( F(t(P))/F(t(0)) )                          （平滑趋势 = 单位预算 log 增益的周期平均）
```

（`T` 等于 `(1/P)Σ_{g=0}^{P−1} ln R₁(g)`，因乘积望远镜相消。`A/T` 以**贡献坐标**的一个周期 `g=0..P−1` 计算；`t(0)=c` 是档位常数、由等级与职业类决定，不含 baseStat；若从面板坐标看，贡献 `g=0` 对应面板值 `offset`，因此 `A/T` 数值与 baseStat 无关（§13）。）则：

1. `A`、`T` 可由一个周期内有限个单位比值精确算出（`T>0`）；并且（用引理 2(c) 的连乘表示）单个 `R₁(g)` 是**相邻档位增益 `ρ_K` 的连乘**：当 `a<q` 时单步至多跨一个档位，故 `maxR = max_K ρ_K`、`minR = 1`（平台步存在）；当 `a>q`（仅 level 50 DHT）时单步可跨 `J∈{⌊a/q⌋,⌈a/q⌋}={1,2}` 个档位，此时 `maxR`、`minR` 分别是可达单步乘积 `∏_{j<J} ρ_{K+j}` 的最大/最小值。因此振幅 `A` 完全由有限多个相邻档位增益（及其单步乘积）决定。
2. `A/T = P·ln(maxR/minR) / ln(periodGain)`；canonical 24 个 `(level,stat)`（普通职业；BLU 的 `(a,b,q,P)` 相同、仅 `c` 变化，故结构相同，数值只随因子常数 `b_C` 与档位偏移略有差异，本文不单列）的数值（精确证书见 §11）为：

   | level | CRT | DHT | DET | TEN |
   | --- | --- | --- | --- | --- |
   | 50 | 2.099 | 0.630 | 7.445 | 3.211 |
   | 60 | 3.000 | 1.092 | 8.623 | 5.392 |
   | 70 | 4.509 | 1.638 | 6.448 | 8.144 |
   | 80 | 6.513 | 2.367 | 9.314 | 11.763 |
   | 90 | 9.519 | 3.459 | 13.612 | 17.192 |
   | 100 | 14.143 | 5.089 | 19.917 | 25.155 |

   其中 23 个满足 `A/T>1`（单位预算增益的振幅**大于**平滑趋势）；唯一例外是 level 50 DHT（`a>q`，每个 raw 步都跨档、无平台，`A/T≈0.630<1`）。全部 24 个满足 `A/T<26`（精确整数证书），最大为 `level 100 TEN` 的 `≈25.155`，并有精确证书 `A/T>25`。
3. **机制（精确，非拟合）**：当 `a<q` 时平台步给出 `min R₁=1`，跳档步给出 `max R₁ = max_K ρ_K`，而 `T≈(1/P)ln(周期增益)`；若各 `ρ_K` 相近（`ρ_K≈1+ε`），则 `A≈ε`、`T≈(s/P)·ε=(a/q)·ε`，故 `A/T≈P/s=q/a`。因此振幅约为平滑趋势的 `q/a` 倍：`q/a` 在 canonical 内最大为 `2780/112≈24.82`（TEN level 100），与表中 25.155 一致（比值并非精确等于 `q/a`，差异来自 `ρ_K` 的缓慢变化）。
4. **可任意大（参数族意义上）**：取 DET 参数族 `det=140m`、`detTrunc=1`（`m≥2`），即 `a=140,q=140m,b=140000m,c=0,mult=1`。则 `t(0)=1000`、`P=m`、`s=1`、所有跳档成本都等于 `m`，且一个周期内单位比值恰为 `1`（`m−1` 次）与 `1001/1000`（1 次）。于是 `A=ln(1001/1000)`、`T=(1/m)·ln(1001/1000)`，**`A/T = m` 精确成立**，随 `m` 任意大。当前数据只到 `det=2780`（`q/a≈19.86`），所以这是参数族意义上的"任意大"，不是对现有六等级的断言。

## 6. 证明（仅精确论证）

### 6.1 引理 1 的证明

由带余除法，存在唯一 `k=floor((a·g+b)/q)` 与 `r=(a·g+b) mod q∈[0,q)` 使 `a·g+b = k·q + r`。于是

```text
a·(g+δ)+b = k·q + r + a·δ
          = k·q + q·floor((r+a·δ)/q) + ((r+a·δ) mod q).
```

第一项被 `q` 整除，故 `floor((a(g+δ)+b)/q) = k + floor((r+a·δ)/q)`；乘以 `mult` 得引理 1。推论 1.1：写 `a·δ = q·Jmin + m_δ`，则 `r+a·δ = q·Jmin + (r+m_δ)`，`0 ≤ r+m_δ < 2q`，故 `floor((r+a·δ)/q)=Jmin+[r+m_δ≥q]`；又 `Jmax=Jmin+[m_δ>0]`，当 `m_δ=0` 时 `ε=0`（因 `r<q`），两值重合。推论 1.2 由 `r(g)` 周期性（§6.3）得。证毕。

### 6.2 引理 2 的证明

(a) 由 `t(g)=c+mult·K(g)`、`K(g+δ)=K(g)+J`（推论 1.1）直接代入。

(b) 取精确增量 `Δ=mult·J`、`Δmin=mult·Jmin ≤ Δ ≤ mult·Jmax = Δmax`。由 (B3) `F` 在档位值域上严格增，故 `F(t+Δmin) ≤ F(t+Δ) ≤ F(t+Δmax)`；取 `ln`（严格增）并减 `ln F(t)` 得两不等式。取等条件由 `F` 严格增与 `Δ=Δmin/Δmax` 决定。每单位版本是同除以正数 `δ`。

(c) 望远镜相消：

```text
∏_{j=0}^{J−1} F(c+mult(K+j+1)) / F(c+mult(K+j)) = F(c+mult(K+J)) / F(c+mult K) = F(t+Δ)/F(t(g)).
```

两包络的差：`Jmax=Jmin+1` 时 `∏_{j<Jmax}ρ_{K+j} = (∏_{j<Jmin}ρ_{K+j})·ρ_{K+Jmin}`，而 `ρ_{K+Jmin}>1`（`F` 严格增），故差别恰为一个档位增益。

(d) 由 (a)(b) 的取等条件直接得到。证毕。

### 6.3 引理 3 的证明

`r(g+P) = (a·g + b + a·P) mod q`，而 `a·P = a·q/gcd(a,q) = q·(a/gcd(a,q)) ≡ 0 (mod q)`，故 `r(g+P)=r(g)`。若 `p>0` 也满足 `a·p≡0 (mod q)`，则 `q | a·p`，即 `(q/d) | (a/d)·p`；因 `gcd(q/d, a/d)=1`，得 `(q/d)|p`，即 `P=q/d ≤ p`，故 `P` 是最小正周期。`K(g+P) = floor((a·g+b+a·P)/q) = K(g)+a/d = K(g)+s`。可达余类：`{a·j+b mod q : j}` = `{(b+d·j) mod q : j}`（因 `{a·j mod q}` 恰为 `d` 的倍数模 `q` 的全体，共 `P` 个），`j=0..P−1` 遍历完一个周期。表内数值由 `(a,q)` 与参考模型参数直接计算，验证脚本逐项断言。

跳档成本闭式：对 `K≥K₀`，`τ_K = ceil((K·q−b)/a)`（因 `K(g)≥K ⟺ a·g+b ≥ K·q`），故

```text
c_K = τ_{K+1}−τ_K = ceil((N+q)/a) − ceil(N/a),   N=K·q−b.
```

记 `M := q mod a`、`Q := floor(q/a)`、`ρ := (−N) mod a = (b−K·q) mod a`。由 `ceil(N/a)=(N+((−N) mod a))/a` 得
`c_K = Q + [ρ < M]`：因为 `((−(N+q)) mod a) = (ρ−M) mod a`，若 `ρ≥M` 则 `c_K=(q−M)/a=Q`，若 `ρ<M` 则 `c_K=(q−M+a)/a=Q+1`。特别地 `c_K∈{Q,Q+1}`。当 `a|q` 时 `M=0`，`c_K=Q=q/a` 恒定。`level 50 DHT` 有 `a=550>q=341`，`Q=0`，故部分 `c_K=0`（例如 `K=2`：`t=2` 与 `t=3` 同阈值 `g=2`），与验证脚本一致。证毕。

### 6.4 定理 1 的证明

(a) 由引理 1，`K(g+δ)=K(g)+J`、`J=Jmin+ε_δ(g)`，再由引理 2(a)，`R_δ(g)` 只依赖 `(K(g), ε_δ(g))`。对固定余类 `g₀ mod P`，`g=g₀+t·P` 的 `K=K₀+t·s` 且 `ε` 只依赖 `r₀`（周期性），故枚举覆盖所有可达组合。

(b) `W` 有限，`Φ_δ` 在其上取到最大/最小值；由 (a)，每个值都出现在候选集中，故极值在候选集中。

(c) 同预算：`Φ_δ(g) ≥ Φ_δ(g') ⟺ ln R_δ(g) ≥ ln R_δ(g') ⟺ R_δ(g) ≥ R_δ(g') ⟺ N/D ≥ N'/D' ⟺ N·D' ≥ N'·D`（`ln` 严格增，分母正）。跨预算：由 [marginal-comparison](../marginal-comparison/README.md) 定理 1，`ln R/δ ≥ ln R'/δ' ⟺ R^{δ'} ≥ R'^{δ} ⟺ N^{δ'}D'^{δ} ≥ N'^{δ}D^{δ'}`；指数为正整数，BigInt 精确。

(d) 精确性是 (a)(b)(c) 的直接推论：候选集覆盖像、比较规则是充要条件。证毕。

### 6.5 定理 2 的证明

**符号刻画**：按 `Δ₁,Δ₂` 分类。`F` 严格增（(B3)），故 `Δ₁=0<Δ₂` 时 `Δ²u=lnF(A+Δ₂)−lnF(A)>0`；`Δ₁>0=Δ₂` 时 `Δ²u=lnF(A)−lnF(A+Δ₁)<0`；两个都正时直接计算。仿射族公式：令 `x=A₀+A`，

```text
Δ²u = ln[ (x+Δ₁+Δ₂)x / (x+Δ₁)² ]，   分子−分母 = (Δ₂−Δ₁)x − Δ₁²，
```

故符号如陈述；`Δ₁=Δ₂=m` 时 `Δ²u=ln[1−m²/(x+m)²]<0`。

**构造见证**：

*情形 I：`a<q`（除 level 50 DHT 外的全部实例）。* 每个跳档只把 tier 索引加 1（档位值加 `mult`）。跳档成本取 `⌊q/a⌋` 或 `⌈q/a⌉`；由 `q>a` 得 `⌈q/a⌉≥2`。两种成本值都出现：任取 `K`，一个周期内 `s` 个跳档成本之和为 `Σ_{i=0}^{s−1} c_{K+i} = τ_{K+s}−τ_K = P`（因为 `t(g+P)=t(g)+mult·s`）；若全部等于 `Q=⌊q/a⌋`，则 `s·Q=P=(q/a)·s` 强制 `a|q`，矛盾；若全部等于 `Q+1` 同样强制 `a|q`，矛盾；故 `Q` 与 `Q+1` 都出现。若 `a|q` 则所有成本都等于 `q/a`（canonical 中该情形为 level 60 CRT，`q/a=3≥2`）。
- 正值见证：取一个成本 `c_K≥2` 的档位，`j:=τ_{K+1}`，则 `τ_K ≤ j−2`，故 `t(j−2)=t(j−1)=A`、`t(j)=A+mult`，属于"`Δ₁=0<Δ₂`"情形，`Δ²u(j−2)>0`；且 `j−2≥0`。
- 负值见证：成本序列 `(c_K)` 关于 `K` 以 `s` 为周期，`⌈q/a⌉` 在无限多个 `K` 上出现；取 `m≥1` 使 `c_m=⌈q/a⌉≥2`，令 `K'=m−1`、`j′:=τ_{K'+1}`。`t(j′−1)=A`、`t(j′)=A+mult`，且下一阈值 `=τ_{K'+1}+c_{K'+1} ≥ j′+2`，故 `t(j′+1)=t(j′)=A+mult`，属于"`Δ₁>0=Δ₂`"情形，`Δ²u(j′−1)<0`；且 `j′−1≥0`。

*情形 II：`a>q`（仅 level 50 DHT，`a=550,q=341`，普通/BLU 同 `(a,q)`）。* 对 `g≥0`，`K(g+1)-K(g)=floor((r(g)+a)/q) ≥ floor(a/q)=1`，故 `t` 每步严格增；`r(g)=550g mod 341` 取遍 `11` 的倍数（`d=11`，`P=31`），单步增量 `∈{1,2}`。直接计算 `r(0)=0`、`r(1)=209`、`r(2)=77`：`Δ(0)=floor(550/341)=1`、`Δ(1)=floor((209+550)/341)=2`、`Δ(2)=floor((77+550)/341)=1`。对仿射 `F_H(t)=4000+t`（`A₀=4000`，`x=4000+t>0`）：`g=0` 时 `(Δ₁,Δ₂)=(1,2)`，符号 `=(2−1)x−1²=x−1>0`；`g=1` 时 `(2,1)`，符号 `=−x−4<0`。

两种情形覆盖全部 36 个实例（BLU 只改变常数 `c`，不改变 `a,q` 与上述论证；DET/TEN 与职业无关），故每个实例都有正、负 `Δ²u`，即 raw 级 log-convex 与 log-concave 均失败。

**level 70 DHT 符号字**：该实例 `a=550<q=900`、`mult=1`，单步 `Δ∈{0,1}`。由符号刻画：`(0,0)→0`、`(0,1)→+`、`(1,0)→−`、`(1,1)→−`（`Δ₁=Δ₂=1` 时 `Δ²u=ln[1−1/(x+1)²]<0`，仿射族）。`Δ` 字计算为 `010110101101011011`（18 项，来自 `t(g)` 序列）；逐项按规则即得符号字 `+-+--+-+--+-+--+--`。由于 `t(g+18)=t(g)+11` 且 `t` 的增量由余类决定，`Δ` 字以 18 为周期（`P=18`），符号字亦然。验证脚本核对了周期 ≤300 的逐点一致。

**否证一般命题**：`t(g)=g`、`F(t)=4000+t` 时 `F(g)=4000+g`，`Δ²u(g)=ln[(4000+g+2)(4000+g)/(4000+g+1)²]`，而 `(a+2)a < (a+1)²` 对 `a=4000+g>0` 恒成立，故 `Δ²u(g)<0` 对所有 `g` 成立（严格 log-concave，绝不出现正号）。所以"任意非恒定非减阶梯序列必有正负号"是假命题；定理 2 的结论是 canonical 36 个实例的逐实例性质。证毕。

### 6.6 推论的证明

`A`、`T` 的定义只涉及一个周期内的有限个单位比值，故可精确计算。望远镜相消：`∏_{g=0}^{P−1}R₁(g) = F(t(P))/F(t(0))`，取对数除以 `P` 即 `T`（`T>0`）。

`A = ln Rmax − ln Rmin`，故 `A/T = P·ln(Rmax/Rmin)/ln(periodGain)`；`A/T > C ⟺ (Rmax/Rmin)^P > periodGain^C`（`ln` 严格增、`P,C>0`），即精确整数比较。表中数值与 `A/T<26` 的精确证书、`level 100 TEN` 的 `A/T>25` 证书由验证脚本给出（§11）。

机制：`a<q` 时存在平台步（`r+a<q`），故 `min R₁=1`；跳档步的比值是 `ρ_K`，故 `maxR=max_K ρ_K`。`T=(1/P)ln(∏_{跳档步}ρ_K)=(1/P)Σ lnρ_K`。若 `lnρ_K≈ε`（`K` 在周期内变化不大），则 `A≈ε`、`T≈(s·ε)/P`，比值为 `P/s=q/a`。

参数族：`det=140m, detTrunc=1` 时 `a=140`、`q=140m`、`b=140000m`、`c=0`、`mult=1`；`K₀=floor(b/q)=1000`，`t(0)=1000`；`d=gcd(140,140m)=140`、`P=q/d=m`、`s=a/d=1`、跳档成本 `q/a=m` 恒定。故 `t(g)=1000+floor(g/m)`，一个周期（`m` 个 raw 单位）内恰好一次跳档：`R₁` 取 `1`（`m−1` 次）与 `1001/1000`（1 次）。于是 `Rmax/Rmin=1001/1000`、`periodGain=1001/1000`、`A/T=P=m`，精确且随 `m` 无界。证毕。

## 7. 反例与边界退化

### 7.1 raw 级"单位预算增益单调"不成立（正反例）

level 70 DHT，`δ=1`：`t(0)=0,t(1)=0,t(2)=1`。`R₁(0)=4000/4000=1`、`R₁(1)=4001/4000>1`、`R₁(2)=1`。故 `Φ₁(0)<Φ₁(1)` 且 `Φ₁(2)<Φ₁(1)`：单位预算增益既上升又下降，"边际递减"与"边际递增"都不成立。

### 7.2 raw 级 log-convex / log-concave 同时被否证

由 §6.5：level 70 DHT 的 `Δ²u` 在 `g=0` 为正、`g=1` 为负（且符号字以 18 为周期轮流出现两种符号）。因此 raw 级既非 log-convex 也非 log-concave。**注意**：brief 中"g=0:+1, g=1:−1, g=2:+1, …"的简化交替描述是不精确的；精确的 18 周期符号字是 `+-+--+-+--+-+--+--`（§5.5），例如 `g=3` 与 `g=4` 都是负号。产生机制：`t` 的跳档由 `floor` 平台隔开，二阶差符号取决于 3 个相邻 raw 位置各自落在平台还是跳档上，而不是平滑曲率。

### 7.3 "任意非恒定非减阶梯序列必有正负号"是假命题

`t(g)=g`、`F(t)=4000+t`：`Δ²u(g)=ln[(A+g)(A+g+2)/(A+g+1)²]<0` 对所有 `g` 成立（§6.5 最后一段）。因此不能把"两种符号都出现"当作阶梯序列的一般性质；本定理的证明是逐实例的（但覆盖全部 36 个 canonical 实例）。

### 7.4 零成本跳档与"跨多档"边界（level 50 DHT）

`level 50 DHT` 有 `a=550>q=341`：每个 raw 步可能跨 1 或 2 个档位（单步增量 `∈{1,2}`），且某些相邻档位的最小贡献阈值相同（`t=2` 与 `t=3` 都在 `g=2`），即 `c_K=0`。此时：

- 单位成本档位 log 增益 `λ_K=lnρ_K/c_K` 分母为 0，无定义；[marginal-comparison](../marginal-comparison/README.md) 的正成本前提不成立。
- 但**窗口**公式（引理 1）仍然有效：`t(g+δ)−t(g)` 与 `R_δ` 均良定义。
- 结论：该等级的边际分析必须使用窗口包络（本定理），不能使用"档位转移"的每单位增益。

### 7.5 DET 的 mult 粒度：不能按 `t→t+1` 插值

level 50 DET 的 `mult=5`：`t(0)=1000`、`t(1)=1000`，下一个可达档位是 `1005`。若按 `t→t+1` 计算"档位增益"会捏造 `1001..1004` 这些**不可达**的档位值，得到的 `ρ` 与 `λ` 不对应任何 raw 窗口。本文所有档位增益 `ρ_K` 都定义在可达档位 `c+mult·K` 上（对 DET 即 `t` 为 `mult` 的倍数）；验证脚本 §9a 断言 level 50/60 DET 的所有档位值都是 `mult` 的倍数且相邻可达档位差恰为 `mult`。

### 7.6 空窗口、`δ=0` 与区间端点

- 若 `v−u<δ`，`W_δ(u,v)=∅`：极值无定义，查询应返回"空窗口"，不能返回 0 或任意默认值。
- `δ=0` 时 `Φ_0=0/0` 无定义；本文要求 `δ≥1`。
- 候选枚举必须使用闭区间约束 `u≤g` 与 `g+δ≤v`；区间端点是否可达会改变候选集（验证脚本对 `[u,v]` 的多组取值逐点核对）。

### 7.7 定义域外 `g<0` 的截断差异（正式候选路径不可达）

canonical evaluator 的 `Math.trunc(v+1e-7)` 在 `g<0` 时与精确 `floor` 不等价。例如 `level 70 WHM CRT, g=−450`（**贡献坐标**；对应的面板值为 `sub + g = 364 − 450 = −86`）：整数模型给出 `floor(200·(−450)/900)+50 = −100+50 = −50`；canonical 收到的是贡献 `−450`（其内部先算 `value = base + 贡献 = 364−450 = −86`，再减 `sub` 回到 `−450`），于是 `200·(−450)/900 + 50 = −50`，再做 `Math.trunc(−50 + 1e-7) = Math.trunc(−49.9999999) = −49`，两者不同（验证脚本 §9d 断言该差异确实存在）。若把面板值 `−86` 当作贡献传入，坐标就混用了；[verify.mjs](verify.mjs) §10 断言贡献 `−450` 对应面板 `−86`。

**这只是定义域外说明**：三属性在 `equipped-effects.ts` 中都以 `value = baseStat + 贡献` 计算，且 `baseStat(CRT/DHT/TEN) = sub`、`baseStat(DET) = main`；正式候选路径的贡献逐项非负（装备/镶嵌/自定义与义军武器/食物），因此 `g >= 0` 且四个分支的 floor 实参恒 `>= 0`（CRT `>= 50`、DHT `>= 0`、DET `>= 200`、TEN `>= 1000`），负实参不可达。结构性证明见 [raw-tier-transform](../raw-tier-transform/README.md) Lemma 4.3b 与参考模型 §2.2。本文所有命题在该可达域上成立；负贡献只可能来自导出 API 被误用或自定义 extractor。

## 10. 应用前提与安全回退

### 10.1 精确包络查询契约

```text
queryWindowEnvelope(level, job, stat, u, v, delta)
  -> { nonEmpty, max: candidate, min: candidate, candidateCount }
     candidate = { N, D, delta, K, epsilon }        // 单位预算 log 增益 = (1/δ)·ln(N/D)

前置:  坐标：u, v, delta 都是**贡献坐标**（属性贡献单位）；面板值需先减 offset
       （CRT/DHT/TEN: sub；DET: main，参考模型 §2.1）再调用。
       0 <= u；delta >= 1（整数）；u + delta <= v（否则 nonEmpty=false）；
       因子 F 是该 (level,job,stat) 下的固定整数因子（B3 严格增）。
枚举:  对每个 g0∈[0,P)：r0=(a·g0+b) mod q；对 g=g0+tP∈[u, v-delta]：
         K = K(g0)+t·s， eps = [r0+(a·delta mod q) >= q]，
         J = floor(a·delta/q)+eps，
         N = F(c+mult·(K+J))，D = F(c+mult·K)。
比较:  同 delta：N·D' ? N'·D（BigInt）；
       跨 delta ：N^delta'·D'^delta ? N'^delta·D^delta'（BigInt，见 [marginal-comparison](../marginal-comparison/README.md)）。
输出:  极值候选（精确有理数对 N/D）与候选计数；不输出浮点 log。
```

### 10.2 使用方式与安全性

- **区间界**：若某区间上 `max Φ_δ` 仍严格小于某个门槛 `Φ*`（用交叉指数精确判定），则该区间内不存在更优窗口；反之 `min Φ_δ` 可用于下界。上下界都必须取"该区间内全部候选"的极值，才能作为安全剪枝依据。
- **粗包络（引理 2）**：只需 `t(g)`（一次档位求值）即可得到 `[(1/δ)lnF(t+Δmin)/F(t), (1/δ)lnF(t+Δmax)/F(t)]`，是**认证**区间；但注意它依赖 `ε` 的未知性，故对任意 `g` 都成立（安全上界），也可用于快速排除明显不可能的分段。
- **精确点回退**：当区间/成本语义不满足（例如需要跨属性、三因子联合、或窗口跨越 cap/装备可行域）时，回退到 canonical evaluator 在实际点上的整数因子求值与 BigInt 交叉乘法；不在包络层下结论。
- **并列语义**：`Φ` 相等不构成严格改善；剪枝只使用严格不等。
- **贡献坐标**：`u,v,δ` 与返回的 `N/D` 都基于贡献坐标档位；不接受把面板总值当贡献。面板输入必须先按 §13.2 换算；坐标未知/混用时回退到 canonical evaluator 的实际点求值。
- 本包络只覆盖**单一因子**与固定 `(level, job, stat)`；三因子乘积、GCD/主属性/TEN 及装备可行性不在本定理范围。
- 不声明性能收益；查询复杂度与枚举策略属于实现策略，不得影响正确性。

## 12. 未解决问题

1. **极值查询的复杂度**：定理 1 给出有限候选集，但最坏规模约 `P × (区间内周期数)`；能否利用 [tier-log-curvature](../tier-log-curvature/README.md) 的档位级单调区间把每个 `(level,stat)` 的候选进一步压缩到 `O(P)` 或 `O(log)` 量级，尚无证明（只有数值观察）。
2. **case (iv) 的完整符号分类**：当窗口内出现"两个不同步长的跳档"（例如 level 50 CRT 在 `2` 个 raw 单位内跨 2 档）时，`Δ²u` 的符号由一般整数表达式决定；本文只证明存在性并规避该情形的分类难点，未给出对所有 `(a,q,Δ₁,Δ₂)` 的闭式符号表。
3. **三因子联合包络**：单因子窗口包络不能直接乘成三因子乘积的包络（相关结构丢失）；需要 [free-budget-upper-bound](../free-budget-upper-bound/README.md) / [simplex-vertex-reduction](../simplex-vertex-reduction/README.md) 层次的联合定理。
4. **带误差上界的定点实现**：BigInt 精确但指数规模随预算增长；若要用定点/浮点包络，需要给出与 [marginal-comparison](../marginal-comparison/README.md) 定理 4(c) 类似的误差加宽规则并证明安全。
5. **"振幅/趋势比可任意大"的现有等级版本**：本文只给出参数族（`det=140m`）的无界构造与 canonical 六等级的数值证书（最大 ≈25.155、`A/T<26` 精确证书）；是否能把 canonical 最大值写成闭式（依赖档位增益的变化规律）未给出。
6. **与真实装备可行域的接口**：本文只作用于公式坐标；把窗口包络安全地用于真实装备池的候选剪枝，还需要可行域/共享槽/食物 cap 的论证与回退路径。
7. **形式化**：可选的 SMT/Lean 证书尚未提供；本文证明为纸面代数证明 + 有限验证。

## 13. baseStat 影响审计（贡献坐标 vs 面板总值）

| 因子 `F_C/F_H/F_D/F_TEN` | 因子值（整数） | 只依赖档位值 `t`；公式不含 baseStat |
| 面板总值 `panel` | `baseStat + g` | **仅用于换算**；不进入本文任何公式、数值例或验证输入 |
| `offset` | CRT/DHT/TEN 取 `sub`，DET 取 `main` | 由等级参数决定（[参考模型 §2.1](../../canonical-evaluator-reference.md)），当前数据下与职业无关；BLU 只改档位常数 `c` 与 `b_C` |

**明确否定的用法**：本文没有把面板值当作 `g`、`δ`、阈值或窗口端点；§5.2/§6.1 的数值例（`g=13/37`、`[100,160]`）、§5.5 的符号字（从贡献 `g=0` 起）、§5.6 的 `A/T` 表（贡献周期 `g=0..P−1`）与 §7.7 的 `g=−450` 全部是贡献坐标。

**逐项回答（任务清单）**：`g` ✓贡献单位；窗口预算 `δ` ✓贡献单位（增量，常数平移不变）；阈值 `τ_K`/`g_k` ✓贡献单位（面板阈值 = 贡献阈值 + offset）；余类/周期表 ✓由 `(a,q)` 决定、以贡献单位表示 `g` 与周期；跳档成本 `c_K` ✓贡献单位阈值差（平移不变）；`A/T` 表 ✓以贡献周期 `g=0..P−1` 计算。**只有 `panel = baseStat + g` 是面板值，且仅用于换算**。

### 13.2 归约链（canonical → 本文坐标）

```text
value = baseStats[stat] + gearAndFoodValue                     (equipped-effects.ts:127)
baseStats.CRT = baseStats.DHT = baseStats.TEN = sub,
baseStats.DET = main                                            (getBaseStats :178-203；参考模型 §2.1)
offset = sub（CRT/DHT/TEN）或 main（DET）
g = value − offset = gearAndFoodValue                           （本文的贡献坐标）
t(g) = c + mult·floor((a·g + b)/q)                              （参考模型 §3）
      floor 实参 = a·g/q + c + b/q ≥ 0 对 g ≥ 0 结构性成立       （参考模型 §2.2；verify-canonical-model.mjs 的可达域非负证书）
```

换算约定：

```text
CRT/DHT/TEN：贡献 = 面板 − sub；  DET：贡献 = 面板 − main
所有属性：  面板 = 贡献 + offset
```

由归约链可见：baseStat 只在"面板 ↔ 贡献"的换算中出现；`t(g)`、阈值差、余类、周期、跳档成本与因子值都是**贡献坐标下与 baseStat 无关的函数**。但若给定的是面板值，必须先减 offset 再进入 `t(g)`；否则档位与因子会错位（§13.4 给可检测反例）。

### 13.3 逐命题判定表

**总判断**：本文全部引理/定理/推论都是**贡献坐标下的公式级命题**，不受 baseStat 影响——窗口增益、因子包络、余类周期、跳档成本、raw 级符号字与 `A/T` 的公式中都不含 baseStat。唯一需要显式声明的是坐标：若把面板值当贡献使用（输入坐标错误），余类、档位与因子会错位，阈值（作为坐标数值）整体平移；但这不是引理/定理结论对 baseStat 的依赖。

| 条目 | 是否受 baseStat 影响 | 判定与理由 |
| --- | --- | --- |
| 引理 1（窗口档位增益） | **否**（坐标要求：`g,δ` 贡献） | 公式只含 `(a,b,q,mult)` 与 `r(g)`；不含 baseStat。若用面板坐标 `x=g+offset`，公式中的余类应按 `x−offset` 计算（等价于整体平移），本文直接用贡献坐标 |
| 推论 1.1（两值/成员判据）、1.2（只依赖余类） | **否** | 由引理 1 的代数直接得到；`P` 只由 `(a,q)` 决定 |
| 引理 2（窗口因子增益包络/连乘/每单位版本） | **否** | 因子值只依赖档位 `t`；包络是 `F` 在档位上的单调性，与属性坐标无关 |
| 引理 3（周期、tier 平移、可达余类） | **否** | `P,s,d`、余类集合、`t(g+P)−t(g)` 只由 `(a,b,q,mult)` 决定；本文 §5.3 表与 baseStat 无关（BLU 仅改变 `c`，不影响 `(a,b,q,P,s)`） |
| 跳档成本闭式/成本范围/零成本跳档 | **否** | `c_K` 是贡献坐标阈值差，闭式只含 `(a,b,q)`；面板平移不改变差（数值相同） |
| 定理 1（有限候选精确包络查询） | **否**（坐标要求：`u,v,δ` 贡献） | 候选 `(K,r,ε)`、`N=F(t+Δ)`、`D=F(t)` 与精确比较全部是贡献坐标 + 因子值；baseStat 不参与。若把面板值当贡献，候选集与因子会错位 |
| 定理 2（raw 级凸凹均失败） | **否** | `t(g)` 作为贡献函数不含 baseStat；符号字从贡献 `g=0` 起编号。换到面板坐标只是评价起点平移 `offset`（周期与符号集合不变），不改变"两种符号都出现"的结论 |
| 推论（锯齿振幅 `A/T`） | **否** | `A/T` 由贡献周期 `g=0..P−1` 的因子比值决定；`t(0)=c` 是档位常数（由等级/职业类决定，不是 baseStat）；若从面板坐标看，贡献 0 对应面板 `offset`，两者一致 |
| §7.7 定义域外 `g<0` 说明 | **数值需坐标声明** | `g=−450` 是贡献；对应面板值 `sub−450=364−450=−86`；canonical 内部收到的是贡献 −450 |
| §10 运行时契约 | **前提要求** | `u,v,δ` 必须是贡献单位；面板输入需先减 offset；坐标未知/混用 → 回退 |

**审计精确化说明（对任务表述的一处细化）**：任务表述"若把面板值当贡献会改变 `cF/cG` 与阈值"需要精确化——阈值**作为坐标数值**会因常数平移改变（面板阈值 = 贡献阈值 + offset）；但**同一属性内**的阈值差（跳档成本 `c_K`）在纯常数平移下数值不变。真正的问题是：(i) 把面板值直接代入贡献档位公式会使档位与因子错位（§13.4 有可检测反例）；(ii) 跨属性/跨坐标混用时阈值差失去可比性。因此运行时仍**必须**使用贡献坐标；不能因为"差不变"而把面板值当贡献。

### 13.4 数值复核

1. **§5.2/§6.5 数值例（level 70 DHT，`sub=364`）**：`g=13`、`δ=10` 是贡献；对应面板值为 `377`（=364+13），`g=37` 对应面板 `401`。窗口 `[100,160]` 是贡献窗口，对应面板窗口 `[464,524]`。档位公式只接受贡献：`t(13)=7`、`t(23)=14`（贡献），与 §5.2(b) 的精确增益 `4014/4007` 一致。
2. **§5.5 符号字**：从贡献 `g=0` 起编号；`Δ` 字 `010110101101011011` 与符号字 `+-+--+-+--+-+--+--` 都是贡献坐标的序列。面板坐标只是把同一序列的索引整体加 `offset`（如 level 70 DHT 为 364），符号集合与 18 周期不变。
3. **§5.6 `A/T` 表**：按贡献周期 `g=0..P−1` 计算；`t(0)=c` 是档位常数（CRT 50/250、DHT 0/200、DET 0、TEN 1000），不含 baseStat；因此表中数值与 baseStat 无关。若改用面板坐标，贡献 `g=0` 对应面板 `offset`（如 level 70 DHT 为 364），起算点一致。
4. **§5.3 周期/余类表**：`P,s,d` 只由 `(a,q)` 算出，BLU 与普通职业相同（BLU 只改 `c`）；与 baseStat 无关。验证脚本 §10 断言：24 个 `(level,stat)` 的周期/平移与职业无关且等于 `q/gcd`、`mult·a/gcd`，288 个逐 `K` 跳档成本 BLU=普通。
5. **零成本跳档（level 50 DHT，`sub=341`）**：`t=2/t=3` 的贡献阈值同为 `g=2`，面板阈值同为 `343`，成本 0；平移不改变"同阈值"事实。
6. **§7.7 边界例**：贡献 `−450` 对应面板 `−86`；canonical 收到的是贡献 `−450`（`value = 364 + (−450) = −86`，再减 `sub=364` 回到 −450）。若把面板 `−86` 当作贡献传入，坐标即混用。
7. **结论**：本文全部数值例、符号字与包络表在贡献坐标下正确；若外部只给面板值，按 §13.2 换算后所有结论与数值（档位、因子、阈值差、窗口增益、`A/T`）不变。
