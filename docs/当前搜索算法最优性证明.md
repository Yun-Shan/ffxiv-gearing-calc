# 当前搜索算法的条件最优性证明

> 状态说明（2026-10-03）：下文关于 CP-SAT 单次模型原型、整数约束及求解状态的讨论属于历史探索。CP-SAT 适配器已从运行代码移除；当前实现仅使用 HiGHS。保留以下分析与结论作为探索记录。

## 结论与范围

在输入候选完整、整数模型与正式规则等价，并且求解器的 `Optimal` / `Infeasible` 状态可信的前提下，单职业搜索和联合搜索都能证明返回值是其**输入候选及指定约束内**的全局最优解。证明不扩展到候选生成器遗漏的装备、镶嵌或食物。

这里的“输入候选”有明确边界：生产候选生成（[optimizer.ts](../src/domain/optimizer.ts)）按项目规则在普通孔和首个禁断孔使用该装备可用的最高级魔晶石，其余禁断孔使用该装备限制孔允许的最高等级魔晶石；它不会枚举普通孔的所有较低级魔晶石。因而本证明针对当前候选生成政策，不等于证明所有游戏允许的镶嵌组合都已搜索。若搜索域需要包括较低级普通孔镶嵌，还须将它们加入候选，或证明在所选约束（尤其速度上限）下它们可由现有候选支配。

当前代码不能给出无条件的机器可验最优性证书：HiGHS 在浮点数上求解 MILP。代码会检查解的整数性、约束、属性重建及因子重建，也会用 BigInt 比较真实目标，但这些检查只验证已返回解的可行性，不独立证明 MIP 全局上界或不可行性。因此，以下是以求解器状态正确为前提的数学证明，不是对每次运行的独立形式化证书。这与结果字段 `formalCertificate: false` 一致。

## 单职业搜索

### 定义

令 `F` 为按输入槽位、食物和约束定义的有限可行配装集合。每个 `x ∈ F` 的正式公式可表示为正整数因子

\[
P(x)=W(x)M(x)D(x)T(x)C(x)H(x),
\]

分别对应武器伤害、主属性、信念、坚韧、暴击期望和直击期望。对固定职业和等级，真实伤害等于 `P(x)` 乘一个与配装无关的正常数；DPS 的排序等价于比较 `P(x)/g(x)`，其中 `g(x)` 是以百分之一秒为单位的正整数 GCD。因此可以用 BigInt 精确交叉相乘比较，不必比较浮点显示值。

### 引理：线性模型表示同一有限问题

对每槽恰选一件装备的 one-hot 等式，及存在食物候选时恰选一种食物的 one-hot 等式，连同属性求和变量，唯一确定装备属性合计。没有食物候选时不建食物选择变量。食物变量、整数加成变量和封顶标记表达取整及上限；属性阶梯通过“因子值相同的属性区间”及 one-hot 因子类表达。GCD、速度、坚韧约束也在模型内。

故模型的每个整数可行解都对应一个满足指定约束的候选配装；每个此类配装也能构造出模型可行解。此引理以候选生成完整且模型行编码无误为前提。当前生产候选向量包含 `PDMG` / `MDMG`，所以 V3 的装备支配剪枝也会比较职业相关武器伤害；直接调用领域搜索接口时，调用方仍须提供完整属性坐标和正确的装备属性提取器。实现会从所选候选重建属性，并校验食物、GCD、模型行及伤害因子。

### 引理：V3 的支配剪枝保留至少一个不劣候选

V3 在求单职业基线前，对非共享槽候选按完整属性向量做坐标支配；生产向量包含武器伤害坐标。若候选 `a` 每个坐标都不低于 `b`，则用 `a` 替换同槽的 `b` 不会降低伤害因子；对 DPS，速度增加只会使 GCD 不增。基础属性固定，食物的逐项加成对原始值单调，所以最终属性仍逐坐标不低。下限约束因此保持可行；若有速度上限或精确 GCD/GCD 集合，剪枝只在速度坐标相等时比较。V3 对共享槽保留原候选，不在这一步剪除共享身份。

对普通共享槽，V3 只在一个候选对**所有职业**的属性向量均不劣时支配另一个；坐标中显式加入 `PDMG` / `MDMG`。戒指投影槽不做此类剪枝，以保留完整戒指对和唯一性伙伴。属性完全相同的普通共享选择可按单职业基线匹配数保留其中一个，因为其对所有职业的目标、约束贡献相同，且该槽没有戒指唯一性关系。

共享食物剪枝会对每职业、每个可能被食物加成的属性，检查该属性从零到全部原始槽位最大和范围内的**每一个整数值**。逐点不低的食物替换后，所有可能配装的最终属性不会下降；涉及速度上限或精确 GCD 时，速度加成必须相等。效果完全相同的共享食物可保留一个物理身份，仍属于共享食物候选集合。

因此，这些剪枝不会移除唯一的最优目标值；它们保留至少一个与被删候选目标相同或更优的可行替代。此结论要求属性映射完整、游戏伤害对相关因子单调，并依赖生产输入中非戒指槽没有跨槽装备唯一性规则。

### 引理：固定点对数带覆盖所有可能更优的因子签名

对正整数因子 `v`，实现以有理数区间证明

\[
q(v)=\operatorname{round}(10^{12}\ln v)
\]

的整数值。设

\[
Q(x)=\sum_{v\in\{W,M,D,T,C,H\}}q(v)
\]

DPS 时再减去 `q(g)`。因每项舍入误差至多半个整数单位，至多七项，所以

\[
|Q(x)-10^{12}\ln(P(x))|\le 7/2
\]

DPS 时将 `P(x)` 替换为 `P(x)/g(x)` 后同样成立。设 `Q* = max_{x ∈ F} Q(x)`，并取一配装 `x*` 达到它。若另一配装满足 `Q(x) < Q* - 7`，则

\[
10^{12}\ln(P(x))\le Q(x)+7/2 < Q^*-7/2\le10^{12}\ln(P(x^*)).
\]

因此 `x` 不可能优于 `x*`。严格更优的真实目标只能出现在 `Q ≥ Q* - 7` 的签名带内。代码以 `errorBand = groups.length` 使用 7，较实际每侧误差更保守。

### 定理：若代理 MIP 被精确求解，单职业返回值为真实目标最优

1. MIP 求出 `Q*` 后，算法从签名带中反复取可行因子签名，重建完整配装，并以 BigInt 比较 `P` 或 `P/g`。
2. 签名带辅助检查对独立因子类的笛卡尔积做穷尽；它是实际可达签名的超集。只有超集中也不存在严格更优组合时才结束捷径证明。时间或容量不足会退回完整 MIP 带内枚举，不会将中断视为证明。
3. 完整枚举路径逐个排除已检查签名，直到模型报告签名带不可行。于是带内没有遗漏的可行候选；由前一引理，带外候选也不可能更优。

故最终留下的 BigInt 最大因子签名对应全局最优配装。若开启最高坚韧模式，先在各职业不固定共享装备的完整候选域最大化最终坚韧值，再将该值作为联合搜索的硬下限；单职业阶段随后固定该值做用户指定的伤害或 DPS 目标优化。在两阶段状态都可信时，结果满足词典序目标“先达到可实现最高坚韧，再在该值下优化目标”。

## 戒指约束与可行域等价

### 引理：两个戒指槽与合法戒指对集合等价

令 `A`、`B` 分别为 `ring`、`ring2` 的有限候选集，`id(a)` 为物品 ID，`U(g)` 表示物品 `g` 是否 unique。游戏规则允许的有序戒指对集合为

\[
F_R=\{(a,b)\in A\times B:\ U(id(a))\Rightarrow id(a)\ne id(b)\}.
\]

为每个戒指候选设二元选择变量 `x_a`、`y_b`。两个槽位的 one-hot 约束为

\[
\sum_{a\in A}x_a=1,\qquad \sum_{b\in B}y_b=1,
\]

对每个 unique 物品 ID `g` 加入跨槽约束

\[
\sum_{a\in A:id(a)=g}x_a+\sum_{b\in B:id(b)=g}y_b\le1.
\]

任一整数可行解由两个 one-hot 约束唯一确定一对 `(a,b)`；跨槽行恰好排除同一 unique ID 的双选。反过来，`F_R` 中每一对都能令对应两个变量为 1，其余为 0，并满足全部跨槽行。因此 MIP 的整数可行戒指域与 `F_R` 一一对应。非 unique 同 ID 可以重复，unique 物品的不同镶嵌方案也会按同一物品 ID 合并约束。只要原 pair 候选与 `F_R` 完全相同、并且 pair 属性逐坐标等于两枚戒指属性之和，成对选择与双槽 MIP 就具有相同的可行解、属性和目标值。

### 成对候选在联合 MIP 中的拆分条件

生产候选和 V3 输入仍是完整合法有序戒指对。联合 MIP 只有在以下条件均成立时才可使用上面的双槽模型：从所有 pair 提取出的左右候选域完整；原 pair 集合恰等于两域的完整笛卡尔积去除同一 unique ID 双选后的结果；pair 属性等于两个 child 属性之和；unique 元数据齐全且在所有 pair 中一致。求解时变量改用左右两组装备候选，并添加跨槽 unique 行；这些条件加上前述一一对应证明，保证模型可行域和目标不变。任一检查失败就继续使用原 pair one-hot 模型。

共享单枚戒指时，项目以共享投影匹配该枚完整装备及镶嵌身份，另一枚在每个职业内自由优化。若共享完整戒指对，则用 pair 的无序物理身份多重集链接两个槽位，并保留同一非 unique 戒指重复两次的重数。内部拆分求解结果再按已验证的 child identity 映射回原 pair 候选。

## 多职业联合搜索

生产候选生成合法有序戒指对，单职业 MIP 和 V3 基线按 pair 槽位选择。联合因子 MIP 可在上述检查通过后仅对联合模型内部使用两个戒指 one-hot 槽和跨槽 unique 行；这改变变量表示，不改变候选或最优值。校验失败时沿用 pair 槽模型，结果最终都映射为原有的两件戒指。

令职业 `c` 的单职业最优目标为 `O_c > 0`，联合候选的同一目标值为 `D_c`，归一化比例为 `r_c = D_c/O_c ∈ [0,1]`。系统最大化

\[
S=\sum_c r_c,
\]

并用 BigInt 有理数交叉相乘作最终比较。

外层分支路径在每个部分共享身份节点上，允许各职业独立选择尚未固定的共享槽；这放宽了共享约束，故各职业单独最优值之和是该分支所有联合扩展的上界。完整枚举共享选择和食物、并只在上界不超过当前可行联合值时剪枝，即得到全局最优。

完整联合因子 MIP 路径用一个必要条件缩小待查集合。因各 `r_c ∈ [0,1]`，

\[
\sum_{c=1}^n r_c\le n-1+\prod_{c=1}^n r_c.
\]

所以任何总分严格超过当前值 `S_0` 的方案，都必须满足 `∏_{c=1}^{n} r_c > S_0-(n-1)`；并且每个 `r_c > S_0-(n-1)`。这些必要条件只筛候选，不替代总分目标。算法对所有仍可能改进的联合因子签名逐个还原配装，以 BigInt 精确计算比例和；只有 MIP 证明剩余签名不可行后才结束。若已达到上界 `n`，则由 `r_c ≤ 1` 可直接知其最优。

实现把这个必要条件转成安全的固定点下界。令 `t=S_0-(n-1)`、`L=10^12`，并令 `K` 为参与比较的因子组数。对每个正整数因子 `v`，量化值 `q(v)=round(L ln v)` 与真实固定点对数的误差不超过 `1/2`；候选与基线相减后，每个因子组的误差不超过 `1`。记某候选与基线的量化对数差为 `D=Q-Q^{base}`，则 `D≥L ln(r)-K`。

若 `t>0`，严格改进要求 `∏r_c>t`，故 `D>L ln(t)-K`。代码用 BigInt 的 atanh 级数和二进制范围缩减，为 `ln(t)` 构造有证明的区间，并取整数下界 `ell≤L ln(t)`。由于 `D` 是整数，任何可改进解都必须满足

\[
D\ge ell-K+1.
\]

现有线性行以 `baseline-loss-K` 表示该下界，所以设置 `loss=-ell-1`。每个职业也满足 `r_c>t`，代码为各职业加同型必要下界，其中误差项取该职业的因子组数。所有对数区间计算均使用 BigInt，负的二进制指数使用 `ln(2)` 的上界构造安全下界；不使用浮点 `Math.log`。若 `t≤0`，则不加这些必要条件，而让有限因子签名完整参与后续枚举。这样，固定点约束只删掉数学上不可能改进的签名，不把乘积目标误作比例和目标。

因此，在各职业单职业基线正确、共享装备/食物身份约束准确，以及求解器状态可信的前提下，联合结果也是全局最优。对于基线为零的职业，实现将其标记为 inactive 并从归一化总分中排除；联合最优结论只针对其余有效职业，不表示 UI 支持任意配置职业权重。

### 能否把基线与联合目标放进一次求解

直接在共享模型中最大化原始目标和会改变结果。设两个职业的独立最优值为 `OPT=(100,10)`；共享选择 A 得到 `(100,1)`，选择 B 得到 `(60,10)`。原目标分别为 `1.1` 与 `1.6`，应选 B；原始和却是 `101` 与 `70`，会错误地选 A。因此不能用原始伤害和或各职业对数和替代 `Σ D_c/OPT_c`。

有限小模型可以精确地合并：复制每个职业的独立候选选择和共享候选选择，以词典序先最大化独立基线、再最大化归一化分数。上例把联合分数乘以 100 后，A、B 分别为 110、160，分数上界为 200；给基线总值乘以 201，就能把两层目标标量化为一个整数线性目标。使用当前 OR-Tools CP-SAT 适配器的一次调用原型确实选出了基线 `(100,10)` 和联合选择 B，达到归一化分数 `1.6`。这验证了小型有限问题可单次调用求解，不代表生产模型规模可行。

生产模型里的伤害是六个整数因子的 BigInt 乘积，DPS 还除以 GCD；联合分母 `OPT_c` 又要由尚未求解的基线模型确定。要在一条线性目标里精确表示它，必须先把所有可能的基线与联合因子签名组合编码成选择变量，并为分数构造共同整数分母。签名笛卡尔积会随各职业的因子域快速膨胀；所得系数和乘积也超出 CP-SAT 的 int64/当前安全整数接口。当前 `LinearMip` 只有一个线性目标映射，HiGHS 的浮点系数也不能为该有理目标提供精确标量化。因此现有约束下没有落地生产版单次模型：基线最优性证明仍须进行，只能把它嵌入一个更大的分层模型，而不是消除这部分工作。保留现有先求基线、再证明归一化联合目标的实现，以免改变目标或牺牲最优性保证。

## 无条件证明缺口

HiGHS 的 `Optimal` / `Infeasible` 来自浮点 MILP 求解。已实现的行校验、整数变量校验和属性/因子重建证明“这个解可行且模型结果一致”，但不能推出“没有未发现的更优可行解”。可选验收后端 CP-SAT 则用有界 int64 整数约束表达同一模型，适配器会先验证系数、变量活动范围及序列化模型；这消除了模型表示中的浮点约束容差，但 CP-SAT 的 `Optimal` / `Infeasible` 状态同样没有可由独立检查器验证的最优性证书。两种求解器的运行状态都是定理条件，不是本项目可以脱离求解器独立检查的证明对象。测试中的小规模穷举对照能发现编码错误，不能证明所有生产规模的输入。因此目前最严格且准确的结论是：

> 在候选完整、模型等价且所选 MIP 求解器正确证明其整数模型为最优/不可行的条件下，算法的固定点误差带、穷尽签名检查及 BigInt 比较推出候选域内全局最优；HiGHS 的浮点求解另有数值容差风险，CP-SAT 的整数建模避免了这一类模型容差，但两者的当前运行结果都没有独立、机器可验的形式化证书。

若要把该条件证明提升为每次运行均可独立核验的证明，需要额外提供可验证的整数优化证明（例如可由独立检查器逐节点验证的分支界证书），或改为完整精确枚举。CP-SAT 的整数运算和严格的 `Optimal` 状态有助于避免浮点建模误差，但仅替换求解器而不提供证明检查，不能消除这一缺口。
