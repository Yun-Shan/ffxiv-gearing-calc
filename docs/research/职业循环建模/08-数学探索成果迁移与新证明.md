# 数学探索成果迁移与新证明

研究日期：2026-10-23。返回[总览](README.md)。本章根据用户提供的[数学探索档案](../../数学探索-证明与复现/READ-ME.md)，分析其定理能否用于职业收益与多 GCD 模型，并补充新的证明。复现环境、实测数量和局限集中在[09](09-新增验证与复现记录.md)。所有新职业系数仍为合成研究参数。

## 1. 迁移判断

| 档案路线 | 对新模型的结论 | 必须补的条件 |
| --- | --- | --- |
| DHT–DET 二次包络与余数消元 | 固定 CRT、固定 GCD 后可保留 | 直击仍是普通直击；DET 与 DHT 的反向分配、食物分段和 caps 正确 |
| CRT 平台起点剖面 | 窄 MNK 模型可保留 | CRT 因子在平台内不变；仅用于覆盖真实域的资源松弛 |
| 完整目标 AM-GM 支持上界 | 可换成新正 CRT 因子 | 其他全部乘区有合法上包络；保留同一装备内属性关联 |
| 普通 CRT 的弦线阈值与 8046 范围 | 不能直接复用，需新曲率证书 | 本章给出非负系数三次的两端点判据 |
| 二次包络段至多一个内部极大 | 在 MNK 三次模型中失效 | 必须覆盖全部驻点，或回退区间/逐档上界 |
| 多职业乘积代理和损失区域 | 一般不等式可保留 | 全部允许 GCD 的正式基线、同域代理上界、实际量化误差 |
| 目标相关职业等价商 | 定理保留，旧职业配对结论不继承 | 完整新目标、可达特征、约束及还原映射逐项验等 |
| 唯一戒指双槽支持 | 线性支持查询可保留 | 新目标先构造安全线性投影；凸包不能替换真实候选 |

因此最有价值的组合是：**正确的新职业目标 → 低成本安全区域证书 → 候选压缩或条件约束 → 原完整求解与复核。** 档案中更紧的戒指界、更多约束行也曾使求解变慢，不能按压缩比例决定上线。

## 2. 窄武僧模型的精确三次结构

承接[01](01-模型数学与多GCD系数.md)的假设：普通、必暴和斗气消耗技共享基础伤害及普通直击因子，不包含不同命中语义、动作级跨属性取整或动态溢出。固定 GCD 的 CRT 部分为：

\[
F_g=\alpha_gN+\beta_gK+\gamma_gcN.
\]

对当前普通职业 CRT 公式，令装备与食物贡献为 `C≥0`，等级参数为 `V=div`，`w=⌊200C/V⌋`。精确自然暴率和暴击倍率为：

\[
c=(w+50)/1000,\quad K=(w+1400)/1000,
\quad N=(w^2+450w+1020000)/10^6.
\]

于是 `F_g=Q_g(w)/10⁹`，其中：

\[
\begin{aligned}
Q_g(w)={}&\gamma_gw^3+(1000\alpha_g+500\gamma_g)w^2\\
&+(450000\alpha_g+1000000\beta_g+1042500\gamma_g)w\\
&+1020000000\alpha_g+1400000000\beta_g+51000000\gamma_g.
\end{aligned}
\]

有理系数可以统一分母。非负系数且至少一项正时，`Q_g` 在非负域正且非减。因此以 `w*=200C/V` 替代向下取整的 `w` 得到安全连续上包络；它只用于上界，正式评分仍保留取整。当前实验把自然暴率限制在不超过 1 的域，未把超范围概率当作模型依据。

也可用连续自然暴率坐标 `c` 推导。此时 `N=1+0.35c+c²`、`K=1.35+c`，所以：

\[
q(c)=a_0+a_1c+a_2c^2+a_3c^3,
\]
\[
(a_0,a_1,a_2,a_3)=
(\alpha+1.35\beta,\;0.35\alpha+\beta+\gamma,\;\alpha+0.35\gamma,\;\gamma).
\]

两种坐标是正仿射变换，曲率符号结论一致。不同坐标的具体导数数值和区间端点不能混用。保证直击、DoT、自动攻击等更广模型不自动属于本节子类。

## 3. 新定理：三次因子的曲率只需检查两个端点

[档案 AM-GM 定理](../../数学探索-证明与复现/docs/mathematical-analysis/theorems/crit-speed-envelope/README.md)给出完整目标上界：

\[
S(x)\le Pq(C)\left[\frac{L(x)}{k}\right]^k,
\]

其中 `P>0` 是参照因子乘积，`k≥1` 是参与 AM-GM 的因子数，`L` 是覆盖全部剩余乘区的仿射和。已有真实可行值 `I>0` 时，任何能追平它的方案必须满足：

\[
L(x)\ge T(C)=k\left[\frac{I}{Pq(C)}\right]^{1/k}.
\]

求导可知 `T''≤0` 当且仅当：

\[
R_k(C)=kq(C)q''(C)-(k+1)[q'(C)]^2\ge0.
\]

**定理。** 对任意非负系数三次 `q=a₀+a₁C+a₂C²+a₃C³>0`，在 `C≥0` 上 `R_k` 是凹函数。因此整个闭区间 `[l,u]` 的曲率条件等价于 `R_k(l)≥0` 和 `R_k(u)≥0`。

**证明。** 展开 `R_k=ΣᵢrᵢCⁱ` 得：

\[
\begin{aligned}
r_0&=2ka_0a_2-(k+1)a_1^2,\\
r_1&=6ka_0a_3-(2k+4)a_1a_2,\\
r_2&=-6a_1a_3-(2k+4)a_2^2,\\
r_3&=-(4k+12)a_2a_3,\\
r_4&=-(3k+9)a_3^2.
\end{aligned}
\]

后三项非正，所以 `R_k''=2r₂+6r₃C+12r₄C²≤0`。凹函数在区间内不低于端点连线，若两端非负则全区间非负；反向显然成立。这里没有用采样代替全称判断。

曲率通过后，`T` 的端点弦线在其下方，是安全必要条件。端点根可用整数开方取得向下有理逼近；降低端点只会让弦线更松。曲率失败时，不能换用切线或继续使用旧弦线；应分区重验或回退完整上界。

同理 `qq''−(q')²` 的二次以上系数分别为 `−2a₂²、−4a₂a₃、−3a₃²`，也可用两端判断整段 `log q` 的凸性。但是否能接回旧 CRT/GCD 下包络路线，还取决于新模型确实具有该目标结构，不能只凭曲率通过。

### 旧范围失效的具体证据

沿用前序合成 1.94 GCD 行：`α=13040、β=4000、γ=3200`，100 级 `V=2780`、`k=4`。以连续上包络检查从 `C=0` 开始的范围，新曲率在 `C=7092` 仍非负，`7093` 为负；档案普通目标的 `8046` 也为负。

这不是给武僧设置 7092 的生产属性限制。它说明**优化守卫必须由当前 profile、范围和 k 计算**；守卫失败只停用该项加强，不删除装备或拒绝本来受完整后端支持的目标。提出恒定因子会改变 k，即使 AM-GM 上界更紧，也仍要重验弦线曲率。

## 4. 反例：MNK 包络段可以有两个内部极大

档案的[二次段上界核](../../数学探索-证明与复现/docs/mathematical-analysis/theorems/crit-speed-envelope/polynomial-segment-upper.mjs)利用导数为开口向下二次式，只检查两个端点和至多一个内部极大。三次 `q` 不能只替换系数后沿用该算法。

在自然暴率坐标取 `α=1、β=1/4、γ=23/20`，于是：

\[
400q(c)=535+700c+561c^2+460c^3.
\]

令 `h(c)=76487/25000−c>0`、`k=4`。`q(c)h(c)^4` 的导数与下面三次式同号：

\[
P(c)=20450-840793c+10701030c^2-40250000c^3.
\]

精确代入得到：

| c | P(c) | 符号 |
| --- | ---: | --- |
| 1/20 | 5267/40 | 正 |
| 3/50 | −20984/125 | 负 |
| 7/100 | 223787/1000 | 正 |
| 4/25 | −624314/125 | 负 |

三个互不相交区间各至少有一根，而三次式最多三根，因此它们都是符号改变的根。函数依次有“内部极大、内部极小、内部极大”，且都在自然暴率 `[0.05,0.16]` 内。

这是满足窄 MNK 代数结构和正仿射支持段的严格反例；并未证明该系数来自真实循环、该支持线来自实际装备，也未断言只取右峰在此例必然低估。它已足以否定原来“一峰”的一般依据。

安全路线有两种：隔离导数三次式的全部根并认证根区间上界；或在 `[u,v]` 上用单调性给出 `q(v)h(u)^k` 的安全上界并递归细分。后者应以有限 CRT 档为叶子，预算不足则回退逐档完整界；连续二分不能保证所有相等边界都有限步认证。

## 5. 多 GCD 的共同低成本证书

若各行均已按时间统一为 `q_g(C)=F_g(C)/T_g`，且在同一完整 CRT 区间上都有安全正上包络，其他乘区的 `P、L、k` 也相同，则：

\[
q_{max}(C)=\max_g q_g(C)
\]

覆盖装备实际选中的行。这是辅助上界，不是让装备任意选更高分的循环。不能再额外除一次 GCD。

定义各行必要阈值 `T_g^*(C)=k[I/(Pq_g(C))]^(1/k)`，共同阈值为 `T_{min}=min_g T_g^*`。若每行通过本章曲率守卫，则每个阈值凹；其逐点最小也凹，因为其下图是各凹函数下图的交集。故 `T_min` 两端的安全下取值连线给出**覆盖全部 GCD 的一条必要条件**。

这允许“先试共同便宜界，失败再按 GCD 条件化”。不要把每行阈值同时加到未知实际 GCD 的装备上；这会把应取并集的条件变成交集。

不同 GCD 的行若只在不同 CRT 子域定义，必须先安全延拓到共同域，或按域变化分区。不能将局部凹性检查通过的片段任意拼接。共同界还放松了速度与系数的关联，可能较松；是否比直接分档省时需要正式测试。

新实验对三个不同时长的行检查 603 个精确行点，其中 `q_max` 的最大行从 2.00 切到 1.94；共同弦线仍逐行满足必要条件。这里只验证数值实现与代数，不验证实际 GCD 候选约束或生产求解速度。

## 6. 完整乘积和候选压缩如何保留

把 CRT 因子单独提出后，剩余正因子仍可由 AM-GM 变成一个仿射和。例如在武器、主属性、坚韧及时间恒定的研究域中，目标 `Q_g(C)·H(DHT)·D(DET)` 可写成：

\[
Q_g(C)HD\le Q_g(C)r_Hr_D
\left[\frac{H^{upper}/r_H+D^{upper}/r_D}{2}\right]^2.
\]

对每件候选先构造同一线性得分，再用档案[支持函数](../../数学探索-证明与复现/docs/mathematical-analysis/theorems/coupled-product-support/support.mjs)在总 CRT 区间内求连续松弛上界。这保留每件装备内部的属性关联；不能先分别取全部属性最大值后把它们当作一套可装备配置。

固定某候选，只有它在**所有允许 GCD 及剩余 CRT 区间**的上界都严格低于真实可行 incumbent，才可从全域候选池删除。局部排除只属于对应分支；同分保留。最高坚韧、共享身份和其他约束仍按[03](03-单职业精确搜索.md)、[04](04-多职业联合搜索.md)处理。

新实验在 24 个固定 GCD 合成候选域中检查 3000 个完整组合，对 360 个候选条件做证书，删除 172 个；每个删除均与该候选的全部完成穷举核对。初始下界取预先指定的第一套完整方案，未借用穷举最优值。这是该辅助界在合成域的有效性证据，不是实际游戏候选压缩率。

[余数消元](../../数学探索-证明与复现/docs/mathematical-analysis/theorems/quadratic-profile-compression/README.md)也可保留：固定 CRT 后，新因子是正数常量，DHT–DET 在每个共同周期余数类仍是凹二次。预算剖面只需 CRT 平台起点；但这只求解资源松弛的极值，不能把松弛最优解作为真实配装下界。

## 7. 多职业证书与等价商的迁移

用全部允许 GCD 的独立最优归一化，`0<r_j≤1`，定义真实目标 `S=Σr_j` 与辅助乘积 `P=Πr_j`。[档案定理](../../数学探索-证明与复现/docs/mathematical-analysis/theorems/product-proxy-localization/README.md)不依赖职业公式：

\[
S\le J-1+P.
\]

若有覆盖完整可行域的乘积上界 `Pbar` 和真实可行总分 `S_inc`，对所有可追平方案：

\[
0\le E=J-1+P-S\le\eta=J-1+Pbar-S_{inc}.
\]

令损失 `l_j=1−r_j`。固定任意两项时，加入其它非负损失只使 E 增大，因此 `l_i l_j≤E≤η`。对任意有理 `t≥0` 满足 `t²≥η`，最多一个职业的损失严格超过 t，故可以保留 J 个“允许一个例外”的区域并集。不能任选一个例外职业，也不能把非例外比例强制为精确 1。

当 `Pbar<1` 时还可收紧：`δ=Σl_j≥1−P≥1−Pbar`，最大损失至少为 `(1−Pbar)/J`。以最大损失职业为例外，其余损失由两两乘积界得到 `l_j≤Jη/(1−Pbar)`。因此可取该有理宽度与安全上取的 `sqrt(η)` 的较小值；`Pbar≥1` 时停用这一额外式，不能除以非正数。新实验同时检查了该收紧。

新脚本用有限域精确乘积最大值构造 Pbar；这验证区域定理，**没有证明新目标 rounded-log 代理已经接通**。生产若使用 Q 最优与 `L/(L−m)`，仍须重新认证完整同域 Q、实际因子/分母数量 m、缩放与数值范围。

### 等价商必须重新验目标

[等价商定理](../../数学探索-证明与复现/docs/mathematical-analysis/theorems/equivalent-job-quotient/README.md)要求固定共享身份后，各职业私有可达特征集和完整归一化函数相同。旧字段相同或旧目标同分不够；新动作构成、AA 的武器间隔、DoT 速度及多 GCD 行都可能破坏等价。

新增反例中，两个职业在旧目标上可合并，但换成不同的非比例循环系数后，独立特征选择的正确总分为 2，强制同特征只有 `131/67`，损失 `3/67`。这是代数反例，未对应实际职业或配装。相同完整新函数的正例仍保持最优。

若合并后某类重数为 m，真实和仍计 `m·r`，乘积仍计 `r^m`，`J` 是原职业总数。量化代理还要单独验等和重新核算误差，不能把类数代替原职业数。档案旧 RDM/SMN 等价曾忽略旧目标不读取的 DLY；新目标一旦读取，该投影就必须重建。

### 唯一戒指支持不是新的配装候选池

[唯一戒指双槽支持](../../数学探索-证明与复现/docs/mathematical-analysis/theorems/unique-pair-support/README.md)只依赖线性价格与同 unique ID 冲突规则，可以用新目标产生的线性价格复用。按 ID 一致的 unique 元数据和全部位置限制仍须保持；支持凸包只描述放松上界，不能把真实戒指选择限制成凸包顶点。

## 8. 对实施优先级的调整

1. 保持[06](06-实施与验收.md)的 R0—R4 前置顺序：先把真实规则与正确新目标接通。
2. 第一项优化实验优先使用固定 GCD 的完整 AM-GM 支持界，配合曲率端点守卫和自适应区间回退，重点比较基线建模前压缩的成本。
3. 多 GCD 先试共同安全界，再按必要性条件化；分别记录预处理成本、删候选量和后续模型耗时。
4. 联合阶段优先保留全域基线和一般损失证书；等价商作为验等成功才启用的机会型优化。
5. GCD×CRT 联合块、所有驻点的精确隔离及更紧唯一戒指界后续独立评估。不得把档案的历史性能排序当作新模型结论。

本章新增了可直接检查的数学条件，也明确排除了一个错误推广；正式运行收益仍需相同新目标、相同候选和完整证明下的对照。
