# 模型数学与多 GCD 系数

状态：研究提案；核对日期：2026-10-23。本文推导目标结构，不代表生产搜索已支持职业循环。整体边界见[研究入口](README.md)，数据与动作来源见[数据与循环预设](02-数据与循环预设.md)，已有实验见[来源与探索证据](07-来源与探索证据.md)。

## 1. 先确定优化的量

当前 `damage` 是通用每威力伤害期望，`dps` 是该值除以 GCD；二者没有表达职业动作序列。新模型必须独立定义计分单位，不能借用旧字段名称推断含义。

| 模型口径 | 权重与分母 | 可承诺的含义 |
| --- | --- | --- |
| 固定动作构成 | 基础威力贡献及触发事件次数，无时间分母 | 该构成的模型总分 |
| 固定循环 | 循环内次数、循环时长 `T_g` 秒 | 循环平均模型伤害/秒 |
| 已归一化频率 | 基础威力/秒、事件/秒 | 直接得到模型伤害/秒 |
| 固定战斗窗口 | `H` 秒内的事件、初始状态与尾段规则 | 该窗口的预计伤害/秒，取决于模型假设 |

循环平均值与固定战斗窗口不是同一个量。固定循环会隐含可重复的状态；有限窗口可能包含一次起手、冷却未转好的结束时刻与未消耗资源。即使平均值可精确计算，也不能抹去这些差异。

全文以 `g` 表示基础 GCD 档位标识，内部宜用整数厘秒，例如 `199` 对应 `1.99 s`；`T_g`、`H` 始终以秒计。厘秒标识不能直接作为秒分母。

一套装备 `x` 的含基础与食物的最终速度决定 `g(x)`。多个允许 GCD 是**互斥选择**：该装备只用 `g(x)` 的系数，不把各档分数求和或取平均。若想评价同一套装备在多个战斗场景中的加权表现，需要另行定义场景目标。

## 2. 武僧窄模型的假设与单位

先限定以下数学子类：伤害项共享基础伤害因子 `Base(x)` 与普通直击期望 `H_D(x)`；没有动作级跨属性取整、不同直击语义或增益窗口相关性；斗气技按普通暴击处理。真实 profile 能否满足这些条件须逐项核验。

设最终 CRT 为 `t`，同版本公式给出暴击概率 `c(t)` 与暴击倍率 `k(t)`，定义：

\[
N(c,k)=1+c(k-1),\qquad K(k)=k.
\]

`N`、`K` 均无量纲，分别表示普通、保证暴击伤害的期望倍率。保证暴击不再通过自然暴击概率决定是否暴击。

对固定 `g` 的同一循环或观察单位，设：

| 符号 | 含义与单位 |
| --- | --- |
| `A_g`、`B_g` | 斗气消耗技以外，普通/保证暴击部分的基础威力贡献，单位为威力 |
| `n_{n,g}`、`n_{c,g}` | 能触发斗气的普通/保证暴击战技次数，单位为次 |
| `r_g` | 该等级与规则下，合格暴击事件给出一点斗气的概率，无量纲 |
| `q_{0,g}` | 同一观察单位内额外获得且纳入本模型的斗气期望，单位为点 |
| `P_χ`、`m` | 消耗技基础威力、每次消耗斗气点数 |
| `T_g` | 该循环长度，单位为秒；总分模型可不提供 |

`A_g` 与 `n_{n,g}` 不能互换：一个高威力动作仍可能只触发一次资源事件。不能从某套装备的最终伤害占比推导固定 `A_g/B_g`，否则占比中既有的暴击、直击收益会被重复计算。

`q_{0,g}` 不是无条件把“开场资源”加入每轮循环。可重复循环需要首尾资源状态一致；一次性的初始资源只属于有限窗口。若队友资源或增益与自身事件相关，也不能默认用一个独立常数替代。

## 3. 从资源期望展开为三个基函数

在长期平均、无资源溢出、允许把资源按平均消耗率换算为动作的近似下：

\[
Q_g(c)=r_g(n_{c,g}+n_{n,g}c)+q_{0,g},
\]
\[
F_g(c,k)=A_gN+B_gK+\frac{P_\chi}{m}Q_g(c)N.
\]

这里 `Q_g` 为斗气点数期望，`P_χ Q_g/m` 为威力贡献；因此 `F_g` 的单位是威力。原始普通/保证暴击贡献中必须排除这里单独计入的斗气消耗技，避免重复计数。

令 `d=P_χ/m`，按基函数 `N`、`K`、`cN` 展开：

\[
F_g=\alpha_g N+\beta_g K+\gamma_g cN,
\]
\[
\alpha_g=A_g+d(r_gn_{c,g}+q_{0,g}),\qquad
\beta_g=B_g,\qquad
\gamma_g=dr_gn_{n,g}.
\]

暴击概率反馈仍保留在 `cN` 中。先以某个参考 CRT 算出斗气动作次数，再永久固定该次数，会失去此项对换装的响应。

固定循环的目标为：

\[
S(x)=Base(x)H_D(x)\frac{F_{g(x)}(c(t),k(t))}{T_{g(x)}}.
\]

若采用频率口径，`A/B` 改为威力/秒，`n_n/n_c` 改为次/秒，`q_0` 改为点/秒；同一展开直接得到威力/秒，**不再除以 `T_g` 或 GCD**。固定冷却 oGCD 与随 GCD 改变的战技频率不同，不能假定所有系数都按 `1/g` 缩放。

## 4. 初始资源、结束余数与有限时间

上述资源均值换算不是有限状态资源模型。即便没有溢出，也一般有：

\[
E\!\left[\left\lfloor\frac{q_{init}+X}{m}\right\rfloor\right]
\ne\frac{q_{init}+E[X]}{m}.
\]

已有合成实验中，`q_init=5`、`m=5`、`X~Binomial(15,0.25)` 时，左侧约为 `1.3143090084`，右侧为 `1.75`。这证明尾段余数不能由平均资源代替；数字不是实际职业循环结论。

固定窗口至少定义：开始资源和冷却、资源上限、同刻事件顺序、何时消耗、消耗技是否可插入、窗口端点是否包含、结束余数是否折现。结束资源按未打出的伤害计入，会改变目标，应明确命名为另一种估值。

若用有限状态递推精确计算上述假设内的期望，需要保留资源、冷却和时间状态。得到的 CRT 依赖可能不再只是 `N/K/cN` 的线性组合；不能把长期平均模型的因子推导直接当作证明。所谓“精确”也只针对已定义的转移规则和概率。

## 5. 何时可拆成独立 GCD 因子与 CRT 因子

要沿用独立的 GCD 系数与 CRT 因子，需存在正数 `a_g` 与共同函数 `F(t)`，使支持域上：

\[
\bar F_g(t)=a_gF(t),\qquad
\bar F_g(t)=F_g(c(t),k(t))/T_g.
\]

频率口径直接用其 `F_g` 定义 `\bar F_g`。`T_g` 是行常数，因此可进入 `a_g`，但在最终比较时不能丢失。

**容易检验的充分条件**：归一化系数行 `(α_g/T_g,β_g/T_g,γ_g/T_g)` 成比例，且所得因子在支持域为正。此时所有 CRT 值上都能提取同一函数。

**不能无条件把该条件写成必要条件。** 若 `N(t)`、`K(t)`、`c(t)N(t)` 在指定 CRT 域上线性相关，不同比例的系数也可能给出相同比例的函数。CRT 概率与倍率本来来自同一属性，不能把 `c` 与 `k` 当任意独立变量来断言线性无关。

例如只支持一个 CRT 档位时，各档的正函数值天然可分离，系数行仍可完全不成比例。这是有限域上的事实，不是扩大支持域的依据。

若以 `B` 为三个基函数在 CRT 档位上的取值矩阵、`A` 为系数行矩阵，则函数表为 `M=AB`。当 `B` 行满秩时，`rank(M)=rank(A)`，此时函数可分离才迫使系数行成比例；缺少满秩前提时该推论不成立。

对声明支持的有限笛卡尔域 `G×C`，更直接的精确判据是：

\[
M_{g,t}=\bar F_g(t)>0,\qquad rank(M)=1.
\]

等价地，任取参考 `(g_0,t_0)`，均满足：

\[
M_{g,t}M_{g_0,t_0}=M_{g,t_0}M_{g_0,t}.
\]

用有理数交叉相乘检查，不能依赖浮点近似 rank、抽样误差或拟合相关系数。CRT 表只可合并完整函数值相同的连续区间；旧普通暴击因子相同不足以保证新函数相同。

已有合成例把普通 `N` 行缩放为 `[1020000,1195000]`、保证暴击 `K` 行缩放为 `[1400000,1650000]`，两行两列的行列式为 `10000000000`，因此不可分离；改成第二行为 `2N`，行列式为零。它验证有限表判据，不是实际 GCD 循环占比。

如果不同 GCD 的真正可行 CRT 集合不同，完整矩形表上的 rank 1 是更强的充分条件；它不自动成为这个不完整可行关系上的必要条件。首版可坚持验证声明的完整支持表以简化契约，但不得将表外推到未经验证的新 CRT 范围。

## 6. 不可分离时仍可能是正乘积模型

`rank(M)>1` 只否定独立的 `a_g×F(t)`；它不否定把 `M_{g,t}` 当作一个正的 GCD×CRT 联合因子：

\[
S(x)=Base(x)H_D(x)M_{g(x),t(x)}.
\]

因此多 GCD 系数不必立即升级为任意伤害分项和后端。联合因子保留 CRT 与速度选择的相关性，单模型必须绑定两轴；另一条路线是固定 GCD 后逐档求解。两条路线的可行域与证明见[单职业精确搜索](03-单职业精确搜索.md)。

每档都可把有理 `\bar F_g(t)` 乘某个正整数 `D_g` 变成整数。但 `D_g` 只是编码尺度：若 `C_g=D_g\bar F_g`，跨档实际比较的是 `Base×H_D×C_g/D_g`，不能直接比较整数乘积。

单模型宜使用覆盖全部允许 `(g,t)` 的共同分母 `D`，令 `C_{g,t}=D M_{g,t}`；只要所有因子值满足数值边界，就可在全域约去同一个 `D`。分母必须包含时间归一化、概率、倍率及有理系数，不能只统一动作威力。

若为减小数值分别除以每行 gcd，消去的行尺度随 `g` 改变，必须作为选择相关倍率恢复。只有对当前整个优化域都相同的正倍率才能从排序中消去；“固定 g 时是常数”不等于“跨 g 时是常数”。

最小反例是两档总量为 `400/300`、时长为 `5/3 s`：总量第一档更大，真实平均值却是 `80<100`。不能把不同循环长度的威力直接当跨档分数。

## 7. 更广机制改变什么

| 新增机制 | 必须重查的依赖 |
| --- | --- |
| 必直、必暴必直及其属性补偿 | CRT×DHT、DET 等联合依赖与取整 |
| 不吃暴击/直击的独立伤害 | 不能再把同一个暴直期望提出整个和式 |
| DoT、自动攻击 | `ssDamage`、武器间隔、快照、频率及独立基础公式 |
| 技能级取整、不同基础缩放 | 威力与武器/主属性/其他属性的耦合 |
| 增益窗口和资源反馈 | 事件与属性概率的相关性、可重复状态、有限窗口 |

同显示 GCD 的两个速度值，`ssDamage` 仍可能不同。已有实验中技速贡献 `42→43` 保持 `1.99 s`，却使该倍率 `1.001→1.002`；引入相关伤害后不能仅按显示 GCD 缓存或签名合并。

可以继续提取确实共有的正因子，将剩余依赖保留为最小联合块；无法证明可乘积分解时才转向一般分项和建模。能力边界与安全上界见[通用建模与耗时优化](05-通用建模与耗时优化.md)，不得用经验权重代替缺失证明。

## 8. 本章需要的验证

1. 对有理数输入验证显式分项和与 `N/K/cN` 展开完全一致，分别覆盖总分、循环平均和频率口径。
2. 检查初始/尾段反例，保证长期平均 profile 不冒充有限窗口精确动作次数。
3. 对支持 CRT 全表检查 rank 1；提供成比例、非比例、基函数退化及扩域后失效的样例。
4. 构造不同 `T_g`、`D_g` 的跨档反转，保证归一化与行尺度被保留；已是频率的模型不得再除 GCD。
5. 对两个互斥 GCD 验证只使用实际档系数；对同 GCD 异 `ssDamage` 验证原始依赖没有被合并。

本次[有限域实验结果](multigcd-feasibility-results.json)还覆盖三个 GCD（194/196/200）各五个 CRT 合成属性向量：显式分项评分与 BigInt 有理数一致，全域 15 点枚举与按档取最优得到同一赢家。该实验复用正式 GCD/伤害公式，但没有真实完整配装、真实循环或新 MIP 后端，不能视为路线 A/B 的集成验证。

上述测试清单仍是实施门槛，已有实验仅覆盖其中部分反例。生产验收、支持域和结果命名统一见[实施与验收](06-实施与验收.md)，联合目标的职业归一化见[多职业联合搜索](04-多职业联合搜索.md)。
