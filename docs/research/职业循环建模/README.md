# 职业循环建模：特殊收益、多 GCD 与精确搜索

状态：研究提案与隔离验证，尚未接入生产。更新日期：2026-10-24。本专题由原《职业特殊收益模型改造方案》扩展而来，分析数学、数据、单职业、多职业和性能的共同约束，并给出可复现探索与分阶段验收方案。

## 1. 核心结论

**可行，也值得做。建议采用内置职业循环预设，按装备实际 GCD 选择系数，让用户继续只配置配装条件，无须先编排循环。** 首个模型从武僧的普通伤害、保证暴击和暴击触发斗气开始；支持范围与数据依据须先落实。

多个 GCD 可以由同一个目标契约支持，但不是把各档系数相加。装备只能使用其实际档位的系数，并按共同时间单位比较。不同档位的普通伤害、必暴和斗气占比一般不成比例，不能默认压成一个 GCD 倍率乘一个公共暴击因子。

推荐先实现**固定 GCD 的正确新目标，再完整分档求解并比较**。GCD×CRT 联合因子块作为后续后端候选，与分档方案在同一目标下比较耗时；它不应成为多 GCD 功能的前置条件。

这套方案可以与通用建模和耗时优化共存：复用合法候选、属性约束、求解器和任务调度，按实际依赖重建目标、签名和安全界。优化必须证明仍覆盖同一候选域及新目标；不能只替换显示公式，也不能把旧目标前 K 名重排当作全域最优。

真实候选验证已推进到正式 Exact-MIP 的隔离接入：五个场景、三档合成系数、40 次完整计时运行的各档与全域精确分数一致，两个同步域另有完整独立穷举。性能有正有负：宽域候选证书使 `on` 从 20.56 秒降到 14.22 秒，但基础 `off` 约 12.24 秒；应分别判断兼容性与自动启用价值，不能默认堆叠所有优化。

## 3. 必须一起处理的边界

| 问题 | 本方案要求 |
| --- | --- |
| 评分与实际战斗 | 区分公式正确、模型代表性与搜索完整；最优性只针对声明的模型和候选域 |
| 多 GCD 的尺度 | 循环时长、公共分母及分支缩放必须恢复；频率模型不再重复除 GCD |
| 模型覆盖 | 不支持、已证不可行、未完成分别处理；不能静默丢弃可能可行的档位 |
| 最高坚韧模式 | 先在原始允许域确定全局最高值，再作为各档共同约束 |
| 联合搜索基线 | 每职业采用全部允许 GCD 的独立最优；不能按当前档位或共享限制重新归一化 |
| 资源与剪枝 | 同一物理属性只计一次成本；所有上界须覆盖新目标及当前条件域 |
| 数值与证明 | 精确分式、充分签名、量化误差及安全整数边界一致；BigInt 不能修复前序 Number 失真 |
| 性能结论 | 分开测模型成本、同目标优化收益与后端差异；结构计数不是实测提速 |

## 4. 当前实现与证据

现有目标是通用每威力期望伤害，DPS 再除以 GCD；已有职业基础公式，但尚未逐技能处理必暴、必直和暴击触发额外动作。扩展需保持 [rules.ts](../../../src/domain/rules.ts) 的显示、[equipped-effects.ts](../../../src/domain/search/equipped-effects.ts) 的搜索求值与整数目标一致，并覆盖联合搜索消费者。

已有四组数学实验及一组真实候选搜索实验：

- [职业收益实验](../../../scripts/experiments/job-objective-feasibility.mjs)：验证排序反转、仅改回调仍优化旧目标、旧签名不充分和有限时间资源余数；[结果](../job-objective-feasibility-results.json)。
- [多 GCD 实验](../../../scripts/experiments/multigcd-objective-feasibility.mjs)：15 点有限域枚举验证分档并集，另验证不可分离、丢失时间分母与错误联合基线的反例；[结果](multigcd-feasibility-results.json)。
- [数学迁移实验](../../../scripts/experiments/job-model-math-transfer.mjs)：三次曲率端点证书、MNK 双峰反例、共同多 GCD 弦线、余数消元及候选支持界；[结果](job-model-math-transfer-results.json)。
- [联合证书实验](../../../scripts/experiments/job-model-joint-certificates.mjs)：全域基线、乘积损失区域、等价商失效及唯一配对支持；[结果](job-model-joint-certificates-results.json)。
- [真实候选搜索实验](../../../scripts/experiments/real-job-model)：新整数目标的进程内适配、独立穷举、资源约束和候选证书 ABBA；[结果与验证](real-candidate-results/verification.json)。

这些证据支持改造的必要性、数学路线及窄模型在真实候选上的搜索兼容性，**不表示生产职业模型、真实循环收益或全场景性能已经验收**。动作权重为合成测试值；当前 bin、MCP 与国际服资料尚未统一版本，不能直接发布为职业默认系数。

## 5. 决策与实施边界

建议采用内置预设、统一目标描述和首版完整分档路线；GCD×CRT 联合块、有限状态资源模型及更多职业机制按证据逐项增加。下一步是同版本资料与固定配装评分验证，再将目标接入正式精确搜索。

计分名称、默认场景、等级/同步支持范围、不支持时的产品行为及未来 UI 内容仍是待确认的实施设计。本次交付仅修改研究文档与隔离实验，没有改变生产功能、生成游戏数据或既有最优性承诺。
