# 字体规范

本规范为配装条件、装备表格、结果数值和说明内容定义通用字号与字重，仅涉及 `font-size` 和 `font-weight`。

M3 数值的唯一来源为 [Material 3 Type scale & tokens](https://m3.material.io/styles/typography/type-scale-tokens)，核对日期为 2026-10-28。该页提供 15 个基础样式（Baseline）及对应的 15 个强调样式（Emphasized）。下表保留页面的字号、字重，并补充本项目计算的 `rem` 值；后文的界面用途是本项目的选用约定。

## 字号与字重标尺

字号列保留该页 token 面板显示的 `pt` 单位。对应 `rem` 列以 16px 的根字号为基准，按 CSS 单位关系 `1pt = (96 ÷ 72)px` 换算：`rem 数值 = pt 数值 × 96 ÷ 72 ÷ 16 = pt 数值 ÷ 12`。结果四舍五入至最多三位小数，省略末尾的零；超过三位小数的结果按近似值使用。

同页「Font size units」给出的公式是 `SP_SIZE / 16 = rem`，其输入为 `sp`。本规范的对应 `rem` 值由上述 CSS 单位换算计算，属于项目计算值，不作为 M3 页面直接提供的 Web token。例如，14pt 对应约 1.167rem；这里没有将 14pt 当作 14px。

基础与强调样式使用相同字号，分别采用对应字重。字重数值直接用于 `font-weight`，其中 400 为常规、500 为中等、700 为粗体。

| M3 样式标识 | 字号 | 对应 rem（根字号 16px） | 基础字重 | 强调字重 |
| --- | --- | --- | --- | --- |
| `display-large` | 57pt | 4.75rem | 400 | 500 |
| `display-medium` | 45pt | 3.75rem | 400 | 500 |
| `display-small` | 36pt | 3rem | 400 | 500 |
| `headline-large` | 32pt | 2.667rem | 400 | 500 |
| `headline-medium` | 28pt | 2.333rem | 400 | 500 |
| `headline-small` | 24pt | 2rem | 400 | 500 |
| `title-large` | 22pt | 1.833rem | 400 | 500 |
| `title-medium` | 16pt | 1.333rem | 500 | 700 |
| `title-small` | 14pt | 1.167rem | 500 | 700 |
| `body-large` | 16pt | 1.333rem | 400 | 500 |
| `body-medium` | 14pt | 1.167rem | 400 | 500 |
| `body-small` | 12pt | 1rem | 400 | 500 |
| `label-large` | 14pt | 1.167rem | 500 | 700 |
| `label-medium` | 12pt | 1rem | 500 | 700 |
| `label-small` | 11pt | 0.917rem | 500 | 700 |

M3 属性 token 的名称为 `md.sys.typescale.<样式标识>.size` 与 `.weight`；强调样式为 `md.sys.typescale.emphasized.<样式标识>.size` 与 `.weight`。例如，`body-medium` 的基础组合是 14pt / 400，强调组合是 14pt / 500。

`label-large` 与 `label-medium` 另有值为 700 的基础属性 `weight.prominent`；本项目在相应用途统一选用强调样式，不再增加一套同值角色。

## 项目选用

文字角色按用途与信息密度选择。工作台中的表格、表单和并排指标优先使用紧凑档位，阅读正文、页面标题和独立统计分别选用对应角色。`large`、`medium`、`small` 表示同一角色内的字号级别，不对应设备断点。以下用途分配为本项目约定，不作为 M3 对具体组件的要求。

### 默认用途

表中 `emphasized.<样式标识>` 表示对应的 M3 强调样式。

| 文字用途 | 默认样式 | 字号 | 对应 rem（根字号 16px） | 默认字重 |
| --- | --- | --- | --- | --- |
| 页面主标题、全屏错误标题 | `headline-small` | 24pt | 2rem | 400 |
| 普通弹框标题、独立工具卡片标题 | `title-medium` | 16pt | 1.333rem | 500 |
| 条件分组、侧栏小节、常见问题的问题 | `title-small` | 14pt | 1.167rem | 500 |
| 搜索阶段与当前状态标题 | `title-small` | 14pt | 1.167rem | 500 |
| 密集表头、表单字段标签 | `label-medium` | 12pt | 1rem | 500 |
| 密集输入内容、下拉选项 | `body-small` | 12pt | 1rem | 400 |
| 表格正文（装备名称、部位、来源、品级与属性）、条件摘要、次要说明、数据版本 | `body-small` | 12pt | 1rem | 400 |
| 并排结果指标的标签 | `body-small` | 12pt | 1rem | 400 |
| 并排结果指标的数值 | `emphasized.body-small` | 12pt | 1rem | 500 |
| 方案差值、数值单位、方案名称 | `body-small` | 12pt | 1rem | 400 |
| 独立展示的搜索计时、候选数量 | `title-medium` | 16pt | 1.333rem | 500 |
| 通用阅读正文、说明段落 | `body-medium` | 14pt | 1.167rem | 400 |
| 主要操作按钮、主导航 | `label-large` | 14pt | 1.167rem | 500 |
| 紧凑按钮、Tab、魔晶石标签、简短状态标签 | `label-medium` | 12pt | 1rem | 500 |

并排指标与多方案对比使用上表中的紧凑指标角色。独立统计角色仅用于单独展示的计时或数量，不推广到所有结果数值；单位、差值和方案名称继续使用辅助文字角色。

### 按需选用

完整标尺中的其他角色按实际用途选择，不要求全部出现在现有页面中。

| 样式 | 使用条件 |
| --- | --- |
| `title-large` | 空间充足的大型弹框标题或内容分节标题；普通弹框仍使用 `title-medium` |
| `body-large` | 需要突出的短导语；不作为关于、常见问题、实验室页面的普遍正文 |
| `label-small` | 非关键的极短徽标文字；普通说明、操作文字、关键指标及其单位和差值不使用此角色 |
| `headline-medium`、`headline-large` | 当前工作台不默认使用；未来有明确需求的宽松独立展示区域可按需选择 |
| `display-small`、`display-medium`、`display-large` | 当前没有默认用途，保留为完整标尺参考；新增独立大字展示需求时再选择 |

未设默认用途表示当前缺少对应场景，不表示该角色永远用不到。

### 强调字重

- 除选用表明确指定强调样式外，默认使用基础字重；正文中的关键结论使用同角色的强调字重。
- 主要动作文字、选中的 Tab 或选项需要通过字重区分时，使用该文字默认角色对应的强调样式，字号保持不变。
- 表格默认采用常规数据字重，仅对明确需要关注的属性或结果局部强调；同一列的同类数值使用相同字号。
- 通用样式使用表中的 400、500、700 三档字重，不自行增加其他档位。
