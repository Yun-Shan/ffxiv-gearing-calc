# 自动配装数学探索：持续进展

更新：2026-10-23 15:07 UTC。研究基线358a639。没有修改远端仓库或磁盘生产算法；性能试验通过明确标注的内存插桩完成。

## 当前最值得保留的路线与最新对照

1. **普通完整目标上界＋自适应区域证书**：所有乘区一起进入证明，不只比较三副属性。先尝试整片排除，必要才细分到精确整数档。曲率条件可自动核验，适用范围宽，失败时回退。
2. **建模前的单职业候选压缩**：在真实初始可行解下安全删除，再生成更小的模型。在宽域VPR/MCH联合流程里，基线阶段这一接法较快。
3. **职业目标相关特征等价商**：逐项验等后，把重复职业特征合并为带重数决策。三职业压力实例196.69/199.79秒，对照已优化流程411.70秒。
4. **唯一戒指双槽支持**：通用精确定理和压缩工具成立，但当前增强接入出现负性能，暂不优先启用。

### 新增通用定理：唯一物品的两个槽位无需枚举全部配对

任意线性支持价格下，分别选两槽最高分；若冲突，只需比较“固定左最优，右选相容最优”和对称方案。线性扫描两个池即可得到精确支持值。用该支持查询输出二维合法配对上凸包，复杂度与输出顶点数有关，不必先展开完整配对表。

1800个随机有限域、103382个配对与36000个支持查询全部通过。5个真实候选域，每个投影的上凸包也与完整配对枚举精确一致：2209–26896个原始配对可用2–7个上凸包顶点描述。**这只是辅助上界的压缩，不是把真实配装候选限制成2–7个配对。** 同一投影点若有任何合法实现，图上均归为合法，避免用非法配对的重叠点误导。

### 为什么高维可以这样画

不是用PCA或分档颜色猜最优点。当前采用两种有证明意义的投影：
- 每职业的完整归一化目标压成一个损失坐标，用乘积证书约束损失区域。
- 全部乘区的安全AM-GM上界压成“CRT＋一个线性支持分数”，支持函数覆盖该投影对应的所有原始高维选择。

图帮助发现结构，最后排除区域依靠有理数不等式、精确取整、物理身份约束与完整搜索对照。更紧的界不等于更快的MILP，这是本轮多次负结果共同说明的限制。

## 最新进展：可复用的两类压缩

### 多职业：目标相关特征等价商

在固定共享装备后，若多个职业有完全相同的私有可达特征和完整归一化评价函数，则存在它们选择相同特征的最优代表。多个职业可合并为一个带重数的特征决策，仍为每个职业还原自己的物理武器。不能只凭职业同类或最优分数相近合并。

三职业 BLM2.45 + RDM2.48 + SMN2.48、770–780、共享全部非武器槽和食物：RDM/SMN 的71种私有相关特征完全相同，差异DLY不被当前目标及约束读取。逐项检查后，完整耗时由“种子＋窄区”的411.70秒降至196.69秒，复跑199.79秒；三次精确最优值均为2033912632751/678063260368。没有与原始未优化三职业流程比较，不声称普遍倍数。

这类相等在本次770–780域有四对职业，在735–780域仍有两对治疗职业，80级同步530有一对；70级同步320与90级同步660本次域未发现。必须按本次候选集合验等，不能永久按职业名缓存。证明及完整前提见 equivalent-job-quotient。

### 单职业：自适应区域证书代替逐属性档扫描

先用全域线性必要条件排除大片区域，失败才二分CRT档位；到单档使用精确整数因子的支持上界。没有经验分区数。四场景删掉的候选集合逐项等于原完整扫描，但查询从120076/244105/214360/32479降至2001/2753/7341/8605。查询次数不是总耗时倍数。

- BLM 770–780：4.38→4.25。
- BLM 735–780：10.62→6.71。
- WAR 770–780：7.00→6.64。

这些仍是少轮实验，云机器耗时有波动。更少候选不保证更快，之前黑魔窄域弦线版的负收益仍保留。

弦线所需曲率范围已量化，不只适用于这一组装备。普通职业、至少4个AM-GM乘区时，100级CRT贡献≤8046即可满足统一充分条件；其它等级由相同公式计算。超界时回退到不依赖此条件的完整支持界，不使用经验剪枝系数。

### “顶点必最优”的精确反例

100级仓库整数公式，C+D+H=2000、三者非负。三个顶点中最好的因子乘积是4488000000000；非顶点(C,D,H)=(0,1200,800)为4495629600000，严格高0.17%。这是属性松弛域的反例，不是实际可穿戴配装，也未声称该非顶点就是全域最优。它足以否定该域必有顶点最优解，说明分档颜色确实可能掩盖关键差异。

## 新增单职业进展：完整乘积的线性必要条件

不能只把 CRT/GCD 二因子压缩后乘其它因子的独立最大值：真实719候选场景这样仍然删不掉任何候选。用正因子AM-GM把其它乘区化成同一件装备上的线性加权和，保留装备内属性关联后，改用搜索开始就有的可行解也可删143/719。

进一步证明：在可自动核验的宽曲率范围内，达到当前可行值所需的加权和阈值是CRT的凹函数。端点弦线给出安全线性必要条件，不必扫描CRT档位。注意切线方向相反，不能用于同样的剪枝。28个现实候选域×4/5/6个乘区的84个曲率检查全部通过，另有5个完整CRT整数域12,623点的精确有理数核验。这些检查不是一般证明的替代，证明见新目录README第6节。

弦线反复收紧到不动点后：黑魔770–780从674剩189，黑魔735–780从1237剩195，战士770–780从1972剩672，白魔同步320从1088剩953。单轮证书构建含准备约0.09–0.17秒，独立进程启动和初始解成本在完整计时里另计。

## 最新优先级：强种子＋可证明的稀疏损失区域

任何可能追平或改进当前值的方案，其职业损失两两乘积受一个严格的有理上界限制。因此最多一个职业能显著偏离独立最优，剩余区域是J个窄区域的并，不需要枚举各因子档位的笛卡尔积。本案例的sqrt版本给出非例外职业比例至少99.9996259107%，但不能擅自固定成精确100%。详见 product-proxy-localization 第9节。

已包含独立基线、强种子与最终复核的冷启动：仅强种子229.05秒；加sqrt窄区180.35秒，复跑196.41秒；更紧窄区207.07秒。精确最优值全部相同。原流程对照600秒未完成，是右截断数据，不报告确定加速倍数。

共享速度的紧凑表达在求解本体中约197.17秒，且约0.6秒生成成本需另计，没有显示可靠增量收益，暂时降优先级。

这些仍是少量研究运行，尚未完成多场景、跨职业的正式验收。ECharts新增归一化损失区域、端点放大及完整耗时比较；Python图仅用于内部检查。

## 最值得继续的方向

### 1. 乘积代理最优解 → 真实联合目标的极窄区间

对J个归一化比例r_j∈(0,1]，真实和S≤J−1+∏r_j。若量化对数代理已求得全域最优，舍入误差为m/L，则可用完全有理的上界 U=min(J,J−1+P_seed·L/(L−m))。种子总损失为δ时，剩余目标差至多为损失平方量级加量化项；若J−1个职业达到独立最优，只剩量化项。

BLM2.45/RDM2.48、770–780、无同步、共享全部非武器装备与食物、排除自定义武器的压力场景：
- 乘积种子给出BLM比例约0.9995912647547818、RDM比例精确1。
- 全局剩余目标上界差约1.39943×10⁻¹¹。小差距不等于精确证明。
- 后续原流程完整复核通过，精确目标为1355849372383/678063260368。
- proof.complete=true，但formalCertificate=false，保留原HiGHS信任前提。
- 复用种子的收尾运行约114秒，不是冷启动耗时；取得种子的成本不可隐藏。首轮相同输入对照已完成：原流程600秒内未完成，乘积种子完整冷启动约229秒通过。

VPR/MCH 同步735共享饰品+DPS的补充对照，两边都完整通过且精确目标8673/4337相同。约80.94/80.63秒的差异视为噪声：原流程已有初始方案，新种子逻辑未触发。

### 2. 完整乘积排序仿射上界 + 真实装备支持函数

乘积可由一个固定规模的排序仿射上界族覆盖。把每件装备的属性关联保留在支持计算中，再以单一CRT资源构造精确连续松弛支持曲线，不枚举所有属性档位笛卡尔积。

用正式单职业最优基线衡量区域证书，CRT切片：
- BLM770–780：224→125。
- BLM735–780：234→138。
- WAR770–780：163→78。
- WHM同步320：224→147。

这些是属性切片，不是装备组合数；使用强基线也不等于搜索开始就能达到这些收缩。尚无整套搜索提速结论。进一步条件化因子box仅多删1–2片，成本更高，当前优先级降低。

### 3. 多职业共享速度投影与有理弱对偶证书

共享速度可以压成一个标量，食物的单调取整用区间逆像处理，私有速度选择变成区间交集。原案例有2109个可达共享速度状态，最终每食物保留4或10个，但简单区间法也得到同样结果，不能计作新增收益。

同一个搜索中间incumbent下，共享CRT相关界保留127/182片；速度证书进一步降至121/182，构造约3.7秒。37个区域由精确支持函数证实速度不可行；浮点LP只发现乘子，最终上界以有理数重新认证，不把原始LP状态作为证明。

## 必须保留的失败证据

- 第一轮：三属性预算上界内部查询约7.26倍中位加速，不代表配装搜索提速。
- 直接增加240条乘积加强行、约25万个非零系数后，压力场景首轮联合求解未在内部保护时间内完成。
- 每职业只加一条有理对数上界，数学与19098个真实样本检查通过，但第二轮MIP也变难，未在保护时间内完成。
- 请求300秒或1200秒会被该研究分支V3内部截到235秒。已区分请求时限、实际时限与模型耗时；后续长测试使用仓库既有unlimited参数和独立外层保护，不修改生产限制。
