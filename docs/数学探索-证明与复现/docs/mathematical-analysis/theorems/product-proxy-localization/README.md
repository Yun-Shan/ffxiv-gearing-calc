# 从乘积代理的最优解到真实联合目标的极窄区间

2026-10-23。状态：下面的一般性不等式与量化误差推导已给出证明；工程收益仅有当前研究证据，不能泛化为已测得的生产提速。

## 1. 适用域

J 个职业，真实联合目标 `S(x)=Σ r_j(x)`，`0<r_j≤1`。比值分母必须是同域的正式独立最优值；不允许用样本最佳值冒充。完整伤害与 DPS 都可，所有乘区与 GCD 必须进入各自 r_j。

原问题的可行域 X 可以包含任意装备、共享身份、唯一性、食物、离散GCD或其他硬约束。以下结论不依赖特定等级、品级、职业公式或简单可行域形状，只要求求代理时使用同一完整X，且 r_j≤1 已成立。

令 `P(x)=∏r_j(x)`。设已有整数对数代理 Q：`|Q(x)−L·ln P(x)−C|≤m/2`，其中C是与x无关的常数（例如各职业基线量化值），m是所有参与取整的对数因子数量。减去GCD对数时同样计入误差。

## 2. 全称不等式与等号条件

对 `r_j∈(0,1]`：

`Σr_j≤J−1+∏r_j`。

证明从 `(1−a)(1−b)≥0` 得 `a+b≤1+ab`；把ab当作新的[0,1]数，与第三项重复，得到J项结论。正比值下等号恰在至多一个r_j严格小于1时成立。

所以如果某个**精确乘积最优解**有J−1个职业达到各自独立最优，它同时是真实联合和的最优解。这不是把两个目标一般等同；没有等号结构时二者可能不同。

## 3. 量化代理的有理数全局上界

设x₀是完整X上的Q最优解。对任意x，由Q(x)≤Q(x₀)及两端误差：

`ln P(x)≤ln P(x₀)+m/L`。

令 `ε=m/L<1`。由 `−ln(1−ε)≥ε` 得 `exp(ε)≤1/(1−ε)`，因此

`P(x)≤P(x₀)/(1−ε)`。

最终真实联合目标的全局上界为

`U=min(J, J−1+P(x₀)·L/(L−m))`。

**整个证书可用精确有理数算出，不需要浮点exp/log。** 对数只在代理误差已有认证的前提中出现。真正需要求解器证明的是Q的全域最优，而不是仅找到一个Q较高的可行点；代理求解超时不能使用本结论当作全局上界。

## 4. 为什么能将剩余目标范围压得很窄

令x₀各职业损失 `l_j=1−r_j(x₀)`，总损失 `δ=Σl_j=J−S(x₀)`。

定义 `E=J−1+P(x₀)−S(x₀)=∏(1−l_j)−1+Σl_j`。

有 `0≤E≤Σ_{i<j}l_i l_j≤(J−1)δ²/(2J)`。

证明中间上界：加第n项时，`E_n=E_{n−1}+l_n(1−∏_{i<n}(1−l_i))`；由乘积的union界 `1−∏(1−l_i)≤Σl_i` 归纳得到pair和界。最后由 `Σl_i²≥δ²/J` 推出。

因此

`0≤U−S(x₀)≤(J−1)δ²/(2J)+P(x₀)m/(L−m)`。

这是一条**二次收缩**结论，不是经验拟合。只要代理种子本身接近各职业独立最优之和，剩余真实目标区间就至多为损失平方量级。

当J−1个r_j恰好为1时E=0，只剩量化认证项：

`U−S(x₀)≤P(x₀)m/(L−m)`。

## 6. 实现路径与风险

- 首次Q目标只用于取得强种子及上界信息，之后仍以精确归一化总和筛选和最终复核。
- 当首次目标切换为Q时，必须禁止把它的对偶界误当作原比值上界变量的对偶界；源实验只在无incumbent、第一轮启用，且关闭该轮ratio-upper终止判断。
- Q目标使用原实现的固定缩放，保留数值精度前提；HiGHS Optimal仍不是独立形式化证书。
- 后续可把Q最优值作为已知上界保留、或把U用于原真实比值上界变量；整数上界变量的逐职业ceil误差必须计入，不能把U直接向下舍入后误剪。
- 原流程可能已有很强的可行种子或直接达到J；这种场景不应额外支付一次Q优化。应比较相同输入下完整总耗时，覆盖成功与失败，不只统计首次可行值。
- 若Q优化本身很难、损失分散或δ较大，上述上界仍安全但未必值得。没有保证对所有实例都明显提速。

## 7. 额外可消去的维度：每职业固定GCD

若每个职业j在自身候选域和独立基线中都固定同一个正GCD `g_j`，即使不同职业的g_j不同，也有

`(D_j/g_j)/(OPT_damage,j/g_j)=D_j/OPT_damage,j`。

因此同一候选与约束下，damage与DPS的**归一化联合目标完全相同**，其最优解集合相同。该条件下GCD维度在数学目标里可完全消去，不必为两种目标重复证明；生产实现仍应做自身回归，不能把数学等价冒充已运行两套代码。若某职业允许多个GCD，则不能消去。

当前BLM2.45/RDM2.48场景满足这一条件。VPR/MCH的公开验收场景没有固定GCD，不能套用此简化。

## 9. 稀疏损失区域：高维比例域压成J个细管的并

这一节不把任何职业强行固定为独立最优。设已认证乘积上界为 `P_U`，已知真实可行和为 `S₀`，定义

`η=J−1+P_U−S₀`，`l_j=1−r_j`。

只需保留 `S≥S₀` 的解（包括同分）。对这些解，

`E=∏(1−l_j)−1+Σl_j=J−1+P−S≤η`。

### 9.1 任意两项损失的乘积都小

`E≥l_i l_j` 对任何i≠j成立。证明：把i,j排在最前，此时E₂=l_i l_j；每增加一项，`E_n−E_{n−1}=l_n(1−∏_{k<n}(1−l_k))≥0`。

所以任何两项损失都满足 `l_i l_j≤η`。取 `h≥sqrt(η)`，最多一个职业损失大于h。整个可能改善区域因此包含在J个细管的并中：

`存在 k，使所有 j≠k 都满足 r_j≥1−h`。

这是按职业数J增长的有限并，不是遍历每个因子档位的笛卡尔积。压缩的是归一化目标空间；它不声称所有装备整数变量已经消失。

### 9.2 用总损失下界进一步收紧管宽

若 `P_U<1`，真实和上界还给出总损失 `Σl_j≥d_min=1−P_U>0`。最大损失至少d_min/J，故第二大损失不超过

`h₁=Jη/d_min`。

可取 `min(sqrt(η),h₁)` 的有理上舍入。还可以严格收紧：若已知第二大损失 `y≤h` 且 `h<d_min/(2(J−1))`，则最大损失至少 `d_min−(J−1)y`，从而

`y(d_min−(J−1)y)≤η`。

左边在[0,h]单调增加，因此y不超过该二次式小根。实现不使用浮点根：在缩放整数上二分，交叉相乘判断，并向上取整。前提不满足时保留前一条安全界。

### 9.3 安全MILP编码

取有理 `h=H/T<1`。若r_j≥1−h，由 `ln(1−h)≥−h/(1−h)` 和原量化误差，必要条件为

`Q_j−Q_base,j ≥ −ceil(LH/(T−H))−m_j`。

每职业一个exception二元变量z_j，Σz_j=1。用该职业因子one-hot域的精确最低Q值构造M_j，添加

`Q_j−Q_base,j ≥ −loss−m_j−M_j z_j`。

这保留了上述J个细管的并，最多只增加J个二元变量、J+1行；M来自实际Q范围，不是经验大常数。量化行只是必要条件，保留额外可能点是允许的。最终目标与最优性复核不变。

不得把“接近独立最优”改成“等于独立最优”。只有另行证明单职业次优间隔大于h时，才可作这样的离散化；本轮没有使用此假设。
