# 唯一物品约束的双槽支持：不枚举完整戒指笛卡尔积

状态：一般支持预言机与上凸包构造命题已证明；1800个有限域及5个真实候选域的全部投影核验通过，完整搜索保持精确最优值；但当前更强界的性能变体存在明显负收益。此处处理的是完整目标上界里的线性支持子问题，不是把真实伤害目标改成线性目标。

## 定义

两个槽位候选集 A、B。每个候选有整数资源 x（例如 CRT 贡献）、有理线性分数 y（实现统一分母后为 BigInt），以及物品 ID 和 unique 标志。只禁止“两个候选 ID 相同且二者 unique 均为真”的组合；非 unique 物品允许同 ID 的不同镶嵌甚至相同属性组合。

对任意有理价格 λ，定义候选分数 s=y−λx。希望最大化合法组合 s(a)+s(b)。这里必须按物品 ID 判断唯一冲突，不能用包含镶嵌的完整身份代替，否则会把同一唯一戒指的不同镶嵌误当成不同可共存物品。

## 线性时间预言机定理

先各自取最高分 a*、b*。

- 若两者相容，二者之和就是全局最大值。
- 若冲突，则比较两种方案：a*配“与a*相容的B中最高分”；b*配“与b*相容的A中最高分”。存在的方案中取较高者；两种均不存在则没有合法组合。

证明：若最优组合(a,b)中的a与b*相容，则 s(a)+s(b)≤max_{a相容b*}s(a)+s(b*)。否则a必须与b*同唯一ID，合法的b必与a*相容，于是另一种上界覆盖它。两种候选本身都合法，故上界可达到。对每个池扫描至多两次，复杂度O(|A|+|B|)，不需要|A|·|B|枚举。负分数、重复属性、非对称槽位域均允许。

## 输出敏感的二维上凸包

合法组合投影为 (x(a)+x(b),y(a)+y(b))。用上面的预言机可构造它们的精确上凸包：

1. 用精确大价格±M求最小/最大资源端点，同资源时取最高分。M取“两个池分数范围之和+1”；由于资源整数且差至少1，严格保证优先比较资源，不是经验大M。
2. 对已知端点连线，取其有理斜率λ，询问预言机是否存在严格高于该线的合法点。
3. 没有则该线段已被全域支持证明；有则新点是暴露的上凸包点，分割两段继续。

使用精确有理/整数比较，不用角度浮点误差。已知端点是上凸包暴露点时，严格高于连线的支撑点必在二者资源区间内部；每个新增点使区间严格分割，有限域保证终止。若最终有h个输出顶点，调用次数为O(h)，总支持计算为O(h(|A|+|B|))。不声称h在所有人工构造下都很小，也不声称最坏情况必为线性。

## 接入配装上界

把这个合法双槽凸包作为一个组，与其它槽位的(CRT,完整乘区线性分数)凹包合并。它保留了“唯一戒指不能重复”的关键关联，替代把两个戒指槽各自独立取最好的放松。合法组合集合是独立笛卡尔积的子集，因此支持上界只会更紧，不会变得不安全。

固定非戒指候选做删点时，可复用该双槽凸包。固定某个戒指候选时，另一个戒指池剔除与它冲突的唯一ID，再计算支持；相同唯一ID的多个镶嵌可复用同一个条件支持曲线。

其它约束可以继续放松，例如戒指规范排序、其它职业的共享兼容性、速度下限。放松只会使界变松。若目标是最终合法配装，仍必须交给原精确模型复核；凸包内的分数插值不代表真实装备存在。

## 适用范围与风险

- 任意可写为上述“同唯一ID冲突”的双槽选择，和任意线性投影分数，不依赖特定等级、品级或属性系数。
- 一般不相容图不满足本定理，不能擅自只取两种替代方案。
- 识别不到两个独立戒指槽、或属性仍需动态分配时，可回退原独立槽位上界。
- 只保证辅助支持精确和完整目标上界安全，不保证更紧界一定改善整个MILP耗时。

## 验证与性能记录

随机1800域共103382个原始配对、36000个价格查询，与完整枚举的支持值和上凸包完全一致，含无合法配对、重复ID及非对称槽位域。5个真实域的每条实际投影也与完整配对枚举精确一致：每域2209–26896个配对，对应上凸包2–7个顶点，支撑调用3–13次。完整枚举仅用于核验，不在研究搜索实现中使用。

完整VPR+MCH同步735宽域：普通两阶段证书111.50/108.62秒；两阶段都增强为唯一戒指界、以补禁用约束方式接入时265.91秒。精确目标一致，数学界更紧但明显变慢。另一个变体在基线建模前过滤候选，联合阶段仍保持普通界：普通基线界86.78秒、唯一戒指基线界98.11秒。后一对才是该表示下可比的戒指增强测试，不能把265.91→98.11全归因于模型重建，因为联合阶段用界也不同。

当前保留该定理和精确支持工具，但不推荐默认启用这层增强。真正可接受的收益仍需更多场景和重复运行；不按“删得更多”判优。
