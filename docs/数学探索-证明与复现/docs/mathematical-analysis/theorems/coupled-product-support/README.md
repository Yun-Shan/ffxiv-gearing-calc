# 保留装备相关性的乘积排序仿射上界与单资源精确支持函数

2026-10-23，第二轮探索。基于 `358a639`，无生产代码或远端修改。

## 核心问题

第一轮独立其它乘区最大值与三副属性预算相乘过松。这里不再把一件装备的武器、主属性、副属性优势拆散取最大，而先把**完整乘积**变成严格的仿射上界，再在每个真实候选向量上计算该上界；跨职业共享时，必须先相加各职业系数再对同一物品取最大。

这不是宣称新发明了一般不等式，也不把线性评分作为新的优化目标。仿射表达式只是目标的上界证书，最终排序与结果仍用原精确伤害。

## 定理 1：任意正乘积的排序仿射上界

设 n 个因子满足 `0<L_i≤f_i≤U_i`。令 `δ_i=U_i−L_i`，非恒定因子的 `y_i=(f_i−L_i)/δ_i∈[0,1]`。

展开乘积：

`∏ f_i = Σ_{S⊆{1..n}} [∏_{i∈S}δ_i ∏_{i∉S}L_i] ∏_{i∈S}y_i`。

所有系数非负。对非空 S，`∏_{i∈S}y_i≤min_{i∈S} y_i`。因此用 min 替代得到一个连续、分片仿射的上界。

固定任意排列 π，令 `v^k` 的前 k 个 π 坐标取上界，其余取下界，`P_k=∏ v_i^k`。定义

`A_π(f)=P_0+Σ_{k=1..n}(P_k−P_{k−1})·y_{π(k)}`。

则对**任何排列**都有 `∏f_i≤A_π(f)`。

证明：将展开中每个 S 的 `∏y_i` 替成 S 在排列中最后一个元素的 y，此 y≥min，因此也是上界。各项按最后元素收集，系数恰为 `P_k−P_{k−1}`。如果排列按实际 y 递减排序，该最后元素就是 min，上界取所有排列中的最小值。

恒定因子不引入 y，不做零除，直接保留在所有 P_k 中。所有仿射系数非负。实现使用有理数和 BigInt，不依赖对数或浮点最优性判断。

### 有限上界族，而非变量笛卡尔积

任取一个排列已经安全；多个排列取最小仍安全。n 是伤害因子数量，不随装备数或属性范围增长。在固定 CRT 档位后，非恒定因子最多为 W/M/D/T/H，最多120个排列；非坦克 TEN 恒定，常为24个。没有枚举各因子所有档位的笛卡尔积。

`min_π max_x A_π(x)` 仍可能严格大于 `max_x min_π A_π(x)`，不能把最小的支持上界当成精确非线性最优值。

## 定理 2：与完整伤害公式的安全复合

若对每个因子有 `f_i(z)≤q_i(z)`，其中 q_i 是仿射函数，则 A 的系数非负意味着

`P(z)≤A_π(f(z))≤A_π(q(z))`。

只需真实 f 在合法 box 内；q 是更乐观的替代。当前实现采用：

- W：普通职业固定等级武器性能加职业常数；BLU 查表暂不在本测量实现范围内。
- M：保留职业 ap/apTank、基础主属性、队伍增益，去掉两次 floor 得到上界；不是忽略主属性乘区。
- D/T/H：去掉向下取整，保持真实等级系数；非坦克 T 固定1000。
- C：先按真实 CRT 档位分片，因此 C 在片内是精确常数；无需假设 raw 级凸凹或近似 CRT。
- GCD：本轮测量先用 damage。推广 DPS 时需固定正 GCD 档位或另给安全分母下界，不能遗漏。

因子下界由各槽逐属性最小值和零食物增益得到，因子上界由逐属性最大值加食物 cap 得到。独立极值只用于设定合法 box；真正支持函数在完整装备向量上计算，保持同件装备的属性相关性。

## 定理 3：高维候选集上的一维精确 LP 支持

组合后得到 `A(z)=b+a·z`。令每槽合法候选向量为 V_s。固定 CRT 总贡献区间 `[L,U]`，将每个候选映成二维点 `(CRT(v),a·v)`。

1. 每槽同 CRT 只保留最大线性得分；构造点集上凹包。不要按得分删除高成本点，因为 CRT 下界可能要求它。
2. 凹包各相邻边斜率递减。所有槽从各自最小 CRT 点开始。
3. 将所有槽边按斜率递减合并。每条边表示一段可增加的 CRT 及对应线性得分增量。
4. 正斜率全部取完是无约束峰。将该峰的总 CRT 夹到 `[L,U]`，沿合并边填充资源，最后一条边可部分取。

得到的是每槽候选凸包、只有一个总 CRT 区间约束时的**精确 LP 最大值**，所以必然上界原离散装备最大值。负斜率不能删除：当下界迫使更多 CRT 时仍需使用。

证明：每槽边斜率递减确保全局排序不会破坏槽内前缀顺序；如果分配先用了更低斜率边而高斜率边尚可用，交换同量资源不降低值。反复交换即得到排序分配。边际收益由正到负，因此区间最优总成本是夹紧后的峰。预处理保留累计成本与增益，后续区间查询二分定位末段，O(log K)，不用重新枚举装备组合。

复杂度主要为每个排列扫描候选、构造和合并凹包；查询次数可很多但复用同一曲线。不存在按所有属性档位建立多维 DP 表。

### 食物与其它约束

当前食物松弛把每种食物的非 CRT 加成取独立 cap，把 CRT 加成保留 `[0,cap_C]`，以两个端点作为一个额外“槽”的线性上包络。因为 a 非负且真实加成不超 cap，安全但未必紧。若加入负系数或需要食物前 CRT 坐标，必须重新处理，不能照搬。

戒指唯一性、GCD和跨槽约束可在此支持计算中放松，得到的只是上界；不能因此声称该 LP 解可穿戴。自定义参数武器未接入本轮测量，检测到就明确报错，不静默遗漏。

## 定理 4：多职业共享必须先求和、后最大化

给每职业构造完整目标的仿射上界 `b_j+a_j·z_j`，包含真实归一化常数 `1/OPT_j`（或任何已声明的固定正权重）。对共享槽，候选身份 k 确定所有职业的贡献 `v_{jsk}`，其联合上界项为

`max_k Σ_j a_j·v_{jsk}`，

而不是 `Σ_j max_k a_j·v_{jsk}`。前者不大于后者，保留共享选择造成的冲突。私有槽按职业分开取最大；共享食物也必须按同一物理身份计算。

因此能把多职业、多属性候选评分压成每个共享身份的一个标量上界，同时保持原归一化求和目标的安全覆盖。它不意味着完整共享问题已可独立求解：跨槽唯一性等仍是松弛；使用一维资源 hull 时，必须明确该资源对各共享身份的可加定义，不能混用不同职业各自的 CRT。

任一真实联合 incumbent 高于该上界即可安全排除相应分支。同分必须按原 tie 语义保留。不可用样本归一化代替正式独立最优基线。

## 风险和停止判据

最坏排列数阶乘，但伤害因子数小且固定；候选较大时仍可能构造成本超过收益。多次求解能否复用曲线取决于 box/因子/食物/候选是否变化，不能复用过期证书。接入前应有相同输入的 shadow 校验、边界/同分/食物/共享身份回归及正式总耗时A/B。若只有切片数减少而总耗时不降，应保留为分析工具而非上线剪枝。

## 最新方向：每职业仅一条的有理对数上界

设联合目标为 `Σ r_j`，每个真实比例 `0<r_j≤1`。已有可行值 B，令 `τ=B−(J−1)`。当 `0<τ≤1` 时，任何能追平或改进B的联合解都满足 `r_j≥τ`。

取完全有理、无经验参数的系数 `a=2τ/(1+τ)`。对 `r∈[τ,1]`：

`−ln r = ∫_r^1 1/t dt ≤ (1−r)(1+r)/(2r) ≤ (1−r)(1+τ)/(2τ)`，

第一步由凸函数 `1/t` 的梯形积分上界，第二步由 r≥τ。于是

`r ≤ 1+a ln r`。

现有生产模型已经有经过取整认证的整数对数得分 Q。若每职业量化差的误差界为 m，`ln r≤(Q−Q_base+m)/L`，故

`r ≤ 1 + a·(Q−Q_base+m)/L`。

右边是该职业所有因子选择变量的一个线性表达式。**无须枚举因子档位笛卡尔积，不引入经验动态权重，不把联合目标改为对数和。** 保留现有真实归一化和的比值上界变量，只添加此变量与 Q 的严格关系；Q 的角色仍是构造安全上界。

对整数比值上界变量 `q≈R·r`，将常量与每个非负 one-hot 变量的系数分别向上取整，可保留至少 `ceil(Rr)` 的可行上界值。代码有符号 ceil 对负系数也朝正无穷，不能使用向零/向下混淆的除法。现有 `jobSurrogates.terms+offset` 恰是完整Q，baseline和groups.length误差照原实现保留。

误差上界也有简单有理式：令 `E(r)=1+a ln r−r`，其最大值在r=a。由 `ln a≤a−1` 得

`0≤E(r)≤(1−a)^2=((1−τ)/(1+τ))^2`。

因此随着真实可行值逼近J，这一上界的非量化误差**二次缩小**。量化与系数ceil误差另计，不省略。τ≤0时不启用，使用原路径；这些条件不是少数等级/品级特例，而是联合解质量条件。

注意共同τ下，仅从所有这些不等式推导一个总对数必要约束，可能与既有“乘积必要界”重复。真正待验证的增量是把每个用于优化/双界终止的比值上界变量直接绑定到精确Q，收紧模型目标，而不是再加一条已有必要约束。

研究脚本 `log-secant-experiment.mjs` 每轮仅通过内存钩子追加每职业一行，原目标、完整性复核和磁盘生产文件不变。高精度有限检查通过，但一般性安全性以上述证明为依据；实际提速仍须等待运行结果。

## 共享速度的等差段扩展表达

`shared-speed-projection.mjs` 将该场景中共享速度的可达集合及私有武器/食物的GCD兼容性投影为每种物理食物的有限集合T_f。它是一个共享资源的投影，不能替代对其它属性的优化。当前含食物效果的前像由严格单调的`g+foodBonus(g)`得到整数区间，位集构造共享资源可达性，戒指unique在成对资源集合中处理。

可把所有T_f的并按候选公差g分成若干等差段，并在每段内保持允许食物集合相同。公差候选来自真实状态差值，不硬写魔晶石数值。固定g时沿每个余数类在缺失状态或食物兼容性变化处分段；在这个**不重叠、同兼容集合分段族**中选择段数较少的公差，不宣称是所有可能重叠覆盖编码中的全局最优。

一段写成`a_r+gk`，`0≤k≤n_r`。用one-hot z_r选择段，统一整数k满足`k≤Σn_r z_r`，再令共享速度`Σa_r z_r+gk`。按实际物理食物selector限制可用段。此扩展表达与表中的(food,sharedSpeed)关系精确等价；没有删除投影允许的状态。原GCD、身份与其它约束仍保留。

当前数据自动得到公差18、三个段：0–54（步长18，全17种食物）；72–144（步长18，14种非速度食物）；单点142（相同14种食物）。只增加3个binary、1个integer和4条行。发出约束前逐食物完整核对重构集合，检查模型候选是生成投影时的候选子集及GCD/等级等输入前提，失配直接失败。

性能试验求解本体约197.17秒，另有约0.6秒投影表构造；相比sqrt窄区复跑196.41秒，没有可靠额外收益。它说明“低维表达成立”和“求解器必然更快”必须区分，当前不优先接入。
