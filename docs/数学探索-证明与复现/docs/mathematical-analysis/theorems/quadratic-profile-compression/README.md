# 二次剖面压缩：精确消元、取整安全带与完整伤害区域证书

日期：2026-10-23。基线：`codex/issue-3-math-analysis`，commit `358a639e8d827dad7973fcb81a55d451c05ff438`。只新增研究文件，没有更改生产搜索、数据或远端分支。

## 1. 结论与状态

1. **已证明：DHT–DET 定和切片的连续二次上界和精确安全带。** 适用所有当前支持等级、任意非负 baseline、预算和独立 caps；不是只适用于少数装备场景的经验规则。
2. **已证明：模周期上的精确二次消元。** 每个余数类只需至多两个整数点，不依赖该类覆盖区间的长度。多职业正有理权重和仍成立。
3. **已证明：三属性自由预算极值压成 CRT 档位剖面；由上界证书安全跳过剖面。** 不主张原目标在 raw 坐标单峰，更不主张顶点/端点就是最优。
4. **已证明：完整伤害和多职业的安全应用契约。** 只能用全目标上界和同一真实可行域的 incumbent 剪真实候选。松弛最优解不能充当真实 incumbent。
5. **已测得：39 个真实候选池派生的自由预算域中，精确内部查询从 227–297 个 CRT 切片减少到 1–8 个。** 微基准收益只属于预算上界计算，不属于正式 MILP 总耗时。
6. **重要负结果：对四个完整伤害场景，独立其它乘区上界 + 抽样可行 incumbent 没有删除任何 CRT 切片。** 因而本轮没有证明真实装备最优区已压缩。下一步必须研究联合约束的相关性，不能仅把三副属性漂亮的图形推给全目标。

已有研究关系：继承 [参考公式](../../canonical-evaluator-reference.md)、[阈值关键集](../pairwise-slice-critical-set/README.md)、[自由预算上界](../free-budget-upper-bound/README.md)。新增的是精确二次包络、安全带、模周期的解析极值和剖面证书筛选；不是重新发现原关键集或通用联合 loss-sum 不等式。

## 2. 量词、坐标与定义域

所有属性都是**贡献**，不是面板值。CRT/DHT 的面板偏移是 sub，DET 是 main。令

- `V=div>0, E=det>0, m=detTrunc>0`，取当前等级参数；
- `A0=4000+200·[BLU]`；
- `h,d,S` 为非负整数 baseline 与可分配增量，`x∈[l,u]∩Z`，且 `0≤l≤u≤S`；
- 实际贡献 `Hraw=h+x, Draw=d+S−x`；
- `H(x)=A0+floor(550(h+x)/V)`；
- `D(x)=m floor((140(d+S−x)+1000E)/(Em))`；
- `F(x)=H(x)D(x)>0`。

独立 caps 给出 `l=max(0,S−κ_D)`、`u=min(S,κ_H)`。空区间直接不可行。若输入是食物前属性，不得直接套用这里的最终贡献公式：应先建立包含食物后的安全域，或对食物 cap/取整分段。所有一般性证明使用精确整数/有理数运算。

## 3. 定理 A：二次包络与安全带

定义 `α=550/V, β=140/E, A=A0+αh, B=1000+β(d+S)`。

因为向下取整不增加值，且各因子为正，

`F(x) ≤ Q(x)=(A+αx)(B−βx)`。

`Q(x)=AB+(αB−βA)x−αβx²`，严格凹；其无约束顶点

`z=(αB−βA)/(2αβ)`。

**命题 A1。** 对任意已知 `L≤max F`，每个满足 `F(x)≥L` 的点都属于 `Q(x)≥L`。若用 `x0` 的精确值作为 L，则所有切片最优值都保留。

**证明。** `F(x)≥L` 与 `F(x)≤Q(x)` 直接推出结论。由于 Q 严格凹，其超水平集是闭区间、空集或整个当前区间。没有使用 F 的单峰性。

**命题 A2。** 在未截断顶点形式下 `Q(x)=Q(z)−αβ(x−z)²`，因此安全区间半宽为 `sqrt((Q(z)−L)/(αβ))`；端点受 caps 截断。公式只解释几何，生产判断不依赖浮点开方。

**精确实现。** 乘以正分母 `VE`，得到整数二次式：

- `a=77000`；
- `H0=A0·V+550h, D0=1000E+140(d+S)`；
- `q(x)=H0D0+(550D0−140H0)x−77000x²`。

比较 `q(x)≥LVE`，在整数峰两侧二分定位边界，保留等号。顶点两侧候选用有符号精确 floor 除法并夹到 `[l,u]`。此法避免 sqrt 误差及“看着像端点”的经验截断。

**退化与局限。** L 差、曲率小或允许区间本来很短时，安全带可能覆盖全区间。并无统一压缩比例保证。L 若只在松弛域可行，A1 只能用于计算松弛极值，不能用于真实装备剪枝。

## 4. 定理 B：周期余数类精确消元

取

`P=lcm(V/gcd(550,V), Em/gcd(140,Em))`。

固定余数代表 r，令 `x=r+kP`。P 的定义确保

`H(r+kP)=H(r)+ak`，`D(r+kP)=D(r)−bk`，

其中 `a=550P/V`、`b=140P/E` 都为正整数。证明是 `floor(y+n)=floor(y)+n`；DET 的步长 m 已计入 P，不可漏掉。

故 `F(r+kP)=H(r)D(r)+(aD(r)−bH(r))k−abk²`，严格凹二次。整数区间最大值必在夹紧到区间后的实数顶点两侧整数上，至多两点。这只对**同一余数类**成立，不宣称原阶梯序列单峰。

当前等级的 P：50→3131，60→60，70→90，80→130，90→190，100→278。50 级周期偏大；实际短切片上，已有 DET 阈值关键集常明显更省。默认应比较可证工作量，不能统一强制采用余数枚举。

### B 的多职业推广

若一个共享转移变量 x 在各职业中产生 `h_j+x,d_j+S_j−x`，其它完整伤害因子及 GCD 在此片内固定，正式联合目标写成 `Σ w_j H_j(x)D_j(x)`，其中 `w_j>0` 包含 CRT、武器、主属性、坚韧、特性、GCD 和**真正独立最优基线**等固定系数。

取各职业周期的公倍数后，每一项都是开口向下二次式；正有理权重和仍是严格凹二次式，故每个余数类仍只需两点。权重可乘公分母变成整数做精确比较。

**限制是结构性的，不是装备品级特例：** 共用转移关系、其它因子固定、食品效果已处理。不同职业若没有共同的 affine 转移，或一职业直击增加而另一职业也把信念增加等不符合反向配置，就不能套用该凹性结论。跨食物 cap、GCD、主属性/武器档位必须分片；公共周期可能膨胀，成本要计入。通用联合场景仍可用分职业安全上界的和，只是未必紧。

## 5. 定理 C：三维预算的精确一维剖面

令自由预算松弛域为 `0≤c≤κ_C,0≤h≤κ_H,0≤d≤κ_D,c+h+d≤R`。CRT 因子记 `C(c)`。

**C1，平台代表。** 固定一个 CRT 档位，取可行域内最小 c。其它 c 的 C 值相同，但可留给 H/D 的预算更少，因此该代表点的 H/D 可行域包含它们。至少一个松弛最优解位于 CRT 档位起点。

**C2，预算饱和。** 给定 c，由 H/D 非减性，存在最优点满足 `h+d=min(R−c,κ_H+κ_D)`。若尚有预算且至少一个坐标未满，可以增加该坐标，值不减；有限次后到达上述边界。

**C3，剖面上界。** 对每个 CRT 起点 c，精确内部最大值记 V(c)。用定理 A 的 Q 在合法区间上的连续最大值得 `U(c)≥V(c)`。连续顶点在区间内时最大分子为 `4a·q(0)+b²`、分母为 `4aVE`；否则取相应边界，全部有理数计算。

任取已精确求过的松弛可行点值 L。如果 `C(c)U(c)<L`，该剖面不含松弛最优点，可以不调用内部精确求解。等号保留。按上界从高到低访问只是减少后续工作，不改变完整性，不是 top-k 截断。

**实现复杂度。** 设 CRT 档位数 N，需 O(N) 上界计算与 O(N log N) 排序；只有 k 个未排除剖面做精确 H/D 计算。最坏 k=N。改为堆或不排序只能改变执行成本，不改变证明。没有“任意装备高维问题都变成一维”的结论：压的是公式级松弛子问题。

## 6. 定理 D：完整伤害及联合搜索的安全区域

真实完整乘积 `P=W·M·T·C·H·D`。对一个候选分支或条件分片 B，必须建立覆盖所有合法完成的 `O_hi(B)≥WMT` 和三属性域。伤害上界为 `O_hi(B)·U_CHD(B)`；DPS 则还需除以该分支合法的正 GCD 下界。各上界的最大值不必由同一件装备达到，故仍安全，但可能极松。

给定真实可行 incumbent `P_inc`，固定 CRT 的必要保留条件为

`O_hi(B,c)·C(c)·U_HD(B,c) ≥ P_inc`。

只在 `<` 时删除以保留同分。证明：真实完成逐项不超过上界，因此违反该条件的完成不可能追平 incumbent。完整乘区反向变化已包含在 O_hi 中；若缺少相关界则不能忽略该乘区。

对联合目标 `Σ f_j/OPT_j`，每个 `OPT_j>0` 必须是正式同域独立最优基线。由逐职业 `f_j≤U_j`，得到 `Σ f_j/OPT_j≤Σ U_j/OPT_j`。因此右边小于真实联合 incumbent 才可剪。必须保留共享物品、镶嵌、食物身份以及戒指唯一性；独立放松可以算上界，但不能重建成共享推荐。

**绝对禁止：** 用松弛模型的高分解作为真实 incumbent；以松弛最优点周围的窄带直接裁掉真实装备；用样本最佳值冒充正式独立最优值；用 raw 分数之和代替联合归一化和；把总属性高等价于完整伤害高。

## 7. 数值验证、压力场景与负结果

- `verify.mjs`：1600 个双属性切片、155416 个点验证包络；阈值边界 `max−1/max/max+1` 保留检查；360 个 2/4 职业代数切片、465528 个点，与正权和余数消元一致。随机权重是一般性代数测试，不是伪造的正式独立最优基线。
- `independent-check.mjs`：独立 BigInt 公式，对 240 个小型三维全域的 922156 个点穷举，与剖面结果一致。
- 当前生产 canonical evaluator 验证脚本通过：1572524 个档位、39744 个因子点；本轮真实池查询另对照所选极值点的生产 DHT/DET 因子。
- 39 个压力域来自当前生产候选池：6 等级×WAR/WHM/DRG/BLM，770–780 的坦克/治疗/法系，宽品级范围同步80的 WHM/BLM/BLU。这是可出现的查询配置；域是候选池的安全松弛，不声称里面每个点可装备。
- 独立上限与总量上界包含食物 caps。自定义武器以保守上限处理；多属性分配同时达到各自上限可能不可行，因此该界可能较松，不会低估。
- 39 个预算模型，新旧精确最优值全部相同。保留 1–8 个 CRT 切片；基准 227–297 个。详见 `results.json`。9 次交替预热后微基准的中位加速约 7.26 倍；因子求值减少中位约 82.08 倍。毫秒级上界查询不是完整搜索速度。
- **负结果一：** 单独对 H/D 缩带有额外计算开销，许多真实池切片比原关键集慢，不能仅凭点数少就替换。
- **负结果二：** `full-damage-certificate.mjs` 将其它乘区全部纳入，使用 4 组实际完整装备的抽样 incumbent。BLM 770–780、BLM 735–780、WAR 770–780 各保留全部234个 CRT 起点；WHM 同步320保留全部224个。此初版保守完整伤害证书在这四组没有实际裁剪收益。
- 6366 个单职业完整装备样本，4/4 场景找到“三副属性更高但完整伤害更低”的严格反序实例；另有3181个合法共享双职业样本（BLM/RDM、WAR/PLD）用于投影探索。保留装备/镶嵌/食物身份及 unique 验证；不设固定 GCD，不含自定义分配武器。不是穷举最优。

所有有限测试只是实现在覆盖点上的验证，不替代 §§3–6 的一般性证明。本轮没有外部独立审稿或形式化证明器认证。

## 8. 可视化解释与下一步优先级

交互 HTML 包含：精确 CRT 剖面与连续上界的 bp 差距、三属性评分对完整伤害、包含武器/主属性/TEN/GCD 的平行坐标、两职业共享的权衡投影、内部查询工作量对比。HTML 内嵌 ECharts，无运行时 CDN 请求。原始样本含可重建身份。

顶点附近的宽亮区仍有研究价值：正确问题应是“如何认证亮区之外的上界低于可行 incumbent”，而不是“证明单个顶点最优”。分档颜色会掩盖 bp 级变化，所以使用差距曲线和精确点值。

下一步最值得研究的是 **条件化的其它乘区与剩余资源相关上界**：固定武器/主属性/TEN/GCD 档位或有限条件分区后，重新计算三属性可用预算，减少独立最大值同时发生的不现实性。必须先量化分区数量与上界收紧，不能枚举全部因子笛卡尔积。多职业优先分析共享选择给各职业造成的联合预算损失，而不是仅对独立上界求和。

尚未完成：正式搜索 shadow 接入、真正独立最优基线、固定 RDM 2.48/BLM 2.45 的完整搜索 A/B、18 场景接受测试、总耗时/内存收益。因此结论是“上界子程序值得继续研究，真实剪枝收益尚未成立”，不是“可直接替换生产剪枝”。
