# 速度加入后的降维：分清子问题上界与完整目标剪枝

研究快照：358a639e8d827dad7973fcb81a55d451c05ff438。只修改研究文件。原始属性均为装备与食物贡献，不是面板总值。

## 1. CRT / GCD 二因子：少数下包络顶点给出安全上界

固定 C+S≤K，暴击因子单调，故可用 C=K−S 放松。令 q(C) 为去掉 CRT 取整的二次因子，g(S)>0 为真实整数 GCD。在整数速度点构造 g 的下凸包 h；h≤g，故 CRT(C)/g(S)≤q(K−S)/h(S)。

若 q 在研究区间满足 log q 的二阶导数≥0，则每个 h 的正仿射区间上，log[q(K−S)/h(S)] 为凸函数。因此该区间的最大值在两端，可只算凸包顶点及区间截断点。不是声称原始离散最优点在装备多面体顶点。

用 t=200C/div+offset，q=10^6+t(t+b)，曲率判据为 2·10^6−b²−2t²−2bt≥0。普通职业 offset=50,b=350；BLU offset=250,b=150。程序用整数乘法核验判据。失败则回退，不使用错误的端点推论。

精确版本按 GCD 档扫描：在同一 GCD 平台内 C=K−S 随 S 下降，所以只需要最左整数点。上下界筛选可以减少真正精确求值次数，但不保证总耗时降低。

验证：28 个真实候选池场景，涵盖 50/60/70/80/90/100 级、不同速度修正与 BLU，588 个切片，共 751,982 个原始整数点。全部精确扫描结果一致、上界覆盖通过。各域的下凸包仅 4–8 点。对照现有相同二因子资源 LP 上界，新上界在 579/588 个切片更紧，但 8 个更松，不能声称支配。精确筛选虽减少求值却比普通事件扫描慢；仅上界查询也比现有 LP 查询慢。详见 results.json。

## 2. 必须保留全部乘区关联：正因子 AM-GM 支持上界

一般定理：设目标为 q(c)∏ᵢ fᵢ(x)，各 fᵢ>0。任选正参照 rᵢ，不需要参照最优。若仿射函数 aᵢ(x)≥fᵢ(x)，则

∏ᵢ fᵢ(x) ≤ (∏ᵢrᵢ) [(Σᵢ aᵢ(x)/rᵢ)/k]^k。

证明：对正数 fᵢ/rᵢ 使用算术平均≥几何平均，再用每项的上界。参照只控制松紧，不控制正确性。选择一个现实可行解的因子，通常能减少参照附近的松弛。

重要区别：先把每个乘区各自取最大值再相乘，会把互相冲突的装备收益拼成虚构装备。上式只需要最大化一个仿射加权和，因此可以保留每个槽位中“必须从同一件装备取得各属性”的关联。

固定 CRT 档位区间后，每槽把候选投影到 (CRT, 加权和)，取上凹包；多槽上凹包按斜率合并，得到总 CRT 落在该区间时的加权和最大值。这是原离散选择的连续放松，严格上界；复杂度不枚举装备笛卡尔积。固定某候选做删点时，预计算去掉该槽的支持曲线，再平移该候选的坐标。

### 变量 GCD

1/g(S) 的整数图取上凹包。其每个线段延长线都是整个速度定义域的仿射上界。对每条上界线分别构造 AM-GM 支持界，再取最小值，仍为合法上界。曲线只依赖固定职业、等级和合法速度范围，不需要固定 GCD。范围外不能复用。

### 当前 BRD 实验实例

拉出精确 CRT 档位因子和常数 TEN=1000；其余五因子为武器性能、主属性、DET、DHT、1/GCD。前三个涉及取整的地方使用向上仿射包络。食物采用对应食物的各属性上限，保留同一食物的关联，但放松真实百分比，故不会低估。所有相关斜率非负，允许对食物 CRT 用 [0,cap]，以同一食物的线性得分上限配对。该放松保留正确性但可能较松。

对每个候选、每个 CRT 档，计算上界；只有所有档位上界都严格小于一个真实可行解的精确 DPS，才删候选。BigInt 有理数交叉相乘决策，不使用显示用浮点比值。环唯一性等原约束仍交给最终精确搜索；放松这些约束只会使上界变松。

此定理不依赖 BRD。最初 full-amgm-check.mjs 的武器/主属性与常量 TEN 假设仅支持所测 BRD；后来 full-amgm-generic.mjs 已单独处理坦克 AP 与可变 TEN，并完成 BLM/WAR/WHM 完整验证，仍明确排除 BLU。一般实现必须为每个职业构造并验证其真实乘区包络，处理坦克 AP、可变 TEN、BLU 武器附加及自定义属性武器的可行域。多职业不能用 AM-GM 乘积替换真实加权和目标；可分别上界后按正权求和，或者在共享身份上构造联合支持界。

## 5. 不按 CRT 档扫描的进一步定理：每段至多一个内部极大值

可把 CRT 取整向上包络为 q(c)=Ac²+Bc+D，其中 A,B,D>0,c≥0。在某个线性支持包络段上，其他乘区之 AM-GM 和为 h(c)=ac+b>0。于是完整上界是常数乘以 F(c)=q(c)h(c)^k。

若 a≥0，F 单调上升，最大值在右端。若 a<0，导数的符号仅取决于

(k+2)Aa c² + [2Ab+(k+1)Ba]c + Bb+kDa。

这是开口向下的二次式，因此一个支持包络段至多有一个内部局部极大值（右根），另一个根如存在则是局部极小值。最大值只需检查两个端点和这一根。段数取决于实际槽位投影凹包的复杂度，而不依赖原始属性整数范围或多属性档位笛卡尔积。

根不必用浮点求解：利用导数二次式顶点找到右根正负号包围区间，再有理数二分。根在 [u,v] 时，q(v)h(u)^k 是安全上界。由 q 递增、h 递减直接证明。这是有误差控制的上界证书，不能把近似根的函数值直接当上界。

对多条速度支持线，可以分别计算全域上界后取最小值，安全但可能比先逐点取最小再取最大更松；也可构造各凹分段线性函数的逐点最小包络。当前只提供一般核函数 polynomial-segment-upper.mjs，尚未将该变体接入生产性能实验，不宣称额外加速。

## 6. 把“完整乘积必须够好”压成线性必要条件

上式给出 F(x)≤P·q(c)·[L(x)/k]^k，其中 L 是完整属性的仿射函数，P 是正参照乘积。设已有真实可行值 I>0，则任何可能达到 I 的方案必须满足

L(x) ≥ T(c) = k·[I/(P q(c))]^(1/k)。

若在 c 的完整合法范围内满足 (k+1)[q'(c)]² ≤ k q''(c)q(c)，则 T''(c)≤0，即 T 为凹函数。故用左右端点连接得到的弦线 a c+b≤T(c)，从而得到全局必要线性条件

L(x)−a c−b ≥0。

这里不能用 T 的切线：凹函数切线在上方，会错误排除合法方案。弦线在下方，才是安全方向。q 采用真实 CRT 的连续上界，也使必要条件更弱而不会更强。对正系数二次 q，曲率条件的左减右是 c 上递增的二次式，核验最大 c 即足够；代码仍保留失败退出，不在失败域应用。

端点 k 次根以整数开方得到向下有理逼近，再连弦。不是把浮点近似根当精确值。精度影响松紧，不影响正确性，不是 magic 剪枝阈值。

这一条件可直接成为 MILP 的线性行，也可不建任何新变量直接做候选删除：固定某件装备，逐槽最大化同一线性得分，再加食物的安全上界。如果总和仍<0，该候选不可能达到已有可行值。无需逐 CRT 档扫描，也无需 LP/MIP 求解器。多条逆 GCD 上界线可各自提供一个必要条件。

可以删除后重算候选范围与每槽最大值，反复到不再删除为止。正确性归纳保持；每个非终止轮至少删除一件，最多初始候选数轮，终止规则不是经验次数阈值。全局弦仍可能比逐档支持界松，低成本不代表总能替代较紧上界。

实现：chord-amgm.mjs（单轮）、chord-fixed-point.mjs（到不动点）。验证范围与耗时见 chord-summary.json、chord-fixed-summary.json。现阶段是严格候选界，是否值得加为 MILP 行须另行验证，不能从删候选效果直接推断加行求解更快。

## 7. 多职业的安全推广，不替换联合目标

联合目标仍为 S=Σⱼ Fⱼ/Bⱼ，Bⱼ 为该职业已证明的独立最优，0<Fⱼ/Bⱼ≤1。若当前联合可行值 S₀>J−1，则所有能达到 S₀ 的解都必须满足每个职业 Fⱼ≥[S₀−(J−1)]Bⱼ。把这个阈值代入各职业的第6节定理，就得到一组共享装备变量上的必要线性条件。各职业参照因子任取正值，不能误把联合配置的本职业分数当作该职业必须达到的阈值。

若已有 product-proxy-localization 的损失管证书：至多一个职业可损失超过 h，那么联合可行域是 J 个分支的并。每个分支只把例外职业的阈值设为上述低阈值，其余设为 (1−h)Bⱼ；所有分支都被某候选违背时才可删除候选。不能要求每个职业同时满足高阈值，否则会误剪例外职业。

共享槽位在线性支持值里必须统一选择一个物理身份，再累计相关职业的得分，不能分别取每个职业的最好装备后当作同一个共享方案。独立上界之和仍安全但更松，不能假称精确联合支持。这一推广是一般证明，目前尚未完成与既有联合损失管的整套性能对照。

## 8. 分区与自适应证书：从粗线性界下探到整数档

全域弦线便宜但松。可按 CRT 分区，每区用自己的端点弦线；某个候选只有在所有区域都被排除时才能删除。固定分区个数影响成本和松紧，不参与正确性。

支持函数不必按每个弦斜率重建：原槽位凹包统一加上线性价格 λ·C，仅将每段斜率加 λ，不改变斜率顺序或凹包拓扑。合并后的斜率数组二分寻找变号点，再夹到指定资源区间，即可得到精确的带价格支持上界。tilted-support.mjs 实现这一有理数查询。

adaptive-amgm.mjs 提供不需要经验分区数的版本：先证整个区域；无法排除时按 CRT 档位中点二分，优先检查接近已有真实可行解的子区。到单一 CRT 档时使用原整数因子的精确 AM-GM 支持界。找到任何未排除叶子即可保留该候选，不再算其余分支。所有区域均排除才删除。有限档位保证终止；遍历顺序只影响耗时，不影响安全性。

注意“未排除区域”不等于里面存在真实配装；上界是放松。该算法只产生必要条件证书，不用这个事件宣称找到可行解。

### 曲率条件并非只对少数装备组合成立

普通职业令 t=50+200C/div、q=10^6+t(t+350)。第6节凹性条件等价于

(t+175)² ≤ [k/(k+2)]·(4·10^6−350²)/4。

右侧随 k 增加而增加，所以 k≥4 时，统一检查 k=4 就是保守充分条件。由精确整数判据二分得到各等级最大 CRT **贡献**：50级987、60级1736、70级2605、80级3762、90级5499、100级8046。精确值以 chord-uniform-domains.json 为准；实现不依赖显示用近似小数。

这些是从公式推导的充分范围，不是根据某次搜索拟合出的 magic value。通常装备域远小于这个范围；超出时只跳过弦线层，仍可用不依赖此曲率条件的原始 AM-GM 支持上界。BLU 的 offset 与 b 不同，应代入其对应公式重新检查，不能套普通职业阈值；当前通用实验代码明确排除 BLU。

## 9. 把同一候选证书用于单职业基线和联合阶段

candidate-certificate.mjs 是无远端状态的通用研究核：输入实际候选池、完整正因子参照和相对目标阈值，输出严格不能达到阈值的槽位候选。必须有生产 canonical evaluator 的可信标记；自定义动态属性、未实现的BLU包络、最大坚韧的字典序目标或曲率条件不成立时跳过，不错误套用伤害剪枝。

单职业：先重新核验初始配装的候选归属、唯一戒指、食物、属性范围及精确GCD条件，再以该真实可行分数为阈值。联合：先核验共享初始配装，计算S；各职业的必要阈值取(S−J+1)B_j，B_j为已证明独立基线。不能擅自把每职业当前分数当作其必须维持的阈值。

两种实现均不改生产文件，使用研究型模块钩子：

- 在现有模型中给被证明无用的候选变量添加零约束。
- 在完整模型构造前过滤候选，让属性范围、因子档和模型系数重新生成。

数学上均安全，但搜索表现可大不相同。第二种不是免预处理，时间包含轻量初始模型、可行种子、证书及正式重建。

### 并行线程的实验审计

原生产基线通过Node worker线程计算。仅在主线程调用registerHooks不会自动覆盖它们；一次早期实验未产生任何实际证书调用，已标记无效干预并排除。后续用Node --import研究预加载模块，让实际基线worker同样安装钩子；每个线程分别保存证书与计时，避免文件互相覆盖。没有改变生产并行度。

### 附加的一般降阶引理

若某个正乘区在完整可行域上恒定，应该从AM-GM和式中提出，而不是把常数继续作为一个虚拟因子。设其它归一化因子之和为s、数量m，恒定因子为c>0，则加权AM-GM给出 ((s+c)/(m+1))^(m+1)≥c(s/m)^m。提出常数因此使该类上界只紧不松。固定GCD的DPS时间因子、恒定TEN、以及在安全属性区间端点取得同一整数档的单调因子都可适用；仍必须保留原有可行性约束。这个引理尚未作为独立性能变体验收，不计入运行收益。
