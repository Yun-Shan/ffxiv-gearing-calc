# 同类职业的目标相关特征商：多个职业压成一个带重数的职业

状态：一般命题已证明；真实三职业实例的定义域检查与两轮完整优化运行已通过。不是依据职业名称或样本分数相近合并。

## 定义与前提

共享选择 x（装备物理身份与共享食物）；职业 j 的私有选择 y_j∈Y_j(x)，各私有选择在固定 x 后彼此独立。目标为 Σ_j w_j f_j(x,y_j)，w_j>0；f_j 是完整目标除以真实独立最优基线，而不是只看 CRT/DET/DHT。

若一组职业存在目标与约束充分的特征投影 z=π_j(y_j)，满足：

1. 对每个共享 x，各职业可达特征集合完全相同 Z(x)。不要求物理物品 ID、候选数或命名相同。
2. 每个职业的完整归一化目标都等于同一个 g(x,z)。所有可行性约束也能通过 x,z 判断，且保持一致。
3. 不存在未建入 x,z 的跨职业私有物品耦合、库存数量、唯一性、预算或食物限制。

则对固定 x，max_{y_j} Σ_j w_j f_j = (Σ_j w_j) max_{z∈Z(x)}g(x,z)。因此存在某个全局最优解，使这一组职业采用相同的特征 z。可以只保留一个代表特征决策并把权重相加，再为每个职业从映射表还原自己的合法物理装备。

证明：任一选择的每项 g≤max_z g，给出上界；选择一个最大化 z*，由可达集合相等分别还原各职业 y_j，并由私有独立性保证同时可行，即达到上界。再对共享 x 取最大即可。

## 能压缩什么，不能压缩什么

- 可以减少目标因子块、私有特征变量与相同约束的重复；不是仅减少显示中的职业数。
- 也可以先不改变量结构，加入相同因子值的等式，让求解器预处理尝试消去重复块。这种实现未必更快，需要实测。
- 不会保存所有同分的物理身份组合，只保证存在同分最优代表及每职业合法还原。如果产品要求枚举全部同分配装，需恢复商类，不能直接丢失这些身份。
- 公式仅差一个职业常数且归一化会消去该常数时可以合并；主属性、武器性能或 GCD 的不同取整函数一般不能当作常数差异。
- 独立基线、共享物品可用范围、强制/排除装备、族群、同步、GCD 或食物约束不同，都可能破坏等价；逐项检查失败时不合并。
- 任意正权求和都成立。对量化 log 乘积代理要另查“代理函数也是同一个函数”；原目标相同本身不够。真实实例进一步固定同一套整数因子，因此每因子的 roundedLog 也完全相同，代理目标的最优代表同样存在。

## 真实实例：BLM + RDM + SMN，770–780，无同步

共享所有非武器槽与食物；BLM GCD2.45，RDM/SMN GCD2.48。排除自定义属性武器。当前代码按固定等级的每威力伤害比较，不引入实战循环、自动攻击或额外职业机制。

最初按所有属性比较时，RDM/SMN 武器集合完全不同。检查发现差别是武器攻击间隔 DLY；该研究快照的 damage/DPS/GCD 公式及所用约束不读取它。投影去掉 DLY 后，两者的71个私有武器属性特征完全相同。INT、INT职业系数、武器魔法性能取整、GCD速度类型与修正、族群、食物公式和独立基线因子也一致。共享631个槽位身份的相关属性匹配。

`coupled-product-support/equivalent-job-cuts.mjs` 在真实联合模型建立后重新核验这些前提；不是仅依赖之前保存的JSON。一项失败即停止这项实验。当前研究型实现增加1079条因子值等式，仍保留各职业的独立物理武器变量及原始联合目标、解码与完整精确复核。

原三职业“乘积种子＋稀疏损失管”完整运行为411.70秒，精确归一化目标2033912632751/678063260368。这个时间不是未优化原流程的对照。等价商实验只评价在该已优化流程之上的增量效果。

## 与高维压缩目标的关系

这是一种不同于“最优点在边界”的精确压缩：先找目标与所有约束真正读取哪些特征，再按相同可达特征与相同评价函数合并重复职业。不要求先知道最优值所在区域，但必须能证明投影充分，不能仅凭3D图形相似或几次最优配装相同。

## 完整运行与覆盖范围检查

首轮等价因子约束后的完整运行196.69秒，原“种子＋窄区”411.70秒；精确值均为2033912632751/678063260368，完整proof标记通过，仍依赖HiGHS求解状态，不是形式化证书。首次联合Q最优解的内层累计时刻约75.01秒，对照260.99秒。复跑199.79秒，精确最优值一致；仍缺更多场景和对照重复，不能外推普遍倍数。

候选域静态检查使用相同GCD2.50、共享所有非武器槽与食物，在选定的5个实际品级域检查。770–780域发现 WAR/DRK、WHM/SGE、SCH/AST、SMN/RDM 四组特征相同；放宽735–780后只剩两个治疗配对。80级同步530域另发现 WHM/AST；70级同步320、90级同步660所选域未发现完全相同的组。域和完整结果见 real-domain-screen.json。这不是全体用户配置的统计发生率，也不能按职业名称永久缓存等价。

## 与稀疏损失管结合时的进一步压缩

原损失管定理给出任意两个原职业损失之积≤η。如果某个等价类含至少两个职业，它们损失相等为l，则自动 l²≤η，这个类不能成为唯一的显著损失例外。只有单成员等价类有必要保留“例外选择”分支；所有等价类均有多个成员时，所有职业都必须处于sqrt(η)邻域。

更一般，一个重复m次的损失l满足 E≥ml−1+(1−l)^m；右端在[0,1]单调非减，可用有理数二分求安全半径。一个简单但较松的推论为 E≥(m−1)l²，从而 l≤sqrt[η/(m−1)]。证明可把E按添加职业递推：每新增一个同损失职业，使E增加 l[1−(1−l)^{i−1}]≥l²。其它职业只会使E增大。

这里“删除多余例外分支”仍以先证明等价并限制到存在最优代表的商空间为前提；不能把原始未合并职业的一次相同分数观察当作该前提。独立变体已完成完整复核，精确目标一致，但耗时232.08秒，高于未固定例外分支的196.69/199.79秒，属于本轮负性能结果，暂不优先。

### 分支消除实验补记

等价类与稀疏损失管组合，固定唯一允许例外为BLM后，完整耗时232.08秒，精确值相同。相较不固定例外的196.69/199.79秒反而较慢。更小的数学可行域并不保证HiGHS更快，这个结果必须和正结果一起保留。
