# 前端设计总览

本文只记录项目级视觉方向、跨页面原则和目标桌面视口。具体页面结构、组件、字段、文案、尺寸、交互状态和响应式意图，以 [Penpot 设计文件](https://design.penpot.app/#/workspace?team-id=71b39894-c9c5-81cd-8008-bc8b2a6ce976&file-id=71b39894-c9c5-81cd-8008-bc8f0497fe39&page-id=385a202b-2e30-80ff-8008-bcd1dbe5cc0b&layout=layers) 中对应画板为准；如与本文表述不一致，以 Penpot 为准。本文不复述具体界面或工程实现。

## 范围与设计视口

设计范围覆盖整个项目的前端页面、功能流程和状态。新增页面与流程沿用本总览中的项目级设计原则，并以 Penpot 中对应画板确定具体内容。

项目目标桌面视口包括 1440 × 695 和 1920 × 1080；具体画板支持的尺寸以 Penpot 标注为准。验收使用对应画板的实际视口。Penpot 未定义的视口或状态不声明与设计稿精确匹配，也不从桌面设计自行推导移动端布局。

## 整体风格

- 以沉稳的深蓝色建立导航与品牌区域；内容区域使用柔和的白色和灰绿色中性色，青绿色承担主要交互强调，橄榄绿用于状态和重点标记。
- 采用克制、清晰、偏工具型的视觉表达。通过留白、轻量边框、浅色底面和明确的文字层级组织信息，避免强烈阴影、装饰性渐变或过多高饱和颜色。
- 保持较高的信息密度，同时让配装条件、搜索过程和结果易于扫描。数据表和数值区域强调对齐与可读性。
- 中文内容以清晰的无衬线字体为主；数字、计时和指标采用更适合读数的字形。具体字族、字号和层级查看 Penpot。
- 以低对比度的航海图、罗盘或星图意象作为背景装饰，保持其辅助地位，不遮挡信息。

## 跨页面一致性

- 全项目页面沿用一致的品牌识别、全局导航、颜色语义、文字层级和信息组织方式。
- 各功能流程清楚呈现操作阶段和状态；配置、搜索、结果与历史信息保持稳定、可追溯。
- 对齐、间距、文字、状态和具体交互以 Penpot 对应画板及其状态为依据。遇到本文与 Penpot 不一致时，以 Penpot 为准。
