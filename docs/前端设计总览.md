# 前端设计总览

本文记录项目级视觉方向、页面入口、滚动边界和目标桌面视口。结构、内容、布局与流程以 [UI 重构规范](ui-refactor/README.md)及用户后续确认为准；[Penpot 设计文件](https://design.penpot.app/#/workspace?team-id=71b39894-c9c5-81cd-8008-bc8b2a6ce976&file-id=71b39894-c9c5-81cd-8008-bc8f0497fe39&page-id=385a202b-2e30-80ff-8008-bcd1dbe5cc0b&layout=layers) 仅作颜色、字体、密度与局部视觉语言参考。

## 范围与设计视口

设计范围覆盖整个项目的前端页面、功能流程和状态。新增页面与流程沿用本总览中的项目级设计原则，具体内容见重构规范。

项目目标桌面视口包括 1440 × 695 和 1920 × 1080；按重构规范和已确认交互在这两个视口验收；不从桌面设计自行推导移动端布局。

## 整体风格

- 以沉稳的深蓝色建立导航与品牌区域；内容区域使用柔和的白色和灰绿色中性色，青绿色承担主要交互强调，橄榄绿用于状态和重点标记。
- 采用克制、清晰、偏工具型的视觉表达。通过留白、轻量边框、浅色底面和明确的文字层级组织信息，避免强烈阴影、装饰性渐变或过多高饱和颜色。
- 保持较高的信息密度，同时让配装条件、搜索过程和结果易于扫描。数据表和数值区域强调对齐与可读性。
- 中文内容以清晰的无衬线字体为主；数字、计时和指标采用更适合读数的字形。表格与结果指标支持已确认的容器自适应字号；其余风格参考 Penpot。
- 以低对比度的航海图、罗盘或星图意象作为背景装饰，保持其辅助地位，不遮挡信息。

## 跨页面一致性

- 全项目页面沿用一致的品牌识别、全局导航、颜色语义、文字层级和信息组织方式。
- 各功能流程清楚呈现操作阶段和状态；配置、搜索、结果与历史信息保持稳定、可追溯。
- 共享表单、装备选择、结果表格和浮层保持一致；单职业与多职业的高级设置共用同一 modal。


## 页面与滚动边界

| 路由 | 页面 |
| --- | --- |
| `/single`（根路径默认） | 单职业选择、条件、搜索进度与结果 |
| `/lab` | 实验室入口 |
| `/joint` | 多职业联合搜索 |
| `/gear-comparison` | 同职业最多四方案对比，支持历史与分享链接导入 |

应用壳持有视口高度，Header 为 64px，工作台 SidePanel 为 280px，主体继承剩余高度。History 列表、溢出职业 tabs、下拉选项和装备限制中的已选列表在各自区域滚动。装备对比允许装备表区域滚动，保留全部行与列，不要求四方案同时完整展示；不通过分页、数据截断或隐藏行处理容量。表格最大高度和动态字号遵循当前已确认的表格规范。

真实浏览器验收覆盖页面导航、搜索/取消、历史恢复、替换、导入及浮层键盘/焦点行为。自动测试、构建及具体验收证据见 [实施与验收](ui-refactor/06-实施与验收.md)和 [Mock 盘点与真实接入](ui-refactor/07-Mock盘点与真实接入.md)。开发容量预览为显式合成夹具，不作为领域计算证据。
