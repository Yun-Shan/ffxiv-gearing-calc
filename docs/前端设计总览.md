# 前端设计总览

本文记录项目级视觉方向、页面入口、滚动边界和目标桌面视口。结构、内容、布局与流程以本文、[工程规则](rules/工程规则.md)及用户后续确认为准；颜色、字体、密度与局部视觉语言以本文的文字版风格参考为依据。本文不依赖外部设计文件。

## 范围与设计视口

设计范围覆盖整个项目的前端页面、功能流程和状态。新增页面与流程沿用本总览中的项目级设计原则，具体内容与交互以用户确认为准。

项目目标桌面视口包括 1440 × 695 和 1920 × 1080；按本文、工程规则和已确认交互在这两个视口验收；不从桌面设计自行推导移动端布局。

## 文字版风格参考

- 以沉稳的深蓝色建立导航与品牌区域；内容区域使用柔和的白色和灰绿色中性色，青绿色承担主要交互强调，橄榄绿用于状态和重点标记。
- 采用克制、清晰、偏工具型的视觉表达。通过留白、轻量边框、浅色底面和明确的文字层级组织信息，避免强烈阴影、装饰性渐变或过多高饱和颜色。
- 保持较高的信息密度，同时让配装条件、搜索过程和结果易于扫描。数据表和数值区域强调对齐与可读性。
- 中文内容以清晰的无衬线字体为主；数字、计时和指标采用更适合读数的字形。表格与结果指标、常见问题/关于/实验室页面的正文支持已确认的容器自适应字号。正文、标签、标题和核心指标通过字号、字重与颜色形成层级，避免大面积装饰性字体。
- 控件和卡片使用轻量圆角、细边框和适量内边距；同类控件保持一致的高度、间距与状态表达。主要动作使用青绿色强调，次要动作降低视觉权重；选中、悬停、禁用与键盘焦点应清楚可辨。
- 表格使用紧凑行距、清晰表头与轻量分隔；名称按阅读方向对齐，数值保持稳定列对齐，关键指标突出但不挤占装备与条件信息。
- 以低对比度的航海图、罗盘或星图意象作为背景装饰，保持其辅助地位，不遮挡信息。

上述描述作为视觉风格参考；具体页面几何、内容、状态与滚动边界由本文、工程规则及用户确认定义。实现时复用现有设计 token 和共享组件，避免为局部页面另建一套颜色或控件风格。

## 跨页面一致性

- 装备表名称列中的真实物品名称为文字按钮，默认保持名称样式，悬停显示虚线下划线；点击浮层字号与所点击名称一致，依次提供最终幻想XIV中文维基（按物品名称）和 Garland 数据（按物品 ID）的外部链接，在新标签页打开。无物品 ID 的占位项保持普通文字。

- 全项目页面沿用一致的品牌识别、全局导航、颜色语义、文字层级和信息组织方式。
- 页面顶部的路径行统一使用同一个面包屑组件，仅展示当前路由位置，不提供点击导航；单职业与多职业工作台由 WorkbenchLayout 通过 props 接收路径并统一渲染，其余页面在各自页头渲染。
- 常见问题、关于与实验室页面的路径行以下内容字号随页面高度动态缩放：路由壳使用 `container-type: size` 建立页面高度容器，页面以 `cqh` 设定基准字号，内部字号以 `em` 相对基准调整；页面标题与面包屑字号保持固定。
- 各功能流程清楚呈现操作阶段和状态；配置、搜索、结果与历史信息保持稳定、可追溯。
- 工作台右侧面板使用宽度容器与受 `clamp()` 限制的 `cqw` 基准字号，内部标题、正文与操作文字按相对字号缩放。
- 职业选择控件由 `JobSelection` 根容器统一设置受 `clamp()` 限制的 `cqh` 基准字号，分组标题与职业按钮继承字号，按钮及图标尺寸按比例缩放。
- 历史记录区域使用尺寸容器与 `cqh` 基准字号，内部文字按相对字号缩放；卡片高度随视口高度变化，字号与高度均用 `clamp()` 限制上下限。
- 共享表单、装备选择、结果表格和浮层保持一致；单职业与多职业的高级设置共用同一 modal。
- GCD 档位重算期间保留原选择；新可行档位返回后保留所有仍可用的已选档位，移除不可用项，不自动补选。全部失效时回到待选择状态。GCD 的非错误说明使用橙黄警告色，错误提示保持错误色。
- 装备品级范围与 GCD 速度范围均使用一个可见标签、两个输入框与中间连接符；两个输入框分别保留最低/最高的无障碍名称。输入立即显示，停止输入 1.5 秒或失去焦点时提交条件，以先发生者为准。
- 同步品级选项在鼠标悬停或键盘聚焦时，以食物选择的侧边浮层样式展示同步品级精确匹配且 `JournalGenre != 0` 的 ContentFinderCondition 条目名称，按条目 ID 升序纵向排列；离开选项列表、选择完成或关闭选择框时隐藏，“未启用”不显示说明。
- 强制装备中的自定义参数武器和盾牌通过参数按钮打开编辑面板，按钮展示“自动”或完整的已确认参数。自动模式对纵向属性区域加蒙版并禁用控件；自定义模式下，曼德维尔类型使用两个大属性和一个小属性选择框，义军类型使用联动的 Slider 与 NumberField。只有完整且符合该装备规则的草稿才能确认，取消不改变已确认值。义军自定义总分配必须恰好填满，未满、超限或未填完整的简短提示位于总分配行右侧；曼德维尔允许暂时重复选择，重复项标红且不可确认。已确认的逐孔与自定义参数选择进入搜索条件并随快照保存和恢复，面板取消时不更新搜索条件。


## 页面与滚动边界

| 路由 | 页面 |
| --- | --- |
| `/single`（根路径默认） | 单职业选择、条件、搜索进度与结果 |
| `/lab` | 实验室入口 |
| `/joint` | 多职业联合搜索 |
| `/gear-comparison` | 同职业最多四方案对比，支持历史与分享链接导入 |
| `/faq` | 常见问题；每条问答使用同一组件，列表容器内滚动 |
| `/about` | 关于；参考项目、数据与图标来源、主要依赖 |

应用壳持有视口高度，Header 为 64px，工作台 SidePanel 宽度随视口宽度在上下限内自适应，主体继承剩余高度。History 列表、溢出职业 tabs、下拉选项和装备限制中的已选列表在各自区域滚动。装备对比允许装备表区域滚动，保留全部行与列，不要求四方案同时完整展示；不通过分页、数据截断或隐藏行处理容量。常见问题页的问答列表在列表容器内滚动，页头保持可见；关于页按正常文档流滚动。表格最大高度和动态字号遵循当前已确认的表格规范。

真实浏览器验收覆盖页面导航、搜索/取消、历史恢复、替换、导入及浮层键盘/焦点行为。自动测试、构建与浏览器验证按[工程规则](rules/工程规则.md)选择与改动相称的检查，并报告实际结果。开发容量预览为显式合成夹具，不作为领域计算证据。
