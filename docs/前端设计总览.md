# 前端设计总览

本文记录项目级视觉方向、页面入口、滚动边界和目标桌面视口。结构、内容、布局与流程以本文、[工程规则](rules/工程规则.md)及用户后续确认为准；颜色、字体、密度与局部视觉语言以本文的文字版风格参考为依据。本文不依赖外部设计文件。

## 范围与设计视口

设计范围覆盖整个项目的前端页面、功能流程和状态。新增页面与流程沿用本总览中的项目级设计原则，具体内容与交互以用户确认为准。

项目目标桌面视口包括 1440 × 695 和 1920 × 1080；按本文、工程规则和已确认交互在这两个视口验收。单职业结果页另提供下述已确认的小屏结果布局，其余页面不从桌面设计自行推导移动端布局。

视口宽度小于 1000px 时，单职业结果页使用小屏结果布局，“当前视口过小，仅可查看结果，建议在大屏幕打开。”作为导航下方结果滚动区域的首项，随结果滚动自然移出视口，不固定或悬浮；其余页面仍以绝对定位在顶部居中显示“当前屏幕过小，可能无法正常使用”的警告框。宽度达到 1000px 时隐藏提示。

### 单职业结果页的小屏布局

- 顶栏沿用现有深蓝导航样式，仅显示 Logo 和工具名称。隐藏面包屑、结果页标题的视觉展示、耗时及条件配置入口，结果标题仍提供给辅助技术。
- 结果内容顶部使用十字分隔的两行两列单卡片：左上为 GCD，右上为坦克的坚韧减伤（非坦克留空），左下为暴击率，右下为直击率。每格标签与数值同行，标签与数值字号均为 18px，内边距为 6px 8px；空间不足时允许换行完整显示。下一行单独显示每威力伤害期望，标签与数值同为 18px，沿用紧凑内边距；不显示每秒期望和生命值。
- 装备部位依次展示，第一行是部位、装备图标和装备名，第二行是魔晶石或自定义属性，左边缘对齐装备图标；行内的行间距、列间距及图标与名称间距均为 4px。继续保留禁忌镶嵌颜色及同步提示。有等价装备时保留替换功能，按钮位于装备名称行右侧。长名称、超长镶嵌内容允许换行完整展示。食物只显示部位、图标和名称一行。隐藏表头、来源、品级、武器性能、各项属性和总属性；物品名称资料浮层仍可查看。
- 右下角固定浮层仅保留「分享配装结果」，沿用现有按钮和分享菜单；小屏不提供「在配装器打开」入口。页面底部和滚动定位预留浮层空间，确保摘要及数据版本可滚动到无遮挡的位置。
- 条件摘要和数据版本接在装备与食物之后，滚动到页面底部查看。结果内容与摘要共用一处纵向滚动，不在装备表或摘要内设置独立滚动区。
- 该布局同时适用于分享链接恢复的单职业结果；桌面结果、联合结果及固定尺寸的分享图片沿用各自布局。

## 启动状态

- 加载与错误外壳的 HTML、必要样式和控制脚本随 `index.html` 内联交付，不依赖 React、外部图片或字体。加载提示延迟 300ms 显示，快速启动直接进入当前路由。
- 启动期间使用独立全屏状态页，品牌与提示居中，不显示导航。应用依赖、游戏数据及必要样式就绪，且主界面首次成功提交后移除外壳；保留现有数据加载与校验方式。
- 应用脚本、必要样式或游戏数据加载失败，以及启动期间未处理的异常，显示“应用加载失败”、直接展示的错误详情和“重新加载”按钮；错误详情置于淡色框内，灰色文字自动换行。错误详情保留失败原因，不提示运行开发命令、重新生成数据等仅维护者能执行的操作。错误状态阻止进入主流程，不自动重试；手动重新加载保留当前网址和本地历史。
- 应用样式异步下载，避免阻塞外壳首次绘制；外部字体与图片失败不阻断启动。启动成功后结束外壳的错误监听，运行期间的业务错误沿用现有处理方式。
- Worker/WASM 保持实际计算时按需加载与初始化；正式主页面成功显示后，在空闲时后台低优先级预取 Worker 依赖、HiGHS JS 和 WASM 文件，不执行模块或启动计算。预取失败不阻塞使用，也不另建持久缓存，资源复用浏览器现有缓存。

- 单职业或联合结果页完成路由渲染后，在页面空闲时导入并执行截图模块与分享图片布局组件；分享链接恢复成功后沿用同一导航流程。同一页面运行期间复用初始化任务，失败静默处理并允许后续重试；专用布局渲染、PNG 生成和剪贴板写入仍由复制操作触发。

## 文字版风格参考

- 以沉稳的深蓝色建立导航与品牌区域；内容区域使用柔和的白色和灰绿色中性色，青绿色承担主要交互强调，橄榄绿用于状态和重点标记。
- 采用克制、清晰、偏工具型的视觉表达。通过留白、轻量边框、浅色底面和明确的文字层级组织信息，避免强烈阴影、装饰性渐变或过多高饱和颜色。
- 保持较高的信息密度，同时让配装条件、搜索过程和结果易于扫描。数据表和数值区域强调对齐与可读性。
- 中文内容以清晰的无衬线字体为主；数字、计时和指标采用更适合读数的字形。表格与结果指标、常见问题/关于/实验室页面的正文支持已确认的容器自适应字号。正文、标签、标题和核心指标通过字号、字重与颜色形成层级，避免大面积装饰性字体。
- 控件和卡片使用轻量圆角、细边框和适量内边距；同类控件保持一致的高度、间距与状态表达。主要动作使用青绿色强调，次要动作降低视觉权重；选中、悬停、禁用与键盘焦点应清楚可辨。
- 表格使用紧凑行距、清晰表头与轻量分隔；名称按阅读方向对齐，数值保持稳定列对齐，关键指标突出但不挤占装备与条件信息。
- 以低对比度的航海图、罗盘或星图意象作为背景装饰，保持其辅助地位，不遮挡信息。

上述描述作为视觉风格参考；具体页面几何、内容、状态与滚动边界由本文、工程规则及用户确认定义。实现时复用现有设计 token 和共享组件，避免为局部页面另建一套颜色或控件风格。

## 跨页面一致性

- 同一页面内的链接与图片复制共用分享事务，进行中禁用所有分享复制入口；视口切换或按钮重挂载不重置该状态。重复调用直接忽略，成功或失败后释放状态。通知宽度不超过 360px 及视口宽度减去左右各 16px，长消息完整换行显示。

- 主导航在“关于”右侧提供“支持与反馈”按钮，与常见问题中的“反馈入口”按钮共用反馈模态框。模态框以卡片呈现反馈渠道，目前仅有带 Github 图标和文字的 GitHub Issues 链接，在新标签页打开。

- 装备表名称列中的真实物品名称为文字按钮，默认保持名称样式，悬停显示虚线下划线；点击浮层字号与所点击名称一致，依次提供最终幻想XIV中文维基（按物品名称）和 Garland 数据（按物品 ID）的外部链接，在新标签页打开。无物品 ID 的占位项保持普通文字。

- 全项目页面沿用一致的品牌识别、全局导航、颜色语义、文字层级和信息组织方式。
- 所有环境使用浏览器 History 路由。`/` 与 `/single` 都显示单职业选择页且不相互跳转；未知路径回到 `/`。单职业与联合工作台的选择、条件、进度和结果各有对应阶段路径，浏览器前进和后退切换阶段。
- 同一工作台内的阶段切换保留当前工作流；离开进度页会取消搜索，回到旧进度地址不会自动启动搜索。成功完成后以结果阶段替换进度阶段，取消或失败回到条件阶段。
- 单职业与联合工作台仅在当前页面刷新时恢复已提交的条件草稿或完成结果；同一工作台切换阶段保持连续，离开工作台后清除恢复数据。浏览器前进或后退进入条件页时优先保留现有条件 Draft；缺失时从当前结果对应的冻结条件快照重建，不读取可能已被覆盖的最新历史记录。“调整条件”按钮仍从当前结果快照建立新的条件草稿。刷新进度页回到条件页，不恢复搜索任务；没有对应工作流数据时回到选择页。损坏或数据版本不匹配的恢复数据会清除并提示，存储失败不阻止继续使用。其他页面不恢复工作台状态。
- 页面顶部的路径行统一使用同一个面包屑组件，仅展示当前路由位置，不提供点击导航；单职业与多职业工作台由 WorkbenchLayout 通过 props 接收路径并统一渲染，其余页面在各自页头渲染。
- 常见问题、关于与实验室页面的路径行以下内容字号随页面高度动态缩放：路由壳使用 `container-type: size` 建立页面高度容器，页面以 `cqh` 设定基准字号，内部字号以 `em` 相对基准调整；页面标题与面包屑字号保持固定。
- 各功能流程清楚呈现操作阶段和状态；配置、搜索、结果与历史信息保持稳定、可追溯。
- 工作台右侧面板使用宽度容器与受 `clamp()` 限制的 `cqw` 基准字号，内部标题、正文与操作文字按相对字号缩放。
- 职业选择控件由 `JobSelection` 根容器统一设置受 `clamp()` 限制的 `cqh` 基准字号，分组标题与职业按钮继承字号，按钮及图标尺寸按比例缩放。
- 历史记录区域的基准字号与卡片最小高度统一随视口高度变化，均用 `clamp()` 限制上下限；内部文字按相对字号缩放，同一视口下职业选择页与弹框内的记录保持一致密度，内容较多时卡片可增高。
- 共享表单、装备选择、结果表格和浮层保持一致；高级设置按钮由通用 SidePanel.Footer 统一渲染，单职业与多职业共用同一 modal。
- 单职业结果与联合结果的职业明细将「分享配装结果」与「在配装器打开」放在同一行，分别靠左和靠右两端对齐。「分享配装结果」按钮、其弹层及「在配装器打开」按钮共用同一 SCSS 固定宽度变量；弹层左边缘与分享按钮对齐；初始弹层不显示标题，提供「复制链接」和「复制图片」，分别使用对齐的 Lucide Link 和 Image 图标；「在配装器打开」使用 Lucide SquareArrowOutUpRight 图标。联合概览选择图片后再选择职业。分享链接以应用部署根路径和 `?s=<token>` 为地址；地址栏保留部署根路径及查询参数，页面内部显示普通单职业或联合结果。刷新时优先解码链接中的分享 token；临时替换装备不改动原链接 token，重新生成链接则使用当前结果。离开分享结果进入条件、选择或其他页面时移除分享参数。成功导入后沿用普通结果页的文案、导航、布局、SCSS 与操作，不设置独立分享结果页或分享专用结果组件；导入不启动优化器或新增搜索历史，未知来源仍需显式确认；分享解析或恢复失败时显示与启动外壳一致的全屏居中错误页，标题为“分享链接恢复失败”，以淡色框直接显示错误详情，灰色文字自动换行，提供“返回首页”按钮，通过路由回到部署根路径并清除分享参数。该错误页独立于启动外壳。「复制图片」使用独立的分享布局组件，从结果快照渲染 PNG 并复制到剪贴板。分享图使用固定 1400×640 布局和 6px 留白，表格除魔晶石列使用 1fr 外，其余列均为 max-content；固定总宽度按坦克可容纳约 5.5 个魔晶石标签预设。分享表格字号为 13px，指标标签为 13px、数值为 15px，行高固定，渲染倍率为 1，输出 1400×640 图片，同一结果在不同视口导出的像素完全一致。顶部指标按GCD、暴击率、直击率、坦克的坚韧减伤、生命值单行等宽排列，右侧条件摘要除省略公式等级外与结果页一致。装备表完整展开，不依赖页面滚动位置。图片标题为「职业 · 推荐配装」，其后展示每威力伤害期望，不显示耗时、种族或同步标签；种族与同步目标在右侧条件摘要中展示。图片不包含分享、打开配装器、重新选择职业和装备替换等操作按钮；复制期间禁用分享按钮，完成或失败通过通知反馈。
- 所有工作台右侧条件摘要对坦克只显示一项「坚韧约束」，值按实际条件显示「最低坚韧值XX」「最低减伤X%」或「最大化减伤百分比」；未设置时显示「未设置」。
- GCD 条件提供「不限」「选择单个档位」「选择多个档位」和速度范围，默认「选择单个档位」且不预选档位；多档模式只选一个也合法。切换模式清空原选择或速度范围，档位为空时保持待选择并阻止搜索。已有条件 Draft 保留选择方式；从历史、结果或分享条件快照重建时，按已选数量识别单档或多档，空数组按单档展示。选择方式仅存于 UI Draft，不进入搜索条件或分享格式；目标仍按实际档位数量推导。
- GCD 档位重算期间保留原选择与选择方式；新可行档位返回后保留所有仍可用的已选档位，移除不可用项，不自动补选。全部失效时回到待选择状态，多档模式剩一项或清空也不自动切换为单档。GCD 的非错误说明使用橙黄警告色，错误提示保持错误色。
- 装备品级范围与 GCD 速度范围均使用一个可见标签、两个输入框与中间连接符；两个输入框分别保留最低/最高的无障碍名称。输入立即显示，停止输入 1.5 秒或失去焦点时提交条件，以先发生者为准。
- 同步目标改变时的最低装备品级辅助调整统一遵循[工程规则](rules/工程规则.md#界面与滚动契约)。
- 同步通过统一紧凑弹出面板设置，宽度固定为 380px，不显示面板标题，保留无障碍名称；模式、列表与自定义区域以连续分割线衔接，分类与选项之间用竖线分隔。自定义错误在标签右侧同一行显示，不占底部提示行。按品级和按副本共享同一生成目录；等级分类倒序，不提供“全部”。每等级依次提供未启用、仅同步等级XX和目录中的具体品级（去重倒序）；已选目标仅在触发器显示。底部自定义输入只提交具体品级，必须为至少90的安全整数且属性上限完整。模式/分类仅改变浏览状态，保留输入草稿；Esc恢复、关闭丢弃草稿。
- 按副本的名称、分类和顺序直接使用生成目录，筛选与合并遵循[数据规则](rules/数据规则.md#同步等级与副本目录)。两种模式右侧列表均不显示分类标题，使用始终可见的自定义细滚动条；内容未超长时显示淡色禁用样式。仅按品级模式提供鼠标/键盘悬浮说明，只显示目录中相同目标的合并名称，不补原始目录外条目；说明浮层左侧优先、避让视口且不被裁切。按副本模式不显示悬浮窗，未启用无说明。
- 按副本实际点击的名称单独保存在界面配置中，选择框与所有右栏同步目标统一显示「副本名(品级XX)」或「副本名(XX级)」。按品级或自定义输入提交后清除副本名，具体品级沿用原数字显示，仅等级目标在选择框与右栏显示为「XX级」，不按数值反推副本。同步浮层的选项与悬浮说明保留原有文字，副本条目右侧仍显示品级数字或「仅同步等级 XX」；传给领域的同步目标仍只有类型和值。
- 强制装备中的自定义参数武器和盾牌通过参数按钮打开编辑面板，按钮展示“自动”或完整的已确认参数。自动模式对纵向属性区域加蒙版并禁用控件；自定义模式下，曼德维尔类型使用两个大属性和一个小属性选择框，义军类型使用联动的 Slider 与 NumberField。只有完整且符合该装备规则的草稿才能确认，取消不改变已确认值。义军自定义总分配必须恰好填满，未满、超限或未填完整的简短提示位于总分配行右侧；曼德维尔允许暂时重复选择，重复项标红且不可确认。已确认的逐孔与自定义参数选择进入搜索条件并随快照保存和恢复，面板取消时不更新搜索条件。
- 同步副本列表显示特殊场景探索选项时，在右侧选择区底部用浅色背景、边框和警告色文字提示“暂未计入特殊场景专属的属性修正效果。”，不在其他副本列表显示此提示。
- 普通强制魔晶石选择包含治疗职业的信仰和坦克职业的坚韧。导入合法装备时，不受目标职业或装备孔位支持的镶嵌逐孔改为自动，保留其他合法镶嵌和装备本身。
- 强制装备下拉框右侧同一行提供“导入”按钮，弹框内输入配装器分享链接，识别后以装备行预览，确认后批量合并到强制装备，取消不改条件。不限制分享链接中的职业，按装备数据的可用职业判断：单职业和联合私有条件须适用于当前职业，共享条件须适用于全部已选职业。共享导入静默忽略非共享槽位，私有导入静默忽略共享槽位，食物静默忽略。当前数据找不到的装备 ID 和因条件限制不能导入的装备用一行警告汇总并跳过，其余装备仍正常导入；无可导入项时禁用确认。预览仅显示将设置的装备及其实际镶嵌或自定义参数。


## 页面与滚动边界

强制装备导入预览复用正式强制装备行的布局、魔晶石孔位和参数展示样式，隐藏移除按钮；预览列表不支持交互，但可滚动查看全部装备。预览和正式强制装备列表统一按武器、盾牌、头部、身体、手部、腿部、脚部、耳饰、项链、手镯、戒指1、戒指2的固定槽位顺序显示。
