# 前端重写设计规格

2026-10-03，用户选择视觉探索的第一张方案。交互需求以《前端 UX 重设计思路》为准；本规格将选定视觉方向延伸到其他步骤和结果状态。

## 视觉与结构

- 深蓝顶栏保留产品身份、单职业 / 多职业导航和重置入口；不增加没有产品能力支撑的菜单。
- 桌面采用浅色工作台，左侧约四分之三用于当前步骤，右侧用于四步流程指引。配置顶部横向标记当前步骤与已确认步骤。
- 职业按数据中的角色组织，名称和可选集合读取生成数据，不从示意图复制不存在的职业。职业图标按用户指定的 XIVAPI 资产地址下载；职业行编号先通过 Lumina MCP 核对，静态 PNG 保留来源记录。
- 青绿色标记当前步骤、选择、推荐和主操作；标题使用深蓝，说明使用可读的灰蓝色。桌面紧凑布局的表单与正文以 12–14 像素为基线，步骤标题 26 像素；数值采用等宽数字。
- 分组优先用留白与细分隔线；职业选择为浅色按钮。右侧低对比幻想背景不承载信息，不干扰文字对比。
- 本次设计与验收只面向正常电脑视口；不要求手机窄屏适配。保留现有窄屏回退，不作为本次验收依据。

## 统一主题规范

| 用途 | 规范 |
| --- | --- |
| 正文与标题 | `--ink: #172b40`；说明 `--muted: #596d80` |
| 主操作与选中 | `--accent: #087f80`；浅色强调 `--accent-soft: #edf8f7` |
| 表面与边线 | 白色工作区；细线 `--line: #dde5eb`；顶栏 `#1c2e3e` |
| 字体 | Noto Sans SC、Microsoft YaHei、sans-serif；无需额外安装；数字 tabular-nums |
| 层级 | 步骤标题 26px，区域标题 14–17px，正文 12–14px，密集结果附注 10–11px |
| 布局 | 顶栏 60px；配置主区 + 310px 指引；职业角色两列分组；智力组横跨整行 |
| 结果 | 配装表与 340–380px 属性/快照侧栏并排；装备行约 40px，保留全部必需列 |
| 间距与形状 | 4/6/8/12/16/24px 间距；表单与按钮轻微圆角；分组细线，不以大阴影分隔 |
| 状态 | 文本标题配合图标与颜色；键盘焦点清晰可见；不可用操作有真实 disabled 状态 |

新增页面优先复用现有主题变量和组件。信息增多时先改变排版和压缩重复区域，不隐藏必须展示的业务信息。

## 步骤与状态

1. 选择职业：初始无职业选择；选择后读取真实默认等级与品级。等级和职业说明在此步显示。未选择时不能继续。
2. 选择目标：推荐每威力伤害期望，另提供按 GCD 折算并说明差异。GCD、速度、坦克坚韧与减伤在默认折叠的高级区域，收起后保留当前值摘要。
3. 设置候选范围：品级、同步和食物使用已有配置；解释同步与填孔规则。来源、强制装备及排除装备在高级区域，保留数量与已设置内容。
4. 检查并开始：汇总全部实际条件，提供回到对应步骤的编辑入口。前三步的“确认并继续”只确认配置，不启动搜索；本步才允许开始搜索。

返回修改保留其他输入。变更职业重新核对该职业配置与适用字段。未确认的步骤不可跳过。运行、已取消、无可行方案、失败与完成有明确标题与下一步说明。新搜索流程只展示当前条件，不比对旧条件；每次单职业及联合搜索持久保存时间、条件、状态与成功结果。第一步提供单职业历史记录列表，可载入指定成功结果进入结果页，不触发新搜索；联合记录在联合入口查看。刷新、重置配置与离开页面不删除历史。历史默认折叠并分页，数据版本不匹配的结果不作为当前数据的推荐载入。

搜索运行时增加估算进度条，小字展示最近报告的搜索阶段、耗时、装备方案/食物候选数、最近核验量与估算剩余进度。百分比使用阶段与耗时估算，最高 95%；组合总数未确定时明确说明，不伪造候选总量或剩余数量。只有正式求解和复核成功后才标记完成。

## 结果与联合搜索

- 结果按结论、推荐配装、食物和总属性、搜索条件排列。同页连续展示，不用标签页隐藏必需明细。
- 每威力伤害期望、GCD 和其他效果直接消费领域返回值。食物实际增量复用领域基础属性与食物函数；不在界面复制游戏公式。
- 装备属性读取最终值，原生副属性上限判断复用现有函数。来源、魔晶石和品级保留。结果绑定实际搜索的配置快照；重新配置时不混排旧结果或新旧对照，只保留第一步的加载旧结果入口。
- 联合搜索保留职业、共享部位、食物策略与每职业完整条件，应用相同文字层级、状态与折叠摘要，不合并进单职业向导。

## 验收

桌面 1440 × 900、1440 × 1024 验证渲染与主要交互；检查显式确认、返回保留、职业适用性、搜索/取消/无解/失败状态、历史加载、同页结果明细与键盘焦点。桌面尽量所有内容一屏呈现，先调整布局与 padding/margin；结果避免重复堆叠完整配置检查，配装表与总属性/搜索快照并排。不得通过裁切、隐藏必需信息或不可读字号消除滚动；全部高级限制展开、历史列表展开或多职业明细超过屏幕时保留可访问浏览。完成后进行源图与截图的视觉对照，运行构建与相关测试，并由独立测试或审查代理核对原始目标。
