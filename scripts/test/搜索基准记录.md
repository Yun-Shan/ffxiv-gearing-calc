### 优化后 V1 真实搜索验证

运行命令：

```powershell
$env:DATA_TEST_ALGORITHM = 'v1'
npm run data:test
```

本次 V1 在相同输入和伤害函数下启用了以下优化：

- 单槽局部改良后继续进行双槽联合改良，使搜索下界在 DFS 前直接达到已知最优值。
- 前缀槽位按“逐属性独立最大值造成的上界虚高影响”排序，将上界最不准确的槽位优先确定。
- 将候选数最少的 5 个槽位合并为精确 Pareto 后缀，并使用包围盒树分组计算安全伤害上界。
- Pareto 状态按所有未来可达后缀下的伤害阈值等价类比较；未采用只比较当前档位的非安全剪枝。
- 普通 DFS 继续缓存相同“食物 + 完整属性向量”的伤害结果，几乎不重复的后缀树包围盒和叶向量改为直接计算。

分享建议中的“总属性预算约束”也已纳入推导，但没有作为独立剪枝实现。若用“最大属性总和减去其他维最小值”推导某一维上界，该上界必然不小于该维原本的真实最大值，无法收紧现有逐维包围盒；若人为继续压低则不再是安全上界，可能剪掉最优解。装备属性之间的互斥关系目前由多槽位联合 Pareto 前沿精确表达，而不是叠加一个无效或不安全的总量约束。
