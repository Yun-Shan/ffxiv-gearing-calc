# 最优配装搜索基准记录

## 2026-09-29：精确 MIP 搜索

单 worker 执行 `npm run data:test` 时默认使用 HiGHS 精确 MIP。该模式把每个槽位和食物建成离散选择变量，按 V2 规则约束食物取整/封顶、GCD、坚韧及最高坚韧目标；伤害因子使用固定点对数作为 MIP 目标，并用 BigInt 精确复核候选，直到剩余因子签名低于可证明的误差界。求解器未证明最优、超过时限或触及 RSS 保护线时会停止且不返回近似结果。

- 搜索时限默认 `115000ms`，可通过 `DATA_TEST_EXACT_TIMEOUT_MS` 调低，最高不能超过 `115000ms`。
- 搜索进程 RSS 达到 `3.5 GiB` 时停止；MIP 在独立 worker 中运行，V8 老生代限制为 `2560 MiB`。
- 不生成或读取预先打表文件；候选因子区间在运行时构建。
- 显式设置 `DATA_TEST_ALGORITHM=v2` 会运行旧 V2 搜索；它仍是近似搜索，不能据此声称严格全局最优。多 worker 也仅支持 V2。

### 完整数据验证

MCP 通用行查询快照包含 `8310` 件装备和 `140` 种食物。MCP 报告检测版本 `2026.09.15.0000.0000`、最近验证版本 `2026.08.05.0000.0000`；服务器说明通用 `get_row` / `search_rows` 查询不受便捷接口版本警告影响。

| 场景 | 搜索耗时 | 峰值 RSS | 结果 |
| --- | ---: | ---: | --- |
| RDM 100，固定 GCD `2.48` | `17.181s` | `523,030,528` 字节 | `91.18741781427764` |
| BLU 完整候选压力运行（测试脚本等级固定为 100） | `60.988s` | `553,193,472` 字节 | `23.4597711510864` |
| WAR 最高坚韧两阶段搜索 | `4.38s` | `510,926,848` 字节 | 已证明最高坚韧后伤害最优 |
| WAR 速度范围 `500..5000` 搜索 | `69.21s` | `520,138,752` 字节 | 已证明约束内全局最优 |

精确 MIP 的小规模穷举对照覆盖无约束 DPS、固定 GCD、最高坚韧和 BLU 的 INT 武器伤害映射；相关 7 个定向测试全部通过。`npm run build` 仍被另外三个测试脚本类型错误阻断：`attribute-combination-counter.ts` 两处缺少 `exactCount`，`scripts/test2.ts` 缺少 `PendingRequest.method/params`；本次修改的文件不在这些错误中。
